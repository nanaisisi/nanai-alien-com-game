# Markdown編集・フォーマットルール (Markdown Edit Rules)

AIアシスタントがリポジトリ内のMarkdownドキュメントを作成・編集する際は、Markdownlint（特にMD033: no-inline-html）に準拠するため、以下のルールを遵守してください。

## 1. 表（Table）内での `<br>` タグ使用禁止

- Markdownの表（セル）内で改行を目的とした `<br>` や `<br/>` などのインラインHTMLタグを記述してはならない。
- 複数の情報や対比（例: 長所/短所、メリット/デメリット）を表す場合は、以下のいずれかの方法で構造化・表現すること：
  1. **列の分離**: 「長所」列と「短所」列のように、独立したカラムに分割する（推奨）。
  2. **記号・句読点による1行集約**: スラッシュ（`/`）、読点・句点（`、` / `。`）、セミコロン等で区切って1行にまとめる。
  3. **リスト形式への展開**: 表セル内に収まらない情報量がある場合は、表形式をやめて見出しと箇条書きリストにする。

## 2. インラインHTMLタグ全般の原則禁止

- 原則としてMarkdown標準の記法を使用し、装飾目的のHTMLタグ（`<p>`, `<div>`, `<span>`, `<font>` 等）を使用しないこと。
- Mermaidブロック（`mermaid` ブロック等）、特定パーサーが必要とする場合を除き、本文や表にHTML要素を混入させない。
