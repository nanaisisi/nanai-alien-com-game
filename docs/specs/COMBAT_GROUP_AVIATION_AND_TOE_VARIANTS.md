# 戦闘団航空統合（ヘリ・UAV）および部隊規模別TO&Eバリエーション仕様書

(Combat Group Aviation Integration & Echelon-Based Dynamic TO&E Specification)

本作における戦闘団（Combat Group）は、大戦略マップ上の1コマとして自己完結した諸兵科連合部隊である。
スロット数は**固定ではなく部隊単位（旅団〜増強師団）に即した「柔軟な目安（概ね10〜18スロット前後、標準モデルで16スロット程度）」**であり、地上兵力に加えて**直協ヘリコプター（有人回転翼/VTOL）および戦術無人航空機（UAV/UGVドローン群）**を有機的に内包する。

---

## 2. 師団直協航空隊（ヘリコプター・UAV）の有機的統合

戦闘団が「師団」ではなく「空地統合戦闘団」と呼ばれる所以は、独立した航空コマをマップ上で飛ばす煩雑さを排し、**前線戦闘団の上空に直協航空支援（CAS）と情報索敵のアンブレラが常時追従する**点にある。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                       直協航空戦力の階層と役割分担                          │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【有人戦闘攻撃ヘリ・重VTOL (Close Air Support)】                           │
│    ・戦術任務: 低空立体機動による近接航空支援、戦車の側背援護、障害越境急襲。│
│    ・長所: 大火力誘導弾による瞬間的粉砕、地形制約（泥濘・河川・断崖）の無視。│
│    ・特性: 燃料（航空推進剤）と高度整備部品の消費大。対空砲・酸弾に脆弱。  │
│                                                                             │
│  【中高度・長時滞空戦術UAV (Reconnaissance & Designation)】                 │
│    ・戦術任務: 戦場フォグ・オブ・ウォー開拓、砲兵・TEL誘導目標のレーザー指示。│
│    ・長所: 高滞空時間、被撃墜時の人的被害ゼロ、キルチェーンの短縮。        │
│    ・特性: 悪天候・極渦嵐・強電磁妨害下での稼働低下。                       │
│                                                                             │
│  【自律ドローン母車・UGV群 (Swarm Carrier & Attrition Combat)】             │
│    ・戦術任務: FPV自爆ドローン投射、最前線での地雷啓開、身代わり損耗盾。    │
│    ・長所: 兵士の死傷率抑制、低Tier部品での大量生産・現地改修が容易。        │
│                                                                             │
```

## 4. 部隊規模・任務に応じたTO&Eバリエーション

基本モデルを基点に、部隊規模（スロット枠の伸縮）や環境・ドクトリンに応じて以下のバリエーションへ派生する。

### 4.1 空中機動・VTOL空地強襲戦闘団 (Airmobile Strike Group)

- **部隊規模目安**: **12 〜 14 スロット**（軽量・高機動力）
- **特徴**: 地上重戦車を排し、航空展開部隊と軽装機動部隊のみで構成。山岳・大河・断崖などの通行不能地形を完全無視して突入・後方遮断を行う。
- **スロット構成案**:
  - `Slot 01〜03`: 戦闘攻撃ヘリ / 武装VTOL隊（計36〜48機）
  - `Slot 04〜05`: 強襲輸送ヘリ隊（空挺歩兵展開用）
  - `Slot 06〜08`: 空挺軽装甲歩兵 / 軽多脚大隊
  - `Slot 09`: 空挺軽量自走迫撃砲 / ロケット隊
  - `Slot 10`: 戦術UAV航空偵察隊
  - `Slot 11`: 自律対空ドローン・軽防空隊
  - `Slot 12`: 師団航空兵站・空中給油梯団

### 4.2 無人自律・ドローン飽和戦闘団 (Autonomous Drone Swarm Group)

- **部隊規模目安**: **14 〜 16 スロット**
- **特徴**: 有人兵員を極限まで減らし、ドローン母車（キャリア）と地上UGVを主軸とした前哨消耗部隊。人的損失による厭戦・政治ペナルティを発生させずに敵防衛線を削る。
- **スロット構成案**:
  - `Slot 01〜04`: 地上突撃UGV大隊（無人装軌車両）
  - `Slot 05〜08`: 自律FPV徘徊ドローン母車連隊
  - `Slot 09〜10`: 無人自走滑腔砲大隊
  - `Slot 11〜12`: 電子戦・C4I戦術中継UAV隊（通信途絶対策）
  - `Slot 13〜14`: 前方自律回収・野戦リサイクル小隊
  - `Slot 15〜16`: 電池・推進剤補給梯団

### 4.3 重装甲要塞突破戦闘団 (Heavy Armored Siege Group)

- **部隊規模目安**: **18 〜 20 スロット**（重厚・大編成）
- **特徴**: 敵主防衛線や高Tier要塞施設を粉砕するための重厚長大編成。重戦車と超大口径砲、重戦闘工兵が二重に配置される。
- **スロット構成案**:
  - `Slot 01〜06`: 主力戦車・超重突撃砲大隊群（6個大隊）
  - `Slot 07〜10`: 重装甲化歩兵・重戦闘工兵連隊
  - `Slot 11〜14`: 重榴弾砲・攻城多連装ロケット特科群
  - `Slot 15`: 重装甲直協ヘリ隊
  - `Slot 16`: 観測UAV・電子妨害隊
  - `Slot 17〜18`: 二重防空大隊（高高度＋近接迎撃）
  - `Slot 19〜20`: 重ARV・二重補給梯団

### 4.4 山岳猟兵・隘路工兵戦闘団 (Mountain Jaeger & Combat Engineer Group)

- **部隊規模目安**: **10 〜 12 スロット**（軽量・高機動力）
- **特徴**:
  - 重装甲車両や巨大多脚が登攀不能な急峻山岳、断崖、亀裂地帯、森林隘路に特化した部隊。
  - 重多脚を主戦力にするのではなく、**「山岳軽装歩兵（猟兵）の下車登攀」＋「強襲戦闘工兵による通路開拓・ワイヤー/足場架橋」＋「直協輸送ヘリ/VTOLによる補給・跳躍侵入」**を中核とする。
  - 多脚機材（Std-L4）は、師団全体ではなく**「前衛の自律斥候犬（UGV）」「工兵の不整地重荷役」「杭打ち固定式の後衛アンカー迫撃砲座」**といった特殊支援スロットに限定配備される。
- **スロット構成案**:
  - `Slot 01〜03`: 山岳軽歩兵大隊（急斜面登攀・隘路潜伏・携帯対戦車ミサイル）
  - `Slot 04〜05`: 山岳戦闘工兵大隊（障害啓開、岩盤爆破、足場・ワイヤー架橋、多脚荷役機）
  - `Slot 06`: 前衛自律斥候小隊（小型4脚UGV犬群・狭隘地ドローン）
  - `Slot 07〜08`: 空中機動・強襲輸送ヘリ隊（高地補給・負傷兵搬送・山頂拠点確保）
  - `Slot 09`: 山岳軽榴弾砲・固定アンカー重迫撃砲大隊（分解輸送・杭打ち無反動射撃）
  - `Slot 10`: 高山・狭隘地用マイクロUAV航空観測隊
  - `Slot 11〜12`: 山岳段列・軽量補給梯団（ラバ型多脚荷役機 / 軽全地形車）

### 4.5 高級装甲・二脚歩行混成戦闘団 (High-Tier Bipedal Assault Group)

- **部隊規模目安**: **14 〜 16 スロット**（高級・エリート編成）
- **特徴**:
  - ガングリフォン風の**装甲車風二脚歩行戦闘車両（全高3.76m以上、全幅5.48m以上、完全歩行駆動）**を、主力戦車や重IFVと小隊単位（4両）で組み合わせた混成中隊（16両）として配備。
  - 一般道路・トンネルを通行できないインフラ制約を抱えるため、大戦略展開には**大型戦略輸送機による空輸・空挺降下**、または専用重トランスポーターが必要。
  - **通常歩行型**による廃墟・高低差での死角クリアリングと、**短時間飛翔型**による障害跳躍・要衝急襲が、戦車の正面突撃力を極限まで高める。
  - 詳細仕様は [`./HIGH_TIER_BIPEDAL_COMBAT_WALKER.md`](./HIGH_TIER_BIPEDAL_COMBAT_WALKER.md) を参照。
- **スロット構成案**:
  - `Slot 01〜04`: 第1諸兵科連合混成大隊（MBT 2個中隊 ＋ 二脚歩行型 2個中隊）
  - `Slot 05〜08`: 第2諸兵科連合混成大隊（二脚跳躍型 2個中隊 ＋ 重IFV随伴歩兵 2個中隊）
  - `Slot 09〜10`: 自走特科・二脚アンカー重迫撃砲大隊
  - `Slot 11`: 複合防空大隊
  - `Slot 12`: 直協戦闘ヘリ隊
  - `Slot 13`: 戦術UAV観測隊
  - `Slot 14`: ドローン母車・UGV小隊
  - `Slot 15`: 二脚・重装甲回収整備大隊（大型クレーンARV）
  - `Slot 16`: 師団航空・重推進剤補給連隊

## 5. 兵站・共食い整備（Cannibalization）の互換性グループ

部隊内のスロット数にかかわらず、装備更新・現場整備は以下の車台・機体規格ごとにグループ化して計算される。
※多脚系は独立した主力車台群ではなく、工兵・荷役・アンカー固定砲などの特殊支援装備（Special Utility）として扱われる。

| 互換性グループ | 主な兵器種別 | 共通化率目安 | 共食い成功率 | 特記事項 |
| :--- | :--- | :---: | :---: | :--- |
| **装軌重装甲系** | 戦車、自走砲、重IFV、重ARV | 70〜85% | **85%** | 重油圧・履帯・装甲板の相互融通 |
| **装輪高機動系** | APC、偵察車、トラック、指揮車 | 80〜95% | **80%** | 民間・産業規格部品との互換性が高い |
| **回転翼・航空推進系** | 戦闘ヘリ、強襲輸送VTOL | 60〜75% | **70%** | 高度航空タービン・ローター。現場融通難度高 |
| **自律電子・無人系** | 戦術UAV、自律UGV、ドローン母車 | 85〜95% | **90%** | モジュール化電子基板、センサ、小型ローター |
| **特殊支援（多脚・工兵）** | 工兵多脚、荷役機、アンカー砲台 | 65〜80% | **75%** | 関節アクチュエータ、油圧杭、ウインチ機構 |

## 6. まとめとシステム実装ガイドライン

- **データ構造**: `CombatGroup.slots` は固定長配列ではなく `Vec<CombatSlot>`。
- **UI表示**: 編成画面では「部隊規模（小隊・大隊単位の数）」に応じたスロット一覧がスクロールまたはグリッド表示され、16枠に縛られない。
- **航空隊の扱い**: 大戦略マップ上での航空コマ操作を不要とし、戦闘団のスロット枠に「ヘリ隊」「UAV隊」を組み込むことで、戦闘解決システムが自動的にCAS（近接航空支援）や砲兵観測の修正値を適用する。
