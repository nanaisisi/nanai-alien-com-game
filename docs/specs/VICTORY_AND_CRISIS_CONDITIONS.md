# 動的情勢推移・集合意識の処遇および終局仕様書

## (Dynamic World Progression, Planetary Hivemind Fate & Endgame Conditions)

本ドキュメントは、本作（4X大戦略＋諸兵科連合戦闘団制＋脱都市タイル進展）における**「動的情勢推移（3大フェーズ）、大気圏外遮断（宇宙のフタ）、惑星の共通集合意識の処遇を巡る終局3大思想ルート、および同盟／単独覇権の決着判定」**を定義する具象仕様書である。

---

## 1. 根本設計思想：逃げ場なき惑星での冷徹な決着

### 1.1 「宇宙のフタ」による脱出の完全遮断

- 本作において「宇宙港を再建して母星へ脱出・帰還する」という安易なCiv型勝利は存在しない。
- 惑星上層大気には超巨大宇宙生物群が**「物理的フタ（Atmospheric Lid）」**として君臨しており、軌道上への脱出試みはすべて粉砕される。
- **すべての決着は、この惑星の地表の泥と血、そして土の上でつけなければならない。**

### 1.2 勝者の選択のみが結果となる力学

- **死んだら消滅**: 首都・全親拠点が物理的に破壊された勢力は歴史から完全に消滅する。
- **負ければ従属**: 劣勢を悟って無条件降伏した勢力は、勝者の大方針の下に従属するか、地下ゲリラ（失踪者コミュニティ）として潜伏する。
- **終わるまで終わらない**: 敵対双方が降伏も絶滅もしない限り、泥沼の戦いは決着がつくまで永続する。

## 3. 終局の3大思想ルート詳細仕様

プレイヤーおよび各勢力は、惑星の共通集合意識（ハイブマインド）をどう処遇するかによって3大ルートへ分岐する。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                        終局の3大思想ルート                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│  ①【共生・同化ルート (Symbiosis & Assimilation)】                           │
│     過程そのもので自ずと同化。星の共通意識と同調し、単一の生体秩序へ統合。  │
│                                                                             │
│  ②【母星化・テラフォーミングルート (Forced Terraforming)】                  │
│     勝った後の強行。力づくで原生生物を排除・隔離し、母星規格へ物理上書き。  │
│                                                                             │
│  ③【集合意識支配・家畜隷属化ルート (Hivemind Enslavement)】                 │
│     勝った後の強行。共通意識を滅ぼさず、首輪を嵌めて生体兵器・家畜として使役│
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.1 ① 共生・同化ルート (Symbiosis & Assimilation)

- **核心思想**: 人類と星の生命を区別せず、境界のない単一の生命系へ融合する。
- **達成条件**:
  - 国家思想スタンス `Harmony >= 0.80`
  - 惑星内の全エイリアン巣窟（Nest）の70%以上と「共生バイオリンク」を締結
  - 特殊プロジェクト「神経同調バイオグリッド」の完成
- **結末と世界変化**:
  - 全人類が共通意識の中に溶け合い、国家・国境・同盟の政治的枠組みそのものが消滅。
  - 戦争は恒久的に終結し、全タイルが生体共生タイルへと不可逆変容する。

### 3.2 ② 母星化・テラフォーミングルート (Forced Terraforming)

- **核心思想**: 異星の生態系を徹底的に拒絶し、人類が生きるための母星環境へと力づくで書き換える。
- **達成条件**:
  - 国家思想スタンス `Purity >= 0.80`
  - 敵対勢力（共生派・異星適応派）の全首都・中枢拠点を完全制圧または降伏受託
  - 特殊建造物「大気除染・惑星テラフォーマー中枢」を稼働させ、領土内瘴気を100%浄化
- **結末と世界変化**:
  - 原生生物は居場所を失い、指定保護区を除いて駆逐される。
  - 全タイルが母星型の純粋な工業・農業基盤へと上書きされる。

### 3.3 ③ 集合意識支配・家畜隷属化ルート (Hivemind Enslavement)

- **核心思想**: 星の意識を破壊せず、サイバネティクスと拘束装置で「生体兵器・労働家畜」として完全使役する。
- **達成条件**:
  - 国家思想スタンス `Supremacy >= 0.80`
  - 集合意識の中枢「原初の母胎（Primal Core）」を軍事制圧し、「神経抑制インプラント」を結合
  - 全他国勢力を軍事力で屈服させる
- **結末と世界変化**:
  - エイリアン群生体は自律性を奪われ、工廠や前線で使役される絶対的奴隷となる。

## 4. 達成形態：「同盟ブロック」か「単独・独自路線」か

共生ルート以外の2ルート（テラフォーミング／家畜支配）において、戦後秩序は同盟関係によって2分される。

| 達成形態                              | 成立条件                                                             | 戦後秩序と統治形態                                                                         |
| :------------------------------------ | :------------------------------------------------------------------- | :----------------------------------------------------------------------------------------- |
| **同盟ブロック路線**(_Alliance Bloc_) | 思想に合意した他国と同盟を結び、連帯して全反対勢力を屈服させた場合   | **「惑星統治連合」の設立**。加盟国間で領土と生体資源を共同管理し、戦後復興協定を締結。     |
| **単独・独自路線**(_Solo Hegemony_)   | 同盟を一切結ばず、全方位の他国をすべて敵に回して単独でねじ伏せた場合 | **「自国単独の絶対覇権」の樹立**。他国の干渉を一切許さず、唯一の主権体として全惑星を支配。 |

## 5. プレイヤーの超越権能：「エイリアン直接操作」の覚醒

共生ルートまたは支配ルートにおいて、集合意識の掌握度（Synchronization Rate）が一定値に達した際、**プレイヤーの操作権能が拡張される**。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                 集合意識掌握時の「エイリアン直接操作」仕様                  │
├─────────────────────────────────────────────────────────────────────────────┤
│  ・通常の軍団ユニット（4個軍団＋増設軍団）に加え、マップ上の野生エイリアン    │
│    群生体（Swarm・Colossus）をマウス選択可能になる。                         │
│  ・移動指示、敵対国家タイルへの侵入・強襲指示を直接発令可能。               │
│  ・補給（弾薬・燃料）の概念がなく、損耗しても瘴気タイルから自律無尽蔵に再生産│
└─────────────────────────────────────────────────────────────────────────────┘
```

## 6. クリア後エンドレス継続プレイ（Just One More Turn）

終局条件を達成した後も、プレイヤーはゲームを終了せず継続プレイを選択できる。

- **外交ステータスの固定化**:
  - 降伏・従属したNPC国家の反乱リスクが凍結され、安定した統治・朝貢状態へ移行。
- **全技術ツリーの開放**:
  - 残された上位アフィニティ技術や惑星規模の大土木工学（海峡埋め立て、メガフロート等）を心ゆくまで研究可能。
- **完全開拓の自由**:
  - 全大陸・全サブタイルの完全開発・インフラ結合度1.00達成を目指すサンドボックス運用。
