# SEC-10: エイリアン生態ライフサイクル・巣窟（Nest）運用仕様書

本仕様書は、マップ上に存在する野生エイリアンの拠点である「巣窟（Nest）」の自律的な挙動、瘴気（Miasma）の拡散シミュレーション、およびプレイヤーとのインタラクション（討伐、共生、誘導）について規定する。

---

## 1. 巣窟（Nest）のライフサイクル

巣窟は単なる「敵のスポーンポイント」ではなく、独自のライフサイクルと刺激蓄積メーターを持つ生態系の中枢である。

### 1.1 ライフサイクルの4段階フェーズ

1.  **Dormant（休眠）**:
    - 初期状態。マップ上にひっそりと存在し、周囲への被害はない。
    - 少数の小型・中型格闘種のみが防衛のために徘徊する。
2.  **Active（活性）**:
    - 人類の接近、環境破壊、または他フェーズからの移行によって活性化。
    - 瘴気（Miasma）の放出が始まり、周囲のタイルへ拡散する。
    - 中型・大型の個体がスポーンし、巣窟周辺の一定範囲を防衛行動としてパトロールする。
3.  **Breeding（繁殖）**:
    - 高い環境適応度、または長期のActive状態から移行。
    - 瘴気の放出量が最大になる。
    - 巣窟のHPと防御力が増加し、防衛部隊のスポーン速度が劇的に上昇する。
4.  **Swarming（暴走大侵入）**:
    - 人類側からの直接攻撃による刺激ヘイトが限界値（Threshold）を超えた場合、または惑星規模のイベントにより発生。
    - 巣窟に蓄積された全戦力（超大型タイタン級を含む）がマップ上に溢れ出し、最もヘイトの高い人類の拠点や部隊へ向けて大移動（スタンプード）を開始する。
    - エネルギーを使い果たすと、Dormantまたは枯渇状態に戻る。

### 1.2 刺激ヘイト蓄積ロジック

巣窟の活性度やSwarmingへの移行は、人類の以下の行動によって蓄積される「刺激ヘイト（Irritation / Hate）」によって決定される。

- **物理的接近**: 巣窟の隣接タイルに軍事ユニットを配置する（微量蓄積）。
- **環境負荷**: 巣窟の近くで工業活動（熱負荷、採掘）を行う（中量蓄積）。
- **直接攻撃**: 巣窟に対して砲撃や直接交戦を行う（大量蓄積、即時Active/Swarming移行の可能性）。

## 2. 瘴気（Miasma）ダイナミクス

瘴気はエイリアンの生命維持に不可欠なガス・胞子群であり、人類には有害な環境ハザードである。

### 2.1 瘴気の自律拡散

- **発生源**: Active以上の巣窟、または特定の地形（毒性湿地など）。
- **濃度勾配**: 0.00（なし）〜 1.00（最高濃度）の浮動小数点値で管理される。
- **拡散計算**: 毎ターン、発生源から隣接タイルへ一定の拡散係数を用いて伝播する。山岳や防壁により拡散は阻害される。

### 2.2 瘴気の効果

| 濃度レベル       | 通常人類ユニット                     | Harmony/エイリアンユニット       | インフラ・都市         |
| :--------------- | :----------------------------------- | :------------------------------- | :--------------------- |
| **低 (~0.3)**    | 命中率・視界微減                     | ペナルティなし                   | ペナルティなし         |
| **中 (0.3~0.7)** | 毎ターン軽微なHPダメージ             | 毎ターン軽微なHP回復             | 居住区の成長低下       |
| **高 (0.7~1.0)** | 毎ターン甚大なHPダメージ、移動力半減 | 毎ターン中回復、光学迷彩ボーナス | インフラ停止、人口減少 |

- Purity/Supremacy系技術により「瘴気除去・防護施設」を建設し、濃度を下げることができる。

## 3. 生態兵站・誘引と共生採取

エイリアンは単純な敵ではなく、戦略的リソースや外交の道具として利用可能である。

### 3.1 フェロモン誘引（Pheromone Decoy / Warhead）

- **フェロモン兵器**: 生体化学兵器の一種。敵国のタイルやユニットにフェロモン弾を撃ち込むことで、そのタイルへの「エイリアン刺激ヘイト」を意図的に最大化させる。
- **間接戦争**: これにより、周辺の巣窟をSwarming状態に陥らせ、大群を敵国へ誘導する「ブラックオプス（偽装作戦）」が可能。

### 3.2 共生協定と生体採取

- **Harmony路線**: 巣窟を破壊せず、保護・研究することで「共生協定」を結ぶことができる。
- **生体資源の採取**: 協定を結んだ巣窟からは、高度な生体甲殻や医薬品の原料となる「高品位バイオ原質」を毎ターン採取できる。
- **採取リスク**: 過剰な採取（採掘クォータの設定ミス）を行うと、巣窟のヘイトが閾値を超え、協定が破棄されて不意討ちのSwarmingを引き起こすリスクがある。
