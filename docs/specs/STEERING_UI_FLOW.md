# 多層ステアリングUI画面遷移・操作フロー仕様書

## (Multi-Layer Steering UI/UX & Automation Escalation Specification)

本ドキュメントは、本作（4X大戦略＋諸兵科連合戦闘団制＋脱都市タイル進展＋多層自動化）における**「国家指針（思想・好戦性・友好性・孤立性）に基づく完全自動運転から、プレイヤーの意図による段階的主導化（ステアリング・例外介入）」**を実現するためのGUI画面遷移、操作プロトコル、移行ラグの可視化、およびBevy ECS実装用データ構造を定義した具象仕様書である。

---

## 1. コア設計思想：「自動化に頼らざるを得ないが、方針は主導する」

### 1.1 背景：情報過多とシミュレーション規模のジレンマ

本作の内部シミュレーションは、「全タイルのインフラ結合度」「戦闘団内16スロットの部品規格・共食い整備」「弾薬C規格のサプライチェーン」「異星適応度」など極めて高解像度に動作する。
これらを手動で1つずつ指示（マイクロマネジメント）することは人間には不可能であり、**「基本はシステムと現場AIによる自律自動運転に頼らざるを得ない」**。

### 1.2 解決策：国家指針と「介入度（Escalation Level）」の動的切り替え

プレイヤーの役割は、現場の作業員や連隊長に細かく命令することではなく、**「国家指針（思想・好戦性・友好性・孤立性）」という大枠の引力を与えること**である。
通常時は完全自動化（Level 0）で健全に国家が自走し、勝負所や危機に直面した領域だけをプレイヤーが「主導化（Level 1〜3）」へ引き上げてピンポイント介入を行う。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                       ステアリング・介入度の4段階構造                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【Level 0: 完全自動化（自律委任・平常運転）】                              │
│    ・国家指針（思想・好戦性・友好性・孤立性）のみを設定。                   │
│    ・工廠AIが最適兵器を自動調達、方面軍AIが自動防衛、内政AIが自動開発。     │
│                                                                             │
│  【Level 1: ドクトリン・RFP主導化（仕様・枠組み誘導）】                     │
│    ・兵器クラス別RFP（例: 「主力戦車は重防御・共通化率70%で更新せよ」）。   │
│    ・工廠の生産枠配分スライダーを手動設定。                                 │
│                                                                             │
│  【Level 2: 方面軍・作戦ベクトル主導化（軍事進撃軸誘導）】                  │
│    ・方面軍パネルから、マップ上へ作戦進撃矢印（Mission Vector）をドラッグ。 │
│    ・特定補給動脈の最優先護衛、SLC船腹プールの重点配分を指定。              │
│                                                                             │
│  【Level 3: 現場承認・例外特権（直接意思決定）】                            │
│    ・前線部隊の現地改修（Block Field）を国家制式化するか否かの承認。        │
│    ・虎の子母星遺産（Gen 0）の出撃許可・共食い整備（スクラップ化）の拒否権。│
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 3. 国家4大指針と内部自動化システムの連動仕様

国家指針は、プレイヤーが直接命令を下さない領域（Level 0）において、各サブシステムの自律エージェントが判断基準として参照する重みパラメータとなる。

### 3.1 思想（Affinity）

- **純血・母星化（Purity）**:
  - 工廠AIは「母星規格の複合装甲・重砲・高耐久化」を最優先で選択。
  - タイル開発AIは「テラフォーミング、密閉型温室ドーム、除染プラント」を自律建設。
- **調和・異星共生（Harmony）**:
  - 工廠AIは「キチン外殻装甲、生体炭素繊維、フェロモン弾頭」を自律採用。
  - タイル開発AIは「異星土壌共生農場、胞子発酵リアクター」を優先配置。
- **超越・自律知能（Supremacy）**:
  - 工廠AIは「無人ドローンキャリア、自律AI射撃統制、軽量高機動フレーム」を優先。
  - タイル開発AIは「データセンター、自動化集積ライン、超電導送電網」を敷設。

### 3.2 好戦性（Belligerence）

- **専守防衛（0.0 〜 0.3）**:
  - 軍事予算比率は最小限。工廠は弾薬備蓄と民生インフラ部品を優先生産。
  - 方面軍AIは「国境・防衛線内での待機・警戒」を維持し、越境しない。
- **全面動員・予防先制（0.7 〜 1.0）**:
  - 資源が許す限り戦闘団の満額編成・弾薬満載を維持。
  - 国境に敵対部隊が接近した場合、方面軍AIが自動で「先制遅滞陣地」を越境敷設。

### 3.3 友好性（Friendliness）

- **寛容・協調（0.7 〜 1.0）**:
  - 領土境界に現れた「自発的失踪者・避難民」を自動で保護し、サブタイルの労働力に編入。
  - 他国との不可侵条約・通行権の更新を自動承認。
- **冷徹・排他（0.0 〜 0.3）**:
  - 境界侵入者をスパイ・密輸業者として自動追放・強制収容。外交要求を自動突っぱね。

### 3.4 孤立性（Autarky / Isolationism）

- **開放・交易網統合（0.0 〜 0.3）**:
  - サプライチェーンAIは他国との共通「C規格弾薬」を積極採用し、国際市場から不足部品を自動買い付け。
- **鎖国・自給自足（0.7 〜 1.0）**:
  - 外国規格を排除し、国内専用の独自モジュール規格・独自閉鎖サプライチェーンを構築。禁輸措置に対して無敵耐性を持つが、初期コストが増大。

## 4. 操作プロトコルと移行ラグ（Re-tooling Lag）の数理モデル

### 4.1 スライダー操作と「ゴーストゲージ（Ghost Gauge）」方式

指針や共通化率スライダーを変更した際、即座に効果が反映されるとゲームのリアリティが崩壊するため、**「実効値（Current）」と「目標値（Target）」を分離するゴーストゲージ方式**を採用する。

```text
[独自特化] ──────────●────────────────── [極限共通化]
                  実効値: 35%  ──────►  目標値: 75% (点線ゴースト)
                  [ 移行ラグ: 8ターン / 整備ペナルティ: -15% ]
```

### 4.2 移行ラグおよび稼働混乱ペナルティの計算式

プレイヤーが目標値を $\Delta S = |S_{\text{target}} - S_{\text{current}}|$ だけ急変させた場合の所要ターン数 $T_{\text{lag}}$ および前線整備ペナルティ $P_{\text{chaos}}$：

$$T_{\text{lag}} = \left\lceil \Delta S \times K_{\text{inertia}} \times \left(1.0 - \text{TechBonus}\right) \right\rceil$$

$$P_{\text{chaos}}(t) = P_{\text{max}} \times \frac{t_{\text{remain}}}{T_{\text{lag}}} \times \Delta S$$

- $K_{\text{inertia}}$: 国家規模・保有軍団数に応じた慣性係数（通常 `10.0 〜 20.0`）。
- $P_{\text{chaos}}(t)$: 移行期間中に前線戦闘団の全補充・補給効率にかかるマイナス補正（最大 `-30%`）。
- **UX演出**: スライダーを動かしている最中に、右側に「⚠️ 急激な方針変更により、今後8ターンの間前線補給効率が15%低下します」と黄色〜赤色の動的警告ラベルが表示される。

## 5. 方面軍作戦ベクトル（Mission Vector）入力プロトコル

Level 2（方面軍主導化）における、マップ直結の大戦略操作仕様。

### 5.1 作戦矢印の描画インタラクション

1. 方面軍司令部タイル（または配下の戦闘団）を選択し、右クリックまたは `Alt + ドラッグ` でマップ上に矢印（作戦進撃軸）を描画。
2. 矢印の先端が「攻略目標タイル（親タイル）」となる。
3. 矢印の太さは「投入兵力規模（通常 1個〜4個軍団）」に連動。

### 5.2 現場AIによる移動隊形の自動解釈

プレイヤーが矢印を引くだけで、配下の戦闘団AIは以下の移動モードを自動で切り替える：

- **インフラ結合度が 0.8 以上の舗装路区間**:
  - 「トラック牽引・高速移動モード（移動コスト 0.6倍、燃料消費低、接敵時奇襲被弾リスク大）」
- **敵哨戒圏または未踏地（インフラ結合度 0.3 未満）進入時**:
  - 「戦闘隊形展開・前進警戒モード（移動コスト 1.8倍、索敵範囲拡大、弾薬消費微小）」
- **海峡・大河川の横断時**:
  - 自動で方面軍の「SLC船腹プール」を要請し、海上輸送ユニットへ一時換装。

## 7. Bevy ECS 実装データ構造仕様 (Rust)

```rust
use bevy::prelude::*;

/// 国家4大指針スライダー
#[derive(Component, Debug, Clone, Reflect)]
pub struct NationalStance {
    /// 思想: 0.0(Purity) 〜 0.5(Supremacy) 〜 1.0(Harmony)
    pub ideology: f32,
    /// 好戦性: 0.0(専守防衛) 〜 1.0(全面動員・先制)
    pub belligerence_current: f32,
    pub belligerence_target: f32,
    /// 友好性: 0.0(排他・冷徹) 〜 1.0(寛容・協調)
    pub friendliness: f32,
    /// 孤立性: 0.0(開放・世界規格) 〜 1.0(鎖国・自給自足)
    pub autarky: f32,
}

/// 各領域の自動化・介入レベル
#[derive(Debug, Clone, Copy, PartialEq, Eq, Reflect)]
pub enum EscalationLevel {
    /// Level 0: 完全自動委任
    Autonomous,
    /// Level 1: ドクトリン・RFP主導
    DoctrineSteering,
    /// Level 2: 方面軍作戦ベクトル主導
    TheaterCommand,
    /// Level 3: 現場直接介入・拒否権
    DirectIntervention,
}

/// 介入度設定リソース
#[derive(Resource, Debug, Clone, Reflect)]
pub struct AutomationSettings {
    pub military_procurement: EscalationLevel,
    pub theater_operations: EscalationLevel,
    pub domestic_development: EscalationLevel,
    pub diplomacy_crisis: EscalationLevel,
}

/// 移行ラグ（金型転換・ドクトリン再編）状態
#[derive(Component, Debug, Clone, Reflect)]
pub struct ReToolingLag {
    pub total_turns: u32,
    pub remaining_turns: u32,
    pub chaos_penalty: f32, // 例: 0.15 なら補給効率 -15%
}

/// 方面軍作戦ベクトル（マップ進撃矢印）
#[derive(Component, Debug, Clone, Reflect)]
pub struct MissionVector {
    pub origin_tile: Entity,
    pub target_tile: Entity,
    pub arrow_width: f32,
    pub posture: OperationPosture,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Reflect)]
pub enum OperationPosture {
    RapidTransit, // 高速道路輸送
    CautiousAdvance, // 警戒隊形
    AssaultBreach,   // 強襲突破
}

/// プレイヤーが指針変更を発令したイベント
#[derive(Event, Debug, Clone)]
pub struct IssueDoctrineDecreeEvent {
    pub target_belligerence: f32,
    pub target_autarky: f32,
    pub target_commonality: f32,
}

/// 現場発議に対する承認・決断イベント
#[derive(Event, Debug, Clone)]
pub struct FieldModDecisionEvent {
    pub proposal_id: u32,
    pub decision: FieldModDecision,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum FieldModDecision {
    AdoptNationally,
    AllowFieldOnly,
    RejectAndStandardize,
}
```
