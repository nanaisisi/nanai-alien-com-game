# 架空6大国 初期保有アセット・スタートアップ定義書

## (Faction Turn 0 Starter Arsenal, Bootloader Facilities & Asset Specification)

本ドキュメントは、本作（4X大戦略＋諸兵科連合戦闘団制＋脱都市タイル進展）における**「ゲーム開始時（Turn 0）における全国家共通のスターター戦力（競技的公平性）」**および**「架空6大国（帝国A、大公国B、連邦C、共和国D、共同体E、連合F）ごとの初期保有ブートローダー工廠設備、初期資源ストック、非対称ボーナス」**を定義するスタートアップ仕様書である。

---

## 1. スタートアップ設計の基本思想

### 1.1 競技的公平性（Fair Competitive Baseline）

- 4Xゲームとしての開始時公平性を保証するため、**全国家は完全に同等な「Turn 0スターター戦力（探査、警備、監視、虎の子母星遺産）」を保有してスタート**する。
- マップ生成直後に即死するような理不尽な戦力差や、初期ユニットの優劣は存在しない。

### 1.2 初期非対称性（ブートローダー工廠の得意設備スロット）

- 各国家の地政学・思想・歴史的背景（[`Faction.md`](./Faction.md)、[`concept_factions_detail_and_naming.md`](../discussion/diplomacy_governance/concept_factions_detail_and_naming.md)）は、ユニットの数値そのものではなく**「母星宇宙船から展開した初期ブートローダー工廠（工作機械プール）の得意分野」**として表現される。
- これにより、序盤数ターン〜数十ターンの内政・工廠再編・研究ステアリングの方向性が自然と各国の特色に沿って誘導される。

## 2. 全国家共通：Turn 0 スターター戦力（初期配備 4個軍団）

大戦略マップ上の基本操作単位（1ユニット）は「**2個師団で構成される1個軍団（Corps）**」である。全国家は降着母船（降着司令部親タイル）周辺に、未踏地の調査・険悪地形の確保・正面打撃・立体強襲を担う役割の異なる**「4個軍団（計4ユニット）」**を1コマずつ初期保有してスタートする。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                 Turn 0 全国家共通スターター戦力（初期 4個軍団）             │
├─────────────────────────────────────────────────────────────────────────────┤
│  [ユニット1: 第1遠征調査軍団] ── 軽探査・前進斥候軍団 (Std-W6装輪主体)       │
│  [ユニット2: 第2山岳軽歩兵軍団] ── 完全徒歩行軍・山岳密林踏破軍団 (車両ゼロ) │
│  [ユニット3: 第3機甲打撃軍団] ── 虎の子母星遺産を含む戦略機甲軍団 (Gen 0戦車)│
│  [ユニット4: 第4空中機動軍団] ── ヘリ/VTOL垂直突入・空地強襲軍団 (航空打撃)  │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 2.1 初期 4個軍団の詳細構成と役割

| ユニット名 (大戦略コマ) | 軍団種別 | 主力装備・編成構成 | 燃料/弾薬消費 | 特徴と初期運用 |
| :--- | :--- | :--- | :---: | :--- |
| **第1遠征調査軍団**(*1st Recon Corps*) | 軽探査・斥候(2個軽師団) | Std-W6 6輪装輪車台ベース(探査バギー、軽装輪車、監視杭) | **燃料極小**(太陽光EV併用) | 初期未踏タイルの索敵・資源探査および監視網展開。平原・舗装路を高速展開。 |
| **第2山岳軽歩兵軍団**(*2nd Light Infantry Corps*) | 徒歩歩兵(2個軽歩兵師団) | 完全徒歩行軍・密閉スーツ歩兵(地上車両ゼロ、駄載輜重、8C小火器) | **非資源消費**(食料のみ) | 車両進入不能な急峻山岳・密林・洞窟を踏破。燃料消費ゼロで自活行軍・拠点防衛が可能。 |
| **第3機甲打撃軍団**(*3rd Armored Strike Corps*) | 重機甲打撃(2個機甲師団) | 母星遺産・遠征主力戦車 (Gen 0)(120C滑腔砲、重複合装甲、同軸8C) | **極めて重い**(高純度H2/120C弾) | **国家の最高至宝**。圧倒的突破力・防御力を持つ正面決戦部隊。損耗時の再生産は初期不可能。 |
| **第4空中機動軍団**(*4th Airmobile Corps*) | 空地強襲(2個空中機動師団) | 戦闘ヘリ/VTOL群 ＋ 空挺軽IFV(地形無視の垂直跳躍、CAS支援) | **航空燃料大**(航空推進剤消費) | 河川・断崖・湿地帯を一挙跳躍。要衝の電撃確保や孤立部隊への緊急空中救援を担当。 |

## 3. 全国家共通：降着初期保有物資（Turn 0 Stockpile）

降着母船の解体部材・有限ストックとして、全国家に均等に配分される初期資源。

| 資源区分 | 初期保有量 | 想定用途・消費目安 |
| :--- | :---: | :--- |
| **エネルギー蓄電** | **500 MWh** | 降着船リアクターの残留電力。初期工廠の稼働用（約10〜15ターン分）。 |
| **構造鉱物** | **200 t** | 母船外殻の解体鋼材。初期インフラ道路敷設・防壁建設用。 |
| **機能性鉱物** | **50 t** | 電子基板・センサー予備部品。初期の精密加工用。 |
| **バイオ原質 / レーション** | **150 t** | 冷凍睡眠解除後の非常用食料備蓄（初期人口で約6〜8ターン分）。 |
| **C規格弾薬** | **300 t** | Gen 0戦車・警備隊用初期弾薬箱（初期防衛戦闘2〜3回分）。 |
| **推進燃料** | **400 t** | 探査・トレーラー輸送用初期合成燃料ドラム。 |

## 4. 架空6大国 初期ブートローダー工廠設備および非対称特性

全国家は共通の基本工廠スロット（4スロット）を持つが、母星から持ち込んだ「親工作機械・中核冶金モジュール」の配分が異なる。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                    架空6大国の初期ブートローダー工廠スロット                │
├─────────────────────────────────────────────────────────────────────────────┤
│  ・帝国A : [超大型鋳造プレス] ── 重装甲板・大口径砲身の生産工数 -25%         │
│  ・大公国B: [精密歯車・耐寒研磨機] ── 共通化率 +15%、寒冷・過酷地整備負荷 -30% │
│  ・連邦C : [重土木建機アセンブリ] ── インフラ道路敷設速度 +35%、資源採掘 +20%│
│  ・共和国D: [高速スタンプ連続金型] ── 基礎部品生産量 +40%、Gen 1生産ターン -1│
│  ・共同体E: [高自動化ドック・海洋冶金] ── 港湾/水上施設コスト -30%、自動化率高│
│  ・連合F : [分散型エッジAIファブ] ── 論理コア加工電力 -30%、初期研究速度 +15% │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 4.1 各国の初期プロファイル詳細

#### ① 帝国 (国A / 第VII神聖皇国主権領)

- **初期思想スタンス**: Purity 70% / Belligerence 60% / Friendliness 40% / Autarky 60%
- **固有ブートローダー設備**: **「皇室直属 60,000トン重油圧鍛造プレス」**
- **初期ボーナス**:
  - 重装甲板（Composite Armor）および 80C以上の砲身製造工数 **-25%**。
  - 戦闘団内の機甲大隊（戦車）の士気・基礎防護値 **+10%**。
- **初期制約**: 電子論理コアの初期生産歩留まりがやや低い（熟練技術者の手作業調整が必要）。

#### ② 大公国 (国B / 北部諸州立憲公国)

- **初期思想スタンス**: Purity 40% / Belligerence 35% / Friendliness 60% / Autarky 75%
- **固有ブートローダー設備**: **「高精度極低温研磨工作機械群」**
- **初期ボーナス**:
  - 全軍の初期部品共通化率（Commonality）**+15%**（共食い整備成功率 95%）。
  - 湿地・泥濘・豪雪地帯での足回り整備負荷（交換部品消費）**-30%**。
- **初期制約**: 初期人口成長率（人工子宮の初期スロット）が控えめ。

#### ③ 連邦 (国C / 中央諸州合衆連邦)

- **初期思想スタンス**: Supremacy 30% / Belligerence 50% / Friendliness 50% / Autarky 30%
- **固有ブートローダー設備**: **「超大型モジュラー土木建機プラント」**
- **初期ボーナス**:
  - 幹線道路・パイプラインの敷設工期 **-35%**（インフラ延伸速度全勢力中トップ）。
  - 構造鉱物（鉄・チタン）の採掘タイル産出量 **+20%**。
- **初期制約**: 州ごとの自治権調整のため、ドクトリン変更時の移行ラグ（Re-tooling Lag）が +2ターン長い。

#### ④ 共和国 (国D / 西部人民共和主権体)

- **初期思想スタンス**: Purity 50% / Belligerence 65% / Friendliness 30% / Autarky 50%
- **固有ブートローダー設備**: **「高速スタンプ連続プレス金型ライン」**
- **初期ボーナス**:
  - 基礎機械部品の生産工数 **-40%**。Gen 1開拓型急造車両の生産ターン数 **-1 ターン**。
  - 人工子宮（Ectogenesis）初期培養槽が 1スロット追加稼働。
- **初期制約**: 車両1両あたりの損耗率がやや高い（大量生産・消耗前提の公差設計）。

#### ⑤ 共同体 (国E / 汎海洋自由企業共同体)

- **初期思想スタンス**: Harmony 40% / Belligerence 30% / Friendliness 70% / Autarky 20%
- **固有ブートローダー設備**: **「モジュラー式自動化浮体ドック」**
- **初期ボーナス**:
  - 海岸・水域タイルの開発コスト **-30%**。SLC輸送船腹プールの初期枠 **2倍**。
  - 他国および闇市との資源取引・C規格弾薬調達コスト **-20%**。
- **初期制約**: 内陸の山岳・岩盤地帯におけるインフラ敷設コストが +25% 割高。

#### ⑥ 連合 (国F / バシレス多元統合同盟)

- **初期思想スタンス**: Supremacy 60% / Belligerence 45% / Friendliness 55% / Autarky 35%
- **固有ブートローダー設備**: **「分散型サブミクロン・エッジファブ」**
- **初期ボーナス**:
  - 電子・論理コアの製造電力消費 **-30%**。
  - 初期技術ツリー（Tech Web）の自律研究速度 **+15%**。無人ドローンの索敵範囲 +1 マス。
- **初期制約**: 初期保有の構造鉱物ストックが 150t（他国より -50t 少ない）。
