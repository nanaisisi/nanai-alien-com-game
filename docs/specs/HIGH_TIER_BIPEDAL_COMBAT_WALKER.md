# 二脚歩行戦闘車両（高級装甲部隊）仕様書

(High-Tier Bipedal Armored Combat Vehicle & Mixed Company Specification)

本作における**「二脚歩行戦闘車両（High-Tier Bipedal Combat Walker / AWGS風）」**の機体規格、インフラ制約、機甲戦闘団内の混成配備モデル、および短時間飛翔・空挺降下型と通常歩行型の運用仕様を規定する。

---

## 1. 開発思想と機体コンセプト（重厚・実戦的な装甲歩行機）

アニメ的な軽快ヒーローロボットや、物理を無視したローラーダッシュ機構を完全排除し、**「装甲車・重IFVの装甲・火器思想を二脚に落とし込んだ、高級・特殊装甲戦闘兵器」**として定義する。

- **機体寸法（輸送規格 ⇔ 通常展開時のダイナミズム）**:
  - **輸送・格納形態（Transport Stowed Mode）**:
    - **全高：3.76 m / 全幅：5.48 m**（大型戦略輸送機の貨物室限界・カーゴベイ規格に収まる折りたたみ・屈曲格納時の最小寸法）。
    - 脚部関節を深く屈曲（クラウチング）させ、センサー・腕部武装を内側に引き込むことで、大型戦略輸送機（C-17/C-5級）のカーゴベイにギリギリ収容可能な限界寸法として設計されている。
  - **通常稼働・戦闘展開時（Operational Combat Mode）**:
    - **全高：5.0 m 〜 6.0 m 前後**（脚部アクチュエータを伸長し直立した際の実効全高。戦車の2倍近い高さとなり、2階建て家屋や遮蔽物の頭越しに機関砲・ミサイルを水平射界に収める）。
    - **全幅：6.5 m 〜 7.5 m 前後**（射撃反動と踏ん張りのため、ワイドトレッド・クローフットを左右に大きく開脚展開した戦闘スタンス）。
  - ローラーダッシュや車輪走行は**不採用（完全歩行駆動）**。大型油圧アクチュエータによるダイナミックな二脚歩行と、接地圧を分散するスパイク／クロー付き大型フットで前進・旋回する。
- **装甲・防護思想**:
  - 車輪・装軌車両のような避弾経始を持つ傾斜装甲板、キャニスター式複合装甲ブロックを採用。
  - 装甲戦闘車（IFV/APC）と同様のMIL-SPEC重装甲を持ち、前面は25C〜35C徹甲弾に抗堪。

## 2. インフラ・輸送特性（大型輸送機規格と地上のインフラ拒絶）

本車両は「どこでも走れる万能兵器」ではなく、**輸送機規格から逆算された巨大アセット**であり、**地上の一般インフラを物理的に拒絶する**。

1. **通常展開時のインフラ完全拒絶（道路・橋梁・トンネル進入不可）**:
   - 通常稼働時は全高5m超・全幅6.5m超に達するため、一般道路（車線幅3〜3.5m）を単独走行できず、街路樹・電柱・対向車線を物理的に粉砕・蹂躙する。
   - 一般の道路トンネル・地下道・標準鉄道トンネル（幅4.5m前後）は直立状態ではもちろん、折りたたみ状態でも進入不能。
   - 数十トンの重量が二脚の足裏に集中するため、舗装道路のアスファルトをめくり上げ、軽量橋梁を踏み抜いて崩落させる。
2. **大型戦略輸送機（Air Lift）への特化適合**:
   - 機体寸法（全高3.76m / 全幅5.48m）は**「大型戦略輸送機の貨物室サイズ限界」**そのものであり、膝を抱え込むように格納することで空輸される。
   - これにより、大戦略マップ上での長距離移動は**大型輸送機による空中空輸・空挺降下**、または港湾での大型揚陸艇（LCAC等）による海上輸送が基本となり、陸路自走による長距離行軍は行わない。

## 3. 二脚歩行戦闘車両の2大バリエーション

機体フレーム（シャシー）を共通化しつつ、推進・展開ユニットの違いで2つのサブタイプを定義する。

| 項目 | ① 通常重歩行型 (Ground Type) | ② 短時間飛翔・空挺降下型 (Jump-Flight Type) |
| :--- | :--- | :--- |
| **主な用途** | 拠点突撃、不整地制圧、待ち伏せ迎撃 | 空挺強襲、立体跳躍急襲、高地・屋上占拠 |
| **推進・跳躍機構** | 純粋油圧・電動アクチュエータ歩行 | 背部ターボファン/高出力ガススラスタ搭載 |
| **跳躍・滑空性能** | 段差の踏み越え（1.5m〜2m程度） | **短時間立体飛翔（30〜60秒）**、ビル屋上跳躍、障害跳躍 |
| **空挺降下能力** | なし（地上輸送・着陸機からの降車） | **大型輸送機からの高高度パラシュート/逆噴射空中投下対応** |
| **装甲・防護力** | 重複合装甲・重スラットアーマー（堅牢） | スラスタ重量・燃料のため装甲厚は前面重視（中装甲） |
| **主兵装** | 35C〜50C自動滑腔機関砲 ＋ 重対戦車ミサイル | 30C軽量機関砲 ＋ 誘導ロケットポッド ＋ 近接破砕砲 |
| **兵站負荷** | 燃料消費：中 / 整備：油圧関節部品 | 燃料消費：**極大（航空推進剤）** / 整備：ジェットノズル |

## 4. 機甲戦闘団内における混成中隊配備モデル

二脚歩行戦闘車両は、単独の「二脚師団」を構成するのではなく、**増強機甲戦闘団の各小隊（4両単位）を組み合わせた「諸兵科混成中隊（16両規模）」**としてスロットに組み込まれる。

### 4.1 2進数・倍々構造に基づく小隊・中隊混成

機甲科の基本原則「4両＝1小隊、4小隊＝1中隊（16両）」に基づき、**「戦車」「重IFV」「二脚歩行型」「二脚跳躍型」**をペアで組み合わせる。

### 4.2 戦術戦闘（343マス）での立体シナジー

1. **戦車（MBT）× 通常歩行機（Ground Walker）の相互補完**:
   - 戦車の弱点である「市街地・瓦礫地帯での低い砲塔仰角」「2階・屋上からの対戦車ミサイル待ち伏せ」を、全高3.76m以上の歩行機が見下ろし・水平射界で粉砕する。
   - 歩行機の弱点である「平原での長距離撃ち合い・走行速度」を、戦車の120C滑腔砲と前面装甲がカバーする。
2. **短時間跳躍機（Jump-Flight Walker）の奇襲と下車歩兵の確保**:
   - 跳躍機が敵の地雷原や対戦車壕をブースターで跳び越え、後方の敵特科陣地や対空ミサイル車両を頭上から急襲。
   - その後、重IFVから下車した歩兵が突入口を確保し、防衛線を完全突破する。

## 5. 兵站・共食い整備（Cannibalization）と生産コスト

- **高級アセット判定**:
  - 生産には「耐熱複合装甲板」「基礎機械部品」に加え、**大量の「電子・論理コア」および「精密油圧アクチュエータ」**を消費する（戦車1両の約1.5倍の工数）。
- **共食い整備グループ**:
  - **二脚歩行系（共通化率 75% / 成功率 80%）**: 通常型と跳躍型の間で、脚部関節・コクピットブロック・油圧シリンダーを相互融通可能。
  - **航空推進系（共通化率 60% / 成功率 70%）**: 跳躍型のブースタースラスタは、戦闘ヘリやVTOLの推進パーツと融通可能。
