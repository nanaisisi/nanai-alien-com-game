# 起動オプション・コマンドライン引数仕様書 (Startup Options & CLI Specification)

本ドキュメントでは、本作（Nanai Alien Com Game）における**起動時コマンドライン引数（CLIオプション）の仕様、開発・検証用ショートカット、および将来的な拡張構想**について解説します。

---

## 1. 概要

本作では、ゲーム起動時にコマンドライン引数を渡すことで、通常のタイトル画面を経由せずに直接特定のゲームステート（インゲーム、勢力選択、設定画面など）へ遷移させることができます。
開発中の動作検証やマップ描画テスト、UIデバッグなどを迅速に行うためのプログラマ・テスター向けショートカット機能として提供されています。

```bash
# 実行例（Cargo経由）
cargo run -- --state in-game
cargo run -- -s settings
```

---

## 2. 実装済み起動オプション一覧

現行の実装（`src/state.rs`, `src/main.rs`）で解釈されるオプションは以下の通りです。

### `--state` / `-s` （初期ステート指定）

アプリケーション起動時の初期状態（`AppState`）を強制指定します。大文字・小文字は区別されません（ケースインセンシティブ）。

| 引数指定値（エイリアス）    | 遷移先 `AppState`         | 説明                                                                                                                        |
| :-------------------------- | :------------------------ | :-------------------------------------------------------------------------------------------------------------------------- |
| `title`                     | `AppState::Title`         | **デフォルト**。通常の起動シーケンスでタイトル画面を表示します。                                                            |
| `in-game`, `ingame`, `game` | `AppState::InGame`        | タイトルや勢力選択をスキップし、大戦略マップ画面（メインゲーム）を直接起動します。マップ生成やカメラ、HUDの検証に最適です。 |
| `faction-select`, `faction` | `AppState::FactionSelect` | 勢力選択画面を直接表示します。                                                                                              |
| `settings`, `setting`       | `AppState::Settings`      | 設定画面（解像度・音量・グラフィック等）を直接表示します。                                                                  |
| `pause`, `pausemenu`        | `AppState::PauseMenu`     | ポーズメニュー画面を直接表示します。                                                                                        |

> [!NOTE]
> 未知の値や不正な引数が指定された場合（例: `--state unknown`）、標準エラー出力に警告 `[WARN] 不明なステート引数: '...'. デフォルト (Title) を使用します。` を出力した上で、安全にデフォルトの `AppState::Title` にフォールバックします。

## 3. 実行コマンド例

### 3.1 開発・テスト時の実行例

```bash
# 1. 直接インゲーム（大戦略マップ）を起動
cargo run -- --state in-game
# または短縮形
cargo run -- -s in-game

# 2. 設定画面を直接起動してUI確認
cargo run -- -s settings

# 3. 勢力選択画面を直接起動
cargo run -- -s faction

# 4. ポーズメニューを直接起動
cargo run -- -s pause
```

### 3.2 ビルド済みバイナリでの実行例

```powershell
# Windows PowerShell
.\target\debug\nanai-alien-com-game.exe --state in-game
.\target\release\nanai-alien-com-game.exe -s settings
```

## 4. 関連する開発用デバッグ機能

起動オプションと連携して利用できる開発・検証用機能です。

### 4.1 隠しデバッグコンソール

インゲーム中またはタイトル画面中、以下のいずれかの方法でデバッグコンソールを呼び出すことができます。

1. **キーボードショートカット**: `~` / `` ` ``（バッククォートキー）
2. **隠しトリガーエリア**:
   - **タイトル画面**: タイトルロゴ右側エリアを5秒以内に5回連続クリック
   - **インゲームHUD**: 画面右上パネル付近の透明エリアを5秒以内に5回連続クリック

初回起動時は警告ダイアログが表示され、承認後にコンソールが開きます。
コンソール上では以下のコマンドが利用可能です：

- `help` : コマンド一覧の表示
- `turn <count>` : ターン経過を進める（資源産出も同時に加算）
- `energy <amount>`, `prod <amount>`, `sci <amount>`, `food <amount>` : 各種資源の加減
- `res <e> <p> <s> <f>` : 4大資源を一括設定
- `goto <q> <r>` / `cam <q> <r>` : 指定ヘックス座標へカメラを即座にジャンプ
- `clear` / `cls` : コンソールログ消去

## 5. 将来的な拡張・実装検討オプション (Roadmap)

今後の開発において、本格的なCLIパーサー（`clap` 等）の導入や、以下の起動時フラグ・オプションの追加が検討されています。

| オプション候補         | 期待される動作                                                                | 想定用途                                               |
| :--------------------- | :---------------------------------------------------------------------------- | :----------------------------------------------------- |
| `--seed <u64>`         | マップ生成時の乱数シード値を固定指定                                          | マップ生成バグの再現、同一マップでのバランス比較       |
| `--map-size <w>x<h>`   | マップのグリッドサイズを一時的に上書き                                        | 小型テストマップ（高速起動）や巨大マップ負荷テスト     |
| `--faction <id>`       | プレイヤー勢力（1〜6）を事前選択してインゲーム起動                            | `--state in-game` と併せて特定勢力固有ロジックを即検証 |
| `--headless`           | ウィンドウ描画を行わずにECSワールドシミュレーションのみ実行                   | 自動ターン進行ベンチマーク、AI対戦高速テスト、CIテスト |
| `--log-level <level>`  | Bevyログフィルターの動的切り替え（`trace`, `debug`, `info`, `warn`, `error`） | 詳細デバッグログの出力切り替え                         |
| `--resolution <w>x<h>` | 起動解像度の上書き（デフォルト: 1280x720）                                    | マルチディスプレイや特定解像度でのUIレイアウト検証     |
| `--fullscreen`         | フルスクリーンモードで起動                                                    | 実機プレイ環境の検証                                   |
