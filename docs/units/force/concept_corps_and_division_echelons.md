# 1ユニット＝2個師団1軍団制 概念・編制検討書

(Study on One-Unit Corps Structure: 2-Division Integrated Armored Corps)

本ドキュメントは、本作（4X大戦略＋サブタイル戦術戦闘）において、大戦略マップ（親タイル）上でプレイヤーが操作する**「1コマ（1ユニット）」の実体が【2個師団で構成される1個軍団（Corps）】である**という基本構造に基づき、その必然性、2進数倍々エシュロンの整合性、各師団の正面4連隊＋師団付砲兵連隊、各師団付輸送飛行隊、軍団直属航空隊（4個飛行隊）、および**「固定8名下車分隊制」「装軌装甲車・8輪装甲車ファミリー」「160C旋回砲塔砲／210C車体据付重砲」「対空多層防空体系」**を体系的に整理した検討書である。

## 1. 「1ユニット＝2個師団1軍団」の基本構造

従来の戦闘機動8個連隊（機甲4＋歩兵2＋偵察2）という兵力規模は、**「各師団が4個戦闘機動連隊＋師団付砲兵連隊＋師団輸送飛行隊を持つ2個師団」**として分割・統合し、航空攻撃・重強襲戦力を軍団直轄として集中配備することで、陸空・兵站の指揮統制が極めて明快な構造となる。

1. **2個師団で1個軍団を構成**:
   - 軍団司令部の下に、**【第1師団】**と**【第2師団】**の2個師団が直属する。
   - 軍団としての最小構成（2個師団）であり、余分な中間階層や肥大化を持たない極めてソリッドな作戦単位。
2. **各師団の正面戦力は「4個戦闘機動連隊」**:
   - 師団長が直接指揮する正面機動戦力は**4個連隊（機甲2＋歩兵1＋偵察1）**とし、スパン・オブ・コントロール（指揮統制限界）に完全に適合させる。
   - 軍団全体で「機甲4個連隊 ＋ 装甲歩兵2個連隊 ＋ 偵察2個連隊」の計8個機動連隊が均等に2個師団へ割り振られる。
3. **下車歩兵は「固定8名分隊制（乗員＋8名下車）」**:
   - IFV（歩兵戦闘車）およびAPC（装甲兵員輸送車）の下車歩兵定員は**「均一に固定8名（1個完全歩兵分隊）」**とする。
   - これにより、歩兵戦闘車でも装甲兵員輸送車でも、下車する歩兵分隊の火器構成・編成が完全に同一規格化され、戦術ドクトリンとECS処理が極めて明快になる。
4. **重砲（特科）の戦車車体マウント構造（160C砲塔型 / 210C車体据付型）**:
   - 師団野戦特科の主力大口径火砲は、戦車と同一クラスの**「重装軌（戦車車体シャーシ）」**をベースとする。
   - **160C自走榴弾砲**: **【全周旋回砲塔型】**（大型密閉砲塔に自動装填装置を内包）。あらゆる射向へ即応旋回し、突撃する機甲主隊の前面・側面に切れ目ない連続曲射支援を実施。
   - **210C超重自走砲**: **【車体据付型（固定戦闘室 / カゼメット・限定旋回式）】**。反動が巨大な超重口径砲を強固な戦車車体に直接据え付け、後部大型駐退器（スペード）で大地に固定。要塞・大深度巨大エイリアン巣窟を直接粉砕する戦略破壊砲。
5. **重装輪車両（トラック系列）と対空車両の多層体系**:
   - **重装輪車両（8×8/10×10大型トラック）**: TEL弾道ミサイル発射機、重装輪回収車、師団弾薬補給給弾車、および長距離対空SAMシステム。
   - **対空車両の多層配備**:
     - **自走対空戦車 (SPAAG)**: 戦車車体ベース（35C複合機関砲＋局所レーダー）。前進突撃する機甲主隊の直頭上をカバー。
     - **重装輪対空システム (Wheeled SAM)**: 重装輪トラックベースの中・長距離地対空ミサイル。師団広域防空アンブレラ。
     - **4輪駆動対空システム (4×4 Light SAM)**: 4×4高機動装甲車ベースの近接・即応SAM。師団本部や後方拠点の軽快防空。
6. **多目的誘導弾発射部隊は「4輪駆動システム」で運用**:
   - 師団直属の対舟艇対戦車部隊は、4輪駆動（4×4）高機動装甲車ベースの**「発射機車＋射撃指揮車＋索敵観測車」**で構成される視界外（NLOS）多目的誘導弾システムとして編成。
7. **師団輸送飛行隊（8機）と軍団航空隊（4個飛行隊 / 32機）の2層航空運用**:
   - 各師団に自前の「師団輸送飛行隊（8機）」を配備し、患者後送（MEDEVAC）や緊急空輸を自前完結。
   - 軍団直属の「軍団航空隊（32機: 戦闘16機＋強襲輸送16機）」は軍団長の決断で主攻軸へ一挙集中投入。

## 7. ゲームプレイおよび戦術戦闘への影響

1. **160C砲塔砲と210C車体据付砲の戦術的撃ち分け**:
   - **160C全周旋回砲塔自走砲**: 343マス盤面において、突撃する友軍の移動方向や突如現れた側面の敵に対し、砲塔旋回のみで即座に射撃諸元を修正して間接・直接射撃を実施可能。
   - **210C車体据付超重砲**: 射角は限定されるものの、駐退スペードを展開した後に撃ち出される破壊力は別格。エイリアンの超大型生体建造物、硬化防壁、地下要塞巣穴をブロックごと破砕する「決戦攻城砲」として機能する。
2. **下車8名固定制によるゲームバランスと編成ロジックの明快化**:
   - IFVでもAPCでも「1両から展開する下車歩兵は8名（1個分隊）」に固定されるため、サブタイル戦闘での分隊管理・スタック処理・下車戦闘AIの設計が極めてシンプルかつ堅牢。
3. **対空車両の多層配備（3階層防空）**:
   - 最前線は「自走対空戦車（SPAAG）」が低空ドローンやCASを機関砲撃墜。中距離・高空は「重装輪SAM」が師団全体をアンブレラ防護。司令部や後方拠点は「4×4近接即応SAM」が局所防衛を担当。
4. **師団自前の輸送飛行隊（8機）による即応衛生後送・補給**:
   - 各師団が自前の輸送飛行隊（8機）と患者輸送車（AME）を連携させ、前線から師団野戦病院への迅速な患者後送（MEDEVAC）を実施。兵員損耗率を低減。
5. **軍団航空隊（4個飛行隊・32機）の集中運用**:
   - 重大な作戦局面において、軍団直轄の戦闘飛行隊2個（16機）と強襲輸送飛行隊2個（16機）を主攻軸へ一挙集中投入可能。
6. **サブタイル戦術戦闘（343マス盤面）への展開**:
   - 親タイル交戦時、第1師団の地上部隊・戦車車体自走砲・輸送ヘリがまず盤面へ展開。
   - 続いて第2師団が相互躍進または側面から展開し、軍団司令部から割り振られた軍団航空隊が上空から直協支援・阻止攻撃・大規模ヘリボーンを実施する。
7. **兵站と損耗のダイナミクス**:
   - 軍団コマが補給動脈から切断された場合、各師団の兵站・回収大隊および軍団重兵站群が連動し、共通パーツの融通による「師団間・ファミリー間共食い整備」が発生。
   - 1個師団が激しく損耗しても、もう1個師団を盾にして後退・再編する「軍団内リソース交代」が自律的に実行される。
