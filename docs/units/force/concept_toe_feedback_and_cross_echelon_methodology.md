# 部隊編成（TO&E）水平展開・フィードバック手法および共通編制評価基準書

(Methodology for TO&E Cross-Variant Feedback & Architectural Harmonization)

本ドキュメントは、[`toe_corps_heavy_armored.md`](../toe/ground/regular/toe_corps_heavy_armored.md) および [`concept_corps_and_division_echelons.md`](./concept_corps_and_division_echelons.md) において確立された**「常設増強軍団（2個師団統合制）」の詳細な編制・兵科分担・迫撃火力ドクトリン・左右両翼スクリーン・プラットフォーム共通化思想・戦車車体自走重砲・2層航空運用**を、[`concept_corps_variants.md`](./concept_corps_variants.md) や [`concept_military_echelon_and_combat_groups.md`](./concept_military_echelon_and_combat_groups.md) に定義されている**他のすべての編成（空中機動、二脚混成、装輪機動、歩兵多層エシュロン等）へ体系的かつ破綻なく水平展開（フィードバック）するための評価基準および改定手順**を定義する。

## 1. フィードバックの基本理念（Horizontal Harmonization Principles）

常設増強軍団モデルで得られた知見を他部隊へ適用する際、**「重機甲軍団の単なる縮小コピーや兵器の置き換え」を行ってはならない**。各軍団アーキタイプが投入される作戦環境（山岳、空中機動、道路動脈、バイオーム等）固有の制約と強みを尊重し、以下の原則に基づき**等価な戦術機能の再定義（Functional Equivalency）**を行う。

## 2. 共通フィードバック評価軸（Audit Checklist）

各編成を点検・改定する際、以下のチェックリストに照らして整合性を検証する。

### 軸1: 軍団階層構造（2個師団統合 ＋ 軍団直轄 ＋ 2層航空）

- **軍団システムの原則**:
  - 大戦略1コマは「軍団司令部・軍団直轄航空隊（32機: 戦闘16＋強襲輸送16）・重兵站群」と、「第1師団（主攻）」「第2師団（助攻）」の2個師団から構成される。
  - 各師団は正面4個戦闘機動連隊に加え、自前の「師団輸送飛行隊（8機）」を持ち、即応MEDEVACと補給を自前完結する。
- **他編成への適用基準**:
  - **空中機動軍団**: 2個空中機動師団（各強襲航空旅団64機）＋軍団直轄航空打撃群（48機）。
  - **装輪機動軍団 / 二脚混成軍団**: 各師団正面4連隊＋師団輸送飛行隊（各8機）＋軍団航空隊（32機）。
  - **地域防衛・警備軍団管区**: 第1警備師団（中枢防衛）＋第2警備師団（動脈防衛）の2個師団管区制。

### 軸2: 下車歩兵「固定8名分隊制」の標準化

- **原則**:
  - IFV・APCから展開するライフル分隊は一律「8名固定（1個完全分隊）」。
  - 歩兵車両の定員設計、サブタイル戦術戦闘（343マス）でのスタック処理、下車戦闘AIを完全規格化。

### 軸3: 迫撃砲・曲射火力ドクトリン（大隊集約 vs 分散の必然性）

- **機甲・機械化部隊の原則**:
  - 小隊・中隊単位で機動性を殺す90C中迫撃班は全廃。各大隊直轄「120C自走重迫中隊（16両）」に集中運用。
- **他編成への適用基準**:
  - **装輪機動軍団 / 二脚混成軍団**: 重機甲と同様に「各大隊付120C自走重迫中隊（16両）」へ統一（装輪自走迫、または二脚アンカー自走迫）。
  - **空中機動軍団**: 超軽量車台の「空挺自走迫（120C）16両」へ集約。
  - **山岳猟兵部隊（例外承認基準）**:
    - 車両が進入不能な岩盤・断崖登攀を行う下車戦闘部隊に限り、大隊迫撃砲（120C固定アンカー座）とは別に「中隊付90C中迫」「小隊付60C軽迫」の分散配備を正当なドクトリン例外として認める。

### 軸4: 側翼保護スクリーン（Recon Combat Screen）の環境的等価物

- **重機甲の原則**:
  - 各師団の側翼に高速装輪車両による「偵察戦闘連隊（80両: 迫撃16両内包）」を配備し、遅滞戦闘を自活。
- **他編成への適用基準**:
  - **装輪機動軍団**: 全軍が装輪であるため、師団ごとに「前衛偵察戦闘連隊」および「後衛・側衛警備連隊」として高速車列を多軸保護。
  - **空中機動軍団**: 装輪車両が随伴できないため、側翼スクリーンを「航空ISR飛行隊（UAV）＋戦闘ヘリペアによる広域滞空監視ライン」に置換。
  - **山岳猟兵軍団**: 小型多脚自律斥候犬（UGV 64機）とマイクロドローンによる「断崖・隘路の多層センサー・トラップ網」を側翼スクリーンとして機能させる。
  - **二脚混成軍団**: 装輪偵察戦闘連隊（各師団80両）を踏襲し、二脚部隊の低い航続距離と舗装路利用不能の弱点を装輪部隊が外側から包み込んで保護。

### 軸5: 突破（Breakthrough）と確保・掃討（Secure & Clear）の分離

- **原則**:
  - 主力突破部隊（戦車/火力）が突入した直後、後方の巣穴・拠点を装甲歩兵部隊（IFV/APC）が掃討・要塞化し、主隊の進撃を止めない均等ペア構成。

### 軸6: 車体・機体プラットフォーム共通化（共食い整備ライン）

- **原則**:
  - **重機甲**: MBT専用車体 ＋ IFV/APC共通中重装軌車体（Std-T4）。
  - **装輪機動**: 共通8x8装輪車台（Std-W8）による単一ファミリー化（共通化率95%）。
  - **二脚混成**: 二脚機体同士で脚部アクチュエータ・動力コアを共通化（80%以上）。随伴装軌車台（Std-T4）との二分化。

## 3. 現行TO&Eバリエーションに対する診断・改定マトリクス

[`concept_corps_variants.md`](./concept_corps_variants.md) に記載されている編成について、軍団システムを適用した改定内容を示す。

| 軍団アーキタイプ | 軍団システム適用・改定内容 |
| :--- | :--- |
| **空中機動・空地強襲軍団** | ・**2個空中機動師団統合型軍団（総員約2.8万人、航空機計176機）**へ改定。・各師団に強襲航空旅団（64機）＋師団輸送ヘリ（8機）、軍団直轄航空隊（48機）。山岳・森林・離島等の険峻地形制圧を主担。 |
| **高級装甲・二脚歩行混成軍団** | ・**2個混成師団統合型軍団（総員約4.2万人、二脚256機）**へ改定。・第1師団（主攻）＋第2師団（助攻）。各師団に160C旋回砲塔砲／210C車体据付砲。軍団直轄に大型二脚回収ARV群および軍団航空隊（32機）。 |
| **装輪機動軍団** | ・名称を**「装輪機動軍団」**に完全統一。・**2個装輪師団統合型軍団（総員約3.2万人、Std-W8約1,500両）**へ改定。・第1師団（打撃2＋歩兵1＋前衛警備1）＋第2師団（打撃2＋歩兵1＋後衛警備1）。全車8x8装輪ファミリー（160C装輪榴弾砲、8x8自走迫120C、8x8防空）。各師団輸送ヘリ8機＋軍団航空隊32機。 |
| **装甲化軍団** | ・戦車2個連隊＋装輪偵察2個連隊＋装甲歩兵2個連隊を基幹とするバランス型打撃軍団。・平原・丘陵での快速進撃・側側翼掩護・警戒斥候を主眼とし、常設増強機甲軍団より機動性と展開速度を向上。 |
| **歩兵多層エシュロン***(Tier 1〜Tier 6)* | ・固定的な地域防衛軍団を廃止し、部隊の装備・車両化レベルを多層化。・Tier 1（純軽歩兵：山岳登攀・森林踏破）、Tier 2（軽装輪自動車化）、Tier 3（装甲車化歩兵）等、任務・地形に応じた柔軟な編制を採用。 |

## 4. ドキュメント改定・維持管理プロトコル（Update Protocol）

編成仕様の不整合を防ぐため、今後のドキュメント更新は以下のプロトコルを順守する。

1. **軍団システム基準の先行確定**:
   - 1ユニット＝2個師団1軍団制、固定8名分隊制、戦車車体自走重砲、多層防空、2層航空運用を前提基準とする。
2. **マスターTO&E（重機甲軍団）の照合**:
   - [`toe_corps_heavy_armored.md`](../toe/ground/regular/toe_corps_heavy_armored.md) において完全な軍団規模の諸元を実証・維持する。
3. **バリエーションTO&Eへの水平展開**:
   - [`concept_corps_variants.md`](./concept_corps_variants.md) および各個別仕様書（`toe_corps_<type>.md`）を順次軍団編成へ改定する。
