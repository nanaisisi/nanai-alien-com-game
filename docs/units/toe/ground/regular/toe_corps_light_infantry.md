# 軽歩兵軍団 詳細編成・運用仕様書 (Light Infantry Corps TO&E)

(Tier 1 軽歩兵軍団 専門編制仕様)

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../../GAME_DESIGN.md)、[`../../../force_structure/concept_military_echelon_and_combat_groups.md`](../../../force/concept_military_echelon_and_combat_groups.md)、[`../../../force_structure/concept_corps_and_division_echelons.md`](../../../force/concept_corps_and_division_echelons.md)、および [`../../../force_structure/concept_corps_variants.md`](../../../force/concept_corps_variants.md) に基づき、車両が進入不能な山岳、隘路、断崖、密林環境を踏破・浸透・制圧する**「軽歩兵軍団（Light Infantry Corps / Tier 1 / 2個師団統合型）」**の戦闘序列（TO&E）、徒歩行軍特性、分解搬送式火力ドクトリン、および山岳物資空輸運用を規定する個別仕様書である。

---

## 1. 概要と戦略的位置づけ

- **定員規模**: 総員 約24,000名、地上車両 0両（完全徒歩行軍）、軍団航空機 計48機（軍団直轄32機 ＋ 師団輸送各8機×2）。
- **編成の核心思想**:
  - **極限地形の踏破能力**:
    - 車両が進入できない急峻な山岳地帯、深い森林、洞窟群、湿地帯を燃料消費ゼロで踏破可能。
    - 敵のレーダー・熱源探知を極限まで低減した隠密浸透・ゲリラ的奇襲に優れる。
  - **平地・正面打撃力の限界**:
    - 戦車や装甲車両を持たないため、平地や幹線道路での機動力・正面装甲防護力は最低クラスであり、重機甲部隊や大型エイリアンの正面突撃には極めて脆弱。

## 3. 作戦特性と運用ルール

1. **地形適性と機動**:
   - 森林・山岳タイルでの移動コスト増加を受けず、インフラ断絶時でも物資駄載・人力輸送により自活行軍が可能。
2. **分散迫撃砲ドクトリン（正当な例外）**:
   - 本部管理中隊・自走迫撃砲に火力を集約する機甲部隊とは異なり、急峻な岩盤・断崖登攀を行う下車戦闘のため、大隊・中隊・小隊レベルでの分解搬送式迫撃砲（60C/81C）の分散配備が正式に認められている。
3. **軍団航空隊による補給・退路確保**:
   - 地上兵站線が遮断されても、師団輸送飛行隊（8機×2）および軍団航空隊（32機）による空中投下・MEDEVACにより孤立拠点の維持が可能。
