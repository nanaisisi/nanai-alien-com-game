# 装甲化軍団（諸兵科連合装甲軍団）詳細編成・運用仕様書 (Armored Corps TO&E)

(Tier 5 諸兵科連合装甲軍団 専門編制仕様)

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../GAME_DESIGN.md)、[`../../../force_structure/concept_military_echelon_and_combat_groups.md`](../../../force_structure/concept_military_echelon_and_combat_groups.md)、[`../../../force_structure/concept_corps_and_division_echelons.md`](../../../force_structure/concept_corps_and_division_echelons.md)、および [`../../../force_structure/concept_corps_variants.md`](../../../force_structure/concept_corps_variants.md) に基づき、主力戦車2個連隊、広大な左右両翼スクリーン（装輪偵察2個連隊）、および装甲化歩兵2個連隊を統合した高機動バランス型打撃部隊**「装甲化軍団（Armored Corps / Tier 5 / 2個師団統合型）」**の詳細な戦闘序列（TO&E）、諸兵科連合運用、および作戦ドクトリンを規定する個別仕様書である。

---

## 1. 概要と戦略的位置づけ

- **部隊規模**: 総員 約26,000名、戦闘・支援車両 約1,200両（主力戦車 128両、装軌IFV 128両、装甲APC 128両、120C自走重迫撃砲 128両、8x8装輪偵察・戦闘車 160両、軍団直轄航空隊 32機、師団輸送飛行隊 16機［計48機］）。
- **編成の核心思想**:
  - **突破・索敵・面制圧の最高バランス（戦車2＋装輪2＋装甲歩兵2）**:
    - 戦車4連隊（256両）を集中投入する重機甲軍団（Tier 6）の重厚な正面突破力に対し、本軍団は**「戦車2個連隊（第1・第2連隊） ＋ 装輪偵察2個連隊（左右両翼スクリーン160両） ＋ 装甲歩兵2個連隊」**で構成される機動バランス型部隊。
    - 各師団が「戦車1個連隊（戦車64両＋IFV64両） ＋ 装甲歩兵1個連隊（IFV64両＋APC64両） ＋ 装輪偵察戦闘1個連隊（80両） ＋ 特科連隊 ＋ 高射連隊」を保有。
  - **広域両翼スクリーンと即応機動**:
    - 左右両翼に配置された計160両の高速8x8装輪部隊が広大な索敵警戒線を展開し、敵の包囲を警戒しつつ主隊の進撃軸を誘導。
    - 平野部から丘陵地帯、幹線道路、市街戦に至るあらゆる戦局に即応し、常設増強機甲軍団よりも迅速な展開速度と低い兵站負荷を実現。

## 3. 作戦特性と運用ルール

1. **機甲と装輪の協同作戦**:
   - 重戦車による突破力と、装輪偵察による長距離機動スクリーニングが完璧に調和。
2. **重機甲軍団（Tier 6）との差別化**:
   - 戦車の集中運用数ではTier 6（256両）に譲るものの、展開の柔軟性と燃費・兵站継続性において優位に立ち、長期遠征作戦において主力を担う。
