# 装輪機動軍団 詳細編成・運用仕様書 (Wheeled Mobile Corps TO&E)

本ドキュメントは、[`../../../force_structure/concept_military_echelon_and_combat_groups.md`](../../../force_structure/concept_military_echelon_and_combat_groups.md)、[`../../../force_structure/concept_corps_and_division_echelons.md`](../../../force_structure/concept_corps_and_division_echelons.md)、および [`../../../force_structure/concept_toe_feedback_and_cross_echelon_methodology.md`](../../../force_structure/concept_toe_feedback_and_cross_echelon_methodology.md) に基づき、幹線道路網・舗装動脈を利用して戦域へ電撃的に自走急行・緊急展開する**「装輪機動軍団（Wheeled Mobile Corps / 2個師団統合型）」**の詳細な戦闘序列（TO&E）、単一8x8装輪車台ファミリー共通化、打撃連隊と装輪歩兵連隊の各師団4連隊構成、固定8名下車分隊制、および2層航空運用を規定する個別仕様書である。

## 1. 装輪機動軍団の概要と戦略的位置づけ

- **部隊規模**: 総員 約32,000名、8x8装輪装甲車台（Std-W8）約1,500両、軍団直轄航空隊 32機、師団輸送飛行隊 16機（計48機）。
- **編成の核心思想**:
  - **1ユニット＝2個師団統合軍団制**:
    - 大戦略マップの1コマは【第1装輪機動師団（主攻）】と【第2装輪機動師団（助攻・相互躍進）】の2個師団、および軍団司令部・軍団航空隊（32機）・重兵站群で構成。
    - 各師団の正面戦力は4個戦闘機動連隊（打撃連隊×2 ＋ 装輪歩兵連隊×1 ＋ 前衛・側衛警備連隊×1）。
  - **全車共通の単一装輪プラットフォーム（Std-W8ファミリー）**:
    - 火力支援車（105C）、歩兵戦闘車（25C機関砲）、装甲兵員輸送車（APC）、自走重迫（120C）、自走榴弾砲（160C）、自走高射機関砲、ARV、指揮車のすべてが同一の8x8装輪車台から派生。
    - 部隊全体の部品共通化率は95%、前線共食い整備成功率は90%に達し、軍団全体の兵站負荷を極限まで低減。
  - **下車歩兵8名固定制（乗員＋8名下車）**:
    - 装輪IFV（乗員3＋下車8）および装輪APC（乗員2＋下車8）ともに下車歩兵を8名完全分隊に統一。
  - **舗装動脈での超高速自走展開（時速80〜100km）**:
    - 重戦車トランスポーターや鉄道牽引に依存せず、軍団全車両が自力で幹線道路を自走し、遠隔地や国境危機正面へ数時間〜数ターンで急行。
  - **各大隊付装輪120C自走重迫中隊（16両）の標準配備**:
    - 各大隊が自前の自走重迫（16両）を保有。遭遇戦において師団特科の展開を待たずに即座に煙幕スクリーンと大口径曲射弾幕を展開可能。
  - **軍団航空隊（32機）と師団輸送飛行隊（8機×2）の2層航空運用**:
    - 軍団長の手元に戦闘ヘリ16機＋強襲輸送ヘリ16機を集中配備し主攻軸を空地支援。各師団には自前の輸送ヘリ8機を常備し衛生後送（MEDEVAC）を自律遂行。

## 3. 兵站・共食い整備互換性グループ

| 互換性グループ | 該当部隊 | 車台系統 | 共食い成功率 | 主な融通パーツ |
| :--- | :--- | :--- | :---: | :--- |
| **装輪共通系 (Std-W8)** | 火力戦闘車、IFV、APC、自走迫、特科、高射、ARV | 8x8装輪 (Std-W8) | **90%** | ランフラットタイヤ、全輪独立懸架サスペンション、ドライブシャフト、民間共通ディーゼルエンジン、ステアリングギア |
| **回転翼航空系** | 軍団直轄航空隊（32機）＋ 師団輸送飛行隊（16機） | 航空 (Aero) | **70%** | タービンエンジン、トランスミッション、ローター部品 |
