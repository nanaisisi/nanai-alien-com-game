# 中型エイリアン軍団 詳細編成・生態仕様書 (Medium Alien Swarm Corps TO&E)

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../GAME_DESIGN.md) のセクション 3.1.2 に基づき、カマキリ状の中型格闘種を中核とし、軽装甲化部隊の粉砕や装甲車両の制圧を担う**「中型エイリアン軍団（Medium Swarm Corps）」**の編制体系、個体生態、および破壊メカニクスを規定する個別仕様書である。

---

## 1. 概要と生態ドクトリン

- **部隊規模**: 中型格闘種 数千頭 ＋ 随伴小型格闘種 1万〜2万頭。
- **作戦上の位置づけ**:
  - 人類の軽装甲車（4x4 LAV）や装甲車（IFV/APC）に対抗する主力格闘軍団。
  - バランスの取れた突撃力・装甲耐久力を持ち、拠点の力押し制圧や前線突破の要となる。
- **威力階層と破壊時間（厳格な原則）**:
  - **原則**: 「**大型格闘種にできないことは中型格闘種にもできない**」。
  - **対戦車**: 主力戦車の重装甲は**破壊不能**。組み付いても装甲を貫通できず撃破される。
  - **対装甲車（IFV/APC）**: 一撃破壊はできず、**破壊するのに長い時間がかかる**。装甲板に張り付き、複数の鎌腕でハッチや装甲継ぎ目を徐々にこじ開けて制圧する。
  - **対軽装甲車（4x4 LAVやトラック）**: **短時間で切り裂き・解体・破壊**が可能。

## 3. 構成個体スペックと戦闘メカニクス

### 3.1 中型格闘種 (Medium Mantis Beast)

- **体格**: 装甲車大（全長4〜6m、全高2.5〜3.5m、重量3〜6トン）。
- **特徴**:
  - 戦車型より一回り小さいカマキリ状の多脚格闘怪獣。
  - 機関砲等の射撃兵器は持たず、純粋な生体格闘戦に特化。
  - 前脚の巨大なキチン質鎌腕は油圧プレスのごとき破砕力を誇り、4x4軽装甲車（LAV）の外板なら瞬く間に切り裂く。
  - IFV/APCに対しては複数頭で取り付き、車体を揺さぶりながらハッチやペリスコープを破壊して無力化する。

### 3.2 中型対空種 (Medium Bio-AA Beast)

- **体格**: 中型クラス（装甲車大）。
- **兵装**:
  - **生体機関砲（近接信管砲弾）**: 目標の予測針路上で破片弾幕を形成。
  - **生体ミサイル**: 背部の筋肉嚢胞から高機動追尾型の自律生体弾（熱源・電波ホーミング）を発射。
- **役割**: 敵の近接航空支援（CAS）や攻撃ヘリを迎撃し、突撃する中型群の上空防護を完遂。

### 3.3 治療種 (Healing / Regeneration Beast)

- **役割**: 突撃で被弾・損傷した中型格闘種の甲殻に再生液を噴霧し、戦闘継続力を維持。

## 4. 作戦特性・運用ルール

1. **軽装甲部隊に対する絶対的優位**:
   - 4x4 LAVや牽引砲部隊（Tier 2/3）と正面交戦した場合、素早い格闘突撃で車列を寸断・短時間で解体する。
2. **装甲化部隊との膠着戦**:
   - IFV/APCに対しては破壊に時間を要するため、敵歩兵部隊の下車戦闘や機関砲掃射との激しい消耗戦となる。
3. **主力戦車に対する無力化**:
   - 主力戦車と正面対決した場合、中型種の鎌腕では装甲を抜けず、戦車の120C主砲や同軸機銃によって返り討ちに遭う。
