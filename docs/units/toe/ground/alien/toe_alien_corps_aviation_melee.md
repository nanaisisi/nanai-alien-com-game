# 陸棲航空格闘軍団 詳細編成・生態仕様書 (Aviation Melee Alien Swarm TO&E)

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../GAME_DESIGN.md) のセクション 3.1.2 に基づき、有翼の格闘型飛行生物により構成され、敵地上部隊の頭上へ低空急降下して近接格闘襲撃を仕掛ける陸棲航空部隊**「陸棲航空格闘軍団（Aviation Melee Swarm）」**の編制体系、飛行生態、および襲撃メカニクスを規定する個別仕様書である。

---

## 1. 概要と生態ドクトリン

- **部隊規模**: 陸棲航空型（飛行格闘種） 数千頭 ＋ 補助飛行個体群。
- **作戦上の位置づけ**:
  - 地上戦力の一翼として配備される急降下格闘航空部隊。
  - 戦車や装甲車両の最も装甲が薄い「上面（ルーフ）」や砲塔ハッチ、下車歩兵を直接襲撃する。
- **制空権と任務の厳格な分離**:
  - **制空権確保は空棲種（エイリアン航空団）の役割**:
    - 本部隊は高高度でのドッグファイトや制空戦闘（人類の戦闘航空団との交戦）を任務としない。
    - あくまで地上部隊を直接支援するための「**地上部隊への近接空中格闘・奇襲**」に特化した有翼生物部隊である。

## 3. 構成個体スペックと戦闘メカニクス

### 3.1 陸棲航空型（飛行格闘種） (Aviation Melee Flyer)

- **体格**: 有翼飛行型（全長6〜9m、翼幅10〜15m、重量2〜4トン）。
- **特徴**:
  - コウモリやワイバーンを思わせる骨格と強靭な皮膜翼を持つ飛行生物。
  - **急降下格闘襲撃**:
    - 高空から一気に垂直急降下し、地上部隊の頭上に突入。
    - 装甲車両の天板（上面装甲）に鋭い爪とカマキリ状鎌腕を突き立て、ハッチを切り裂き、車載機銃やアンテナを薙ぎ払う。
    - 下車歩兵に対しては、低空を滑空しながら爪で薙ぎ倒して捕食・殺傷する。
  - **対空能力の限定**:
    - 空中戦（格闘空戦）の能力は低く、敵の大型制空戦闘機に後方から狙撃された場合は一方的に撃墜される。

### 3.2 低空対空牽制種 (Low-Altitude Suppressor)

- **体格**: 小型〜中型有翼種。
- **役割**: 敵地上部隊の高射機関砲（高射連隊の35C自走高射機関砲など）の砲身に体当たりしたり、酸を吹きかけて照準器を奪い、主力の急降下を支援。

### 3.3 飛翔治療種 (Flying Parasitic Healer)

- **役割**: 飛行怪獣の背部に寄生し、対空砲火で穴の空いた翼膜や甲殻を素早く分泌液で塞ぎ、飛行能力の喪失を防ぐ。

## 4. 作戦特性・運用ルール

1. **ルーフ（上面装甲）攻撃のボーナス**:
   - 地上戦車の強固な前面装甲を無視し、最も脆弱な上面装甲に対して直接ダメージを与えるため、人類の重戦車に対しても高いダメージ効率を誇る。
2. **高射機関砲・多層対空網への脆弱性**:
   - 人類の装甲軍団・機甲軍団に配備されている「高射連隊（35C自走高射機関砲・CIWS）」の近接防空火網に突入すると、急降下中にミンチ状に粉砕され壊滅的損害を受ける。
3. **山岳・隘路での奇襲適性**:
   - 谷間や断崖の陰から突如として低空出現し、敵の対空レーダーの死角を突いて急襲する戦法を得意とする。
