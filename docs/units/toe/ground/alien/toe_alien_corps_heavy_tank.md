# 大型エイリアン軍団 詳細編成・生態仕様書 (Heavy Tank-Beast Corps TO&E)

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../../GAME_DESIGN.md) のセクション 3.1.2 に基づき、主力戦車に匹敵する巨体と重装甲を持つ「戦車型（大型格闘種）」を基幹とし、人類の機甲軍団・装甲化軍団と泥沼の決戦を繰り広げる**「大型エイリアン軍団（Heavy Tank-Beast Corps）」**の編制体系、個体生態、および破壊メカニクスを規定する個別仕様書である。

---

## 1. 概要と生態ドクトリン

- **部隊規模**: 戦車型（大型格闘種） 数百〜1,000頭 ＋ 中型格闘種 数千頭 ＋ 随伴小型種 数万頭。
- **作戦上の位置づけ**:
  - 人類の常設増強機甲軍団（Tier 6）や装甲化軍団（Tier 5）に正面から激突する主力決戦部隊。
  - 重厚な生体装甲と圧倒的な質量で敵前線を突破・圧壊する。
- **破壊メカニクスと交戦時間**:
  - **戦車型は一撃必殺の超兵器ではない**:
    - 主力戦車を一撃で粉砕・爆散させるような非現実的な攻撃力は持たない。
    - **「敵戦車に組み付き、長い時間を掛けて強靭な鎌腕と顎で装甲板を切り刻み・こじ開けて破壊する」**。
  - **泥沼の格闘戦**:
    - 人類戦車隊のゼロ距離射撃や榴弾砲兵の至近弾に晒されながらも、頑強なキチン殻で耐え忍び、乱戦の中でじわじわと敵装甲車両を圧壊・解体していく。
  - **対装甲車（IFV/APC）**:
    - 中型種よりも遥かに短い時間で装甲車を叩き潰し、乗員と下車歩兵を排除可能。

## 3. 構成個体スペックと戦闘メカニクス

### 3.1 戦車型（大型格闘種） (Heavy Tank Mantis Beast)

- **体格**: 主力戦車大（全長7〜9m、全高3.5〜4.5m、重量40〜60トン）。
- **特徴**:
  - 超大型昆虫・甲殻類を想起させる巨大なカマキリ状生体兵器。
  - **重層キチン複合甲殻**: 人類の120C徹甲弾（APFSDS）の直撃にも耐える傾斜生体装甲を持つ。
  - **超硬質大鎌腕**: 特殊な金属濃縮結晶を含む鎌腕。敵戦車に飛び乗り・抱え込み、油圧のごとき膂力で装甲板の溶接部やハッチを力任せに切り裂き、こじ開ける。破壊には数分〜十数分の継続接触時間を要する。
  - **格闘専従**: 火器は一切持たず、突進による体当たりと近接解体のみを行う。

### 3.2 大型対空種 (Heavy Bio-AA Beast)

- **体格**: 大型クラス（全長6〜8m、重量30トン級）。
- **兵装**:
  - **大口径生体機関砲**: 40mm相当の高圧生体破片弾を高速連射。濃密な近接信管弾幕により敵CAS機・大型爆撃機の投下コースを破断。
  - **自律追尾生体ミサイル**: 胴体背部の発射孔から熱源・電波・光波を複合探知する誘導生体弾を複数斉射。
- **役割**: 機甲軍団の頭上を覆う敵航空戦力を排除し、泥沼の地上戦空間を維持。

### 3.3 大型治療種 (Heavy Regeneration Beast)

- **体格**: 大型（重量20トン級）。
- **役割**: 大量の再生生体ゼリーを分泌・噴霧し、被弾した戦車型の甲殻欠損を急速に埋め戻す。

## 4. 作戦特性・運用ルール

1. **機甲軍団との正面衝突**:
   - 人類の機甲軍団（戦車4連隊）と正面から激突した場合、極めて高い損害率を出し合いながらも、近接乱戦に持ち込むことで人類側の遠距離射撃優位を無効化する。
2. **時間の経過と装甲破壊**:
   - 戦車型が敵戦車に接触し続ける限り、装甲破壊ゲージが蓄積し、一定時間後に戦車を確実に無力化・解体する。
3. **随伴歩兵・IFVの排除が鍵**:
   - 人類側が随伴歩兵（IFV/下車小隊）による近接対戦車援護を展開している場合、戦車型は集中攻撃を受ける。そのため、随伴の中型・小型種が敵歩兵をいかに迅速に掃討できるかが勝敗を分ける。
