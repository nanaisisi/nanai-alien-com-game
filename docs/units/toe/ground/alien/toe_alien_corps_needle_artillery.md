# 長距離砲撃軍団 詳細編成・生態仕様書 (Long-Range Needle Artillery Corps TO&E)

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../GAME_DESIGN.md) のセクション 3.1.2 に基づき、超大型ニードル砲撃種を中核とし、遠距離からミサイル程度の巨大生体棘弾（ニードル）を放物線投射する野生エイリアンの支援部隊**「長距離砲撃軍団（Long-Range Needle Artillery Corps）」**の編制体系、生態スペック、および投射メカニクスを規定する個別仕様書である。

---

## 1. 概要と生態ドクトリン

- **部隊規模**: 超大型ニードル砲撃型 数十頭 ＋ 護衛群（中型格闘種 数百頭、小型種 数千頭）。
- **作戦上の位置づけ**:
  - 人類の長距離自走榴弾砲やミサイル部隊に対抗し、遠距離から敵陣地や前線部隊へ放物線砲撃を行う支援部隊。
  - 大戦略マップ上で長距離の火力投射を担当する。
- **威力特性と制約（厳格な原則）**:
  - **「巨体の割にはミサイル程度の威力しかない」**:
    - 全高20m級の超大型種であるが、発射されるニードル弾は人類の巡航ミサイルや大型ロケット弾と同程度の威力に留まる。
    - 惑星破壊や要塞一撃消滅のような超絶威力ではなく、長射程による散発的な嫌がらせ、後方兵站線の攪乱、敵前線部隊への牽制が主目的。

## 3. 構成個体スペックと戦闘メカニクス

### 3.1 超大型ニードル砲撃型巨獣 (Titan Needle Artillery Beast)
- **体格**: タイタン級（全高18〜22m、全長35〜50m、重量250〜400トン）。
- **特徴**:
  - 胴体中央部に天を仰ぐ長大な生体発射筒（生体砲身）を持つ巨獣。
  - **発射メカニクス**:
    - 高圧ガス嚢と強力な筋収縮により、体内で結晶化した巨大な有機骨棘（全長3〜5mの生体ニードル弾）を斜角投射。
    - 放物線軌道を描いて数十キロメートル先（隣接〜遠隔タイル）へ着弾。
  - **威力水準**:
    - 巨躯から期待されるような戦略核並みの威力はなく、**「大型対地ミサイルと同程度」**。
    - 着弾時に強酸と破片を撒き散らし、非装甲目標や陣地を破壊するが、重装甲戦車の正面装甲を一撃で貫徹することはできない。
  - **接近戦の脆弱性**:
    - 接近戦能力は極めて低く、敵の機甲部隊や歩兵部隊に肉薄された場合は自衛できない。

### 3.2 陣地防空対空種 (Artillery Site AA)
- **兵装**: 近接信管生体弾幕砲、自律生体ミサイル。
- **役割**: 砲撃位置から移動できないニードル巨獣を敵の空爆・対地攻撃ヘリから徹底防衛。

### 3.3 治療種 (Healing / Cooling Beast)
- **役割**: ニードル発射時の摩擦熱や反動で傷んだ発射腔組織に冷却液と再生ゼリーを注入。

## 4. 作戦特性・運用ルール

1. **スタンドオフ遠距離支援**:
   - 自らは後方タイルや険しい谷間に陣取り、前線で交戦中の「大型エイリアン軍団」や「中型エイリアン軍団」の頭上を越えて敵前線・後方補給路へ砲撃支援を行う。
2. **カウンターバッテリー（対砲兵射撃）への警戒**:
   - 人類の長距離自走榴弾砲（155C）や長距離ミサイル打撃軍団の精密対地ミサイルによる反撃を受けると、巨体ゆえに回避できず大損害を被る。
3. **護衛群への依存**:
   - 接近戦格闘能力が皆無に近いため、護衛の中型・小型格闘種が壊滅した場合、容易に掃討される。
