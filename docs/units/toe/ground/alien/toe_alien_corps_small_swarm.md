# 小型エイリアン軍団 詳細編成・生態仕様書 (Small Alien Swarm Corps TO&E)

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../GAME_DESIGN.md) のセクション 3.1.2 に基づき、野生・固有エイリアンのうち小型格闘種が津波のように押し寄せる軽量スウォーム軍団**「小型エイリアン軍団（Small Swarm Corps）」**の編制体系、個体生態、および戦闘規則を規定する個別仕様書である。

---

## 1. 概要と生態ドクトリン

- **部隊規模**: 小型格闘種 数万頭規模の超高密度スウォーム集団。
- **作戦上の位置づけ**:
  - 急峻な山岳地帯、密林、洞窟群、都市廃墟などの不整地を自在に移動・浸透。
  - レーダーや赤外線センサーに対する単体シグネチャは極めて小さいが、数千〜数万頭のフェロモン連鎖と群体機動により敵防衛線の間隙を突破。
- **戦闘能力の限界と特性**:
  - **対装甲目標**: 装甲車（IFV/APC）や主力戦車の重装甲には刃が立たず、装甲表面を引っ掻く程度で破壊することはできない。
  - **対軽装甲・歩兵目標**: 非装甲トラック、陣地内の下車歩兵、観測班、補給輜重隊に対して圧倒的な殺傷力と足止め能力を発揮する。

## 3. 構成個体スペックと戦闘メカニクス

### 3.1 小型格闘種 (Small Melee Beast)
- **体格**: 人馬〜軽車両大（全高1.2〜1.8m、重量200〜500kg）。
- **特徴**:
  - 四肢または六肢による高速歩行・跳躍能力。岩盤登攀・森林樹上移動が可能。
  - 鋭利なキチン質爪と二重鎌腕による近接斬撃。
  - 銃弾に対する耐性は個体としては低いが、高密度な群れによって敵の火力を飽和させる。

### 3.2 小型対空迎撃種 (Small Bio-AA Variant)
- **体格**: 中型寄りの小型種（全高約2m）。
- **兵装**: **生体機関砲（近接信管砲弾）**。
- **役割**:
  - 航空機や攻撃ヘリに一方的に蹂躙されるのを防ぐ例外能力。
  - 上空に向けて高圧ガスで生体破片弾を斉射し、目標近傍で炸裂させて破片弾幕を展開。

### 3.3 治療種 (Regeneration Beast)
- **役割**:
  - 酸分泌腔から高活性タンパク質・硬化分泌液を噴出し、損傷した小型個体の甲殻・筋繊維を急速に自己修復・再生させる。

## 4. 作戦特性・運用ルール

1. **地形無視と不整地機動**:
   - 森林・山岳・湿地タイルでの移動コスト増加を受けず、車両進入不能タイルにも進入可能。
2. **包囲・足止め効果**:
   - 戦車などの重装甲目標を破壊することはできないが、履帯への絡みつき、ペリスコープ・センサーの汚損、随伴歩兵の排除により、敵部隊の行動力を著しく奪う。
3. **指揮種の排除**:
   - 指揮官個体は存在せず、群れ全体のフェロモン連鎖により自律行動するため、中枢狙撃による部隊瓦解は発生しない。
