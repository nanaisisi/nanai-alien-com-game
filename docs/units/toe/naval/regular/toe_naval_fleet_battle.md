# 通常艦隊 詳細編成・運用仕様書 (Standard Battle Fleet TO&E)

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../../GAME_DESIGN.md) のセクション 3.2.1 に基づき、人類正規海軍の外洋主力戦闘部隊**「通常艦隊（Standard Battle Fleet）」**の編制序列（TO&E）、艦艇スペック、内部2進数制エシュロン、および作戦規則を規定する個別仕様書である。

---

## 1. 概要と戦略的位置づけ

- **艦隊規模**: 計62隻 ＋ 艦載機32機、総員 約10,400名。
- **作戦上の位置づけ**:
  - 外洋における水上打撃戦、制海権掌握、シーレーン確保、および沿岸火力支援を担当する主力戦闘艦隊。
  - 2隻の全通甲板小型空母（計32機運用）による直協制空・索敵アンブレラと、レールガン・巡航ミサイルによる遠距離水上打撃力をバランス良く兼ね備える。
- **内部2進数（2の累乗）共通階層構造**:
  - 小型空母 2隻 ＋ 防空駆逐艦 4隻 ＋ 汎用駆逐艦 8隻 ＋ 汎用フリゲート 16隻 ＋ 護衛コルベット 32隻。

## 3. 作戦・戦術メカニクス

1. **沿岸火力投射（射程1タイル）**:
   - `130C-N` 艦載砲および巡航ミサイルにより、隣接する沿岸陸上タイルで交戦中の友軍地上軍団へ直接火力支援ボーナス（攻撃力＋25%）を付与。
2. **多重レイヤー防空・対潜網**:
   - 防空駆逐艦のSAMアンブレラ、小型空母のVTOL戦闘機、フリゲートの対潜ヘリ・ソナー網により、空棲・水棲エイリアンの奇襲をアウトレンジで遮断。
3. **近接戦闘艦による阻止スクリーン**:
   - 32隻の快速コルベットが前衛で高密度の60C速射砲・30mm弾幕を展開し、巨艦の死角に肉薄してくる水棲スウォームを粉砕。
4. **母港・メガフロート依存**:
   - 行動半径制限があり、定期的に母港やメガフロート基地に帰投・補給を要する。
