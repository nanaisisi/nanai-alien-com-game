# 戦艦艦隊 詳細編成・運用仕様書 (Battleship Strike Fleet TO&E)

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../../GAME_DESIGN.md) のセクション 3.2.1 に基づき、超弩級戦艦の超長距離電磁投射砲（レールガン）を中核とする人類正規海軍の決戦艦隊**「戦艦艦隊（Battleship Strike Fleet）」**の編制序列（TO&E）、艦艇スペック、内部2進数制エシュロン、および作戦規則を規定する個別仕様書である。

---

## 1. 概要と戦略的位置づけ

- **艦隊規模**: 計62隻、総員 約11,200名。
- **作戦上の位置づけ**:
  - 国家の海上決戦兵器。圧倒的な防護力と超長距離レールガン砲撃による敵戦線・要塞の破砕を担当。
  - 大戦略マップ上で**「沿岸から2タイル内陸」**の敵要塞、都市、エイリアン大型巣窟（Hive）へ直接間接艦砲射撃を実行可能。
- **内部2進数（2の累乗）共通階層構造**:
  - 超弩級戦艦 2隻 ＋ 防空駆逐艦 4隻 ＋ 汎用駆逐艦 8隻 ＋ 汎用フリゲート 16隻 ＋ 護衛コルベット（近接戦闘艦） 32隻。

## 3. 作戦・戦術メカニクス

1. **大戦略2タイル先への超長距離沿岸砲撃**:
   - `EM-180C` レールガン斉射（8門×2隻＝計16門）により、沿岸から2タイル内陸にある敵要塞・都市・エイリアン大型巣窟（Hive）へ直接間接砲撃を実行可能。
2. **陸上戦艦打撃軍団との技術・回航連携**:
   - 超弩級戦艦の主砲（`EM-180C`）および艦体ブロック設計は、陸上戦艦打撃軍団の「陸上戦艦」と同一の海軍工廠ラインで共有。
   - 陸上戦闘艦群の海上回航（フェリー航行）時には、本戦艦艦隊が護衛を務める。
3. **前衛32隻の近接阻止スクリーン**:
   - 巨艦の弱点である近接魚雷艇や水棲格闘生物の肉薄に対し、32隻の快速近接戦闘艦が重厚な阻止線を展開。
