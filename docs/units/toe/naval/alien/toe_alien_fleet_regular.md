# エイリアン通常艦隊 詳細編成・生態仕様書 (Alien Regular Fleet TO&E)

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../../GAME_DESIGN.md) のセクション 3.2.2 に基づき、外洋での水上打撃戦・制海権確保を担当する野生エイリアンの主力海洋群**「エイリアン通常艦隊（Alien Regular Fleet）」**の編制体系、個体生態、および戦闘規則を規定する個別仕様書である。人類の「通常艦隊」と1対1で一致する。

---

## 1. 概要と生態ドクトリン

- **部隊規模**: 中型重装甲甲殻獣 数十頭 ＋ 強酸投射種・生体魚雷射出種 数百頭。
- **作戦上の位置づけ**:
  - 人類通常艦隊（駆逐艦・巡洋艦基幹）と完全一致。外洋における制海権確保と水上打撃を担当。
  - 重厚な甲殻による正面水上戦闘、長距離強酸投射、および誘導生体魚雷による水上・水中複合打撃を展開。
- **戦闘バランス**:
  - 人類の通常艦隊（駆逐艦・フリゲート・コルベット）と正面から撃ち合い・殴り合いを行う外洋の主力生体戦力。

## 3. 構成個体スペックと戦闘メカニクス

### 3.1 中型重装甲甲殻獣 (Medium Armored Carapace Beast)
- **体格**: 駆逐艦クラス（全長60〜90m、重量5,000〜8,000トン級）。
- **特徴**:
  - 耐熱・耐衝撃性に優れた多層キチン殻を持ち、水上艦の中口径砲弾やミサイルの直撃に耐える。
  - 巨大なハサミと顎により、接近した敵水上艦の舷側を噛み砕く。

### 3.2 強酸投射種 (Bio-Acid Bombardment Beast)
- **体格**: 全長40〜60m。
- **兵装**: **有機強酸投射管**。
- **特徴**:
  - 人類の艦載砲に匹敵する十数キロメートルの射程を持ち、超高濃度の有機フッ酸弾を投射。
  - 敵艦の上部構造物、レーダーアンテナ、CIWSマウントを融解・破壊する。

### 3.3 生体魚雷射出種 (Torpedo Brood Beast)
- **体格**: 全長30〜45m。
- **兵装**: **誘導生体魚雷**。
- **特徴**: 体内でスクリューフィンと音響追尾脳を持つ生体魚雷を次々と産生し、水中から連続発射する。

## 4. 作戦特性・運用ルール

1. **外洋主力艦隊との対決**:
   - 人類の通常艦隊（62隻）と正面衝突した場合、激しい砲撃・雷撃戦を展開。
2. **多重攻撃**:
   - 水上からの強酸弾と海中からの生体魚雷による上下挟撃を行い、敵艦隊の防空・対潜網を同時に飽和させる。
