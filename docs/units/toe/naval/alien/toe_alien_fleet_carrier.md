# エイリアン航空艦隊 詳細編成・生態仕様書 (Alien Carrier Fleet TO&E)

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../../GAME_DESIGN.md) のセクション 3.2.2 に基づき、浮遊母艦生体（バイオキャリア）の背部から多数の飛行生体を収容・発進させる野生エイリアンの洋上航空拠点群**「エイリアン航空艦隊（Alien Carrier Fleet）」**の編制体系、個体生態、および航空作戦規則を規定する個別仕様書である。人類の「航空艦隊」と1対1で一致する。

---

## 1. 概要と生態ドクトリン

- **部隊規模**: 浮遊母艦生体（バイオキャリア） 数頭 ＋ 艦載小型飛行種 数百頭 ＋ 警戒生体。
- **作戦上の位置づけ**:
  - 人類航空艦隊（空母・強襲揚陸艦基幹）と完全一致。洋上から飛行エイリアン群を大量発進させる生体航空拠点。
  - 海洋から内陸タイルへ向けて広域制空・飛行生体急襲を展開可能。
- **生体空母の機能**:
  - 水面を平坦に浮遊する巨大生体が、飛行個体の着巣・休息・栄養補給・孵化を担う。

## 3. 構成個体スペックと戦闘メカニクス

### 3.1 浮遊母艦生体（バイオキャリア） (Bio-Carrier Colossus)

- **体格**: 全長180〜260m、全幅50〜80m、重量60,000〜90,000トン級。
- **特徴**:
  - 巨大な浮力気嚢と平坦なキチン質背部甲板を持つ生体空母。
  - 背部に数十〜百頭以上の飛行生体を張り付かせ、休息・補給・再発進を管理。
  - 体内の孵化腔により、戦闘で損耗した小型飛行種を短時間で産み増やす補給機能を持つ。

### 3.2 艦載小型飛行種 (Carrier-Borne Striker)

- **体格**: 翼幅5〜8m。
- **特徴**: 母艦から一斉に滑空・羽ばたき離陸し、水上艦隊の上空を覆い尽くす。艦橋やCIWS、レーダーアンテナに群がって破壊。

### 3.3 警戒生体 (Biological AEW Flyer)

- **特徴**: 高高度を長時間滑空し、生体受光器官とフェロモン伝達により敵艦隊の接近を早期探知。

## 4. 作戦特性・運用ルール

1. **広域制空・航空阻止**:
   - 人類の航空艦隊と同様、大戦略マップ上で洋上から沿岸・内陸タイルへ航空戦力を投射可能。
2. **母艦の防御**:
   - 浮遊母艦自体は鈍重であり、水上艦のレールガン砲撃や深海からの魚雷攻撃を受けると回避が困難。
