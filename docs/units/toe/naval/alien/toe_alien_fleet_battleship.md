# エイリアン戦艦艦隊 詳細編成・生態仕様書 (Alien Battleship Fleet TO&E)

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../../GAME_DESIGN.md) のセクション 3.2.2 に基づき、全長200m超の超大型甲殻巨獣（リヴァイアサン級）を中核とし、長距離生体砲撃・沿岸破壊を担当する野生エイリアンの決戦海洋群**「エイリアン戦艦艦隊（Alien Battleship Fleet）」**の編制体系、個体生態、および破壊規則を規定する個別仕様書である。人類の「戦艦艦隊」と1対1で一致する。

---

## 1. 概要と生態ドクトリン

- **部隊規模**: 超大型甲殻巨獣（リヴァイアサン級） 数頭 ＋ 重キャビテーション衝撃砲種 ＋ 共生迎撃群。
- **作戦上の位置づけ**:
  - 人類戦艦艦隊と完全一致。超重装甲と長距離大口径生体砲撃による決戦打撃および沿岸砲撃を担当。
  - 海洋における生体ヒエラルキーの頂点に君臨する巨大決戦生物。
- **破壊力と装甲水準**:
  - 軍艦の大口径レールガン砲撃にも耐える規格外の超重甲殻。
  - 口部・背部から放たれる衝撃波と巨大酸弾により、敵水上艦を一撃で両断し、沿岸2タイルの陸上防衛線を粉砕する。

## 3. 構成個体スペックと戦闘メカニクス

### 3.1 超大型甲殻巨獣（リヴァイアサン級） (Leviathan Colossus)

- **体格**: 海洋タイタン級（全長200〜300m、全幅40〜60m、重量80,000〜120,000トン）。
- **特徴**:
  - 島や山塊を思わせる巨大な外殻を持つ超巨大怪獣。
  - **重キャビテーション衝撃砲**:
    - 口腔内の超音速流体加速器官により、超高圧のキャビテーション気泡衝撃波を発射。着弾時に海水と空気を爆発的に膨張させ、軍艦の外板を破断・艦橋を吹き飛ばす。
  - **超長距離生体沿岸砲撃**:
    - 背部の生体発射孔から巨大な有機火球・強酸塊を放物線投射し、**沿岸から2タイル内陸**の都市や要塞を粉砕可能。

### 3.2 共生迎撃群 (Symbiotic Interceptor Brood)

- **特徴**: リヴァイアサンの体表の無数の穴に生息し、飛来する対艦ミサイルや誘導爆弾に対して生体破片や強粘着液を吹きかけて空中爆発・無力化させる。

## 4. 作戦特性・運用ルール

1. **人類戦艦艦隊（EM-180C）との決戦**:
   - 人類の超弩級戦艦（レールガン8門×2隻）と対峙した場合、海を揺るがす超長距離砲撃戦を展開。
2. **沿岸2タイルへの艦砲射撃能力**:
   - 人類戦艦艦隊と同様、大戦略マップ上で沿岸から2タイル奥の陸上ターゲットを直接砲撃可能。
3. **雷撃・潜水艦への警戒**:
   - 巨大ゆえに深海からの集中雷撃（潜水艦隊）に晒されると、下腹部を狙われて重大な損傷を被るリスクがある。
