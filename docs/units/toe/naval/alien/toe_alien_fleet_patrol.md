# エイリアン哨戒艦隊 詳細編成・生態仕様書 (Alien Patrol Fleet TO&E)

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../GAME_DESIGN.md) のセクション 3.2.2 に基づき、沿岸監視・領海警戒・高速索敵を担当する野生エイリアンの俊敏な海洋生体群**「エイリアン哨戒艦隊（Alien Patrol Fleet）」**の編制体系、個体生態、および遊泳規則を規定する個別仕様書である。人類の「哨戒艦隊」と1対1で一致する。

---

## 1. 概要と生態ドクトリン

- **部隊規模**: 刺胞遊泳個体・魚雷獣など 数百〜数千頭の高速遊泳群。
- **作戦上の位置づけ**:
  - 人類哨戒艦隊と完全一致。沿岸監視、領海警戒、高速索敵を担当。
  - 表層〜浅海域を俊敏に遊弋し、海域に侵入した船舶や友軍の動向をフェロモン・生体ソナーで探知。
- **戦闘能力と特性**:
  - 軽快な遊泳速度を誇り、機雷や自爆魚雷のように敵艦に肉薄・強酸を浴びせる奇襲攻撃に優れる。
  - 正規軍艦の装甲を貫通する重打撃力は持たず、大型水上艦の砲火やCIWSには脆弱。

## 3. 構成個体スペックと戦闘メカニクス

### 3.1 表層監視種 (Surveillance Sensor Beast)

- **体格**: 中型海洋生物（全長5〜8m）。
- **特徴**: 水面直下を泳ぎながら感覚触手を大気中に露出させ、船舶の航跡波やレーダー波を探知して群れ全体に共有。

### 3.2 高速遊泳魚雷獣 (Living Torpedo Beast)

- **体格**: 小型〜中型（全長2〜4m、重量500kg〜1トン）。
- **特徴**:
  - ジェット水流推進により水中を時速40〜50ノットで高速突進。
  - 敵艦の吃水下に衝突し、高圧強酸嚢を破裂させて外板を腐食・浸水させる。

### 3.3 小型刺胞遊泳個体 (Stinging Scout)

- **特徴**: 半透明の毒針触手を引きずりながら海面を覆い、ダイバーや小型艇の進入を阻害。

## 4. 作戦特性・運用ルール

1. **索敵・警戒網の提供**:
   - 海洋タイル上の視界を確保し、他の大型エイリアン艦隊へ敵船団の位置諸元を伝達。
2. **通商破壊・民間船への脅威**:
   - 非武装の民間船に対しては致命的な損害を与えるが、護衛コルベット（近接戦闘艦）の30mm機関砲や60C速射砲には容易に撃破される。
