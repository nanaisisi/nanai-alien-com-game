# エイリアン潜水艦隊 詳細編成・生態仕様書 (Alien Submarine Fleet TO&E)

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../../GAME_DESIGN.md) のセクション 3.2.2 に基づき、深海に潜航し高い隠密性から奇襲雷撃を行う野生エイリアンの深海潜航群**「エイリアン潜水艦隊（Alien Submarine Fleet）」**の編制体系、個体生態、および潜航戦闘規則を規定する個別仕様書である。人類の「潜水艦隊」と1対1で一致する。

---

## 1. 概要と生態ドクトリン

- **部隊規模**: 深海潜航巨獣 数頭〜十数頭 ＋ 超音波共鳴種 ＋ 誘導生体魚雷放出種。
- **作戦上の位置づけ**:
  - 人類潜水艦隊と完全一致。深海での高度な隠密行動、敵索敵網の突破、奇襲雷撃を担当。
  - 大戦略マップ上でステルス潜航状態を維持し、敵の大型戦闘艦隊（戦艦艦隊・航空艦隊）や輸送船団の背後から奇襲雷撃を敢行。
- **深海生態とステルス性**:
  - 超深海の水圧に耐えうる柔軟かつ強靭な生体装甲を持ち、金属音や電波を発しないため通常ソナー・レーダーでの探知が極めて困難。

## 3. 構成個体スペックと戦闘メカニクス

### 3.1 深海潜航巨獣 (Deep-Sea Submersible Beast)
- **体格**: 潜水艦クラス（全長80〜130m、重量6,000〜12,000トン級）。
- **特徴**:
  - マッコウクジラや深海イカの生体特性を進化させた超深海生体兵器。
  - 水深数千メートルの超高圧に耐え、水温躍層（サーモクライン）の下に潜んで敵対潜哨戒網を回避。
  - スクライブ音（機械回転音）を出さない筋肉うねり推進により、完全な無音航行を実現。

### 3.2 誘導生体魚雷 (Autonomous Living Torpedo)
- **体格**: 全長6〜8m。
- **特徴**:
  - 潜航巨獣の体内で急速育成され射出される自律型生体魚雷。
  - 敵艦のスクリュー水流・エンジン音を感知して自動誘導。
  - 接触時に艦底のキール（竜骨）下で強烈な生体キャビテーション爆発を起こし、一撃で大浸水を発生させる。

### 3.3 超音波共鳴種 (Acoustic Resonance Beast)
- **特徴**: 海底地形に反射させた極超音波パルスを用い、自らの位置を暴露することなく数百キロメートル先の水上艦の位置をピンポイント特定。

## 4. 作戦特性・運用ルール

1. **ステルス潜航奇襲**:
   - 人類のフリゲート（曳航ソナー）や対潜ヘリによる厳重な対潜スクリーンが展開されていない場合、敵戦艦や空母の直下に無傷で侵入可能。
2. **水上での脆弱性**:
   - 潜航時は無類の脅威となるが、浅瀬に追い込まれたり浮上を余儀なくされた場合、水上艦のレールガン砲撃や航空爆撃により急速に無力化される。
