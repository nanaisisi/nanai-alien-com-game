# 通常海上戦闘団・上位世代発展仕様書（生体技術・耐圧甲殻改修 / Gen 4）

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../GAME_DESIGN.md) のセクション 3.2.3 および [`../../../discussion/military_tactics/concept_frontier_industry_and_weapon_generations.md`](../../../discussion/military_tactics/concept_frontier_industry_and_weapon_generations.md) に基づき、通常艦隊ツリーの発展段階（Gen 3 復元 ──► Gen 4 異星超克・特化進化）において、通常水上・海洋艦艇へ適用される生体工学・自己修復装甲・無音波動推進改修仕様を規定するものである。

※独立した別枠ツリーとしての「融合生物艦隊」は廃止され、通常艦隊の近代化改修・上位世代ユニットとして直接実装・運用される。

---

## 1. 上位発展（Gen 4）の基本アーキテクチャ

通常ツリーの各艦艇に対し、海棲エイリアン研究と海洋バイオファクトリーの成果が近代化改修パッケージとして適用される。

- **有機自己修復船体（Living Hull）**:
  - 特殊高張力鋼と生体甲殻の分子結合フレームにより、魚雷や対艦ミサイルによる被弾亀裂が急速に自己増殖・閉塞。沈没耐性が大幅に向上。
- **無音生体推進（Hydro-Dynamic Undulation）**:
  - スクリューキャビテーションを激減させ、有機的波動運動推進モジュールを船体下部に併設。パッシブソナー探知距離を半減。

## 2. 通常艦隊の上位発展改修仕様

| 通常艦種 | 上位発展（Gen 4改修）の特徴 | 改修兵装・推進 |
| :--- | :--- | :--- |
| **護衛コルベット/フリゲート** | 前方警戒・高速迎撃・哨戒 | 自己修復キチン装甲、生体パルス放電CIWS、有機無音フィン |
| **汎用駆逐艦** | 水上・潜航ハイブリッド両用化 | 耐圧生体バルクヘッド、生体魚雷射出管（誘導刺胞魚雷）、電磁レールガン |
| **大型戦艦** | 洋上超重装甲と大口径生体プラズマ投射 | 超重キチン複合装甲、重電磁投射砲＋生体巡航ミサイル |
| **正規空母** | 生体航空機・ドローンの急速運用 | 生体カタパルト、急速自己増殖ドック、成層圏バイオ索敵アンテナ |

---

## 3. 作戦・兵站ドクトリン

- **通常艦隊からのシームレス更新**:
  - 造船所または海洋前線基地において、既存の通常艦艇をGen 4仕様へドック改修することで部隊枠を変更せず戦力更新。
- **沿岸浸透と陸上攻撃**:
  - 浅瀬や毒性湿地帯での抗堪性を高め、沿岸部での火力投射能力を維持。
