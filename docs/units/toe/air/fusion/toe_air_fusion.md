# 通常航空戦闘団・上位世代発展仕様書（生体技術・可変有機翼改修 / Gen 4）

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../GAME_DESIGN.md) のセクション 3.3.3 および [`../../../discussion/military_tactics/concept_frontier_industry_and_weapon_generations.md`](../../../discussion/military_tactics/concept_frontier_industry_and_weapon_generations.md) に基づき、通常航空隊ツリーの発展段階（Gen 3 復元 ──► Gen 4 異星超克・特化進化）において、通常航空機へ適用される航空力学・生体翼・自己修復外皮改修仕様を規定するものである。

※独立した別枠ツリーとしての「融合生物航空団」は廃止され、通常航空団の近代化改修・上位世代ユニットとして直接実装・運用される。

---

## 1. 上位発展（Gen 4）の基本構造（Bio-Aerodynamic Synergy）

通常ツリーの各戦闘機・爆撃機・支援機に対し、飛行型エイリアン研究とバイオ航空工廠の成果が近代化改修パッケージとして適用される。

- **可変有機翼・自己修復外皮**:
  - 主翼後退角やキャンバーが筋肉組織によって飛行中に連続可変。高機動と超音速巡航を両立。
  - 被弾損傷を受けても大気中の微量有機粒子を摂取して数分で外皮を再生。
- **生体兵装・アビオニクス統合**:
  - 通常の空対空ミサイルや誘導爆弾に加え、機内生成バイオ弾薬（超高速生体誘導針）や広域生体電波妨害（バイオECM）を統合。

## 2. 通常航空団の上位発展改修仕様

| 通常飛行隊・機種 | 上位発展（Gen 4改修）の特徴 | 改修兵装・推進 |
| :--- | :--- | :--- |
| **戦闘航空団（制空戦闘機）** | 高高度迎撃・超機動ドッグファイト | ハイブリッドジェット＋有機可変翼、生体超高速誘導針弾、レーダー吸収生体皮膚 |
| **爆撃航空団（戦略爆撃機）** | 戦略爆撃・敵地上軍団面制圧 | 体内超高温プラズマ炉、生体熱線クラスター弾、大深度重爆撃ダイブ |
| **電子戦・哨戒航空団** | 広域生体ECM・敵C4I機能妨害 | 生体共鳴電波妨害器官、神経パルス逆流照射、成層圏長時間滞空嚢 |
| **空中戦艦・空中空母** | 洋上・超巨大空中プラットフォームの自己再生 | 外皮自己増殖ドック、大気浮遊生体ガス嚢ハイブリッド浮力支援 |

## 3. 作戦・兵站ドクトリン

- **通常航空団からのシームレス更新**:
  - 航空基地の整備ハンガーで既存の通常戦闘機・爆撃機をGen 4へブロック更新可能。別枠編成の新設は不要。
- **無着陸継続作戦**:
  - 機体修復・生体補給の自律化により、空中給油や基地帰投頻度を激減させ、極めて長い作戦滞空時間（Loiter Time）を実現。
