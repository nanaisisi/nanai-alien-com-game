# 航空・正規軍 航空機・装備プラットフォーム仕様書 (Air Regular Arsenal & Aircraft Platforms)

本作における人類通常勢力の軍用・民間航空機プラットフォーム、共通機体・派生バリアント体系、特殊航空兵器、および空中要塞艦艇の詳細仕様書である。

---

## 1. 航空機・航空兵器の6大プラットフォーム系統

本作における航空機体系は、航空工廠における金型転換コスト低減、サプライチェーン（ジェットエンジン・推進剤・アビオニクス）の規格化、および前線での共食い整備性維持のため、以下の6つの系統に厳密に区分・階層化される。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                    航空通常兵器 6大プラットフォーム系統                      │
├─────────────────────────────────────────────────────────────────────────────┤
│  ①【大型重制空・戦闘爆撃機系列 (双発 25〜35t級)】                           │
│    └─ 大航続距離・大推力双発エンジン。制空・スウィングロール・護衛の基幹    │
│  ②【軽量即応迎撃・前線戦闘機系列 (単発/VTOL 10〜18t級)】                    │
│    └─ 高速スクランブル・分散道路離着陸（STOL）・無滑走路前線展開（VTOL）     │
│  ③【戦略侵入・ステルス全翼機系列 (複合ステルス 20〜150t級)】                 │
│    └─ 全面光学迷彩・電波全周吸収外皮。不可視深部精密爆撃・強行偵察・第6世代  │
│  ④【重戦術・戦略輸送機/哨戒機系列 (大型高翼機 70〜250t級)】                 │
│    └─ 不整地STOL空輸・空中給油・早期警戒管制（AEW&C）・長距離海洋対潜哨戒   │
│  ⑤【師団直協・回転翼/VTOL系列 (直協航空連隊 8〜15t級)】                      │
│    └─ 地上増強師団常設オーガニック。NOE低空CAS・ヘリボーン強襲・空中MEDEVAC  │
│  ⑥【国家戦略決戦空中艦艇系列 (超大型浮揚要塞 20,000〜60,000t級)】           │
│    └─ 反重力/熱核ジェット。空中戦艦（直接殴り合い）・空中空母・超巨大輸送船 │
└─────────────────────────────────────────────────────────────────────────────┘
```

> [!NOTE]
> **機体・主翼桁（メインスパー）の物理的耐用年数（最大1世紀）**:
> アビオニクスやエンジン換装、外皮補修を行っても、高G機動・気流疲労による主翼桁の金属疲労限界は不可避である。
>
> - **超大型空中艦艇・戦略輸送機**: 40〜60年（主翼桁・反重力マウント改修で最大 **80〜100年/1世紀**）
> - **大型重制空・戦闘爆撃機**: 25〜40年（SLEP寿命延伸で最大60年）
> - **軽量迎撃機・回転翼/VTOL**: 15〜25年（過酷な振動・高負荷のため30年程度が限界）
>   耐用年数を超過した機体は耐G制限がかかり、空中分解リスクが急増するため、ドローン標的機への改修または解体・スクラップ処理される。

## 3. 航空機体系列ごとの詳細仕様と運用特性

### 3.1 ① 大型重制空・戦闘爆撃機系列 (Heavy Fighter Platforms: 25〜35t級)

大気圏内制空戦闘および長距離打撃の中核をなす重戦闘機ファミリー。

- **大型重制空戦闘機**:
  - 大推力双発エンジンによりマッハ1.8超のスーパークルーズ（超音速巡航）を実現。大容量燃料タンクと大型レドームを備え、視程外射程（BVR）戦闘において圧倒的な先制撃破能力を発揮する。
  - 主兵装: 長距離アクティブレーダー誘導空対空ミサイル（AAM）4発、中距離AAM 4発、高機動短距離AAM 2発、30C高初速航空機関砲 1門。
- **戦闘爆撃機（ストライクファイター）**:
  - 制空戦闘機と機体フレーム・エンジンを共通化しつつ、アビオニクスを対地精密誘導・地形追従に換装した派生型。
  - 最大10トンの兵装ペイロードを持ち、バンカーバスター、長距離対地巡航弾、クラスター焼夷弾を大量投下。

---

### 3.2 ② 軽量即応迎撃・前線戦闘機系列 (Light & V/STOL Platforms: 10〜25t級)

正規飛行場の破壊・滑走路寸断下でも運用可能な高抗堪性・即応展開プラットフォーム群。

- **単発軽量迎撃機 (Light Interceptor)**:
  - 単発ターボファンエンジン、カナード＋デルタ翼。前線拠点の幹線道路や簡易滑走路から数分以内のスクランブル発進が可能。
  - 整備トラック数台で給油・再装填が完了する極めて高い現場稼働率を誇る。
- **第5世代SVTOL戦闘機 (Short Take-Off and Vertical Landing)**:
  - リフトファンおよび推力偏向ノズルによる完全垂直離着陸（VTOL）および短距離滑走（STOVL）能力。
  - 滑走路の存在しない平原、未開墾の森林伐採地、小型空母の全通甲板から直接発進し、前線地上軍団へ即時CASを提供する。

---

### 3.3 ③ 戦略侵入・ステルス全翼機系列 (Advanced Stealth Platforms: 20〜150t級)

光学迷彩と電波吸収外皮を兼ね備えた、絶対的先制奇襲・深部侵入ファミリー。

- **第6世代光学・電波ステルス戦闘機**:
  - 全面アクティブ光学迷彩パネル（背景投射メタマテリアル）により肉眼・可視光カメラから完全に消失。
  - パッシブ量子センサーと極極超音速AAMを完全内装し、敵に探知されることなく先制必殺の空戦を実施。
- **光学・電波ステルス戦略爆撃機**:
  - 無尾翼全翼形状（フライングウィング）によりレーダー波を乱反射させず、さらに光学迷彩で目視を欺瞞。
  - 最高度の防空SAM網を単機で突破し、敵中枢司令部やタイタン級繁殖巣穴へバンカーバスターをピンポイント投下。
- **超音速光学ステルス偵察機 (Mach 4〜6)**:
  - スクラムジェット/複合サイクルエンジンにより成層圏界面（高度25,000〜30,000m）を極超音速巡航。
  - 武器を持たず、超高解像度SARと量子生体共鳴センサーで敵領空全域・地下巣穴を一挙にマッピング。

> [!CAUTION]
> **気流観測センサー（戦闘妖精・雪風ギミック）による対抗**:
> 光学迷彩・電波ステルス機であっても、大気中を高速飛行する際に生じる「微細な大気の断熱圧縮・気流擾乱」を捉える気流観測施設・特殊センサーが配備されている空域では、飛行航跡が逆探知され迎撃を受ける脆弱性を持つ。

---

### 3.4 ④ 重戦術・戦略輸送機/哨戒機系列 (Heavy Cargo & Patrol: 70〜250t級)

長距離作戦行動の基盤となる高バイパス大型ターボファン機ファミリー。

- **重戦術輸送機 (C-17級: 積載70t)**:
  - 強化多輪降着装置と大型スロッテッド・フラップによる不整地STOL性能。完全武装歩兵102名、または4×4 LAV 3両、または重IFV 1両を収容。
- **早期警戒管制機 (AEW&C)**:
  - 背部に固定式大型アクティブフェーズドアレイレーダー（探知距離400km+）を搭載。友軍全機・防空部隊に迎撃諸元を高速データリンク。
- **長距離海洋対潜哨戒機**:
  - 長時間滞空能力、磁気探知機（MAD）、ソノブイ投射管、対潜短魚雷、対艦巡航ミサイルを搭載。外洋タイルの潜水艦・潜航エイリアンを捜索・撃沈。

---

### 3.5 ⑤ 師団直協・回転翼/VTOL系列 (Organic Division Aviation: 8〜15t級)

地上増強師団にオーガニック（直轄常設）として内包される米軍式直協航空アセット。

- **重武装直協戦闘ヘリ / 重VTOLガンシップ (Attack Gunship)**:
  - コクピット装甲バスタブ（13C〜20C弾抗堪）、NOE（地形追随低空飛行）戦術、30Cチェーンガン、対戦車重誘導弾 8〜16発。
  - 戦術戦闘（343マス）において地上軍団司令部の要請で直ちに上空へ突入・CAS介入。
- **強襲戦術輸送ヘリ / 中型ティルトローター (Assault Transport)**:
  - 完全武装歩兵24〜32名（1個小隊）または軽装甲車1両を空輸。隘路や有毒湿地を飛び越えるヘリボーン強襲、緊急物資空中架橋、MEDEVAC（負傷兵・損傷論理コア回収）を実行。

---

### 3.6 ⑥ 国家戦略決戦空中艦艇系列 (Strategic Aerial Warships: 20,000〜60,000t級)

反重力浮揚・熱核ジェットにより大気圏内を浮遊・遊弋する人類最高峰の空中決戦プラットフォーム群。海軍工廠（臨海造船所）のドック技術から発展した超弩級アセット。

- **超大型空中戦艦 (全備30,000〜50,000t / 全長250m)**:
  - **連装 EM-180C 電磁投射砲 4基（計8門）**、60C速射砲 8基、多目的VLS 128セル、多層CIWS 16基。
  - 敵要塞直上に突入し、ゼロ距離から電磁砲と機関砲を撃ち込む直接殴り合いの空中移動要塞。
- **超大型空中空母 (全備40,000〜60,000t / 全長300m)**:
  - 全通飛行甲板、電磁カタパルト2基、艦載戦闘機48機、防空SAM-VLS 64セル。
  - 地上の飛行場に依存せず、前線上空に長期滞空して持続的な航空優勢を提供する移動式エアベース。
- **超巨大戦略輸送飛行船 (全備20,000t / 全幅200m級)**:
  - 複層メガカーゴデッキにより、地上重機甲軍団（重戦車・自走砲数十両、数千名）を丸ごと収容。
  - 地形障害を完全に無視して大陸間・戦域間を数ターンで長距離空輸・展開する最高峰兵站ユニット。

---

## 4. 陸上・海上・サプライチェーンとの統合連携

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                    航空兵装・サプライチェーン統合マップ                     │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   【共通口径・共通弾薬（C規格）】                                           │
│     ・30C機関砲: 戦闘機、師団直協戦闘ヘリ、装甲車IFVで共用                   │
│     ・EM-180C 電磁投射砲: 空中戦艦 ⇄ 水上戦艦 ⇄ 陸上戦艦で主砲弾・部品共通 │
│     ・60C速射砲: 空中戦艦 ⇄ 護衛コルベット ⇄ 陸上近接艦で共有               │
│                                                                             │
│   【兵站エネルギーの差別化】                                                │
│     ・一般車両: 重油・軽油・バイオ燃料                                      │
│     ・航空機全般: **高品位航空推進剤（高純度炭化水素 / 液体水素）**を激しく消費│
│     ・兵站断絶時: 地上部隊よりも先に航空機の出撃可能機数が制限される        │
│                                                                             │
│   【製造インフラの二重構造】                                                │
│     ・通常航空機 (Gen 1〜3): 航空機工廠（Air Factory）でライン量産           │
│     ・空中戦艦・空中空母: 臨海造船所（海軍工廠）の大型ドックでブロック建造   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

1. **弾薬C規格の相互互換性**:
   - 航空機関砲弾（30C）、電磁砲弾（`EM-180C`）、速射砲弾（`60C-N`）は陸上部隊・艦隊と同一の弾薬補給パレットから共有可能。
2. **航空推進剤ボトルネック**:
   - 航空アセットは通常の軽油ではなく高純度の航空推進剤を消費するため、大戦略マップ上での航空基地・補給動脈の防衛が航空戦力維持の生命線となる。
