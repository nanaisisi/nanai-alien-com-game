# 海上・正規軍 艦艇・装備プラットフォーム仕様書 (Naval Regular Arsenal & Naval Platforms)

本作における人類通常勢力の海上戦闘艦艇プラットフォーム、共通船体・派生バリアント体系、および艦載兵器・特殊装備の詳細仕様書である。

---

## 1. 海上戦闘艦艇の6大プラットフォーム系統

本作における海上通常艦艇体系は、海軍工廠（臨海造船所）における建造ブロック共通化、補給部品の規格化、および前線での共食い整備性維持のため、以下の6つの系統に厳密に区分・階層化される。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                    海上通常兵器 6大プラットフォーム系統                      │
├─────────────────────────────────────────────────────────────────────────────┤
│  ①【超弩級水上決戦艦系列 (70,000〜80,000t級)】                             │
│    └─ 最大限の耐圧重装甲・電磁防護と国家決戦投射能力を誇る超大型中核艦      │
│  ②【航空母艦系列 (25,000〜80,000t級)】                                      │
│    └─ 全通飛行甲板・航空管制C4I中枢・洋上航空打撃のコア                     │
│  ③【外洋主力駆逐艦系列 (7,500〜9,000t級)】                                  │
│    └─ 全周フェーズドアレイ・電磁狙撃砲またはレールガン＋VLS多重防空・打撃   │
│  ④【外洋哨戒・対潜フリゲート系列 (4,000t級)】                               │
│    └─ 曳航ソナー・多目的VLS・艦載対潜ヘリによる外翼スクリーン・対潜ワークホース│
│  ⑤【高速近接護衛コルベット系列 (1,200〜1,500t級)】                           │
│    └─ 高速ウォータージェット・60C速射砲・対水上RWSによる群れ肉迫阻止艦      │
│  ⑥【特設・民間輸送船艇系列 (1,000〜100,000t級)】                            │
│    └─ 大容量バルクホールド・RORO甲板・特設コンテナ兵装化プラットフォーム     │
└─────────────────────────────────────────────────────────────────────────────┘
```

> [!NOTE]
> **船体・キール（竜骨）の物理的耐用年数（最大1世紀）**:
> 兵装・電子戦レーダー・機関は定期ドックで近代化換装されるが、船体ハル・耐圧竜骨は高塩害・高波浪・深海圧力疲労により不可逆的に劣化する。
> - **超弩級戦艦・正規空母**: 50〜70年（大規模ドック改修・延命で最大 **100年/1世紀**）
> - **駆逐艦・フリゲート**: 30〜45年（改修延命で最大60年）
> - **護衛コルベット・哨戒艇**: 20〜30年（酷使・高速疲労のため早期減耗）
> 構造寿命が限界に達した艦艇は船体強度が低下し、解体（Scrap）されて新造艦の構造鉱物資材に還元される。

## 3. 各艦種・兵装システムの詳細仕様

### 3.1 ① 超弩級水上決戦艦系列 (Super Dreadnought Platform: 70,000t級)

国家の海上決戦兵器。圧倒的防護力と超長距離レールガン砲撃による敵戦線・要塞の破砕を担当。

- **船体構造・防護**:
  - 重装甲耐圧ダブルハル構造に加え、バイオ酸弾および超音速運動エネルギー弾を減衰・無力化する電磁リアクティブアーマー（ERA）を主要区画に集中配置。
- **主兵装: 4連装 EM-180C 超大型電磁投射砲（レールガン）×2基（計8門）**:
  - 大戦略2タイル先（沿岸から内陸深部）の敵要塞、都市、エイリアン大型巣窟（Hive）へ直接間接砲撃を実行可能。
  - 陸上戦艦打撃軍団の「超弩級陸上戦艦」と同一口径・同一砲塔ブロック規格を採用。
- **副兵装・自衛**:
  - `130×800C` (`130C-N`) 連装両用副砲 4基（計8門）による対水上・対空両用射撃。
  - 長距離対地巡航ミサイルVLS 32セル、全周多層CIWS 8基。

---

### 3.2 ② 航空母艦系列 (Carrier Platforms)

#### 1. 大型正規空母 (Fleet Carrier: 80,000t級)
- **航空艤装**: アングルド・デッキ、電磁カタパルト4基、大型昇降エレベーター3基。
- **艦載機運用（計64機 / 隻）**:
  - 固定翼艦載戦闘機 32機（広域制空・精密爆撃）
  - 艦載早期警戒機（AEW） 16機（水平線外C4I・ターゲティング伝送）
  - 艦載対潜哨戒機・対潜ヘリ 16機（外洋広域対潜掃討）
- **自衛兵装**: 短SAM-VLS 32セル、30C CIWS 4基。

#### 2. 小型空母 (Light Carrier: 25,000〜30,000t級)
- **航空艤装**: 全通飛行甲板、スキージャンプ勾配またはVTOL着艦スポット、格納庫エレベーター2基。
- **艦載機運用（計16機 / 隻）**:
  - VTOL戦闘機 8機（直協局所制空・近接航空支援CAS）
  - 攻撃・対潜ヘリ 4機（対潜索敵・誘導雷撃）
  - 早期警戒・索敵ドローン（UAV） 4機（艦隊データリンク中継）
- **役割**: 通常艦隊の中核旗艦として機能し、陸上小型空母と同規模の航空支援・C4I能力を提供。

---

### 3.3 ③ 外洋主力駆逐艦系列 (Destroyer Platforms: 7,500〜9,000t級)

#### 1. 防空駆逐艦 (Air Defense Destroyer: 9,000t級)
- **電子装備**: 4面固定式アクティブ・フェーズドアレイレーダー（長距離早期警戒・同時多目標追尾）。
- **兵装**:
  - `EM-40C` 電磁狙撃砲 1基（極超音速弾芯による高高度航空・弾道迎撃）。
  - 長距離防空SAM-VLS 64セル（艦隊広域防空アンブレラ）。
  - 近接防空SAM（RAM） 1基、30C CIWS 2基。

#### 2. 汎用駆逐艦 (General Purpose Destroyer: 7,500t級)
- **兵装**:
  - 中口径電磁投射砲（レールガン） 1基（水上砲撃戦・沿岸火力支援）。
  - 多目的VLS 32セル（対地・対艦巡航ミサイル、対潜アスロック）。
  - 4連装対艦巡航ミサイル発射筒 4基（計16発）。
  - 3連装短魚雷発射管 2基、CIWSおよびSeaRAM複合近接防衛。

---

### 3.4 ④ 外洋哨戒・対潜フリゲート系列 (Frigate Platform: 4,000t級)

- **ソナー体系**: 艦首バウソナー ＋ 艦尾繰出式曳航パッシブソナーアレイ（深海音響探知）。
- **兵装**:
  - 多目的VLS 16〜32セル（垂直発射対潜アスロック VLA、個艦防空短SAM）。
  - 近接防護CIWS ＋ SeaRAM。
- **航空艤装**: 艦尾ヘリ格納庫および発着甲板（艦載対潜哨戒ヘリ 1機常駐運用）。

---

### 3.5 ⑤ 高速近接護衛コルベット系列（近接戦闘艦） (1,200〜1,500t級)

- **設計思想**:
  - 陸上戦艦打撃軍団における近接戦闘艦のコンセプトを海上プラットフォームに特化。大口径砲の死角に肉薄してくる水棲エイリアンスウォームや特攻水上艇を、快速機動と高密度火網で迎撃・粉砕する。
- **兵装**:
  - **60×400C** (`60C-N`) 高速艦載速射砲 1基。
  - **多目的誘導弾システム**（小型対舟艇・低空エイリアン兼用キャニスターランチャー）。
  - **対水上30mm機関砲RWS** 2〜4基（遠隔操作火器管制ステーション、超高レート掃討）。
  - ※ロケット投射機および爆雷は非搭載（対水上・対低空高速掃討に特化）。
- **推進性能**: ウォータージェット推進による40ノット超の超高機動展開。

---

### 3.6 ⑥ 特設・民間輸送船艇系列 (Merchant & Auxiliary Platforms)

- **特設武装貨物船 (Qシップ: 15,000t級)**:
  - 民間貨物船の外見を保ちつつ、船倉に秘匿コンテナVLS、甲板に60C速射砲2基を仮設。開拓初期の自衛・奇襲排除。
- **武装沿岸哨戒艇 (200〜500t級)**:
  - 浅水域・河口部での哨戒を担う高速艇。30C RWSと軽魚雷を装備。
- **特設護衛哨戒船 (2,000〜3,000t級)**:
  - 漁船・調査船ベースに簡易ソナーと爆雷投下軌条、自衛SAMを架装。
- **民間大型輸送船 (50,000〜100,000t級)**:
  - 非武装コンテナ・鉱石船。膨大な戦略物資（IND-1/2、燃料、食料）の海上大量空輸・輸送。

## 4. 陸上戦艦打撃軍団・他体系との兵站・共通化連携

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                   海軍工廠（臨海造船所）建造・兵器共通化                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   【共通ブロック建造 (海軍工廠)】                                           │
│     ・超弩級戦艦 ⇄ 超弩級陸上戦艦（主砲 EM-180C、艦体装甲モジュール共通）   │
│     ・小型空母 ⇄ 陸上小型空母（全通飛行甲板、航空管制C4Iブロック共通）      │
│     ・防空駆逐艦 ⇄ 陸上防空艦（主砲 EM-40C、SAM-VLS、フェーズドアレイ共通） │
│     ・護衛コルベット ⇄ 陸上近接戦闘艦（速射砲 60C-N、多目的誘導弾共通）     │
│                                                                             │
│   【洋上回航（フェリー航行）連携】                                          │
│     ・陸上戦闘艦の海上回航時、通常艦隊・護衛艦隊が同伴して対潜スクリーン展開│
│                                                                             │
│   【海底資源化（アイアンボトム・サウンド）】                                │
│     ・海上撃沈艦艇群の海底沈没残骸から特殊合金（IND-2）をサルベージ回収可能 │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

1. **砲熕・ミサイル兵器の規格共通化**:
   - `EM-180C` 超大型レールガン：水上超弩級戦艦および陸上超弩級戦艦で完全共有。
   - `EM-40C` 電磁狙撃砲：防空駆逐艦および陸上防空艦で共有。
   - `60C-N` 高速艦載速射砲：護衛コルベット、特設武装船、および陸上近接戦闘艦で共有。
2. **造船ドック設備の共用**:
   - 海上艦艇および陸上戦闘艦はすべて同一の臨海造船所（海軍工廠）ドックで建造されるため、プレイヤーは同一の工業ライン投資で双方を整備可能。
