# 陸上・正規軍 兵器・車両仕様書 (Ground Regular Arsenal & Vehicle Platforms)

本作における人類通常勢力の陸上戦闘車両プラットフォーム、共通派生バリアント体系、特殊戦闘兵器、および陸上戦艦群の詳細仕様書である。

---

## 1. 陸上戦闘車両・兵器の6大プラットフォーム系統

本作における陸上兵器体系は、兵站ラインの簡素化・金型転換コスト低減・共食い整備性向上のため、以下の6つの系統に厳密に区分・階層化される。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                   陸上通常兵器 6大プラットフォーム系統                      │
├─────────────────────────────────────────────────────────────────────────────┤
│  ①【重装軌・戦車系列 (50〜60t級)】                                         │
│    └─ 最大限の複合装甲と大出力を誇る重突撃・決戦プラットフォーム            │
│  ②【装軌装甲車系列 (25〜35t級)】                                            │
│    └─ 不整地・泥濘地での踏破力と重防護を両立（下車歩兵固定8名分隊）         │
│  ③【8輪装甲装輪車系列 (20〜30t級)】                                         │
│    └─ 同一8×8車体による10大バリアント共通化（下車歩兵固定8名分隊）          │
│  ④【重装輪トラック系列 (15〜25t級)】                                       │
│    └─ 非装甲/軽装甲キャビン。155C装輪榴弾砲・TELミサイル・重兵站            │
│  ⑤【4輪駆動高機動系列 (5〜8t級)】                                           │
│    └─ 高速機動・小型展開性に優れた軽装甲戦術システム（多目的誘導弾/SAM）    │
│  ⑥【国家戦略決戦兵器系列 (超弩級・特殊兵器)】                               │
│    ├─ 二脚歩行戦闘車両（高級装甲・大型戦略輸送機空輸規格）                  │
│    └─ 陸上戦艦・陸上戦闘艦群（臨海造船所建造・超大型電磁レールガン）       │
└─────────────────────────────────────────────────────────────────────────────┘
```

> [!NOTE]
> **車体・フレームの物理的耐用年数（最大1世紀）**:
> 兵装・動力モジュールは野戦交換部品（FieldSpares）で更新・維持されるが、車体フレーム・装甲モノコック・戦艦ハルは金属疲労・衝撃荷重・異星大気腐食により不可逆的に劣化する。
> - **超弩級陸上戦艦**: 最長 80〜100年（ドック大改修前提）
> - **重装軌・戦車系列**: 40〜60年（改修延命で最大80年）
> - **装甲車・装輪・高機動系列**: 25〜40年（改修延命で最大50年）
> - **二脚歩行兵器**: 20〜30年（関節公差拡大・疲労のため短命）
> 耐用限界を迎えた車台は構造健全度（Structural Integrity）が低下し、最終的に新造プラットフォームへの全面リプレイスが求められる。

## 2. 車体系列ごとの詳細スペックと搭載兵装

### 2.1 ① 重装軌・戦車系列 (Heavy Tracked: 50〜60t級)
敵主力を正面から破砕し、敵の重砲撃・エイリアン酸弾に耐えうる最重装甲車体。

| 車種名 | 車体・マウント構造 | 乗員 | 主兵装・特殊装備 | 運用・配備先 |
| :--- | :--- | :--- | :--- | :--- |
| **主力戦車 (MBT)** | 全周旋回砲塔 | 3名 | 120C〜135C滑腔砲 ＋ 同軸機関銃 ＋ APS | 機甲連隊（基幹打撃） |
| **160C自走榴弾砲** | **全周旋回砲塔型** | 3〜4名 | 160C榴弾砲（大型砲塔・自動装填） | 師団野戦特科連隊（主攻支援） |
| **210C超重自走砲** | **車体据付型 (カゼメット)** | 4名 | 210C超重砲 ＋ 後部大型駐退スペード | 師団特科超重破壊大隊（要塞粉砕） |
| **装軌連装対空戦車 (Heavy SPAAG)** | 全周旋回砲塔 | 3名 | 35C連装高射機関砲 ＋ 近接SAM ＋ 捜索追尾レーダー | 師団高射連隊（重機甲突撃直協防空） |
| **重装軌超重ARV** | 車体固定クレーン | 3名 | 60t級牽引ウインチ ＋ 大型クレーン | 連隊/師団/軍団重回収班 |

> [!IMPORTANT]
> **重砲の2大マウント設計の必然性**:
> - **160C砲塔自走砲**: 343マス盤面で友軍の機動軸に合わせて砲塔のみを旋回させ、連続斉射・同時着弾（MRSI）を行う即応支援砲。
> - **210C車体据付超重砲**: 210mmの超絶な発射反動を砲塔リングでは受け止められないため、車体に直結。車体後部の油圧スペードを地面に打ち込んで固定射撃し、要塞・巨大巣穴を破砕する。

### 2.2 ② 装軌装甲車系列 (Tracked Armored: 25〜35t級)
機甲連隊の戦車に直随伴し、路外・泥濘・森林地帯を強行突破する履帯式装甲ファミリー。

- **共通特徴**: 下車歩兵定員は**「固定8名（1個完全歩兵分隊）」**に統一。
- **主要バリアント**:
  - **装軌IFV**: 30/40C機関砲砲塔 ＋ ATGM（乗員3名 ＋ 下車8名）
  - **装軌APC**: RWS（12.7C機銃） ＋ 拡張キャビン（乗員2名 ＋ 下車8名 ＋ 予備弾薬容積）
  - **装軌自走迫撃砲**: 120C重迫撃砲砲塔・自動装填（乗員4名）
  - **装軌単装対空車 (Medium SPAAG)**: 35C単装高射機関砲 ＋ 近接SAMポッド（乗員3名）
  - **装軌対空レーダー・指揮車**: 3次元対空捜索レーダーマスト ＋ 射撃統制端末
  - **装軌CEV（戦闘工兵車）**: 啓開プラウ ＋ ドーザー ＋ 爆薬射出機
  - **装軌中距離SAM**: 垂直/傾斜装軌式地対空ミサイルキャニスター

### 2.4 ④ 重装輪車両系列 (Heavy Wheeled Tactical Truck: 8×8/10×10)
非装甲・軽装甲キャビンの大重量プラットフォーム。大重量火器システムや兵站輸送を担う。

- **155C装輪自走榴弾砲**: 装輪トラック荷台に無人砲塔/自動装填機構を架装した長射程機動砲。
- **TEL弾道・長距離誘導弾発射機**: キャニスターランチャーを車体後部に搭載した軍団直轄ミサイルシステム（大戦略2タイル先へのスタンドオフ攻撃）。
- **重装輪対空ミサイル (Wheeled SAM)**: 師団・軍団上空を覆う中・長距離防空SAMシステム。
- **重装輪長距離対空レーダー車**: 大深度・広域対空監視レーダーを架装した防空指揮ノード。
- **重装輪大型回収車 (W-ARV)**: 装輪部隊用の大型クレーン・レッカー車。
- **弾薬補給給弾車・大型燃料タンカー**: パレット化弾薬の自動移送クレーンを備えた兵站車両。

### 2.5 ⑤ 4輪駆動高機動系列 (4×4 Light Tactical: 5〜8t級)
高速機動・小型ネットワークシステムを搭載する軽装甲車両。

- **多目的誘導弾システム (NLOS-MPM)**:
  - **発射機車 (4×4)**: キャニスター式多目的重誘導弾（対舟艇・対戦車・大型生体目標）。
  - **射撃指揮所車 (4×4)**: 目標割り振り・データリンク演算。
  - **レーダー索敵観測車 (4×4)**: 前進展開して目標を捜索・精密照射。
- **4×4近接即応SAM車**: 短距離地対空ミサイル（拠点・司令部局所防衛）。
- **軽装甲高機動偵察車 (4×4 LAV)**: 機銃・対戦車誘導弾・センサーポッドを装備した先導警戒車。

### 2.6 ⑥ 国家戦略決戦兵器系列 (超弩級・特殊兵器)

#### 1. 二脚歩行戦闘車両（AWGS風・高級装甲部隊）
- **機体寸法**: 全高 3.76m〜4.20m（輸送機格納時） / 全幅 5.48m以下。大型戦略輸送機のカーゴベイ規格に完全適合。
- **主兵装**: 35C/40C機関砲、重対戦車ミサイルポッド、スモークディスチャージャー。
- **運用特性**: 地上インフラ拒絶地域（山岳・崩壊都市）における完全歩行走破および跳躍ブースターによる短時間立体急襲（30〜60秒）。
