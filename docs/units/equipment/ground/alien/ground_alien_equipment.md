# 陸上・エイリアン生体兵装・種別仕様書 (Ground Alien Bio-Arsenal & Species Platforms)

本作における野生・固有エイリアンの陸上生態系における生体兵装、個体階層体系（生体プラットフォーム）、および戦闘メカニクスの詳細仕様書である。

---

## 1. 陸上エイリアン生体兵装・個体の階層体系

野生エイリアンは人間のような火器工場や車両金型・補給品規格を持たず、生態系の体格階層（サイズクラス）と群生適応によって以下の系統に区分・階層化される。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                    陸上エイリアン生体 6大プラットフォーム系統               │
├─────────────────────────────────────────────────────────────────────────────┤
│  ①【小型格闘・侵食種系列 (人馬〜軽車両大: 200〜500kg)】                     │
│    └─ 敏捷な四肢/六肢・高密度スウォーム・浸透奇襲（非装甲・歩兵の殺傷）    │
│  ②【中型格闘・装甲解体種系列 (装甲車大: 3〜6t級)】                          │
│    └─ カマキリ状中型怪獣。軽装甲車（LAV）瞬時解体・装甲車（IFV）時間掛け解体│
│  ③【戦車型・大型格闘種系列 (主力戦車大: 40〜60t級)】                         │
│    └─ 超硬化キチン複合殻。敵戦車に組み付き長時間を掛けて装甲板をこじ開ける │
│  ④【決戦巨獣・タイタン系列 (全高20m級: 250〜500t級)】                        │
│    ├─ 超大型接近戦型: 圧倒的質量と超巨大鎌腕で敵戦車・バンカーを踏み潰す   │
│    └─ 超大型ニードル砲撃型: 巨大骨棘を放物線投射（巨体の割にミサイル威力）  │
│  ⑤【陸棲航空格闘系列 (ワイバーン型: 翼幅10〜15m / 2〜4t級)】                │
│    └─ 低空急降下による「地上部隊への近接空中格闘・奇襲」（上面装甲切り裂き）│
│  ⑥【群生専従・機能支援系列 (防空・治療個体)】                               │
│    ├─ 対空種: 生体機関砲の近接信管砲弾幕 ＋ 自律追尾生体ミサイル           │
│    └─ 治療種: 高活性修復分泌液による甲殻亀裂・筋組織の急速自己再生         │
└─────────────────────────────────────────────────────────────────────────────┘
```

> [!NOTE]
> **野生エイリアンの戦闘ドクトリンと生態原則**:
>
> - **格闘種の威力階層と破壊時間**:
>   - **戦車型（大型格闘種）**: 主力戦車を一撃で破壊する超兵器ではなく、「**厚い装甲に張り付き、長い時間を掛けて装甲板を切り刻み・こじ開けて破壊する**」。
>   - **中型格闘種**: 「**大型格闘種にできないことは中型格闘種にもできない**」原則に従う。主力戦車は破壊できず、**装甲車（IFV/APC）に対しても破壊するのに長い時間がかかる**。一方で**軽装甲車（4x4 LAVや非装甲トラック）なら短時間で切り裂き・破壊**できる。
>   - **小型格闘種**: 装甲目標には歯が立たず、下車歩兵や非装甲目標の殺傷・足止めに特化。
> - **指揮種の排除**: 人間のような指揮通信車に相当する「指揮種」は存在しない。群生本能やフェロモン連鎖によって自律的に前進・群がる。
> - **対空能力の例外保持**: 空中からの航空攻撃に一方的に蹂躙されるのを防ぐため、対空種のみ**生体機関砲による近接信管砲弾（対空破片炸裂弾）**と**生体ミサイル（自律追尾生体弾）**による本格的な対空迎撃火力を例外的に保持する。
> - **超大型種（タイタン級）と部隊の分離**:
>   1. **超大型エイリアン軍団**: 超大型接近戦型巨獣を基幹とし、圧倒的な質量と超巨大鎌腕で敵陣地や戦車を踏み潰し・蹂躙する部隊。
>   2. **長距離砲撃軍団**: 超大型ニードル砲撃型巨獣を基幹とし、巨体の割にはミサイル程度の威力しかない長距離ニードル（巨大棘弾）を遠距離から放物線投射する部隊。
> - **陸棲航空型**: 制空権確保は空棲種（エイリアン航空団）の役割とし、陸棲航空型は低空急降下して敵地上部隊へ「**近接空中格闘襲撃**」を仕掛ける飛行怪獣。

## 2. エイリアン生体兵装・個体カテゴリー詳細スペック

### 2.1 小型格闘・侵食種 (Small Melee Beast)

- **体格・規模**: 小型（全高1.2〜1.8m、重量200〜500kg、人馬〜軽車両大）。
- **解剖学的特徴・兵装**:
  - 四肢または六肢の多脚歩行。急峻な岩盤登攀、密林樹上・洞窟の天井走行が可能。
  - **鋭利なキチン質爪・小鎌腕**: 人間や非装甲車両の外板を容易に切り裂く。
  - **群体フェロモン連鎖**: 視界外の仲間と化学シグナルで同期し、死角から群れで殺到する。
- **戦闘能力と限界**:
  - 装甲車両（IFV/APC/戦車）の装甲板には傷を付ける程度で貫通・破壊は不能。
  - 一方で、下車歩兵、観測班、非装甲輜重トラックに対しては津波のように群がり瞬時に殺傷・制圧する。

---

### 2.2 中型格闘種 (Medium Mantis Beast)

- **体格・規模**: 中型（全長4〜6m、全高2.5〜3.5m、重量3〜6トン、装甲車大）。
- **解剖学的特徴・兵装**:
  - カマキリを大型怪獣化したような多脚骨格と強靭な外骨格。
  - **高硬度キチン質大鎌腕**: 油圧プレスのごとき膂力を持ち、炭素鋼板や軽装甲を剪断する。
  - 機関砲や誘導弾などの射撃器官は一切持たず、純粋な生体格闘戦に特化。
- **威力階層と破壊時間（厳格な原則）**:
  - **対戦車**: 主力戦車の重装甲は**破壊不能**。組み付いても装甲を破れず反撃を受けて撃破される。
  - **対装甲車（IFV/APC）**: 一撃破壊は不可能であり、**破壊するのに長い時間がかかる**。車体に取り付き、ハッチや装甲継ぎ目を徐々にこじ開けて乗員を排除する。
  - **対軽装甲車（4x4 LAV・偵察車）**: **短時間で装甲を切り裂き・解体・破壊**が可能。

---

### 2.3 戦車型・大型格闘種 (Heavy Tank Mantis Beast)

- **体格・規模**: 大型（全長7〜9m、全高3.5〜4.5m、重量40〜60トン、主力戦車大）。
- **解剖学的特徴・兵装**:
  - **重層キチン複合甲殻**: 人類の120C徹甲弾（APFSDS）の直撃にも耐えうる傾斜生体装甲。
  - **超硬質大鎌腕**: 金属濃縮結晶を含んだ巨大鎌腕。油圧ショベル以上の破砕トルクを発揮。
  - **泥沼の格闘戦**: 主力戦車を一撃で爆散させる超兵器ではなく、「**敵戦車に組み付き、長い時間を掛けて装甲板を切り刻み・こじ開けて破壊する**」。
- **戦闘能力と役割**:
  - 機甲連隊の戦車隊と正面衝突し、ゼロ距離での格闘戦に引きずり込んで人類側の射撃優位を封じる主力決戦生体。
  - 装甲車（IFV/APC）相手であれば中型種よりも遥かに短い時間で叩き潰し排除可能。

---

### 2.4 超大型接近戦型 (Titan Melee Colossus)

- **体格・規模**: 超大型・タイタン級（全高18〜25m、全長30〜45m、重量300〜500トン）。
- **解剖学的特徴・兵装**:
  - **超重複合キチン装甲**: 戦車の主砲連射や大口径榴弾の直撃を物ともせず前進する規格外の耐久力。
  - **超巨大鎌腕と踏み潰し質量**: ビル大の鎌腕による薙ぎ払いと、数十トン〜数百トンの自重による踏み潰し。
  - **陣地・戦車の圧壊蹂躙**: 敵防衛線に到達した場合、戦車やトーチカ、コンクリート防壁を一撃で物理的に圧壊する。
- **制約**:
  - 射撃能力は一切持たず、敵陣地に突入して初めて破壊力を発揮する。

---

### 2.5 超大型ニードル砲撃型 (Titan Needle Artillery Beast)

- **体格・規模**: 超大型・タイタン級（全高18〜22m、全長35〜50m、重量250〜400トン）。
- **解剖学的特徴・兵装**:
  - **生体長大発射筒**: 胴体中央に天を仰ぐ長大な発射腔を持つ。
  - **高圧生体骨棘（ニードル弾）**: 体内で急速結晶化させた全長3〜5mの巨大有機ニードルを高圧ガス嚢で斜角投射。
  - **威力特性**: 全高20m級の巨躯を持つが、発射されるニードル弾は**「人類のミサイル程度の威力」**に留まる。長射程を活かした散発的な嫌がらせ・後方攪乱・前線牽制が主目的。
- **制約**:
  - 接近戦能力は極めて脆弱であり、敵部隊に肉薄された場合は自衛できない。

---

### 2.6 陸棲航空型・飛行格闘種 (Aviation Melee Flyer)

- **体格・規模**: 有翼飛行型（全長6〜9m、翼幅10〜15m、重量2〜4トン、ワイバーン型）。
- **解剖学的特徴・兵装**:
  - コウモリ状の頑強な皮膜翼と軽量化したキチン骨格。
  - **対地急降下格闘襲撃**: 高空から垂直急降下し、地上部隊の頭上へ突入。装甲車両の最も薄い「上面（ルーフ）」に爪や鎌腕を突き立て、ハッチや車載火器を破壊する。
- **役割の厳格な分離**:
  - 制空権確保は空棲種（エイリアン航空団）の担当であり、本部隊は空中戦（ドッグファイト）を行わない。敵戦闘機に狙われた場合は脆弱。

---

### 2.7 対空種 (Bio-AA Beast: 中型〜大型)

- **体格・規模**: 中型〜大型（重量5〜30トン級）。
- **例外的な保持兵装**:
  - **生体機関砲（近接信管砲弾）**: 目標予測針路上で炸裂し、無数の高硬度骨片・破片を散布する対空弾幕。
  - **生体ミサイル**: 背部嚢胞から発射される高機動・自律追尾生体弾（熱源・電波・光波ホーミング）。
- **役割**:
  - 生体群が上空からの攻撃ヘリや対地爆撃機に一方的に蹂躙されるのを防ぐ防空の要。

---

### 2.8 治療種 (Regeneration Beast: 中型)

- **体格・規模**: 中型（重量3〜10トン級）。
- **解剖学的特徴・機能**:
  - **高活性修復分泌液**: 体内腔で生成された生体ゼリー・硬化タンパク質を被弾個体の装甲亀裂や損傷部に噴霧・塗布。
  - 戦闘中および戦闘終了後に個体の甲殻や筋組織を急速に自己治癒（Regeneration）させる。

## 3. 生体兵器と人類陸上兵器の対比一覧

| :--------------------------- | :---------------------------- | :------------------------------------------------------------------ |
| **小型格闘種**               | 軽歩兵・斥候班                | 人間・トラックを瞬時殺傷。戦車・装甲車には通用しない。              |
| **中型格闘種**               | 軽装甲車（LAV）〜中型IFV      | 軽装甲車は短時間で破壊。IFV破壊には長時間を要する。戦車は破壊不能。 |

| **超大型接近戦型**           | 陸上戦艦・要塞決戦兵器        | 圧倒的質量で敵陣地・戦車を踏み潰し圧壊。射撃能力なし。              |
| **超大型ニードル砲撃型**     | 自走榴弾砲・長距離TEL         | 巨体の割にミサイル程度の威力。遠距離からの放物線投射・牽制。        |
| **陸棲航空型（飛行格闘種）** | 対地攻撃ヘリ・CAS機           | 車両上面への近接急降下格闘。制空戦闘は行わない。                    |
| **対空種**                   | 自走高射機関砲・野戦SAM       | 生体近接信管砲弾と自律追尾ミサイルによる本格対空迎撃。              |
