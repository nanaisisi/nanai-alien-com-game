# 師団直協航空アセット（米軍式航空連隊）運用仕様書

(Direct Support Aviation Assets & US-Style Organic Aviation Regiment Doctrine)

本作における常設増強師団にオーガニック（直轄常設）として内包される**「米軍式・師団直協航空連隊（計32機: 戦闘飛行隊×2＋輸送飛行隊×2）」**および戦術UAV/ドローンの機体規格、兵站燃料（航空推進剤）、CAS（近接航空支援）介入、および空中輸送メカニクスを規定する仕様書である。

---

## 1. 開発思想と直協航空の原則

本作の大戦略マップ上では「単体の戦闘機・ヘリユニットが飛び回る煩雑さ」を排し、**地上増強師団にオーガニック（直轄常設）として内包される米軍式航空アセット（Combat Aviation Brigade 相当）**として運用する。

1. **常時追従する航空傘（Aviation Umbrella）**:
   - 師団直轄航空連隊（32機）は地上増強師団と一体となって前進・展開する。
   - 戦術戦闘（343マス）が発生した際、師団司令部（プレイヤー/AI指揮官）の要請によって直ちに上空へ突入・介入する。
2. **2進数・倍々構造に適合した「1飛行隊＝8機」基準**:
   - 4機（1セクション / 2ペア）を最小戦術単位とし、**2セクション＝1個飛行隊（8機）**とする。
   - 師団直轄として**戦闘飛行隊×2個（16機）＋輸送飛行隊×2個（16機）の計4個飛行隊（32機）**を基本TO&Eとする。

## 3. 戦術戦闘・兵站シミュレーションにおける運用ルール

### 3.1 近接航空支援（CAS: Close Air Support）介入

- 増強師団が戦術戦闘（343サブタイル）に突入した際、戦闘飛行隊の機体（最大16機）が出撃可能。
- **進入と離脱**:
  - 外周エッジから高速侵入し、指定した敵重装甲個体・特科陣地へ一撃離脱（スラッシュ＆ラン）または低空旋回制圧を実施。
  - 滞空燃料および機関砲・ミサイル弾薬を撃ち尽くすと、自動的に盤外の師団段列へ帰投・補給に入る。
- **対空火網（防空傘）との相互作用**:
  - 敵の防空部隊（自走高射機関砲・短距離SAM）の射程内では、被弾・墜落判定が発生。
  - 特科部隊による敵対空火網の事前制圧（SEAD）や、自軍UAVによる囮展開との連携が重要。

### 3.2 空中輸送・緊急兵站架橋（Air Bridge）

- 幹線道路や鉄道が破壊・寸断された山岳・渡河・湿地・汚染地帯において、輸送飛行隊が以下のバイパス機能を提供する：
  1. **ヘリボーン強襲展開**: 山岳猟兵や軽装歩兵小隊を、敵の防衛線を飛び越えて後方要衝や高地へ直接降下。
  2. **緊急航空補給**: 弾薬・燃料・補修部品を前線孤立部隊へ直接空輸し、兵站断絶（Critical 状態）による戦闘停止を遅延。
  3. **負傷兵・損傷コア回収（MEDEVAC）**: 損傷した二脚車両や戦車から脱出した搭乗員・高価な論理コアを後方野戦病院へ回収。

### 3.3 航空推進剤（Aviation Fuel）の兵站消費

- 航空機は一般装軌・装輪車両の軽油・重油とは異なり、**高純度の「航空推進剤」**を激しく消費する。
- 兵站断絶時には、地上車両よりも先に航空連隊の出撃可能機数が制限（燃料枯渇による地上待機）される。

## 4. 共食い整備（Cannibalization）と部品互換性

- **回転翼・航空推進系（共通化率 60〜75% / 成功率 70%）**:
  - 戦闘ヘリと輸送ヘリの間で、タービンエンジン・ローターハブ・アビオニクス基板の部品取りが可能。
  - 跳躍型二脚歩行車両（Jump-Flight Walker）のガススラスタノズルとも一部部品融通が可能。
