# 本部管理中隊（HHC）および本部付補助諸兵科 仕様定義書

(Headquarters & Headquarters Company: Base Infrastructure & Attached Specialized Assets Specification)

本作における各戦闘団（Combat Group）および傘下の連隊・大隊は、単一または混成の戦闘中隊のみで成立しているのではなく、それらの作戦行動・指揮統制・生存性を担保する**「本部管理中隊（HHC: Headquarters & Headquarters Company / 本部管理群・付隊）」**をオーガニック（直属）に保有している。

本ドキュメントは、全部隊に共通する**「基本構成（基盤的補助諸兵科）」**と、各部隊の兵科特性・任務に応じた**「本部付き専門部隊」**の2層構造、およびゲームシステム（ECS・C4I・兵站・整備）への影響メカニクスを定義する。

---

## 1. 本部管理中隊（HHC）の基本構造：2層モデル

部隊規模（大隊、連隊、師団・戦闘団）を問わず、本部管理中隊は以下の2層構造で編成される。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                 本部管理中隊（HHC）の2層構造モデル                          │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【第1層: 全兵科共通・基盤的補助諸兵科 (Base Infrastructure Platoon)】     │
│    ・司令部機能 / 幕僚・指揮所装甲車（C4Iノード）                          │
│    ・通信・戦術データリンク小隊（電波中継・抗生体ジャミング）               │
│    ・本部補給・輸送小隊（FARP/FSP開設、前線弾薬・燃料・真水配分）           │
│    ・衛生・野戦救護小隊（装甲野戦救急車、前線トリアージ、生体除染）         │
│    ・野戦整備・回収班（故障・被弾車両の即時牽引、共食い整備窓口）           │
│    ・司令部警護・防護小隊（近接警備、対空・対ドローン局所監視）             │
│                                                                             │
│  【第2層: 主兵科・任務特化・本部付き部隊 (Specialized Attached Assets)】   │
│    ・部隊の主兵科（機甲・歩兵・偵察・特科等）に応じて直属する専門戦力      │
│    ・指揮官（大隊長/連隊長/師団長）が直率し、即座に投入できる「戦術切り札」 │
│    ・例: 機甲 ➔ 戦闘工兵・架橋・重回収 / 歩兵 ➔ 重迫撃砲・対戦車 / 偵察 ➔ EW │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 2. 全兵科共通：基盤的補助諸兵科の詳細

各大隊・連隊・師団本部において、戦闘単位（小隊・中隊）を後方・側面から支える共通機能。

| 機能要素 | 装備・構成 | 戦術・兵站上の役割 | 損耗・機能停止時のペナルティ |
| :--- | :--- | :--- | :--- |
| **司令部・指揮所 (Command & Staff)** | 装甲指揮車（C4I）、移動幕僚シェルター、戦術卓 | 部隊全体の作戦立案、進撃・防御スタンス制御、命令伝達。 | 指揮統制ディレイ増大、大戦略ベクトルの反応低下、混乱状態。 |
| **通信・電子情報 (Signal & Link)** | 戦術データリンク中継車、指向性レーザー通信車、成層圏リンク | リアルタイム戦況共有、エイリアンの生体ジャミング環境下でのリンク維持。 | サブタイル視界共有喪失、間接照準射撃の精度激減（キルチェーン寸断）。 |
| **本部補給・輸送 (Supply & Transport)** | 高機動燃料タンカー、装甲弾薬運搬車、水タンク | 中隊への直接給油・弾薬補給、前進補給点（FARP/FSP）の設営。 | 弾薬切れ・燃料枯渇、行軍速度の低下、持続斉射能力の停止。 |
| **衛生・野戦救護 (Medical & Triage)** | 装甲野戦救急車、緊急外科コンテナ、生体汚染除染テント | 負傷兵の迅速回収・前線トリアージ、エイリアン体液・毒素の除染。 | 兵員損耗率（戦死率）の跳ね上がり、士気低下、後方送還不能。 |
| **野戦整備・回収 (Maintenance & Recovery)** | 装甲回収車（ARV）、移動工作車、溶接・クレーンコンテナ | 擱座車両の即時回収・牽引、現地応急修理、共食い整備の実行窓口。 | 被弾車両の現地放棄率上昇、全滅判定の増加、稼働率回復の遅延。 |
| **司令部警護 (Security & Defense)** | 警護歩兵分隊、遠隔銃座（RWS）、局所対ドローンジャマー | 指揮所周辺の残敵警戒、迂回遊撃エイリアン・特殊潜入部隊の排除。 | 司令部への奇襲脆弱性、C4I中枢の不意な壊滅リスク。 |

## 3. 部隊特性に応じた「本部付き専門部隊」体系

各部隊の主兵科および作戦ドクトリンに基づき、本部管理中隊内に組み込まれる専用アセット。

### 3.1 機甲連隊 / 機甲大隊の本部付部隊

戦車の圧倒的突撃力・突破力を「地形や障害で停止させない」こと、および「戦車自体の死角・重整備を支える」ことに特化。

* **連隊直轄・自走重迫撃砲中隊（Armored Mortar Company: 120C装軌自走重迫撃砲 16両）**:
  * 機甲連隊は直射火力が絶大であるため小隊・中隊単位の90C小規模迫撃は持たず、連隊直轄の自走迫撃砲中隊（16両）として集中配置。
  * 連隊長の命令一下、突撃軸の前方や直射不能な稜線裏・市街地瓦礫へ大口径曲射弾幕と突撃用煙幕スクリーンを一括投射する。
* **連隊直轄・装甲戦闘工兵小隊（Armored Combat Engineers）**:
  * **装甲架橋車（AVLB）**: 河川・峡谷・地割れへの即時架橋。
  * **戦闘工兵車（障壁啓開・地雷原突破車）**: 敵地雷原、バリケード、エイリアン生体硬化外殻障壁の強制開口。
* **重装甲偵察・前哨小隊（Heavy Scout Platoon）**:
  * 重装甲偵察車（4〜8両）。主力戦車の突撃軸前方における地質探査（底なし沼・軟弱地盤の回避）および敵伏兵の炙り出し。
* **重回収小隊（Heavy Recovery Platoon）**:
  * 60t級超の主力戦車を単独牽引可能な大型装甲回収車（ARV）を専属配置。

### 3.2 普通科・機械化歩兵連隊 / 歩兵大隊の本部付部隊

下車歩兵の脆弱性を補い、歩兵部隊自前の火力投射と接近拒否能力を最大化。

* **重迫撃砲小隊（Heavy Mortar Platoon: 120mm自走迫撃砲 4〜8両）**:
  * 大隊長が直接命じて30秒以内に投射できる「即応ポケット砲兵」。塹壕・市街地ビル・敵巣穴の掃討。
* **対戦車・重誘導弾小隊（Anti-Tank Guided Missile Platoon）**:
  * 長距離対戦車重誘導弾搭載装甲車（4〜8両）。戦車部隊の援護がない局面でも大型突撃個体や敵重装甲をアウトレンジ撃破。
* **戦術UAV・近接斥候班（Tactical Drone & Scout Team）**:
  * 下車歩兵用小型ドローン（クアッドコプター）および赤外線・生体波長スキャナーによる閉鎖空間（森林・洞窟）の事前クリアリング。

### 3.3 偵察戦闘連隊の本部付部隊

広域スクリーン、情報収集、および友軍主隊への精密キルチェーン形成に特化。

* **電子戦・信号諜報小隊（SIGINT / EW Platoon）**:
  * 敵性生体電磁パルス・無線通信の傍受、逆探知による巣窟特定、局所指向性ジャミング。
* **大深度長距離UAV班（Long-range Recon UAV Team）**:
  * 中型カタパルト射出式UAVの運用班。師団砲兵・直協航空機の射程限界まで目標を標定。
* **前進航空統制・統合火力誘導小隊（JTAC / Forward Air Control）**:
  * 師団野戦特科連隊および師団直協航空連隊（ヘリ/VTOL）への高精度レーザー照射・リアルタイム着弾修正。

### 3.4 師団野戦特科連隊 / 高射連隊の本部付部隊

面制圧力および防空傘の効率を極限まで高めるセンサー・計算機ノード。

* **対砲兵・弾道レーダー小隊（Target Acquisition Platoon）**:
  * 敵射撃・エイリアン生体酸弾の弾道を即座に逆算・発射点を特定し、即時カウンター射撃（対砲兵射撃）を可能にする。
* **射撃指揮所装甲車（FDC: Fire Direction Center）**:
  * 全大隊の火砲・ロケット・気象観測データ（風向・気温・大気圧）を集約し、精密射撃諸元を自動並列演算。
* **師団早期警戒・防空統合指揮所（Air Defense Command Post）**:
  * 高射連隊本部に配置。低空から高空までのレーダー・光学情報を一元化し、各防空大隊へ迎撃目標を自動割振。

### 3.5 火力エシュロンの整理：60C（小隊携行） / 90C（中隊中迫） / 120C（大隊重迫）

現場運用のリアリズムと指揮統制・兵站の観点から、歩兵・迫撃火力の担当範囲をエシュロンごとに明確に区分する。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                 迫撃砲・歩兵火力の階層区分（エシュロン体系）                │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【小隊レベル (Platoon)】 ── 60C 軽迫撃砲 (`60×300C`)                       │
│    ・運用形態: 完全人力携行（兵士1〜2名で運搬、コマンド手持ち撃ち可能）    │
│    ・戦術射程: 200m 〜 1.5km（小隊長の手元、目視範囲の障害物・稜線裏）     │
│    ・位置づけ: 小銃分隊の突撃に随伴する「歩兵直接火力」の一部              │
│                                                                             │
│  【中隊レベル (Company)】 ── 90C 中迫撃砲 (`90×500C`)                       │
│    ・運用形態: 中隊本部付 迫撃班（車載ラック運搬 / 三脚・重底板据付運用）  │
│    ・戦術射程: 800m 〜 5.0km（中隊作戦正面全域をカバー）                    │
│    ・位置づけ: 中隊長の「直率即応曲射火力」。突撃路への煙幕展開・面制圧    │
│                                                                             │
│  【大隊レベル (Battalion)】 ── 120C 重迫撃砲 (`120×600C`)                   │
│    ・運用形態: 大隊直轄・自走重迫撃砲中隊（16両: 4小隊編成、装軌/装輪）     │
│    ・戦術射程: 2.0km 〜 10.0km+（大隊突撃軸・要塞・大深度巣穴の粉砕）       │
│    ・位置づけ: 大隊長の「ポケット砲兵中隊」。戦車滑腔砲級の大破壊力        │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

* **中隊運用のポイント（90C中迫撃班）**:
  * 60Cが「分隊員が抱えて走れる即応擲弾の延長」であるのに対し、90C（30〜40kg超＋砲弾4〜5kg）は人力突撃随伴が不可能なため、軽装・一般歩兵中隊本部（IFV/高機動車）に集約運用される。
  * ※なお、全車装軌化された機甲部隊では90Cを配備せず、大隊直轄の120C自走重迫撃砲中隊（16両）に曲射火力を一本化する。
* **大隊運用のポイント（120C自走重迫撃砲中隊 16両）**:
  * 専門的な大口径重迫撃砲（120C）は、大隊直轄の「自走重迫撃砲中隊（16両＝4小隊×4両）」として集中配備。
  * 大隊長の手元で16門の一斉曲射斉射や突撃用大煙幕スクリーンを一括投射できるため、大隊単独で完全な諸兵科連合突撃・制圧が可能となる。

## 5. ゲームメカニクスへのフィードバック（ECS・パラメータ連携）

本部管理中隊（HHC）の存在は、単なるフレーバーテキストではなく、以下の具体的なゲームロジックとして反映される。

### 5.1 指揮統制（C4I）とキルチェーン

* **HHC健常時**:
  * 偵察部隊が視界に捉えた目標に対し、特科連隊や直協航空機が即座にアウトレンジ射撃可能（キルチェーン遅延 0ターン）。
* **HHC被弾・通信車損耗時**:
  * 射撃要請の遅延（1〜2ターンディレイ）、命中精度低下。
  * 司令部装甲車が破壊された場合、部隊は「指揮混乱（Disorganized）」状態となり、大戦略マップ上の作戦ベクトル進行が一時停止する。

### 5.2 前方整備（ARV）と共食い整備

* **HHCの回収・整備班が健常**:
  * 戦術戦闘で「機能停止（M-Kill / F-Kill）」となった車両を戦闘終了後に80%の確率で即時回収。
  * 部隊単独で共食い整備を実施し、翌ターンまでに一部車両を稼働状態（Mission Capable）に復帰させる。
* **HHCの回収・整備班が全滅**:
  * 損傷車両は戦場に放棄（全損扱い）。戦闘団の戦力損耗が不可逆となる。

### 5.3 補給線途絶時の自己維持期間

* 大隊・連隊のHHCが保有する補給小隊により、師団兵站デポからの補給線が1〜2ターン寸断されても、自活して戦闘を継続できるバッファ（内蔵補給プール）を提供する。
