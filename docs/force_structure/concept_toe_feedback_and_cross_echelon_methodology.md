# 部隊編成（TO&E）水平展開・フィードバック手法および共通編制評価基準書

(Methodology for TO&E Cross-Variant Feedback & Architectural Harmonization)

本ドキュメントは、[`toe_combat_group_heavy_armored.md`](../toe_definitions/toe_combat_group_heavy_armored.md) において確立された**「常設増強機甲師団」の詳細な編制・兵科分担・迫撃火力ドクトリン・左右両翼スクリーン・プラットフォーム共通化思想**を、[`toe_combat_group_variants.md`](../toe_definitions/toe_combat_group_variants.md) や [`concept_military_echelon_and_combat_groups.md`](./concept_military_echelon_and_combat_groups.md) に定義されている**他のすべての増強師団編成（空中機動、ドローン特務、山岳猟兵、二脚混成、装輪機動、要塞突破、地域警備等）へ体系的かつ破綻なく水平展開（フィードバック）するための評価基準および改定手順**を定義する。

## 1. フィードバックの基本理念（Horizontal Harmonization Principles）

常設増強機甲師団で得られた知見を他部隊へ適用する際、**「重戦車師団の単なる縮小コピーや兵器の置き換え」を行ってはならない**。各師団アーキタイプが投入される作戦環境（山岳、空中機動、泥濘、都市、電磁妨害環境等）固有の制約と強みを尊重し、以下の原則に基づき**等価な戦術機能の再定義（Functional Equivalency）**を行う。

## 2. 6大共通フィードバック評価軸（Audit Checklist）

各編成を点検・改定する際、以下の6つのチェックリストに照らして整合性を検証する。

### 軸1: 迫撃砲・曲射火力ドクトリン（大隊集約 vs 分散の必然性）

- **機甲・機械化部隊の原則**:
  - 全車自走化・装甲化された部隊では、小隊・中隊単位で機動性を殺す90C中迫撃班は全廃。各大隊直轄の「120C自走重迫撃砲中隊（16両: 4小隊編成）」に集中運用し、大隊長直属の即応投射火力とする。
- **他編成へのフィードバック適用基準**:
  - **装輪機動師団 / 二脚混成師団**: 重機甲と同様に「各大隊付120C自走重迫中隊（16両）」へ統一（装輪自走迫、または二脚アンカー自走迫）。
  - **空中機動師団**: 超軽量車台の「空挺自走迫（120C）16両」へ集約。
  - **山岳猟兵・軽歩兵部隊（例外承認基準）**:
    - 車両が進入不能な岩盤・断崖登攀を行う下車戦闘部隊に限り、大隊迫撃砲（120C固定座）とは別に「中隊付90C中迫」「小隊付60C軽迫」の分散配備を正当なドクトリン例外として認める。

### 軸2: 側翼保護スクリーン（Recon Combat Screen）の環境的等価物

- **重機甲の原則**:
  - 中央の重装軌突破部隊を守るため、高速性に優れた装輪車両による「第1偵察戦闘連隊（左翼80両）」「第2偵察戦闘連隊（右翼80両）」を対称配備し、自前の自走重迫（16両）で遅滞戦闘を自活する。
- **他編成へのフィードバック適用基準**:
  - **装輪高速機動師団**: 全軍が装輪であるため、左右連隊ではなく「前衛偵察戦闘大隊」および「後衛・側衛警備大隊」として師団の長大な高速車列を多軸保護。
  - **空中機動師団**: 装輪車両が随伴できないため、側翼スクリーンを「航空ISR飛行隊（UAV）＋戦闘ヘリペアによる広域滞空監視ライン」に置換。
  - **山岳猟兵師団**: 小型多脚自律斥候犬（UGV 64機）とマイクロドローンによる「断崖・隘路の多層センサー・トラップ網」を側翼スクリーンとして機能させる。
  - **二脚歩行混成師団**: 装輪偵察戦闘連隊（計160両）をそのまま踏襲し、二脚部隊の低い航続距離と舗装路利用不能の弱点を装輪部隊が外側から包み込んで保護。

### 軸3: 突破（Breakthrough）と確保・掃討（Secure & Clear）の分離

- **重機甲の原則**:
  - 戦車と重IFVが敵主力を撃破した直後、後方取り残された残敵や巣穴・市街地を「第1装甲化歩兵連隊（重IFV 64両＋装甲APC 64両＋自走重迫 32両）」が引き受け、主隊の進撃を止めない。
- **他編成へのフィードバック適用基準**:
  - 各バリエーション編成において、「先頭で突入する打撃部隊」と「拠点を占領・要塞化して維持する部隊」が混同されていないかを監査。
  - **要塞突破師団**: 「重戦車・突撃砲連隊（突破）」に対し、「重装甲工兵・攻城歩兵連隊（APC＋工兵啓開車: 要塞掃討・要塞化）」が同等規模で組み込まれていることを確認。
  - **無人自律ドローン師団**: 「自律UGV突撃連隊（突破）」の直後に有人管理の「後方処理・通信防護大隊」が追従する構造を明記。

### 軸4: 3階層本部付き隊（HHC）と縮退ルールの整合

- **重機甲の原則**:
  - 「師団司令部管理中隊（HHC） ⇄ 連隊本部管理中隊（HHC） ⇄ 大隊本部管理班」の3階層で、上級ほど重い支援（架橋・重整備・長距離レーダー）を持ち、下級ほど軽量・戦闘直協（指揮C4I・救護回収）に専念する。
- **他編成へのフィードバック適用基準**:
  - 各種バリエーション編成の各大隊・連隊に、この3階層HHCが欠落していないかを監査。
  - 特殊バイオーム特化部隊における本部付加隊のバリエーション：
    - **空中機動師団**: 前方給油再武装点（FARP）設営班、空中MEDEVAC小隊。
    - **山岳師団**: 高度順応医療班、ワイヤー・懸垂架橋班。
    - **対エイリアン極限部隊**: 特殊生物化学除染隊（大隊レベルにも簡易除染班を前進配備）。

### 軸5: 車体・機体プラットフォーム共通化（共食い整備ライン）の二分化

- **重機甲の原則**:
  - 「案A：近代欧米標準方式（MBTは正面打撃・防御特化の低重心専用車体、IFV/APC/自走迫/支援車は共通の中重装軌Std-T4プラットフォーム）」を採用。
- **他編成へのフィードバック適用基準**:
  - **装輪高速機動師団**: 共通の8x8装輪車台（Std-W8）を基軸に、砲塔換装（105C火力支援車、25C機関砲IFV、兵員輸送APC、120C自走迫、ARV、指揮車）を行う「ストライカー式単一ファミリー共通化」を徹底。
  - **二脚歩行混成師団**: 二脚機体（通常歩行型 vs 短時間飛翔型）における脚部アクチュエータ・動力コアの共通化率を80%以上に設定し、随伴装軌車台（Std-T4）との二重兵站負荷を局限する。
  - **無人師団**: UGVの突撃車台・IFV車台・迫撃車台を同一の装軌自律共通プラットフォームで一本化。

### 軸6: 直協航空連隊（計32機）の作戦環境適応

- **重機甲の原則**:
  - 戦闘飛行隊×2（戦闘ヘリ/VTOL 16機）＋ 輸送飛行隊×2（強襲輸送ヘリ 16機）＝ 計32機（1個飛行隊＝8機編成）を師団直属として完全内包。
- **他編成へのフィードバック適用基準**:
  - **基準維持グループ**: 要塞突破師団、二脚混成師団、装輪機動師団は「標準32機（戦闘16＋輸送16）」を基本型として踏襲。
  - **航空拡充グループ（空中機動師団）**: 地上重戦車を持たない代償として、師団直協連隊を**「強襲航空旅団（計64〜96機: 戦闘32〜48機＋強襲輸送32〜48機）」**へスケーリングアップ。
  - **縮小・特化グループ（山岳猟兵師団）**: 山岳の気流・高高度出力低下に対応するため、戦闘ヘリを減じ「高高度強襲輸送ヘリ 16機」および「高高度戦術UAV隊」へ特化。

## 4. ドキュメント改定・維持管理プロトコル（Update Protocol）

編成仕様の不整合を防ぐため、今後のドキュメント更新は以下のプロトコルを順守する。

1. **基本仕様書の先行確定**:
   - 編成思想・ドクトリンの新方針（例: 迫撃砲の集約、新車台規格）が生まれた場合、まず本ドキュメント（`concept_toe_feedback_and_cross_echelon_methodology.md`）または `concept_military_echelon_and_combat_groups.md` を改定し、ルール化する。
2. **マスターTO&E（重機甲師団）の照合**:
   - 新ルールを [`toe_combat_group_heavy_armored.md`](../toe_definitions/toe_combat_group_heavy_armored.md) へ適用し、完全な数値（両数・中隊数・兵員数・弾薬規格）として実証する。
3. **バリエーションTO&Eへの水平展開**:
   - 本ドキュメントの「6大共通評価軸」に基づき、[`toe_combat_group_variants.md`](../toe_definitions/toe_combat_group_variants.md) の各編成を診断・アップデートする。
4. **個別詳細仕様書（Individual TO&E Specs）の切り出し**:
   - バリエーションのうち、重要度や特殊性の高いもの（装輪高速機動師団、空中機動師団、二脚混成師団など）は、重機甲師団と同様に独立した `toe_combat_group_<type>.md` として順次詳細仕様書を新設する。
