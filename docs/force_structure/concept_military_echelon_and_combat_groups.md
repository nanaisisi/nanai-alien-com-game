# 軍事編成・部隊単位体系および常設増強師団概念仕様書

(Military Echelon, Unit Hierarchy & Reinforced Division Conceptual Specification)

本作（4X大戦略＋サブタイル戦術・増強師団制）における**「大戦略マップ（親タイル）と戦術マップ（サブタイル）における軍事組織階層（エシュロン体系）」**、**「なぜ大戦略1コマが米軍式航空隊を含む常設の諸兵科連合増強師団なのか」**、および**「各種増強師団タイプ（機甲、機械化歩兵、空中機動、海兵水陸、山岳多脚など）の分類体系」**を定義する基本仕様書である。

---

## 1. 軍事組織階層（エシュロン体系）の全体像

本作は大戦略（親タイル）と戦術戦闘（サブタイル）の2重スケールを採用しており、指揮統制とマイクロマネジメント排除の観点から、階層ごとに明確な役割分担を設けている。


## 2. 部隊単位（Unit Echelon）の定義と規模感

機甲科・諸兵科連合における**「4両＝1小隊、4小隊＝1中隊（16両）、2個戦車中隊＋2個歩兵戦闘車（IFV）中隊＝1個大隊（64両）」**という倍々・ペア構造を基底モデルとする。

| 階層 (Echelon) | 兵力規模 | 車両・航空機数 | 組織の内訳とペア補完関係 |
| :--- | :--- | :--- | :--- |
| **小隊 (Platoon)** | 30〜40名 | **4両 / 機** | 最小射撃単位。2両セクション（バディ）× 2組で相互躍進。 |
| **中隊 (Company)** | 120〜160名 | **16両 / 機** | 4個小隊（4両×4＝16両）。同一車種による戦術行動単位。 |
| **大隊 (Battalion)** | 600〜800名 | **約64〜80両** | **諸兵科連合・主従補完の最小完結単位**。**【2個戦車中隊 (32両: 主力突撃打撃) ＋ 2個歩兵戦闘車［IFV］中隊 (32両: 随伴・補完戦力) ＋ 大隊付自走重迫 (16両)】**等の自己完結構成。※ 機甲大隊における歩兵戦闘車中隊は、単なる別兵科の並列配置ではなく、**「戦車の死角を警戒し、待ち伏せRPG・対戦車猟兵やエイリアン近接肉迫を排除して戦車を成立させる【高度・自律的な随伴歩兵（補完戦力）】」**としての立ち位置を担う。 |
| **連隊 / 旅団 (Regiment / Brigade)** | 2,500〜3,500名 | 130〜180両 | 2個諸兵科大隊 ＋ 連隊直轄特科・工兵・偵察隊。 |
| **常設増強師団 (Reinforced Division)** | **10,000〜25,000名** | **500〜1,300両＋32機** | **大戦略マップ上の1コマ**。基幹戦闘連隊群 ＋ 特科連隊 ＋ 高射連隊 ＋ 装輪偵察戦闘連隊 ＋ 米軍式【師団直協航空連隊（計32機）】 ＋ 兵站・通信・工兵群。 |

> [!NOTE]
>
> ### 大隊における「随伴歩兵」の哲学的・実戦的立ち位置
>
> 機甲科において「諸兵科連合」を謳いつつも、戦車大隊の本質は**「戦車が最大の突破力を発揮するための組織」**である。
> 大隊内に混成された2個歩兵戦闘車（IFV）中隊は、教科書的な対等連合という以上に、**「戦車の致命的な死角（森林・市街地・泥濘・巣窟）を索敵・掃討し、戦車を守るための【近接随伴・スクリーニング戦力】」**として機能する。
> これにより、歩兵が削られると戦車の生存性が激減し、逆に戦車を失うと歩兵が敵重装甲にすり潰されるという、実戦に即した非対称な相互依存メカニクスが成立する。
> [!NOTE]
>
> ### 部隊規模のシステム設計：ゲーム的スロット枠の排除
>
> ゲーム的な「スロット枠」といった抽象キャップは一切設けない。
> 増強師団が保持する部隊は、所属各大隊・直轄中隊・航空飛行隊のコレクション（`Vec<SubUnit>`）として扱われ、少数の急造編成（2〜3個大隊規模）から、重厚な本設増強師団（8〜10個大隊超・航空連隊内包）まで柔軟に編成される。

## 3. なぜ「臨時戦闘団」ではなく「常設の増強師団（米軍式航空隊内包）」なのか

従来の4Xゲームで発生していた「戦車単体ユニット」「歩兵単体ユニット」「大砲単体ユニット」を1マスずつ動かすシステムには、以下の重大な欠陥が存在していた。

1. **マイクロマネジメントの破綻**:
   * 大砲を護衛するために戦車と歩兵を毎ターン1ヘックスずつ並走させる必要があり、前線が広がると操作クリック数が激増する。
2. **非現実的な単一兵科運用（スタック問題）**:
   * 「戦車だけを30スタックして突撃」「長距離砲だけ並べて安全圏から撃滅」といった、現実の兵站・防空・諸兵科連合を無視したメタ戦法が横行する。

本作では、大戦略の1コマを単なる臨時混成の戦闘団（Task Force / Combat Group）ではなく、**国家正規軍の恒久的・基盤的な戦略単位である「常設の諸兵科連合増強師団（Reinforced Combined Arms Division）」**として位置づけている。

* **米軍式オーガニック航空連隊（Combat Aviation Brigade）の内包**:
  * 陸上戦力のみならず、**戦闘攻撃ヘリ・重VTOLガンシップ・戦術輸送ヘリ・偵察/攻撃ドローン大隊からなる「師団直協航空連隊（計32機）」を常設直属部隊として完全内包**する。
  * これにより、大戦略マップ上で航空機だけを別コマとして飛ばす煩雑なマイクロ操作（空港配備・航続距離・パトロール指示）を完全に排除。増強師団が前進すれば、その上空に自動的に直協航空支援（CAS: Close Air Support）や低空航空阻止・緊急ヘリボーン補給のアンブレラが常時追従する。
* **常設部隊としての戦略的重み**:
  * 「任務ごとに現地で兵科をつぎはぎする臨時戦闘団」ではなく、平時から独立した指揮所・通信大隊・特科連隊・高射連隊・兵站連隊・航空連隊を恒常的に備えた**「自己完結した常設の軍事単位」**であるため、前線における継戦能力と組織的抗堪性が圧倒的に高い。
* **操作の簡潔性と組織の深み**:
  * プレイヤーは大戦略マップ上で「太い作戦矢印」を指示するだけでよく、内部の連隊・大隊構成やドクトリン（機甲主進、空中強襲、ドローン飽和など）により、部隊の性格が自律的に決定される。

## 4. 2進数・倍々構造（2^N Binary Buddy Echelon System）

本作の部隊編制および運用ロジックは、徹底して**「2進数（倍々構造：1 ➔ 2 ➔ 4 ➔ 8 ➔ 16）」**を基本原則として設計されている。
軍事組織における「バディシステム（ペア運用）」と一致し、**同格の2個単位が互いに前進と援護（Fire and Maneuver）を行い、損耗時には2個単位同士で即座に共食い・再編補完できる**極めて明快な数理モデルである。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                 2進数・倍々エシュロン階層構造 (Binary Hierarchy)            │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  2^0 = 1両・班 (Single Vehicle / Team)                                      │
│    │                                                                        │
│    ▼ (×2: ペア・バディ)                                                     │
│  2^1 = 2両 (Section / 分隊バディ) ── 1両が前進、1両が援護監視（相互補完）   │
│    │                                                                        │
│    ▼ (×2: 小隊)                                                             │
│  2^2 = 4両 (Platoon / 基幹戦術小隊) ── 2両セクション × 2ペア                │
│    │                                                                        │
│    ▼ (×2: 中隊ハーフ) ── (4小隊 = 16両で1個基幹中隊)                       │
│  2^3 = 独立旅団・即応戦闘団規模 ── 前線打撃大隊群 vs 火力支援群              │
│    │                                                                        │
│    ▼ (×2: 標準師団完結)                                                     │
│  2^4 = 標準増強師団 / 諸兵科連合戦闘団 ── 機甲・歩兵連隊 ＋ 特科・航空・兵站 │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 4.1 2進数ペア補完の数理と現場メリット

1. **1対1（1-1）の直接補完**:
   * 隣接する2個大隊（例: 第1機甲大隊 と 第2機甲大隊）が「ペア大隊」として機能。
   * 第1大隊が激戦で稼働率 40% に落ちた場合、僚友である第2大隊の健全パーツや弾薬を優先融通し、即座に「1個大隊を100%健全化、1個を後方再編」という2進集約（2-to-1 合併）が自律判定される。
2. **2対2（2-2）の群補完**:
   * 4個大隊からなる基幹機甲連隊群は、前半2個大隊と後半2個大隊がペアとなって前進・支援を交代。
   * 損耗時も「2個大隊を前線維持、残り2個大隊を後方共食いドナー」として半分ずつ綺麗にリソースをやりくりできる。
3. **直協戦闘群と支援兵站群の半身補完**:
   * 戦闘団全体は、直協戦闘群（戦車＋歩兵）と、後方支援群（特科・防空・航空・兵站群）という「刃（Combat）」と「柄（Support）」のペアとして成立。
   * 兵站断絶時も、後方支援連隊の補給トラック・ARVから前線装甲大隊へ段階的にリソースが注ぎ込まれる。

## 6. 地域配備と機動運用：防衛力の欠如を招かない戦略移行メカニクス

現代安全保障および国土防衛における重要課題である**「地域配備（管区固定）から機動運用（全国展開・即応増援）へのシフト」**を、本作では「後方の完全な防衛力欠如（空白化）」という極端なゲーム的破綻を招かないよう、以下の**二層構造（主力転地と留守警備の分業）**としてモデル化している。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                 地域配備と機動運用のリアルな共存メカニクス                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【部隊の主力が前線へ機動転地しても、地域防衛はゼロ（無防備）にならない】  │
│                                                                             │
│  1. 留守警備基盤（Rear Security Element）の常駐:                            │
│     ・増強師団が前線へ出撃しても、タイルの「基地施設（Base）」や「地方警備  │
│       隊・監視杭・工兵・予備役」は現地に残り、平時の治安・害獣監視は維持。  │
│                                                                             │
│  2. 転地によって生じるのは「絶対的無防備」ではなく【抗堪・即応余力の低下】:│
│     ・重戦車や自走砲・防空SAMといった「重装備打撃力」が前線へ移動するため、 │
│       万が一その地域に本格的な敵軍や巨大エイリアンが急襲してきた場合、     │
│       「単独で撃退する能力」から「耐え忍んで本隊の帰還を待つ遅滞戦」へ変化。│
│                                                                             │
│  3. 鉄道・動脈インフラによる「双方向の迅速性」:                             │
│     ・機動運用化された部隊は、行くのも早ければ「危急の際に自国領へ戻るのも  │
│       早い」。インフラ網が繋がっていれば数ターンで本拠地へ再展開可能。      │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 6.1 2大運用モードのゲーム的仕様比較

| 運用モード | 主な任務と展開 | タイル防衛力・治安 | 転地機動力 | 兵站・維持コスト |
| :--- | :--- | :--- | :--- | :--- |
| **地域配備モード**(*Regional Defense*) | 担当管区（2〜4親タイル）に常駐。インフラ警備、災害救助、エイリアン小害獣の駆除。 | **強固 (100%)**重装備も現地にあるため、奇襲もその場で完全迎撃可能。 | **低速**管外への移動には移動準備ラグ（2ターン）が発生。 | **極小**タイルのインフラから現地自活。燃料消費 -50%。 |
| **機動運用モード**(*Mobile Deployment*) | 危機正面（国境紛争、侵攻された島嶼部・資源地帯）への迅速展開・集中突破。 | **基礎維持 (30%)**主力不在だが、留守警備隊が最低限の治安・遅滞防衛を継続。 | **超高速**幹線鉄道・道路牽引・海上SLC船腹プールをフル活用し長距離急行。 | **大**前線兵站デポからの補給プッシュと燃料消費が全額発生。 |

### 6.2 国家ドクトリンによる「全軍機動運用化」へのシフト

1. **開拓期・平時**:
   * 大半の部隊は「地域配備」として各管区のインフラ保護や治安維持を担い、国家財政を圧迫しないよう低コストで運用される。
2. **情勢緊迫・南西/国境危機エスカレーション**:
   * 外部脅威やエイリアン暴走の発生に伴い、国家指導者（プレイヤー）は**「防衛力整備計画」を発動し、地域配備師団を「機動運用師団」へ順次改変**。
   * これにより、特定正面への戦力集中・抑止力向上が実現される。
3. **留守地域の防衛バランス（納得感の担保）**:
   * 機動運用化によって主力が出撃しても、現地には留守警備隊が残るため、民生生産が即座に停止したり暴動が起きることはない。
   * ただし、留守地域に敵の本格的な空挺侵入や大規模巣窟の暴走が起きた場合は、現地警備隊が「時間稼ぎ（遅滞戦闘）」を行い、**「動脈インフラを使って前線から機動部隊を急行・反撃させる」という緊迫感ある防衛機動戦**が成立する。
