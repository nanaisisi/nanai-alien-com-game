# 陸上装甲・戦闘車両プラットフォームおよびバリアント総合仕様書
(Ground Combat Vehicle Platform Families, Chassis Standards & Variant Architecture)

本ドキュメントは、本作（4X大戦略＋サブタイル戦術戦闘）において軍団・師団に配備されるすべての陸上戦闘車両について、**車体プラットフォーム系統（重装軌・装軌装甲・8輪装甲・重装輪トラック・4×4高機動）**、**共通化・派生バリアント体系**、および**砲塔・据付マウント構造**を網羅・体系化した仕様書である。

---

## 1. 車体プラットフォーム系統の基本分類

兵站ラインの簡素化、工廠での金型転換（Re-tooling）コスト低減、および前線での共食い整備性を最大化するため、全車両を以下の5大プラットフォームに厳密に区分する。

```text
┌─────────────────────────────────────────────────────────────────────────────┐

├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  ①【重装軌・戦車系列 (Heavy Tracked MBT Chassis: 50〜60t級)】              │
│    └─ 最大限の防護力と大出力を誇る重突撃・決戦プラットフォーム              │
│                                                                             │
│  ②【装軌装甲車系列 (Tracked Armored Vehicle: 25〜35t級)】                   │
│    └─ 泥濘地・不整地での踏破力と重防護を両立した履帯式装甲ファミリー       │

│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 2. 車体系列ごとの詳細仕様と搭載兵器

### 2.1 ① 重装軌・戦車系列 (Heavy Tracked: 50〜60t級)
敵主力を正面から破砕し、敵の重砲撃・エイリアン酸弾に耐えうる最重装甲車体。

| 車種名 | 車体・マウント構造 | 乗員 | 主兵装・特殊装備 | 運用・配備先 |
| :--- | :--- | :--- | :--- | :--- |
| **主力戦車 (MBT)** | 全周旋回砲塔 | 3名 | 120C〜135C滑腔砲 ＋ 同軸機関銃 ＋ APS | 機甲連隊（基幹打撃） |
| **160C自走榴弾砲** | **全周旋回砲塔型** | 3〜4名 | 160C榴弾砲（大型砲塔・自動装填） | 師団野戦特科連隊（主攻支援） |
| **210C超重自走砲** | **車体据付型 (カゼメット)** | 4名 | 210C超重砲 ＋ 後部大型駐退スペード | 師団特科超重破壊大隊（巣穴粉砕） |
| **装軌連装対空戦車 (Heavy SPAAG)** | 全周旋回砲塔 | 3名 | 35C複合機関砲×2 ＋ 近接SAM ＋ 捜索追尾レーダー | 師団高射連隊（重機甲突撃直協防空） |
| **重装軌超重ARV** | 車体固定クレーン | 3名 | 60t級牽引ウインチ ＋ 大型クレーン | 連隊/師団/軍団重回収班 |

> [!IMPORTANT]
> **重砲の2大マウント設計の必然性**:
> - **160C砲塔自走砲**: 343マス盤面で友軍の機動軸に合わせて砲塔のみを旋回させ、連続斉射・同時着弾（MRSI）を行う即応支援砲。
> - **210C車体据付超重砲**: 210mmの超絶な発射反動を砲塔リングでは受け止められないため、車体に直結。車体後部の油圧スペードを地面に打ち込んで固定射撃し、要塞・巨大巣穴を破砕する。

### 2.2 ② 装軌装甲車系列 (Tracked Armored: 25〜35t級)
機甲連隊の戦車に直随伴し、路外・泥濘・森林地帯を強行突破する履帯式装甲ファミリー。

- **共通特徴**: 下車歩兵定員は**「固定8名（1個完全歩兵分隊）」**に統一。
- **派生バリアント**:
  - **装軌IFV**: 30/40C機関砲砲塔 ＋ ATGM（乗員3名 ＋ 下車8名）
  - **装軌APC**: RWS（12.7C機銃） ＋ 拡張キャビン（乗員2名 ＋ 下車8名 ＋ 予備弾薬/重火器容積）
  - **装軌自走迫撃砲**: 120C重迫撃砲砲塔・自動装填（乗員4名）
  - **装軌単装対空車 (Medium SPAAG)**: 35C単装高射機関砲 ＋ 近接SAMポッド（乗員3名。中装軌の車形容積に最適化した単装対空戦闘車）
  - **装軌対空レーダー・指揮車 (Tracked Radar/CP)**: 3次元対空捜索レーダーマスト ＋ 射撃統制端末（自走対空小隊・中隊の目となる探知ノード）
  - **装軌CEV（戦闘工兵車）**: 啓開プラウ ＋ ドーザー ＋ 爆薬射出機
  - **装軌中距離SAM**: 垂直/傾斜装軌式地対空ミサイルキャニスター

### 2.3 ③ 8輪装甲装輪車系列 (8×8 Wheeled Armored: 20〜30t級)
舗装路・乾燥平原での圧倒的な戦略機動力を誇り、防弾・装甲戦闘を行う共通プラットフォーム。
同一の8×8車体から派生し、**対空バリアント（8輪装甲単装対空車・レーダー車）を含めた共通装甲ファミリー**を展開する。

| バリアント分類 | 乗員・定員 | 主要兵装・機能モジュール | 配備先・役割 |
| :--- | :--- | :--- | :--- |
| **① IFV（歩兵戦闘車）** | **乗員 3名 ＋ 下車 8名** | 30/40C機関砲砲塔 ＋ ATGM ＋ APS | 機甲随伴、装甲歩兵連隊。 |
| **② APC（装甲兵員輸送車）** | **乗員 2名 ＋ 下車 8名** | RWS（12.7C機銃/40C擲弾） | 装甲歩兵連隊。拠点確保・掃討。 |
| **③ RCV（偵察戦闘車）** | **乗員 3名 ＋ 斥候 2名** | 25C機関砲 ＋ 昇降式光学・赤外線マスト | 偵察戦闘連隊。前線威力偵察。 |
| **④ 火力戦闘車両 (MCV)** | **乗員 3名**（自動装填） | 105C低反動砲 ＋ FCS | 偵察戦闘連隊。即応対戦車・陣地破壊。 |
| **⑤ 自走迫撃砲 (MSP)** | **乗員 4名**（自動給弾） | 120C重迫撃砲砲塔 | 各大隊付自走重迫中隊。即応曲射。 |
| **⑥ 8輪装甲単装対空車** | **乗員 3名** | **35C単装高射機関砲 ＋ 短距離SAM** | 偵察戦闘連隊・装輪機動部隊の直協防空。 |
| **⑦ 8輪装甲対空レーダー車** | **乗員 3名** | **昇降式3次元フェーズドアレイ対空レーダー** | 装輪対空小隊の目標捕捉・射撃諸元伝送。 |
| **⑧ 指揮通信 (CP/SIG)** | **乗員 2名 ＋ 幕僚 4〜6名** | C4I戦術卓、大容量データリンク | HHC、通信大隊。キルチェーン統制。 |
| **⑨ 患者輸送 (AME/MED)** | **乗員 2名 ＋ 衛生 2名 ＋ 担架4〜6名**| 応急外科設備、生体除染隔離カプセル | HHC衛生小隊。トリアージ・後送。 |
| **⑩ CBRN偵察車** | **乗員 3名 ＋ 分析員 1名** | 外部ロボットアーム、生体毒素質量分析器 | 師団NBC防護隊。生体毒素検知。 |
| **⑪ 兵站支援型 (前線ARV)** | **乗員 3名**（牽引・工作員）| クレーン、ウインチ、前線装甲牽引装具 | 連隊回収班。装甲車前方牽引。 |
| **⑫ 施設支援型 (CEV)** | **乗員 2〜3名**（戦闘工兵）| 折り畳み架橋、地雷啓開プラウ、ドーザー | 施設戦闘工兵大隊。前線障害啓開。 |

### 2.4 ④ 重装輪車両系列 (Heavy Wheeled Tactical Truck: 8×8/10×10)
非装甲・軽装甲キャビンの大重量プラットフォーム。大重量火器システムや兵站輸送を担う。

- **155C装輪自走榴弾砲**: 装輪トラック荷台に無人砲塔/自動装填機構を架装した長射程機動砲。
- **TEL弾道・長距離誘導弾発射機**: キャニスターランチャーを車体後部に搭載した師団・軍団直轄ミサイルシステム。
- **重装輪対空ミサイル (Wheeled SAM)**: 師団上空を覆う中・長距離防空SAMシステム（キャニスターランチャー車）。
- **重装輪長距離対空レーダー車**: 大深度・広域対空監視レーダーを架装した防空指揮ノード。
- **重装輪大型回収車 (W-ARV)**: 装輪部隊用の大型クレーン・レッカー車。
- **弾薬補給給弾車・大型燃料タンカー**: パレット化弾薬の自動移送クレーンを備えた兵站車両。

---

### 2.5 ⑤ 4輪駆動高機動系列 (4×4 Light Tactical: 5〜8t級)
高機動・小型ネットワークシステムを搭載する軽装甲車両。

- **多目的誘導弾システム (NLOS-MPM)**:
  - **発射機車 (4×4)**: キャニスター式多目的重誘導弾（対舟艇・対戦車・大型生体目標）。
  - **射撃指揮所車 (4×4)**: 目標割り振り・データリンク演算。
  - **レーダー索敵観測車 (4×4)**: 前進展開して目標を捜索・精密照射。
