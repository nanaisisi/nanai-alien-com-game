# 1ユニット＝2個師団1軍団制 概念・編制検討書

(Study on One-Unit Corps Structure: 2-Division Integrated Armored Corps)

本ドキュメントは、本作（4X大戦略＋サブタイル戦術戦闘）において、大戦略マップ（親タイル）上でプレイヤーが操作する**「1コマ（1ユニット）」の実体が【2個師団で構成される1個軍団（Corps）】である**という基本構造に基づき、その必然性、2進数倍々エシュロンの整合性、各師団の正面4連隊＋師団付砲兵連隊、各師団付輸送飛行隊、軍団直属航空隊（4個飛行隊）、および**「8輪装甲装輪車（8×8 Wheeled Armored Vehicle）共通ファミリー（10大バリアント）」と「重装輪車両（特科・TEL等の大型トラック/トレーラー系列）」の明確な区分**を体系的に整理した検討書である。

---

## 1. 「1ユニット＝2個師団1軍団」の基本構造

従来の戦闘機動8個連隊（機甲4＋歩兵2＋偵察2）という兵力規模は、**「各師団が4個戦闘機動連隊＋師団付砲兵連隊＋師団輸送飛行隊を持つ2個師団」**として分割・統合し、航空攻撃・重強襲戦力を軍団直轄として集中配備することで、陸空・兵站の指揮統制が極めて明快な構造となる。

1. **2個師団で1個軍団を構成**:
   - 軍団司令部の下に、**【第1師団】**と**【第2師団】**の2個師団が直属する。
   - 軍団としての最小構成（2個師団）であり、余分な中間階層や肥大化を持たない極めてソリッドな作戦単位。
2. **各師団の正面戦力は「4個戦闘機動連隊」**:
   - 師団長が直接指揮する正面機動戦力は**4個連隊（機甲2＋歩兵1＋偵察1）**とし、スパン・オブ・コントロール（指揮統制限界）に完全に適合させる。
   - 軍団全体で「機甲4個連隊 ＋ 装甲歩兵2個連隊 ＋ 偵察2個連隊」の計8個機動連隊が均等に2個師団へ割り振られる。
3. **砲兵・ミサイル部隊は「重装輪車両系列（大型トラック/自走システム）」で運用**:
   - 師団野戦特科連隊の155C装輪自走榴弾砲や、210C重榴弾砲、TEL長距離ミサイル発射機、大型弾薬給弾車、重装輪回収車は、装甲戦闘車ではなく**「非装甲・軽装甲キャビンの重装輪車両（Heavy Wheeled Tactical Vehicle 8×8/10×10）」**をベースとした発射・射撃統制システムとして直属配備される。
4. **多目的誘導弾発射部隊は「4輪駆動システム」で運用**:
   - 師団直属の対舟艇対戦車部隊は、4輪駆動（4×4）高機動装甲車ベースの**「発射機車＋射撃指揮車＋索敵観測車」**で構成される視界外（NLOS）多目的誘導弾システムとして編成。
5. **師団にも「師団輸送飛行隊（8機）」を直属配備**:
   - 各師団に自前の**「師団輸送飛行隊（多用途・強襲戦術輸送ヘリ 8機）」**を1つずつ配備。MEDEVAC（患者後送）、前線緊急補給、局所ヘリボーンを即時自律遂行。
6. **軍団航空隊（4個飛行隊 / 計32機）の集中打撃・重強襲運用**:
   - 軍団直属の**「軍団航空隊（Corps Aviation Group）」**は、**4個飛行隊（8機×4＝計32機）**で編成（戦闘2個飛行隊 16機 ＋ 強襲輸送2個飛行隊 16機）。軍団長の作戦決断により主攻軸へ一挙集中投入可能。
7. **師団本部付き専門部隊群の保持（自律運用の基盤）**:
   - 各師団は自前で、師団司令部管理中隊（HHC）、通信大隊、施設戦闘工兵大隊、軍事情報・ISR隊、8輪装甲CBRN偵察隊、4×4多目的誘導弾隊を完全に直属保有する。

## 2. 車体プラットフォームの明確な階層区分

## 7. ゲームプレイおよび戦術戦闘への影響

1. **大戦略操作（1コマ＝1軍団）**:
   - 盤面上を動かす1コマは「機甲軍団」といった2個師団を束ねる軍団単位。
   - プレイヤーは各師団を個別に微調整する必要がなく、軍団として一括で進撃・防衛の作戦矢印を指示する。
2. **「8輪装甲車（前線戦闘）」と「重装輪車両（後方特科・兵站）」の役割明確化**:
   - 前線で交戦する10大バリアントは**同一の8輪装甲装輪車**であるため、装甲防御力が高く、前線部隊同士での部品共食い整備が極めてスムーズ。
   - 特科連隊の155CやTEL、重回収車などの大重量システムは**重装輪車両（8×8大型トラック系）**として独立しているため、長大な射程と大弾薬積載力を両立し、工廠での車体製造ラインもすっきりと二極分化される。
3. **師団自前の輸送飛行隊（8機）による即応衛生後送・補給**:
   - 各師団が自前の輸送飛行隊（8機）と8輪装甲患者輸送車（AME）を連携させ、前線から師団野戦病院への迅速な患者後送（MEDEVAC）を実施。兵員損耗率を低減。
4. **軍団航空隊（4個飛行隊・32機）の集中運用**:
   - 重大な作戦局面において、軍団直轄の戦闘飛行隊2個（16機）と強襲輸送飛行隊2個（16機）を主攻軸へ一挙集中投入可能。
5. **サブタイル戦術戦闘（343マス盤面）への展開**:
   - 親タイル交戦時、第1師団の地上部隊・野戦特科・輸送ヘリがまず盤面へ展開。
   - 続いて第2師団が相互躍進または側面から展開し、軍団司令部から割り振られた軍団航空隊が上空から直協支援・阻止攻撃・大規模ヘリボーンを実施する。
6. **兵站と損耗のダイナミクス**:
   - 軍団コマが補給動脈から切断された場合、各師団の兵站・回収大隊および軍団重兵站群が連動し、共通パーツの融通による「師団間・車種間共食い整備」が発生。
   - 1個師団が激しく損耗しても、もう1個師団を盾にして後退・再編する「軍団内リソース交代」が自律的に実行される。
