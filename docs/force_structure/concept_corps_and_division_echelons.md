# 1ユニット＝2個師団1軍団制 概念・編制検討書

(Study on One-Unit Corps Structure: 2-Division Integrated Armored Corps)

本ドキュメントは、本作（4X大戦略＋サブタイル戦術戦闘）において、大戦略マップ（親タイル）上でプレイヤーが操作する**「1コマ（1ユニット）」の実体が【2個師団で構成される1個軍団（Corps）】である**という基本構造に基づき、その必然性、2進数倍々エシュロンの整合性、各師団の正面4連隊＋師団付砲兵連隊、および各師団がオーガニックに保持する本部付き専門部隊群（HHC・通信・工兵・ISR・NBC防護・対戦車）を体系的に整理した検討書である。

---

## 1. 「1ユニット＝2個師団1軍団」の基本構造

従来の戦闘機動8個連隊（機甲4＋歩兵2＋偵察2）という兵力規模は、**「各師団が4個戦闘機動連隊＋師団付砲兵連隊を持つ2個師団」**として分割・統合することで、軍事組織として極めて明快な対称構造となる。

1. **2個師団で1個軍団を構成**:
   - 軍団司令部の下に、**【第1師団】**と**【第2師団】**の2個師団が直属する。
   - 軍団としての最小構成（2個師団）であり、余分な中間階層や肥大化を持たない極めてソリッドな作戦単位。
2. **各師団の正面戦力は「4個戦闘機動連隊」**:
   - 師団長が直接指揮する正面機動戦力は**4個連隊（機甲2＋歩兵1＋偵察1）**とし、スパン・オブ・コントロール（指揮統制限界）に完全に適合させる。
   - 軍団全体で「機甲4個連隊 ＋ 装甲歩兵2個連隊 ＋ 偵察2個連隊」の計8個機動連隊が均等に2個師団へ割り振られる。
3. **砲兵連隊（野戦特科連隊）は師団付のまま配置**:
   - 砲兵は軍団直轄に吸い上げるのではなく、**各師団がそれぞれ自身の野戦特科連隊（155C自走榴弾砲48両 ＋ 210C/TEL）を直属保有**する。
   - これにより各師団が独立した火力投射能力を維持し、サブタイル展開時にも各師団の正面に対して直接・即応の火力支援を実施できる。
4. **師団本部付き専門部隊群の保持（自律運用の基盤）**:
   - 各師団はそれぞれ自前で、師団司令部管理中隊（HHC）、通信大隊、施設戦闘工兵大隊、軍事情報・ISR隊、特殊生物化学武器防護隊、対舟艇対戦車誘導弾隊といった**「本部付き専門部隊」を従来の仕様通り完全に直属保有**する。
   - これにより、各師団は軍団からの支援が途絶しても、障害啓開・C4I通信・生体毒素除染・要衝拒絶を独力で遂行できる。

## 4. ゲームプレイおよび戦術戦闘への影響

1. **大戦略操作（1コマ＝1軍団）**:
   - 盤面上を動かす1コマは「機甲軍団」「空中機動軍団」といった2個師団を束ねる軍団単位。
   - プレイヤーは各師団を個別に微調整する必要がなく、軍団として一括で進撃・防衛の作戦矢印を指示する。
2. **正面4連隊＋師団砲兵＋本部付専門部隊の自律性**:
   - 各師団が「正面4個戦闘機動連隊＋専属の砲兵連隊＋本部付き（通信・工兵・ISR・防護・重ミサイル）」を持つことで、1個師団単独でも完璧な諸兵科連合戦闘を展開可能。
   - 第1師団が先行突入している際も専属の火力支援を即座に要請でき、第2師団が側面展開した際も自身の砲兵連隊により直ちに支援射撃・対砲兵射撃を開始できる。
   - 架橋や地雷啓開、対エイリアン除染も軍団工兵の到着を待たずに各師団の工兵大隊・除染隊で即時対応可能。
3. **サブタイル戦術戦闘（343マス盤面）への展開**:
   - 親タイルでの交戦時、第1師団の戦闘大隊群と第1野戦特科連隊、および師団工兵・ISR部隊がまず盤面へ展開。
   - 続いて第2師団が相互躍進または側面から展開し、軍団直属の航空連隊（VTOL/ヘリ32機）が空から上空制圧を実施する。
4. **兵站と損耗のダイナミクス**:
   - 軍団コマが補給動脈から切断された場合、各師団の兵站・回収大隊および軍団重兵站群が連動し、部品・弾薬を融通し合う「師団間共食い整備」が発生。
   - 1個師団が激しく損耗しても、もう1個師団を盾にして後退・再編する「軍団内リソース交代」が自律的に実行される。
