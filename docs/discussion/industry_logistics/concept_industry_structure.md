# 産業構造の検討

本作（4X大戦略＋サブタイル戦術・戦闘団制）における産業基盤、サプライチェーン、兵器製造・インフラ整備に関する検討ドキュメント。

---

## 1. 設計方針と課題意識

1. **過度なマイクロマネジメントの排除とリアリズムの両立**:
   - 4Xゲームにおいて「数千社の部品工場やネジ単位の下請け企業」を手動操作させると、プレイヤーの認知負荷が爆発する。
   - 一方で、単なる「工場＝生産力+X」で終わると、近代〜近未来のリアルな防衛産業、重工大手と新興テックの協業、サプライチェーンの脆弱性が表現できない。
2. **サブタイル（343マス/7マス・クラスター）との連動**:
   - マクロな資源産出だけでなく、サブタイル上の「工業地区・コンビナート」の配置やインフラが直感的に結びつく構造を目指す。

---

## 2. 産業の3層レイヤー（抽象化モデル）

兵器開発・生産および都市工業を、以下の3つのレイヤーの組み合わせとして捉える。

```text
+-------------------------------------------------------------------------+
| [Layer 3: 新興テック・特化企業 (Emerging Tech)]                           |
|  - 自律AI、高度電子戦、エイリアン生体神経同調、指向性エネルギー          |
|  - 「革新的機能・特異能力」を付与（ソフトウェア・アビオニクス）           |
+-------------------------------------------------------------------------+
                                    │ 統合・協業 (Co-Development)
+-------------------------------------------------------------------------+
| [Layer 2: 既存重工大手 (Prime Contractors / Heavy Industries)]           |
|  - 車体/機体フレーム、大型動力炉（核融合/タービン）、大口径火砲          |
|  - 「基本スペック・耐久力・量産規模」を担保（プラットフォーム）          |
+-------------------------------------------------------------------------+
                                    │ 立脚・支台 (Underpinned by)
+-------------------------------------------------------------------------+
| [Layer 1: 都市・タイルの基礎産業基盤 (Industrial Base / Supply Chain)]    |
|  - 特殊鋼、微細加工、樹脂、規格ボルト、熟練整備工（町工場群）            |
|  - サブタイルの工業集積度（コンビナート規模）によって自動計算される基礎値 |
+-------------------------------------------------------------------------+
```

### レイヤー詳細

1. **Layer 1: 基礎産業基盤（目に見えない町工場群・サプライチェーン）**:
   - 個別企業を管理するのではなく、都市・サブタイルの「工業化レベル」「熟練工インフラ」としてバックグラウンド集計。
   - これが不十分な辺境植民都市では、「設計図があっても部品精度が出ず、最新兵器の稼働率・整備性が激減する」といった現実的な制約として機能。
2. **Layer 2: 重工プラットフォーム（ベース車体・機体・艦体）**:
   - 装軌車体、装輪車体、大型航空フレーム、艦体など。
   - 複数の兵種（戦車、歩兵戦闘車、自走砲など）が「同一の共通プラットフォーム」から派生することで、量産コスト削減・生産ライン共用が可能。
3. **Layer 3: 機能特化・新興モジュール（協業コンポーネント）**:
   - RWS（リモートウェポンステーション）、長距離FCS、アクティブ防護（APS）、生体センサなど。
   - 重工の頑丈な箱の上に、新興企業の最新電子装備やエイリアン共生パーツをアドオンする。

## 3. サブタイルにおける工業コンビナート（クラスター構造）

親タイル内部の 343 マスにおいて、7マス単位のクラスター（地区）を形成する。

- **複合シナジー（コンビナート化）**:
  - 「製鉄/精錬」＋「化学/合成」＋「発電施設」が隣接することで、生産効率やボーナスが相乗的に向上。
- **戦術戦・局所破壊との連動**:
  - 戦術戦において、コンビナートの中心（組立ドック）を守りつつ、外周の変電サブステーションやパイプラインが破壊されると、一時的に生産稼働率が低下するリアルな兵站破壊。

---

## 4. 部品共通化（Commonality）と兵站効率

- 戦闘団（固定編成）内部で、同一メーカーの車体プラットフォームや共通モジュール（RWSや同一口径砲）が多く使われている場合、**「部品共通化率」**が上昇。
- 整備小隊の修理速度向上、損耗補充コストの低下としてシステム的に還元される。

---

## 5. 転換コストと段取りフリクション（Conversion Friction & Line Reconfiguration）

民生・軍需を問わず、工場ラインの生産品目変更には必ず**「段取り時間」「治具・金型の換装」「初期歩留まりの低下」**という不可避なフリクションが発生する。

1. **民生・軍需共通の段取りコスト（Tooling & Setup Time）**:
   - 建機工場を装甲戦闘車に転換する場合や、乗用車ラインを輸送トラックへ切り替える場合、あるいは別世代の半導体露光マスク・基板レイアウトに変更する場合、一定期間（ターン数）ラインが停止または極端な低稼働率（アイドリング）に陥る。
2. **学習曲線と初期不良（Learning Curve & Ramp-Up Yield）**:
   - ライン転換直後は歩留まり（Yield）が低く、資源消費に対する完成品比率が悪化する。
   - 生産を継続することで現場の熟練度・工程最適化が進み、徐々に設計上の最大スループット・高歩留まりへ収束する。
3. **ゲームデザイン上の意義**:
   - 「戦況に応じて即座に別兵器を大量生産する」という非現実的なスイッチングを抑制し、**「既存の生産ラインを維持しつつ改修モジュールで延命するか、一時的な供給空白を覚悟してライン転換に踏み切るか」**という重い戦略的意思決定を生み出す。

## 6. テクトニクス・環境振動への産業適応工学（Seismic & Environmental Adaptation）

精密半導体ファブや高精度工作機械プラントの立地において、母星物理学的に「完全に安定した陸地」は惑星上に存在しない。現実世界の日本や台湾、韓国が地震帯にありながら世界トップの半導体・精密産業を維持しているように、本作でも**「災害多発地域でも工学投資によって精密産業を成立させる」**モデルを採用する。

```text
┌─────────────────────────────────────────────────────────────┐
│          環境振動・地震帯における精密産業の適応モデル       │
├──────────────────────────────┬──────────────────────────────┤
│     【工学投資（Capex/Opex）】 │        【稼働・被災リスク】          │
├──────────────────────────────┼──────────────────────────────┤
│ ・超高剛性免震ピット・基礎杭 │ ・有感地震時の自動安全停止（ラインダウン） │
│ ・アクティブ除振エアスプリング│ ・微小振動による一時的露光不良・歩留まり低下 │
│ ・配管・薬液系の多重フレキシブル化 │ ・復旧時の再キャリブレーション所要時間 │
└──────────────────────────────┴──────────────────────────────┘
```

1. **立地と追加工学コストのトレードオフ**:
   - プレート境界や火山帯近傍（地熱や鉱物濃集の恩恵地）に精密ファブを建設することは可能だが、**免震ダンパー・高耐震基礎インフラ（追加の建設資材・維持電力）**を要求される。
   - 投資を怠った安価なファブは、微小地震のたびに精密露光の歩留まりが暴落し、大地震で機器アライメントが全損する。
2. **安全停止と再キャリブレーション（Interruption & Resumption）**:
   - 地震発生時、最新ファブは自動停止して物理破壊を免れるが、装置の再起動・真空引き・アライメント調整に数ターンの「復旧ダウンタイム」を要する。

## 7. 国家共通ルールと低非対称性（Universal Industrial Mechanics）

各国家・勢力ごとに別個の産業システム・特殊ルールを乱立させず、**「同一の物理・工学・市場原理」**を全国家が共有する。

1. **普遍的な工学法則**:
   - 治具換装の段取り時間、歩留まりの学習曲線、免震基礎の資材コスト、部品共通化の恩恵は、すべての勢力において同一の計算式で動作する。
2. **差異は「政策ステアリングと初期立地」に集約**:
   - 国家間の差は、特殊な異能（マジック）ではなく、「重工業に優遇税制を敷いている」「標準化令を強権的に推進しやすい」「領土が火山帯に偏っている」といった**初期条件およびプレイヤーのステアリング方針（ドクトリン配分）**の差として自然に表現する。

## 8. 今後の検討論点

- **ステアリングUI（政策・誘導レバー）**:
  - プレイヤーが直接工場を弄らずに、補助金・標準化令・研究開発重点配分によって産業ピラミッドを誘導する具体的なインターフェース仕様。
- **ライン転換ラグの定量的パラメータ化**:
  - プラットフォーム（車体等）の転換 vs モジュール（兵装等）の換装における所要ターン数と歩留まり低下率の基礎設計。
- **精密産業における免震インフラのTier別要件**:
  - 通常工場（Tier 1）と超微細ファブ（Tier 3〜4）における振動許容値と追加インフラコストの定義。
