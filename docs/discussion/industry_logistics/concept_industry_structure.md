# 産業構造の総合設計仕様書 (Comprehensive Industrial Structure Specification)

本作（4X大戦略＋サブタイル戦術・脱・都市中心タイル進展制）における**「産業基盤の多層構造」「8大産業ジャンルと階層マッピング」「コンビナート・カスケード循環」「ライン転換フリクションと学習曲線」「テクトニクス・環境振動適応工学」「デュアルユース自己組織化とブートローダー連動」「国家ステアリング政策」**に関する包括的検討・確定設計ドキュメント。

## 1. 設計方針と基本理念

### 1.1 問題意識：4Xゲームにおける「産業モデル」の限界克服

従来の4X戦略ゲームでは、産業が「都市の生産力（ハンマー）の合計値」として極度に単純化されるか、逆に無数の工場やネジ・部品単位のサプライチェーンを手動操作させることでプレイヤーの認知負荷が爆発する二極化に陥っていた。
本作では、以下の3つの核心方針によって、**「過度なマイクロマネジメントの完全排除」**と**「現実の高度重工・防衛産業・サプライチェーンのリアリズム」**を調和させる：

1. **「軍事は産業の氷山の一角（民生基盤の海に浮かぶ突起）」**:
   - トラクターや貨物トラック、商船が作れない社会に、装甲車や戦闘艦は作れない。
   - 人間の生活・土木・開拓・経済活動（民生サプライチェーン）が深まるにつれて、副次的に高度な先端兵器や国家事業が成立する発展史観を据える。
2. **「産業の3層レイヤー」と「8大産業ジャンル」の立体統合**:
   - 目に見えない下請け町工場網（Layer 1）、長寿命な重工プラットフォーム（Layer 2）、新興・特化モジュール（Layer 3）の立体構造を導入。
   - 各ジャンル間の類似性・接続性を数理モデル化し、工廠ライン転換や研究シナジーを自動判定する。
3. **「サブタイル・クラスター（343マス/7マス・コンビナート）」との物理連動**:
   - マクロな資源産出だけでなく、サブタイル上の工業地区における廃熱・副生ガス・電力・工業用水・物流ハブの「カスケード結合」を表現。
   - 戦術戦での変電所や配管切断が、親タイルの産業稼働率へリアルタイムに波及する。

### 2.2 階層間の入出力フロー

1. **下層から上層への制約（公差と歩留まり）**:
   - Layer 1の加工精度（工作機械精度・材料純度）が目標水準に達していない場合、Layer 2やLayer 3の設計図があっても製品の初期歩留まり（Yield）が暴落し、完成品の故障率が急上昇する。
2. **上層から下層への要求（SWaP-Cの拘束）**:
   - Layer 3の最新電子装備やレーザー兵装を搭載するためには、Layer 2のプラットフォーム側に十分な容積・重量・電力・排熱（Size, Weight, Power, and Cooling）の受容余力が必要となる。

### 3.1 5大カスケード・パイプライン

1. **熱エネルギー・カスケード（Thermal Cascade）**:
   - 最上流（発電炉・電解炉）から生じる超高温熱源（400〜600℃）を製鉄・重化学で消費。
   - 中温排熱（150〜250℃）を機械加工・塗装乾燥ラインへ送気。
   - 最終的な低温廃熱（60〜90℃）を居住区暖房やバイオ温室（食料・レーション培養）へ循環し、排熱ペナルティを相殺する。
2. **副生ガス・化学カスケード（Gas & Chemical Cascade）**:
   - 水素直接還元製鉄（H2-DRI）で使用された還元オフガスを隣接の化学プラントへ供給し、肥料や合成樹脂、C規格火工品のバインダーとして再利用。
3. **電炉・サルベージ鋼材完全循環（EAF Loop）**:
   - 戦場で回収された残骸・スクラップ（サルベージ鋼）を電気アーク炉（EAF）へ100%投入。
   - 粗鉱石からの一次製錬に比べ、消費電力を65%削減しつつ高品質鋼を再生産する。
4. **工業用水・閉鎖冷却循環（Hydrological Closed-Loop）**:
   - 高温プラントの冷却排水を濾過・脱塩処理し、下流の超微細ファブや湿式精錬へ供給。水資源消費を最小化。
5. **幹線物流ハブ直結（Integrated Logistics Spine）**:
   - クラスターの中心には必ず「中心サブタイル通過型インフラ（鉄道・運河）」が接続。
   - 完成した重量ブロック（戦車車体、大型プレハブ）が中間トラック輸送なしで大戦略動脈網へ直結される。

### 3.2 戦術戦における局所破壊と脆弱性波及

サブタイル戦術戦闘において、外周の送電サブステーションや蒸気パイプラインが破壊された場合、組立ドックそのものが無傷であっても以下の連鎖デバフが発生する：

- **配管切断（Thermal/Fluid Breach）**: 蒸気圧・冷却水喪失により、隣接する製鉄炉・化学炉が緊急停止（操業率 -50%）。
- **変電所破壊（Grid Severance）**: 組立ドックのNC工作機械が非常電源に切り替わり、生産スループットが25%に縮退。
- **カスケード断絶復旧ラグ**: 戦闘終了後、配管工兵による再溶接と再キャリブレーションに2ターンの復旧ダウンタイムを要する。

## 4. 工廠ライン転換フリクションと学習曲線の数理モデル

戦況に応じて瞬時に別兵器を100%出力で量産できる非現実的なスイッチングを排し、現実の製造工学における**「治具換装（Setup Time）」「学習曲線歩留まり（Yield Curve）」「部品共通化（Commonality Bonus）」**を定量的アルゴリズムとして定義する。

### 4.1 段取り替え工期（Tooling Setup Time）の数理モデル

工廠ラインの生産品目をアイテム $A$ からアイテム $B$ へ切り替える際の転換所要ターン数 $T_{\text{setup}}$ は、ジャンル間類似度 $S_{\text{genre}}(A, B)$ およびモジュール類似度 $S_{\text{module}}(A, B)$ に基づき決定される：

$$T_{\text{setup}} = \text{round}\Big( T_{\text{base}} \times \big(1.0 - S_{\text{total}}(A, B)\big) \Big)$$

ここで、総合類似度 $S_{\text{total}}$ は以下のように算出される：

$$S_{\text{total}}(A, B) = w_g \cdot S_{\text{genre}}\big(\text{genre}(A), \text{genre}(B)\big) + w_m \cdot S_{\text{module}}(A, B)$$

- $T_{\text{base}}$: 基準転換工期（標準値: 5ターン）。
- $w_g, w_m$: 重み付け係数（標準値: $w_g = 0.4$, $w_m = 0.6$）。
- **具体例**:
  - 同一車体の派生換装（装甲戦闘車 ➔ 自走迫撃砲: $S_{\text{total}} = 0.85$）:
    $$T_{\text{setup}} = 5 \times (1.0 - 0.85) = 0.75 \approx 1\text{ ターン}$$
  - 同一重工内の異車体転換（装輪トラック ➔ 装甲装輪車: $S_{\text{total}} = 0.60$）:
    $$T_{\text{setup}} = 5 \times (1.0 - 0.60) = 2.0 \approx 2\text{ ターン}$$
  - 異分野・異業種転換（造船ドック ➔ 航空機フレーム: $S_{\text{total}} = 0.15$）:
    $$T_{\text{setup}} = 5 \times (1.0 - 0.15) = 4.25 \approx 4〜5\text{ ターン}$$

### 4.2 学習曲線と歩留まり（Yield Curve）

ライン稼働後の実効生産効率（歩留まり $Y(t)$）は、生産開始からの経過ロット数（ターン数 $t$）に応じてシグモイド型（ロジスティック曲線）で改善する：

$$Y(t) = Y_{\text{min}} + \frac{Y_{\text{max}} - Y_{\text{min}}}{1.0 + e^{-k (t - t_{\text{mid}})}}$$

- $Y_{\text{min}}$: 初期歩留まり（新規設計: 0.60、熟練派生型: 0.75）。
- $Y_{\text{max}}$: 最大達成歩留まり（標準規格品: 0.98、極限先端品: 0.90）。
- $k$: 学習速度係数（工廠の工作機械精度および熟練工プールに依存、標準値: 0.8〜1.2）。
- $t_{\text{mid}}$: 立ち上がり変曲点（標準値: 2.0ターン）。

```text
歩留まり Y(t)
 1.0 ┌────────────────────────────────────────── 最大歩留まり Y_max (~98%)
     │                                     .----
 0.8 │                             .------'
     │                     .------'
 0.6 │初期歩留まり Y_min ──'
     │ (転換直後 ~60-75%)
 0.0 └───────────────────────┬──────────────┬──────► 稼働ターン数 t
                            t=0            t=3
```

- **投入資源の損失**:
  - 歩留まりが 0.65 の場合、消費原材料（構造鉱物・エネルギー）の 35% は加工屑・不良品として破棄（または一部スラグ・スクラップ化）され、完成品出荷数は定格の 65% にとどまる。

### 4.3 部品共通化率（Commonality Bonus）の定量的影響

部隊（戦闘団）または国内全工廠における部品共通化率 $C \in [0.0, 1.0]$ は、以下の3大恩恵をシステムへ自動付与する：

1. **工廠段取り替え工期の短縮**:
   $$T_{\text{setup, eff}} = \max\big(1, \; T_{\text{setup}} \times (1.0 - 0.30 \cdot C)\big)$$
2. **野戦整備・部品消費効率の向上**:
   - 戦闘団の交換部品（Field Spares）消費量を最大 -40% 削減：
     $$\text{Spares\_Cost} = \text{Spares\_Base} \times (1.0 - 0.40 \cdot C)$$
3. **予備部品ライン維持費の逓減**:
   - 国内で維持すべき金型種類の削減により、工廠の固定維持費（エネルギー消費）が最大 -25% 低減。

## 5. テクトニクス・環境振動への産業適応工学

超微細半導体ファブ（Layer 3）や高精度大口径砲身切削プラント（Layer 2）において、惑星上の環境振動（地震動・火山性微動・重交通振動）は歩留まりを破壊する致命的因子となる。
本作では、現実世界の地震国（日本・台湾等）における先端ファブ工学をモデルとし、**「災害多発地域であっても適切な工学投資によって精密産業を完全成立させる」**工学適応体系を規定する。

```text
│   - 歩留まり 0.70 から再スタート、短期間で 0.95+ へ復帰                     │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

1. **工学投資の有無による明暗**:
   - **適切な免震設備を保有するファブ**: 地震規模に応じた1〜2ターンの「安全停止・再キャリブレーション（復旧ダウンタイム）」のみで安全に操業再開。
   - **無対策・安価なファブ**: 治具・光学素子の物理的破砕が発生し、プラント再建に多額の資源と4〜6ターンの停止を強いられる。

## 6. 民生基盤から立ち上がるデュアルユース自己組織化とブートローダー連動

### 6.1 デュアルユース自己組織化（Civil-Military Symbiosis）

軍事専用のラインを平時から膨大に維持することは国家財政を圧迫する。本作では、民生産業の厚みがそのまま軍事即応力へと転化する**デュアルユース（軍民両用）メカニクス**を実装する。

```text
【民生基盤の日常需要】                           【有事・防衛への転用】
・農機具・大型ブルドーザー (IND-2) ───────► 装甲車体フレーム・自走砲シャーシ
・沿岸漁船・内航貨物フェリー (IND-6) ─────► 沿岸哨戒艇・兵站揚陸舟艇
・鉱山・土木用大型ダンプトラック (IND-2/3) ─► 重装輪TELミサイル発射母機
・気象観測・農業散布ドローン (IND-5/7) ────► 前線観測・電子戦無人機
・都市通信・事務用サーバー網 (IND-7/8) ───► C4I戦術データリンク計算ノード
```

- **デュアルユース転用率（Dual-Use Flexibility）**:
  - 国内のトラクターや商船の製造ラインは、有事布告（動員令）によって段取り工期 $T_{\text{setup}} = 1〜2\text{ターン}$ で軍用輸送トラックや警備艇の量産へ切り替えることができる。
  - 民生ラインの総規模が大きい国家ほど、平時の軍事維持費を最小化しつつ、開戦後に爆発的な動員生産力を発揮できる。

### 6.2 ブートローダー工廠・工作機械プールとの完全連動

入植初期の宇宙船解体フェーズから高度工業国家への離脱は、**「工作機械プール（Machine Tool Pool）」の自己増殖サイクル**によって駆動される。

1. **マザーマシン（万能母機）の自己複製**:
   - 宇宙船に積載された初期の精密5軸加工機（Gen 0）から、粗製旋盤・フライス盤（子機）を削り出し、工廠の「生産可能スロット数」を拡張する。
2. **工作機械の世代階層**:
   - **粗製工作機械（Tier 1）**: 誤差 $\pm 0.1 \text{ mm}$。建機、粗鋼装甲、牽引榴弾砲の生産が可能。
   - **精密NC工作機械（Tier 2）**: 誤差 $\pm 0.01 \text{ mm}$。C規格滑腔砲、戦車ガスタービン、自動装填装置の量産が可能。
   - **超精密ナノ加工機（Tier 3〜4）**: 誤差サブミクロン。半導体露光マスク、超伝導電磁砲レール、光論理プロセッサの製造が可能。

## 7. 国家ステアリング政策とUI表現

指導者（プレイヤー）は工場のネジを直接締めるのではなく、**「国家産業ドクトリン」「兵器クラス別RFPスライダー」「金型転換承認」**を通じて大局的に産業を誘導する。

### 7.1 国家産業政策レバー（Industrial Policy Levers）

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                  国家産業・生産ステアリング制御パネル                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  [1. 標準化令 (Standardization Mandate)] ──── [ 厳格適用 (High) ]          │
│      ・効果: 全軍の部品共通化率 +30%、ライン転換工期 -1ターン              │
│      ・摩擦: 現場の特化新装備・ワンオフ尖鋭兵装の配備が制限される           │
│                                                                             │
│  [2. デュアルユース振興 (Dual-Use Subsidies)] ─ [ 重点投資 (Active) ]        │
│      ・効果: 民生建機・商船ラインの軍用転用ペナルティを半減                 │
│      ・摩擦: 民生メーカーへの補助金（毎ターン国庫エネルギー -50 MWh）      │
│                                                                             │
│  [3. 先端ファブ防振免震助成 (Seismic Hardening)] ─ [ 全額助成 (Level 3) ]    │
│      ・効果: 地震・テクトニクス発生時の精密ファブ停止期間を1ターンに短縮    │
│      ・摩擦: 先端工場建設コスト +60%                                        │
│                                                                             │
│ ─────────────────────────────────────────────────────────────────────────── │
│  ▼ 未決事項・工廠ブロック更新承認トレイ (2件)                               │
│                                                                             │
│  (!) 第2重工コンビナート: 主力装甲「Block II 複合装甲改修」の金型更新申請   │
│      [ 承認する (転換: 2ターン, 稼働率-20%) ]    [ 却下・現行Block I維持 ]  │
│                                                                             │
│  (!) 前線工兵隊具申: 湿地帯用「多脚懸架型IFV (Block Field)」の制式化具申    │
│      [ 国家制式採用 (全工廠へ展開) ]             [ 現地限定改修を黙認 ]     │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

1. **ゴーストゲージと移行ラグの可視化**:
   - プレイヤーがスライダーを操作した際、目標値（RFP）へ向けて「現在の工廠生産値（実線）」が数ターンかけて徐々に追従していく様子を「ゴーストゲージ（点線）」で表示。
   - 産業の慣性とタイムラグを直感的に把握できる。
2. **現場改修（Block Field）の追認サイクル**:
   - 前線の過酷な戦場で兵士や工兵が勝手に改造した「現地改修仕様」を、国家制式として取り込むか、中央規格を守るために却下するかを選択する。

## 8. Rust / Bevy ECS 実装データアーキテクチャ案

ゲームエンジン（Bevy ECS）上で本産業構造を管理するための具象データ構造設計。

```rust
use bevy::prelude::*;
use std::collections::HashMap;

// ==========================================
// 1. 産業ジャンル & 階層定義
// ==========================================

/// 8大産業ジャンル
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Reflect)]
pub enum IndustrialGenre {
    MaterialsSteel,     // IND-1: 鉄鋼・素材
    HeavyMachinery,     // IND-2: 重機・構造重工
    Powerplants,        // IND-3: 動力・推進機関
    OrdnanceEnergetics, // IND-4: 兵器・火薬・火工品
    Aerospace,          // IND-5: 航空宇宙工学
    NavalMarine,        // IND-6: 造船・海洋重工
    Electronics,        // IND-7: 電子・半導体・センサ
    SoftwareAI,         // IND-8: 情報・AIソフトウェア
}

/// 産業3層レイヤー区分
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash, Reflect)]
pub enum IndustrialLayer {
    Layer1Base,      // 基礎産業基盤・町工場群
    Layer2Platform,  // 重工プラットフォーム
    Layer3Emerging,  // 新興テック・特化モジュール
}

// ==========================================
// 2. カスケード結合・コンビナートコンポーネント
// ==========================================

/// サブタイル・クラスター内のカスケード循環状態
#[derive(Component, Debug, Clone, Default, Reflect)]
pub struct IndustrialClusterCascade {
    /// 利用可能な高温熱量 (MW-thermal)
    pub available_thermal_heat_mw: f32,
    /// 副生還元ガス余剰量 (t/ターン)
    pub byproduct_reducing_gas_tons: f32,
    /// 閉鎖循環冷却水の充足率 (0.0 〜 1.0)
    pub closed_water_ratio: f32,
    /// 配管・インフラ切断による機能低下率 (0.0 = 正常, 1.0 = 完全破壊)
    pub pipe_severance_penalty: f32,
}

// ==========================================
// 3. 工廠ライン & 転換フリクション
// ==========================================

/// 工廠ラインの段取り・金型転換ステート
#[derive(Debug, Clone, Reflect)]
pub enum LineToolingState {
    /// 安定生産稼働中
    Operational {
        consecutive_turns: u32,
    },
    /// 金型・治具の換装中 (残りターン数, 転換元アイテムID, 転換先アイテムID)
    Reconfiguring {
        remaining_turns: u8,
        from_item_id: String,
        to_item_id: String,
    },
    /// 地震・環境振動による再キャリブレーション中 (残りターン数)
    SeismicCalibration {
        remaining_turns: u8,
    },
}

/// 個別製造ラインコンポーネント
#[derive(Component, Debug, Clone, Reflect)]
pub struct ProductionLineComponent {
    pub line_id: String,
    pub genre: IndustrialGenre,
    pub layer: IndustrialLayer,
    pub produced_item_id: String,
    /// 定格最大スループット (t/ターン または 個数/ターン)
    pub rated_throughput: f32,
    /// 現在の実効歩留まり率 (0.60 〜 0.98)
    pub current_yield_ratio: f32,
    /// 金型・稼働ステート
    pub tooling_state: LineToolingState,
    /// 防振・免震インフラ格付け (0: 無対策 〜 4: アクティブ除振)
    pub seismic_protection_tier: u8,
}

// ==========================================
// 4. 国家産業政策リソース
// ==========================================

/// 国家全体の産業ステアリング設定
#[derive(Resource, Debug, Clone, Reflect)]
pub struct NationalIndustrialPolicy {
    /// 標準化令の強度 (0.0 〜 1.0)
    pub standardization_mandate: f32,
    /// デュアルユース振興の助成強度 (0.0 〜 1.0)
    pub dual_use_subsidy: f32,
    /// 免震・防災工学補助レベル (0 〜 4)
    pub seismic_hardening_level: u8,
    /// 工作機械プール保有総数
    pub total_machine_tool_pool: u32,
    /// 割り当て済み工作機械数
    pub allocated_machine_tools: u32,
}

// ==========================================
// 5. ターン更新実行システム設計案
// ==========================================

/// 工廠ラインの毎ターン進捗および歩留まりシグモイド更新
pub fn update_production_lines_system(
    mut lines: Query<(&mut ProductionLineComponent, &IndustrialClusterCascade)>,
) {
    for (mut line, cascade) in lines.iter_mut() {
        // カスケード配管破壊ペナルティの適用
        let infrastructure_multiplier = (1.0 - cascade.pipe_severance_penalty).max(0.2);

        match &mut line.tooling_state {
            LineToolingState::Reconfiguring { remaining_turns, .. } => {
                if *remaining_turns > 1 {
                    *remaining_turns -= 1;
                } else {
                    line.tooling_state = LineToolingState::Operational { consecutive_turns: 0 };
                    line.current_yield_ratio = 0.65; // 転換直後初期歩留まり
                }
            }
            LineToolingState::SeismicCalibration { remaining_turns } => {
                if *remaining_turns > 1 {
                    *remaining_turns -= 1;
                } else {
                    line.tooling_state = LineToolingState::Operational { consecutive_turns: 0 };
                    line.current_yield_ratio = 0.75;
                }
            }
            LineToolingState::Operational { consecutive_turns } => {
                *consecutive_turns += 1;
                // ロジスティック学習曲線による歩留まり向上
                let max_yield = 0.98;
                let growth_rate = 0.8;
                let mid_point = 2.0;
                let sigmoid = 1.0 / (1.0 + (-growth_rate * (*consecutive_turns as f32 - mid_point)).exp());
                line.current_yield_ratio = (0.65 + (max_yield - 0.65) * sigmoid)
                    * infrastructure_multiplier;
            }
        }
    }
}
```
