# 国家制御・多層ステアリングシステム仕様書

(Multilayer National Steering, Equipment Doctrine & Autonomous Industrial Dynamics)

本作（4X大戦略＋サブタイル戦術・戦闘団制）における**「多層化された国家制御・誘導システム（Multilayer Steering Architecture）」**、**「兵器クラス別の要求仕様（RFP）制御」**、および**「産業慣性・移行ラグ・ボトムアップ現場改修」**を体系化した設計仕様書である。

---

## 1. 基本思想：神の手による指示から「多層ステアリング」へ

従来の4Xゲームでは、プレイヤーは全知全能の存在として「戦車のボルトを締め、工場でどの車両を作るか1台単位で指示し、研究室でどの技術を開発するかポチッと選択する」というマイクロマネジメントを行ってきた。

しかし本作では、**「社会・産業・軍部・研究現場は状況に応じて自律的に動く生命体である」**というリアリズムに立つ。国家指導者（プレイヤー）の役割は、現場を直接操ることではなく、**「複数の階層（大戦略・戦域・個別兵器クラス）において方針・ドクトリンを布告し、圧力をかけて望ましい方向へ誘導（ステアリング）すること」**にある。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                   国家制御・誘導システムの多層アーキテクチャ                │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【Layer 1: 国家基本ドクトリン（マクロ大戦略・全体指針）】                  │
│    ・全軍共通化率の重視 ⇔ 新鋭特化・ワンオフ容認                            │
│    ・サプライチェーン自立度（完全自給・独自開発 ⇔ 同盟ライセンス・外材許容）│
│    ・3大アフィニティへの国家傾斜投資（Purity / Harmony / Supremacy）        │
│                                                                             │
│  【Layer 2: 方面軍・戦域ドクトリン（作戦環境・交戦規定）】                  │
│    ・環境適応優先度（瘴気・湿地仕様、極寒・高地仕様、過密市街地防衛）       │
│    ・損耗許容度と交戦規定（ROE: 電撃攻勢・損耗無視 ⇔ 現地保全・低損耗）    │
│    ・戦場残骸解析・敵性生体組織の現場流用（認可 ⇔ 厳罰禁止）               │
│                                                                             │
│  【Layer 3: 兵器クラス別・要求仕様（RFP）制御（個別兵器の方向性誘導）】     │
│    ・主要兵器カテゴリ（主力装甲、歩兵戦闘車、支援砲兵、軽装輪、無人機等）   │
│      ごとの【3軸要求仕様スライダー】（防護 / 機動・踏破 / 火力・射程）     │
│    ・プラットフォーム共通化拘束（車体・動力系のファミリー化指定）           │
│    ・獲得モジュール技術の採用認可・排他指定（生体装甲・AI管制の配備先）     │
│                                                                             │
│  【Layer 4: 工廠ライン・実戦現場の自律改修（ボトムアップ実装）】            │
│    ・工廠による最適派生型（Block II / Block III）の自律設計・自動更新       │
│    ・現場部隊の現地改修（フィールド・モディフィケーション）の追認・制式化   │
│    ・金型転換・サプライチェーン再編に伴う「移行ラグ」の発生                 │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 2. Layer 3：兵器クラス別の要求仕様（RFP）制御メカニクス

プレイヤーが直接設計図を引くことなく、自国の軍事技術を意図した方向へ誘導するための中核レイヤーが、**軍・工廠に対する「要求仕様方針（Operational Requirement Directive / RFP）」**である。

### 2.1 兵器クラスの分類

戦闘団（固定編成スロット）を構成する基本ビークル・装備群を以下のカテゴリに大別する：

1. **主力装甲（Main Armor / MBT相当）**: 前線突破・対戦車中核。
2. **歩兵戦闘・装甲輸送（IFV / APC）**: 歩兵小隊の防護移送・直接火力支援。
3. **間接火力・野戦砲兵（SPG / MRLS）**: サブタイル戦術マップ広域・親タイル間支援。
4. **機動偵察・軽装輪（Recon / Light Wheeled）**: 高速索敵・側面警戒・電子戦。
5. **無人・自律支援機（UGV / Drone Swarm）**: 危険地帯突入・弾幕デコイ・観測支援。

### 2.2 3軸要求仕様スライダー（Directional RFP）

各兵器クラスに対し、プレイヤーは3つの設計思想バランスをスライダーで指定する（合計100ポイントの配分）：

```text
       【装甲・防護 (Survivability)】
                 /\
                /  \
               /    \
              /      \
             /   ●    \  <-- 国家指定ベクトル (例: 装甲40 / 火力40 / 機動20)
            /          \
           /____________\
【機動・踏破 (Mobility)】  【火力・射程 (Firepower)】
```

| 設計軸 | 重点化時の効果 | トレードオフ・現場の歪み |
| :--- | :--- | :--- |
| **装甲・防護 (Survivability)** | 複合装甲、増加装甲、アクティブ防御、生体殻の優先装備。部隊の損耗率・撃破率が激減。 | 車両重量が大幅増加。泥濘・湿地での移動力低下、燃費悪化、空輸・海上輸送枠の圧迫。 |
| **機動・踏破 (Mobility)** | 高出力軽量タービン、多脚/低圧幅広装軌、軽量複合材の優先採用。地形ペナルティ激減、機動包囲力向上。 | 防護が薄くなり、重火器の一撃に脆弱。エンジン整備工数が増大。 |
| **火力・射程 (Firepower)** | 大口径長砲身、自動装填機構、長射程誘導弾、精密RWSの優先配備。先制撃破率・交戦距離の延伸。 | 弾薬消費量が激増し兵站を圧迫。砲塔重量増による車体バランス悪化・整備負荷増。 |

### 2.3 プラットフォーム共通化拘束（Family Constraint）

プレイヤーは工廠に対し、異なる兵器クラス間での**「車体（シャーシ）・動力プラットフォームの共通化」**を拘束命令として発令できる。

- **「同一シャーシ制式化」（例: 主力戦車車体をIFV・自走砲へ流用）**:
  - **メリット**: 部隊内モジュール共通化率（Commonality Index）が跳ね上がり、整備コスト激減、サブタイル工廠のライン切替コストがゼロ化。
  - **デメリット**: IFVとしては車体が重すぎ、自走砲としては容積不足になるなど、単体性能（専門設計比）で10〜20%のカタログスペック低下を甘受する必要がある。
- **「完全専用設計の容認」**:
  - 各兵器クラスが極限の性能を発揮するが、前線の整備兵が扱う予備パーツが多重化し、兵站破綻リスクが上昇する。

### 2.4 モジュール採用認可・排他指定（Adoption Filter）

技術ウェブ（Tech Web）で新技術が解禁された際、国家指導者は兵器クラスごとに採用の「認可／禁止」を指定できる。

- **生体モジュール（Harmony系）の選択的解禁**:
  - 「歩兵戦闘車には自己修復生体装甲の装備を認めるが、伝統的な重装甲戦車部隊には純血（Purity）複合装甲を維持せよ」
- **自律AI管制（Supremacy系）の限定投入**:
  - 「砲兵の射撃諸元計算・ドローン部隊にはAI完全自律を認めるが、前線有人装甲車には人間指揮官のオーバーライド回路を義務付ける」

## 3. 産業慣性・移行ラグ・ボトムアップ現場改修

国家がステアリングを切った瞬間、即座に全軍の装備が魔法のように切り替わることはない。社会・工廠・前線には**「慣性（Inertia）」**と**「移行ラグ（Transition Lag）」**が存在する。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                     ドクトリン変更と移行ラグのタイムライン                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│ [T: 方針変更布告] ──> [T+1〜T+2: 金型改修・試作] ──> [T+3〜T+4: 工廠量産・混在] ──> [T+5: 換装完了]
│        │                      │                             │                     │
│    (布告コスト)          (生産一時停止)               (整備ペナルティ最大)      (新規格定着)
│                       ・工廠稼働率 -40%             ・前線部隊の稼働率低下       ・共通化率回復
│                       ・試作評価イベント発生         ・旧型/新型の部品多重化      ・新スペック発揮
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.1 金型転換とサプライチェーン再編（Tooling Friction）

- 指導者が兵器のRFP（3軸スライダー）を大幅に変更（例: 防護偏重から機動偏重へ50ポイント以上のシフト）した場合、工業コンビナートタイルにおいて**「金型・治具の再編（Re-tooling）」**が発生する。
- 転換期間中（2〜4ターン）、該当工廠での補充車両の生産歩留まりが一時的に30〜50%低下する。

### 3.2 過渡期の整備ペナルティ（Transition Penalty）

- 部隊内の車両が一斉に切り替わるわけではないため、前線部隊には「旧型（Block I）」と「新型（Block II）」が混在する。
- **部品規格の二重化**:
  - 混在期間中は共通化率が一時的に急落し、戦闘団の修理速度・稼働率にペナルティが発生する。
- **プレイヤーの政策選択**:
  1. **一斉全軍換装（Rapid Overhaul）**: 高コスト・高フリクションだが、短期間で新規格へ移行。
  2. **漸進的自然損耗更新（Attritional Replacement）**: 破壊・損耗した車両から順次新型に更新。工廠の負担は少ないが、混在期間が長期化する。

### 3.3 現場発のボトムアップ改修（Field Modifications）

中央の指示が現場の過酷な現実に合致していない場合、前線の部隊と工兵は生き残るために**「勝手な現地改修（現地非公認仕様: Block Field）」**を行う。

- **発生トリガー**:
  - 湿地帯に投入された重戦車が頻繁にスタックする。
  - 酸性瘴気タイルで標準装甲が急速腐食する。
  - 敵エイリアンの酸噴射に対し、倒したエイリアンの甲殻を前線で装甲車に溶接する。
- **指導者への陳情・選択イベント**:
  - 方面軍司令官より「現場改修型が極めて有効である」との上申が届く。
  - **選択肢A: 国家制式化（Adopt as Official Block）**:
    - 国内全工廠へ図面をフィードバックし、制式カタログに登録。移行コストを払って量産体制へ移行。
  - **選択肢B: 黙認・現地限定運用（Tolerate Locally）**:
    - 該当方面軍内でのみ改修を許可。他地域への波及はないが、補給網からは外れるため現地部品の消費が必要。
  - **選択肢C: 軍紀粛正・不認可（Prohibit & Discipline）**:
    - 規格統一と中央集権を最優先。部隊の士気・生存率は下がるが、サプライチェーンの乱れを阻止。

## 4. プレイヤー操作体系：国家戦略ステアリング画面（UI/UX）

プレイヤーが日常的に向き合うUIは、従来の「生産リストから戦車アイコンをクリックする画面」ではなく、**「国家政策コックピット（National Steering Cockpit）」**である。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ 【国家軍備・装備ステアリング指令室】 (Equipment Steering Cockpit)            │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  [全体ドクトリン] 共通化優先度: [ 高 (75%) ]  │  サプライチェーン: [ 独自優先 ]   │
│ ─────────────────────────────────────────────────────────────────────────── │
│  ▼ 兵器クラス別 RFP 指針                                                     │
│                                                                             │
│  [1. 主力装甲 (Main Armor)]           現行配備: Block II (制式共通装軌)      │
│    防護 [====|====] 45%               移行状況: [ 安定稼働中 ]               │
│    機動 [==|======] 25%               共通化率: 82%                          │
│    火力 [===|=====] 30%               次期Block III改修要求: [ 計画策定中 ]  │
│                                                                             │
│  [2. 歩兵戦闘 (IFV)]                  現行配備: Block I-F (現地改修型混在)   │
│    防護 [==|======] 20%               移行状況: [ 換装中: 残り2ターン ]      │
│    機動 [=====|===] 50%               シャーシ拘束: [ 主力装甲と共通化 ]     │
│    火力 [===|=====] 30%               稼働率影響: -15% (過渡期ペナルティ)    │
│                                                                             │
│  [3. 無人支援 (UGV/Drone)]            現行配備: Mk.3 スウォーム              │
│    AI自律統御: [ フル認可 ]           生体外殻採用: [ 不認可 (Purity遵守) ] │
│ ─────────────────────────────────────────────────────────────────────────── │
│  [未決事項・現場陳情 (1件)]                                                 │
│  (!) 南部方面軍: 瘴気湿地帯用「多脚懸架型IFV」の緊急制式化要求が届いています │
│      [ 具申書を開く ]                                                       │
└─────────────────────────────────────────────────────────────────────────────┘
```

1. **直感的な現状とベクトルの乖離表示**:
   - 現場が今何を作っているか（現行配備Block）と、国家が求めている目標仕様（RFP）のズレがゲージで直感的にわかる。
2. **移行リスクの明示**:
   - スライダーを動かした際、「この改修により国内工廠のライン転換に3ターンを要し、前線のIFV稼働率が一時的に-15%低下します。発令しますか？」という警告ダイアログと影響試算が表示される。
3. **現場発イベントの集約**:
   - 方面軍からの現地改修（Block Field）の承認要請が未決トレイに集約され、大戦略上の決断を迫る。

## 5. まとめと他システムとの連動関係

- **[兵器・モジュール共通化仕様書](./../military_tactics/concept_weapon_module_commonality.md)**:
  - RFPスライダーの共通化拘束が、モジュール共通化率（Commonality Index）の基礎数値を決定する。
- **[入植ブートローダーと国家サプライチェーン](./concept_bootloader_and_national_supply_chains.md)**:
  - 初期は金型転換の余力がないためRFPスライダーの自由度が低く、産業ブートが進むにつれて高度な兵器ステアリングが可能となる。
- **[技術ウェブ・アフィニティ進化仕様書](./../world_progression/concept_technology_tree_structure.md)**:
  - 技術ツリーで獲得した「葉技術モジュール」が、Layer 3のモジュール採用フィルターに並び、兵器への実装がアンロックされる。
- **[方面軍統治仕様書](./concept_theater_operations_and_joint_sectors.md)**:
  - Layer 2の戦域ドクトリンが方面軍AIの行動基準を決定し、Layer 4の現場改修陳情を発生させる。
