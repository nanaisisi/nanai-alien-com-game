# 鋼業・水素直接還元製鉄・電気炉および装甲材工学仕様書

## (Steel Industry, Hydrogen Direct Reduction, Electric Arc Furnace & Armor Engineering Specification)

本ドキュメントは、本作（4X大戦略＋諸兵科連合戦闘団制＋脱都市型タイル進展）における**「鉄鋼産業（鋼業）の全電化プロセス、水素直接還元製鉄（DRI）、電気炉（EAF）による戦場サルベージ循環、および防衛装備を支える装甲材工学体系」**を規定する詳細設計仕様書である。

## 1. 鋼業の基本哲学と世界観背景

### 1.1 化石コークス高炉からの完全脱却と「全電化・水素製鉄」

- **未踏異星における製鉄の必然**:
  - 入植初期の惑星においては、地球のような数億年にわたる古生代植物堆積によって形成された「良質な瀝青炭・石炭層」が存在するとは限らず、仮に炭化水素資源が存在してもコークス炉インフラの設営には膨大な資材と時間を要する。
  - したがって、母星から持ち込まれた再建ロードマップおよび異星開拓の標準製鉄プラントは、**「海水電解によるグリーン水素」「核融合・地熱・OTECによる電力」「電気炉（EAF）」を直結させたクリーン重工モデル**を最初から前提とする。
- **全電化・ゼロカーボン重工コンビナート**:
  - 水素を還元剤として利用することで、高炉から排出されるのは二酸化炭素ではなく「高温水蒸気（$H_2O$）」のみとなる。
  - 水蒸気は冷却・回収されて工業用水や電解原料として閉鎖循環し、惑星大気への化学汚染・熱負荷を制御する。

### 1.2 質量収支と師団スケールへの整合

諸兵科連合戦闘団（増強師団：戦車256両＋重IFV384両＋装輪支援車群等、総重量数十万トン規模）の装備損耗・更新に合わせ、鋼業の産出・処理能力は**「整数トン（t）」単位**で厳密に裏付けられる。

## 2. 水素直接還元（DRI）と電気炉（EAF）の結合プロセス

### 2.1 水素直接還元シャフト炉（H2-DRI: Direct Reduced Iron）

- **還元反応工学**:
  - 鉄鉱石（主成分: $Fe_2O_3$）に対し、予熱された高圧水素ガスを炉下部から吹き込む：
    $$Fe_2O_3 + 3H_2 \longrightarrow 2Fe + 3H_2O \; (\text{吸熱反応})$$
  - 一酸化炭素還元と異なり炭素が残留しないため、極めて炭素濃度の低い「純度の高い直接還元鉄（スポンジ鉄）」が得られる。
- **熱源とエネルギー収支**:
  - 水素還元は吸熱反応であるため、シャフト炉内の温度（約800〜900℃）を維持するために電力またはプラズマ加熱ヒーターを併用する。
  - 消費目安：構造鉱物粗鉱石 1.5t ＋ 水素 60kg ＋ 電力 0.3 MWh ➔ **直接還元鉄（DRI） 1.0t**。

### 2.2 電気アーク炉（EAF: Electric Arc Furnace）とスクラップ循環

- **黒鉛電極アーク加熱**:
  - 大電流アーク放電（3,000℃超）により、DRIスポンジ鉄および戦場スクラップを急速再溶解。
  - コークス高炉と異なり「原料投入から短時間でのオン・オフ稼働」が可能であり、電力網の余剰電力や夜間電力を柔軟に吸収できる。
- **戦場残骸（サルベージ）の100%完全循環**:
  - 破壊された敵味方の戦車残骸、撃破された陣地建材、工場解体スクラップを直接炉内へ投入可能。
  - **鉱石採掘プロセスをスキップ**し、通常製鉄の約30〜40%の電力消費で再製品化を達成。兵站線が伸び切った前線での現地再生能力（ARV回収連携）の基幹となる。

### 2.3 取鍋精錬炉（LF）と真空脱ガス装置（VD）による超清浄鋼

- **装甲材・特殊砲身に不可欠な二次精錬**:
  - 電気炉で溶かした粗鋼（溶鋼）に含まれる微量な溶存水素、酸素、窒素、硫黄を除去する。
  - **水素脆化（Hydrogen Embrittlement）の完全克服**:
    水素直接還元製鉄において最も致命的な欠陥は、鋼中に残留した水素原子が結晶格子内に入り込み、高強度鋼に微小クラックを発生させて脆性破壊を引き起こす現象である。
  - 真空脱ガス（VD）装置によって真空度 0.1Torr 以下で激しく撹拌脱ガスし、残留水素濃度を極限まで低減させることで、強靭無比な防護装甲用超高張力鋼を創出する。

| :------------------------- | :----------------------------------------------------- | :------------------------------------- | :------------------------------------------------- | :--------------------------------------------------------------------------- |

## 4. 装甲材工学体系（Armor Metallurgy & Engineering）

### 4.1 均質圧延装甲（RHA: Rolled Homogeneous Armor）

- **定義と工学根拠**:
  - ニッケル・クロム・モリブデンを添加した低合金高張力鋼を熱間圧延し、焼き入れ・焼き戻し（調質処理）によって板厚全体にわたり均一な硬度（HB 300〜380程度）と強靭性を持たせた装甲板。
- **物理特性**:
  - 防弾性能の国際基準単位（RHA換算mm厚）として機能。
  - 成形炸薬弾（HEAT）のメタルジェットに対しては板厚通りの防護力にとどまるが、機関砲弾や砲弾破片、エイリアン中型種の打撃爪に対しては極めて高い耐性を示す。

### 4.2 複合装甲（Composite Armor）

- **構造力学**:
  - 鋼板（高硬度外層） ＋ セラミック（炭化ケイ素/炭化ホウ素ブロック） ＋ アラミド繊維/チタン合金（背面層）の多層サンドイッチ構造。
- **対HEAT・対APFSDSメカニズム**:
  - 外層の硬化鋼が徹甲弾（APFSDS）の弾芯ノーズを破砕。
  - 中間セラミック層の衝撃波キャビテーションにより、侵徹体の運動エネルギーを広範囲に粉砕・吸収。
  - 背面層がセラミック破片を受け止め、車内への剥離（スポーリング）を完全に遮断する。

### 4.3 バイオ傾斜複合装甲（Chitin-Bio Graded Armor）

- **エイリアン生体濃縮鉱物との融合**:
  - エイリアン大型種・タイタン級の甲殻から採取された「有機キチン・金属間化合物ナノ積層構造」を、粉末冶金および放電プラズマ焼結法（SPS）で鋼材表面から内部へ向けて連続的に組成変化（傾斜機能化）させる。
- **ゲーム的性能**:
  - 従来の均質鋼・複合装甲に比べ、**防護力1.4倍、自重20%削減**。
  - 生体酸・強酸性瘴気による腐食劣化を中和する自己防護被膜を形成。

## 5. Bevy ECS 実装データ構造仕様 (Rust)

鋼業コンビナート、電気炉施設、および装甲材生産をゲームシステム上で管理するためのBevy ECSコンポーネント定義。

```rust
use bevy::prelude::*;

/// 鋼業・製鉄コンビナート施設
#[derive(Component, Debug, Clone, Reflect)]
pub struct SteelMillFacility {
    /// 稼働ステータス
    pub is_active: bool,
    /// 現在の製鉄プロセス種別
    pub process_type: SteelFurnaceProcess,
    /// 水素直接還元シャフト炉の定格処理能力 (t/Turn)
    pub dri_capacity_tons: u32,
    /// 電気炉 (EAF) の定格溶鋼能力 (t/Turn)
    pub eaf_capacity_tons: u32,
    /// 炉内温度・プラズマ安定度 (0.0 〜 1.0)
    pub thermal_efficiency: f32,
}

/// 製鉄プロセス・炉種別
#[derive(Debug, Clone, Copy, PartialEq, Eq, Reflect)]
pub enum SteelFurnaceProcess {
    /// 急造スクラップ溶解（低品質・高不純物）
    ScrapReMelting,
    /// 水素直接還元 ＋ 電気炉 (H2-DRI + EAF)
    HydrogenDriElectricArc,
    /// 真空脱ガス超清浄精錬 (VD/VAR Advanced)
    VacuumDegassedCleanSteel,
    /// エイリアン甲殻・生体ナノ傾斜焼結 (Bio-Plasma Sintering)
    BioPlasmaGradedSintering,
}

/// 工廠で生産される装甲材グレード
#[derive(Debug, Clone, Copy, PartialEq, Eq, Reflect)]
pub enum ArmorGrade {
    /// 粗製鋼板 (Gen 1)
    CrudePlate,
    /// 均質圧延装甲 RHA (Gen 2)
    RolledHomogeneousArmor,
    /// 多層複合装甲 (Gen 3)
    MultilayerComposite,
    /// バイオ傾斜複合装甲 (Gen 4)
    BioChitinGradedComposite,
}

impl ArmorGrade {
    /// 防護係数と重量係数の取得 (防護力倍率, 自重倍率)
    pub fn characteristics(&self) -> (f32, f32) {
        match self {
            Self::CrudePlate => (0.7, 1.2),
            Self::RolledHomogeneousArmor => (1.0, 1.0),
            Self::MultilayerComposite => (1.3, 0.9),
            Self::BioChitinGradedComposite => (1.4, 0.8),
        }
    }

    /// 製造に必要な投入原料（構造鉱物t, 機能鉱物t, 水素kg, 電力MWh）
    pub fn required_inputs_per_ton(&self) -> (f32, f32, f32, f32) {
        match self {
            Self::CrudePlate => (1.3, 0.0, 0.0, 0.4),
            Self::RolledHomogeneousArmor => (1.2, 0.05, 50.0, 0.8),
            Self::MultilayerComposite => (0.8, 0.3, 40.0, 1.2),
            Self::BioChitinGradedComposite => (0.6, 0.4, 30.0, 1.5),
        }
    }
}

/// タイル上の水素・スクラップ兵站バッファ
#[derive(Component, Debug, Clone, Default, Reflect)]
pub struct SteelMillLogisticsBuffer {
    /// 水素貯蔵量 (kg)
    pub hydrogen_storage_kg: u32,
    /// 戦場回収スクラップ・屑鉄ストック (t)
    pub scrap_iron_stock_tons: u32,
    /// 直接還元鉄 (DRI) ストック (t)
    pub dri_sponge_iron_tons: u32,
    /// 完成装甲板インベントリ (t)
    pub armor_plate_stock_tons: u32,
}
```
