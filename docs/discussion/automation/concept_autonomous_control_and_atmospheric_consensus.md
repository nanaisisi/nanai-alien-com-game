# 自律制御アーキテクチャと集団合意ダイナミクス仕様書

(Autonomous Control Architecture & Collective Consensus Dynamics: Lightweight Failure-Handling & Atmospheric Governance)

本作（4X大戦略＋サブタイル戦術・戦闘団制＋自律サプライチェーン）における**「指導者（プレイヤー）の操作を『最高指導者の直接命令』ではなく『社会の空気・集合的合意の傾き』として定義する思想」**、および**「LLMに依存しない超軽量な自動バランサー制御・現場の修正ハンドリング・集団的誤謬（うっかり・行き過ぎ）メカニクス」**を体系化した設計仕様書である。

---

## 1. 基本思想：プレイヤー操作＝「社会の空気・暗黙の合意」

### 1.1 マイクロマネジメントと絶対専制のゲーム的破綻

歴史上の軍事・産業において、**「最高権力者が現場の細かい工程や部隊装備に直接口出しして良い結果を生んだ例はない」**。
ゲームにおいても、プレイヤーが全工場の生産ラインや全トラックの積載を直接操作する設計は、以下の破綻を招く。

1. **認知負荷のパンク**: ターンが進むにつれてクリック作業の海に溺れ、大戦略の楽しさが失われる。
2. **現場自律性の喪失**: 現場の弾力性、局地適応、サプライチェーンの融通が完全に死滅する。

### 1.2 本作のプレイヤー立ち位置：神の指ではなく「ツァイトガイスト（時代の空気）」

本作において、プレイヤーがスライダーを動かしたりドクトリンを選択する行為は、「最高指導者が勅令を出した」のではない。
**「国家という巨大な集合生命体の中で、なんとなく醸成された社会のムード、世論の傾き、業界・軍部の暗黙の合意（Zeitgeist）」**を体現する。

## 2. 「過程（自動制御）」と「結果（表出）」の明確な分離

システムを**「制御部（目標方針ベクトル）」**、**「計算過程（自動バランサー）」**、および**「結果を表出する他システム（兵器・部隊・兵站）」**の3層に分離する。

### 2.1 3層構造の役割定義

1. **統帥方針層（Policy Vector: 入力）**:
   - プレイヤーが入力する大枠の重み付け（例: 標準化率目標、備蓄バッファ日数、損害許容度、アフィニティ投資比率）。
   - 個別の生産キューや部隊の個別装備には一切触れない。
2. **自動制御バランサー層（Autonomous Balancer: 過程）**:
   - **完全な裏方・自己主張しないバックグラウンド計算機**。
   - 独自のポップアップやモーダル選択肢を一切持たない。
   - 不足資源があれば代用品を割り当て、輸送が詰まれば遅延させて平滑化し、現場の能力の範囲内で「最も破綻の少ない解」を自動決定する。
3. **結果を表出する既存システム群（Manifestation Systems: 結果）**:
   - 自動制御が「いい感じに帳尻を合わせた結果」は、既存の各システム上のデータ（ステータス、装備タグ、移動力、ログ）として自然に表出する。

## 3. 集団心理ゆえの「うっかり・行き過ぎ・集団的誤謬」

「社会全体の合意や空気感」で動く以上、**「合っていることもあれば、なぜか集団全体で間違ってしまうこともある」**。

### 3.1 集団的誤謬の3大パターン

1. **空気の過剰忖度（極端化の暴走）**:
   - プレイヤーが「共通化・標準化」寄りに空気を誘導した結果、現場が忖度しすぎて**「極地駐屯部隊まで標準タイヤの軽トラックを受領し、雪原で立ち往生する」**（「誰も標準化に反対できなかった」）。
2. **技術・流行への過剰な陶酔（バブル・集団的熱狂）**:
   - 「これからは多脚・エイリアン生体技術の時代だ！」と社会全体が浮かれた結果、**「旧式トラックのゴムタイヤを作る工場がひっそりとゼロになり、前線の車両がタイヤパンクで続々と放置される」**。
3. **成功体験への執着（前例踏襲の罠）**:
   - 前回の戦いで要塞砲が大戦果を挙げたため、社会全体が要塞砲至上主義に陥るが、敵エイリアンは地中潜行種へ進化しており、砲弾が空しく地表を耕す。

## 4. LLM完全非依存：超軽量ルールベース＆システム間表出

これらの人間味あふれるドラマ、現場の帳尻合わせ、結果の歪みを、**クラウドLLMのAPIを一切呼ばず、完全ローカルかつマイクロ秒単位のCPU負荷で実現**する。

### 4.1 破綻検知と自動調停（単純なしきい値とクランプ）

Bevy ECSの軽量Systemとして、毎ターン数マイクロ秒でチェック・調停する。

```rust
// 破綻トリガーと自動調停結果（純粋な内部データ）
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum AutoBalancingResolution {
    // 資源不足に対し、代替素材置換で生産継続を決定
    SubstituteResource { original: ResourceType, substitute: ResourceType },
    // 急激な仕様変更に対し、在庫消化まで過渡期混用を決定
    TransitionBuffer { lag_turns: u32, readiness_penalty: f32 },
    // 無茶な標準化に対し、そのまま配備し環境デバフを容認
    EnvironmentalPenaltyAcceptance { speed_multiplier: f32 },
}
```

### 4.2 「結果」としての他システムへの表出パターン

自動バランサーが自律調停した結果は、ポップアップで介入を迫るのではなく、**各システムのプロパティ（属性）として自然に反映**される。

1. **兵器・工廠システムへの表出**:
   - 自動制御が「装甲材の不足を現地エイリアン外殻で代用」と判断した場合、工廠の生産枠に `[暫定現地改修仕様: 防御-10%, 耐酸+10%]` のバリアントが自動登録され、ラインが停止せず稼働し続ける。
2. **戦闘団・部隊インスペクターへの表出**:
   - 極地への標準化車両配備を自動制御がそのまま実行した場合、部隊詳細画面の移動力パラメータに `極地踏破デバフ: -30% (標準車輪仕様)` と表示され、マップ上の行動範囲が短くなる。
3. **兵站・サプライチェーンへの表出**:
   - 急激な新弾薬換装時、自動制御が在庫消化を優先した場合、弾薬ゲージの内訳に `新旧弾薬混用率 40:60 (移行期間残り2ターン)` と表示され、わずかな攻撃力ブレとして実戦に反映される。
4. **情報閲覧（Wiki / ニュースログ）への表出**:
   - 静的な報告フィードに「第2工廠、レアメタル不足に伴い生体装甲代用ロットの出荷を開始」という1行ログが静かに流れる。

## 5. 本設計がもたらすゲーム的価値

1. **マイクロマネジメント地獄からの完全な解放**:
   - プレイヤーは「国家の空気・時代の大きな流れ」を舵取りする本質的な面白さに集中できる。
2. **「うっかり・失敗」がドラマと愛着に変わる**:
   - 失敗したときに単にペナルティを受けるだけでなく、「現場がなんとか帳尻を合わせようとして珍妙な魔改造兵器を生み出す」「裏取引で補給を回し始める」といった組織の人間味が生まれる。
3. **完全ローカル・低スペック保証**:
   - LLM不要、常時通信不要。オフライン環境や内蔵GPUノートPCでも軽快に動作し、単体テストも決定論的（100%再現可能）にパスする。
