# 外交危機・偶発紛争およびエスカレーション・ラダー設計書

(Diplomatic Incidents, Gray-Zone Crises, and Escalation Ladder System)

本ドキュメントは、本作（4X大戦略＋サブタイル戦術・戦闘団制）における**「平時から全面戦争へ至るグレーゾーン事態」「偶発的衝突・外交危機イベント」「エスカレーション・ラダーと開戦事由（Casus Belli）の力学」**を定義する詳細設計仕様書である。

---

## 1. 設計思想と背景

従来の多くの4Xゲームでは、「宣戦布告」ボタンを押せば瞬時に平時状態から総力戦へと移行し、それ以前の国境小競り合いや探り合いは単なる「国境侵入による外交ペナルティの累積」として抽象化されてきた。

本作では、大戦終結後の星間入植という設定（[`../../Faction.md`](../../Faction.md)）および未確定国境・自発的失踪者（[`../diplomacy_governance/concept_frontier_dissidents_and_territorial_claims.md`](../diplomacy_governance/concept_frontier_dissidents_and_territorial_claims.md)）を踏まえ、**「平時と戦時の間のグラデーション（グレーゾーン）」をゲームメカニクスとして具現化**する。

```text
┌────────────────────────────────────────────────────────────────────────┐
│               平時・グレーゾーン・全面戦争のエスカレーション連続体     │
└────────────────────────────────────────────────────────────────────────┘
  【段階0: 潜在的摩擦】
    ・未画定国境での民間探査・資源探査の競合、スパイ・不正規情報戦
        │
        ▼
  【段階1: 局地偶発事象（グレーゾーン）】
    ・民間調査船の拿捕、密輸ルート摘発、国境未定地での非正規部隊衝突
        │
        ▼
  【段階2: 外交危機（クライシス対応）】
    ・最後通牒前の緊急外交交渉、経済制裁・資産凍結、海上・回廊封鎖
        │
        ▼
  【段階3: 限定紛争（代理戦争・局地軍事行動）】
    ・特定境界タイル・サブタイルに限定した交戦、失踪者軍閥を介した代理戦
        │
        ▼
  【段階4: 全面戦争（宣戦布告・総力戦）】
    ・方面軍全戦力動員、相手国コアタイル攻撃、国家合意吸収・無条件降伏要求
```

## 2. エスカレーション・ラダー（危機段階メーター）構造

各国家間の関係には、従来の親密度（-100〜+100）とは独立に、二国間ごとに**「緊張度・危機指数（Crisis Escalation Level: 0〜5）」**および**「危機緊張値（Crisis Tension Points: 0〜100）」**が管理される。

```text
 緊張度Lv │ 状態名称           │ 許可されるアクション                     │ 主な開戦事由(CB)
──────────┼────────────────────┼──────────────────────────────────────────┼─────────────────────
  Lv 0    │ 安定・監視期       │ 探査船派遣、国境観測所設営               │ なし
  Lv 1    │ 摩擦・探り合い     │ 威嚇飛行、不法操業摘発、電子妨害         │ 領犯抗議
  Lv 2    │ 局地危機(Crisis)   │ 拿捕、資産凍結、非致死性兵器による阻止   │ 拿捕・損害賠償
  Lv 3    │ 限定武力衝突       │ 未確定国境タイルでの交戦、代理部隊支援   │ 自衛反撃権
  Lv 4    │ 戦争寸前(Brink)    │ 通商破壊、シーレーン封鎖、最後通牒       │ 主権侵害・封鎖突破
  Lv 5    │ 全面戦争(Total War)│ 敵本土・首都タイルの侵攻、核・大量破壊   │ 国家存亡の危機
```

### 2.1 緊張値の動的変動メカニクス

1. **緊張値の上昇要因（インシデントトリガー）**:
   - 自然国境を越えた先での資源採掘インフラ設営（[`../map_tile/concept_tile_centric_expansion.md`](../map_tile/concept_tile_centric_expansion.md)）。
   - 相手国領域周辺への戦闘団（増強師団）の異常集中配置。
   - 相手国出身の失踪者コミュニティに対する一方的武力弾圧、または彼らへの兵器横流し。
   - 通商回廊（シーレーン・陸上鉄道）の傍受・監視インフラ建設。
2. **緊張値の下降・安定要因**:
   - 外交チャネルによる損害賠償の支払い・共同探査協定の締結。
   - 係争サブタイルからの部隊引き戻し（兵力引き離し協定）。
   - 外交的譲歩（技術ライセンスの一部開示、通商関税の引き下げ）。

## 3. グレーゾーン事態・偶発危機の具体シナリオ

### シナリオ1: 国境未定地における民間採掘船・探査ドローン拿捕事件

```text
[国家A 巡回戦闘団] ─── (拿捕・臨検) ───► [国家B 認可・民間試掘隊]
       │                                         │
       ▼                                         ▼
 【即時解放要求】 ◄─── (外交チャンネル) ───► 【不法侵入・密輸認定】
       │                                         │
   (拒絶・時間切れ)                           (身代金要求・技術没収)
       └───────────────────► 【危機Lv2へ上昇】 ◄┘
```

- **発生契機**:
  - タイル境界の未確定地帯（Claim未完全成立タイル）に、一方の国が民間採掘・調査ドローンを送り込んだ際、他方の警備部隊と遭遇。
- **プレイヤーの選択肢**:
  1. **強硬措置（拿捕・機材没収・搭乗員拘束）**:
     - *結果*: 相手国の先進掘削データと資源を獲得するが、相手国の世論が激化。緊張値 +25。相手国に「違法拿捕に対する奪還・報復」の限定開戦事由が付与。
  2. **現場警告・国外退去命令**:
     - *結果*: 緊張値微増（+5）。領有主張の正当性は誇示できるが、資源利益は得られない。
  3. **非公式な見逃し（裏取引）**:
     - *結果*: 緊張値変動なし。密輸ネットワークを介して相手国のレアメタルの一部が自国闇市場に流入するが、自国タカ派閥の支持率低下。

### シナリオ2: 逃亡技術者・亡命政治家の越境保護事件

- **発生契機**:
  - 敵対国の思想統制・過酷な軍務から逃亡した高級技術者グループが、自国国境の前哨基地（FOB）に亡命を申請。
- **プレイヤーの選択肢**:
  1. **政治的亡命受入れと技術吸収**:
     - *結果*: 相手国の固有技術ツリーに関する研究ブースト（Tech Webの進展促進）を獲得。しかし相手国指導部は「国家機密強奪」と断じ、最後通牒を発令。危機Lv3（限定衝突段階）へ直行。
  2. **身柄の即時引き渡し（関係融和）**:
     - *結果*: 相手国との緊張値大幅低下（-20）。ただし自国内のリベラル・人道主義派閥の不満増大、失踪者コミュニティとの信頼失墜。
  3. **第三極集落（失踪者キャンプ）への密かな逃走手引き**:
     - *結果*: 表立った国家間衝突を回避しつつ、緩衝地帯の失踪者コミュニティの親愛度上昇。

### シナリオ3: 航行の自由作戦と海上・回廊封鎖

- **発生契機**:
  - 海洋タイル（[`../map_tile/concept_maritime_governance_and_ocean_engineering.md`](../map_tile/concept_maritime_governance_and_ocean_engineering.md)）または重要峡谷回廊において、自国の海上輸送プラットフォームが相手国の排他的経済水域主張ラインを横断。
- **事象の推移**:
  - 相手国による警告射撃・停船要求 → 護衛戦闘団の現場展開 → 対艦ミサイル照準ロックの応酬。
  - プレイヤーは「危険海域を迂回して兵站遅延を甘受する」か、「駆逐・揚陸戦闘団を投入して強行突破（エスカレーション）」するかの決断を迫られる。

## 4. 第三極（自発的失踪者・軍閥）を介した代理紛争

国家同士が正面衝突を望まない場合、緩衝地帯に存在する「自発的失踪者（Frontier Dissidents）」が非正規戦の代理人（Proxy）として利用される。

```text
[国家A] ── (型落ち旧式兵器・弾薬供与) ──► [失踪者ゲリラ・武装集落]
                                                 │
                                         (ゲリラ襲撃・インフラ破壊)
                                                 │
                                                 ▼
[国家B] ◄── (被害・補給遅延) ────────── [国家B 辺境採掘プラント]
```

1. **ブラックオプス（偽装支援）**:
   - 自国の刻印・兵器識別コードを削り落とした「規格化以前の旧式装備（[`../industry_logistics/concept_resource_economy_and_logistics.md`](../industry_logistics/concept_resource_economy_and_logistics.md)）」を失踪者勢力に供与。
   - 失踪者が敵国の資源パイプラインや送電線を襲撃しても、自国の公式関与は否定可能（Denial of Responsibility）。
2. **露呈リスクとスキャンダル**:
   - 作戦が敵諜報機関や法医学調査（Forensics）によって露呈した場合、国際連合会議での信用失墜と、相手国に「テロ支援国家認定」による正当な全面開戦事由を献上することになる。

## 5. 開戦事由（Casus Belli）と戦後講和・吸収への影響

エスカレーションを経て戦争に突入した際、「どのような開戦事由で戦争が始まったか」が、その後の戦闘団の士気、国内世論の継戦能力、および終戦時の**合意吸収・領土割譲交渉**（[`../events/concept_faction_consensus_and_standardization.md`](../events/concept_faction_consensus_and_standardization.md)）に決定的な影響を与える。

| 開戦事由 (Casus Belli) | 発生契機 | 戦争目的の制限 | 国内厭戦感の増加速度 | 講和・併合時の国際反発 |
| :--- | :--- | :--- | :--- | :--- |
| **自衛反撃権 (Self-Defense)** | 自国領内タイルの直接攻撃、先制空爆の迎撃 | 侵入部隊の排除・国境原状回復 | 極めて遅い（高い防衛士気） | 軽微（国際的同情） |
| **拿捕・主権回復 (Sovereignty)** | 国境未定地での施設強制解体、民間船不法抑留 | 係争タイルの割譲・損害賠償 | 普通 | 軽微〜中程度 |
| **テロ・非正規戦報復** | 敵国支援によるゲリラ破壊工作の確定 | 緩衝地帯の非武装化・賠償 | やや遅い | 中程度 |
| **先制懲罰・体制転覆 (Aggression)** | 危機メーター未飽和での一方的奇襲宣戦 | 相手国全土の合意吸収・無条件降伏 | 極めて速い（厭戦暴動リスク） | 壊滅的（他全国家の包囲網形成） |

## 6. ゲームシステム・UIとの統合

1. **情勢警告インジケーター**:
   - 画面上部および戦略マップ上の係争タイルに「危機アラート（黄色/橙色/赤色）」を表示。
   - 危険海域や境界サブタイルに部隊を移動させる際、「この移動は緊張度を+15上昇させ、交戦規定（ROE）が解除されます」という警告プレビューを表示。
2. **交戦規定（Rules of Engagement: ROE）の設定**:
   - プレイヤーは各方面軍司令部に対し、平時の交戦規定を命令可能：
     - *専守防衛（Hold Fire）*: 攻撃されるまで反撃しない（偶発事故を最小化）。
     - *威嚇排除（Warn & Intercept）*: 非致死威嚇、進路妨害のみ許可。
     - *現場判断自由（Free Fire in Gray-Zone）*: 領犯者は警告なしで撃破（即座にエスカレーションの危険）。
