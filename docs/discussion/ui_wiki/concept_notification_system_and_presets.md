# 通知システム・プリセット仕様書 (Systemic Notification Architecture & Configurable Presets)

本作（4X大戦略＋サブタイル戦術・戦闘団制＋自律サプライチェーン）における**「自律制御が裏方で帳尻を合わせた結果（新モジュール誕生、暫定ロット出荷、兵站ボトルネック、環境ペナルティ等）をプレイヤーへシステマチックに伝える通知システム」**、および**「通知過多（情報スパム）を防ぎプレイヤーの好みに最適化する通知プリセット機構（デフォルト＋ユーザーカスタム）」**を体系化した設計仕様書である。

---

## 1. 基本思想と設計方針

### 1.1 「過程」を邪魔せず「結果」を好みの粒度で知る

自動制御バランサーは裏方で黙々と機能するが、その結果として現場で何が起きたか（例: 「新モジュール・代用仕様がカタログに追加された」「極地部隊に踏破デバフが発生した」）は、プレイヤーのプレイスタイルによって**「細かく全部知りたい人」**と**「大局だけ追いたい人」**で要求が大きく異なる。

- **マイクロ情報志向**: 「どの工廠でどんな代用ロットが生まれたか、全モジュール変更を逐一チェックしたい」。
- **マクロ統帥志向**: 「部隊が立ち往生するか、前線が崩壊する致命的危機以外は通知で邪魔されたくない」。

### 1.2 解決策：システマチックなイベントバスと通知プリセット

1. **システマチックな通知発行（Event-Driven Notification）**:
   - 各システム（工廠、兵器カタログ、部隊、兵站動脈）が状態変化を起こした際、Bevy ECSのイベントバスへ標準化された通知メッセージを投網式に発行。
2. **通知フィルタリング・プリセット（Notification Presets）**:
   - プレイヤーはゲーム開始時に「デフォルトプリセット」を選び、さらに自分好みにトグルスイッチを改変して「ユーザープリセット」として保存できる。

## 2. 通知の分類体系（4大カテゴリと重要度）

すべての通知は、以下の分類（Category）と重要度（Severity）タグを持つ純粋な構造体として発行される。

```rust
// 通知の重要度レベル
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
pub enum NotificationSeverity {
    Info,      // 参考情報（ログに流れるのみ、HUDを邪魔しない）
    Notice,    // 通知（トースト通知またはアイコンバッジ）
    Warning,   // 警告（黄色インジケータ、クリックで該当画面へジャンプ）
    Critical,  // 緊急（赤色フラッシュ、ターン終了時のブロック確認可能）
}

// 通知カテゴリ
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub enum NotificationCategory {
    MilitaryArsenal,   // 兵器・新モジュール・現場魔改造・制式化
    LogisticsSupply,   // 兵站・弾薬混用・動脈ボトルネック・港湾船腹
    FrontlineTactics,  // 部隊ステータス・環境デバフ・移動困難・交戦
    IndustrialEconomy, // 工廠ライン転換・素材代用・歩留まり変動
    AtmosphericEvents, // 世論・空気感の過剰忖度・流行バブル・外交危機
}
```

## 3. 通知プリセット機構（Default & User Customizable）

プレイヤーはUI設定画面でプリセットを即座に切り替えられ、個別項目を自由にカスタムできる。

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        【通知プリセット設定画面】                      │
├────────────────────────────────────────────────────────────────────────┤
│ 現在のプリセット: [ ★ 現場ウォッチャー (ユーザーカスタム1) ▼ ]          │
│                                                                        │
│ [標準プリセットから読み込み]                                           │
│  ( ) 統帥・大局モード (Minimal)   : 致命的警告と重要外交のみ           │
│  (●) バランス型 (Balanced - 推奨) : 新モジュール誕生・中度警告まで表示 │
│  ( ) 現場ウォッチャー (Detailed)  : 現場の代用ロット・全ぼやきを全受信 │
│                                                                        │
│ ────────────────────────────────────────────────────────────────────── │
│ 【個別通知ルール設定（ユーザーカスタマイズ）】                         │
│                                                                        │
│  [新モジュール・兵器カタログ]                                          │
│    ☑ 現場魔改造・代替仕様の制式カタログ追加時通知      (Notice)       │
│    ☑ 規格共通化モジュールの生産開始時通知              (Info)         │
│                                                                        │
│  [部隊・戦術運用]                                                      │
│    ☑ 環境不適合（極地で標準タイヤ等）の移動デバフ発生  (Warning)      │
│    ☑ 弾薬不適合・旧式弾薬混用による威力ブレ発生        (Notice)       │
│                                                                        │
│  [兵站・動脈インフラ]                                                  │
│    ☑ 輸送動脈の過密・ボトルネック発生 (遅延2ターン以上)(Warning)      │
│    ☑ 海上船腹プール (SLC) の上限逼迫                   (Critical)     │
│                                                                        │
│  [通知アクション]                                                      │
│    ☑ Critical通知がある場合、ターン終了ボタン押下時に確認を挟む       │
│    ☑ トースト通知クリックで該当都市／部隊へカメラ即時センタリング     │
│                                                                        │
│  [ ユーザープリセットとして保存 ]   [ デフォルトに戻す ]               │
└────────────────────────────────────────────────────────────────────────┘
```

### 3.1 組み込みデフォルトプリセット（3種）

| プリセット名 | 対象プレイヤー層 | 表示される通知の範囲 |
| :--- | :--- | :--- |
| **① 大局統帥モード (Strategic Minimal)** | テンポ重視、マクロ操作に専念したいプレイヤー | `Critical` のみ（都市包囲、補給完全断絶、宣戦布告）。新モジュールや軽微デバフはログにのみ記録。 |
| **② バランス型 (Standard Balanced: 初期値)** | 一般プレイヤー、標準的な4X体験 | `Warning` 以上 ＋ 新モジュール誕生、主要研究完了。トースト通知が控えめに画面端へ表示。 |
| **③ 現場ウォッチャー (Field Observer)** | 世界観や現場の泥臭いドラマを楽しみたいプレイヤー | `Info` を含む全通知。工廠の代用ロット出荷、前線兵士の愚痴ログ、弾薬混用率の変動まで全てフィードに流れる。 |

### 3.2 ユーザープリセット（User Presets: 保存・改変）

- プレイヤーがデフォルトプリセットのチェックボックスを1つでも変更すると、自動的に「ユーザープリセット（`UserPreset_1` 等）」としてローカル保存（JSON/TOML形式）される。
- 複数のカスタムプリセット（例: 「平時用内政プリセット」「総力戦用軍事プリセット」）を保存し、ゲーム中にワンクリックで切り替えることも可能。

## 4. 通知の提示UI表現（HUDの邪魔をしない3層レイヤー）

通知は画面中央を塞ぐモーダルポップアップを極力避け、以下の3つの非侵入型レイヤーでシステマチックに提示される。

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [画面左上: チッカーログ]                                               │
│   ・第2工廠: 代替キチン装甲ロットを出荷                                │
│   ・第1機甲師団: 旧式弾薬混用中 (残り2T)                               │
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│                                 【メインマップ】                       │
│                                                                        │
├────────────────────────────────────────────────────────────────────────┤
│                                                [画面右下: トースト一覧]│
│                                                ┌──────────────────────┐│
│                                                │ 💡 新仕様モジュール  ││
│                                                │ [局地改修ツンドラ型] ││
│                                                │ カタログに登録完了   ││
│                                                └──────────────────────┘│
│                                                ┌──────────────────────┐│
│                                                │ ⚠️ 踏破デバフ検知    ││
│                                                │ 第3歩兵団(極地雪原)  ││
│                                                │ [クリックで部隊表示] ││
│                                                └──────────────────────┘│
└────────────────────────────────────────────────────────────────────────┘
```

1. **トースト通知スタック（画面右下）**:
   - `Warning` や `Notice`（新モジュール誕生など）が数秒間ポップし、クリックすると該当の工廠カタログや部隊インスペクターへ即座にカメラジャンプ。
2. **システムチッカー / ニュースフィード（画面左上または下部）**:
   - `Info` レベルの細かな現場の動きが、1行テキストとして静かにスクロール（Wikiや履歴ログからいつでも過去ログを全文検索可能）。
3. **重要インジケータ（ターン終了ボタン連動）**:
   - `Critical` な警告が存在する場合、ターン終了ボタンの横に「⚠️ 未確認の重要警告 2件」と表示され、うっかりターンを回してしまう事故を防止。

## 5. Bevy 0.20 実装アーキテクチャ

メモリ確保を最小限に抑え、キャッシュ効率を高めたECSイベント設計を採用する。

```rust
// 通知メッセージイベント
#[derive(Event, Debug, Clone)]
pub struct GameNotificationEvent {
    pub category: NotificationCategory,
    pub severity: NotificationSeverity,
    pub title: &'static str,
    pub message: String,
    pub target_entity: Option<Entity>, // クリック時にフォーカスする対象
}

// ユーザー通知設定リソース
#[derive(Resource, Debug, Clone)]
pub struct NotificationConfig {
    pub active_preset_name: String,
    pub min_severity_to_toast: NotificationSeverity,
    pub category_filter: HashMap<NotificationCategory, bool>,
    pub block_turn_end_on_critical: bool,
}
```

- **フィルタリング処理**:
  - `EventReader<GameNotificationEvent>` を購読する通知ディスパッチャーシステムが、`NotificationConfig` の設定と突き合わせて1マイクロ秒未満で描画対象（トースト・ログ・無視）へルーティング。
