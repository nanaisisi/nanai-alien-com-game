# 惑星適応・テラフォーミング・エイリアン生態系 技術体系設計仕様書

(Three-Pillar Parallel Tech Progression: Planetary Adaptation, Homeworld Terraforming, and Alien Biosphere)

本作（4X大戦略＋サブタイル戦術・戦闘団制）における**「降着基盤からの並列的産業・技術発展」**、およびその中核をなす**「3大技術ツリー（産業の惑星適応／母星テラフォーミング／エイリアン生態系・生体共生）」**の詳細構造と産業・軍事への波及メカニクスを規定する設計仕様書である。

本ドキュメントは、[`concept_technology_tree_structure.md`](./concept_technology_tree_structure.md)（放射状Web構造とアフィニティ）および[`RESOURCE_ECONOMY_SYSTEM.md`](./../../specs/RESOURCE_ECONOMY_SYSTEM.md)（資源サプライチェーン）を具体化・補完する。

---

## 1. 基本設計思想：単一線形ツリーの否定と「並列的進化」

従来の4Xゲームにみられる「農耕→鉄器→内燃機関→宇宙」といった一本道ツリーは、未知の異星に入植した人類の直面する現実とは異なる。
人類は初期宇宙船の解体物資（Tier 0）からスタートし、生き残るために**「複数の異なる工学分野を並行して推進」**し、それらを複合させることで産業と軍事を飛躍させていく。

```text

│     ・[生態×母星] ＝ 強化母星作物（耐毒・高カロリー）・共生バクテリア土壌    │
```

1. **並列推進の必然性**:
   * 1つのツリーだけを極端に伸ばしても産業のボトルネックに直面する（例: 生体組織を大量に手に入れても、惑星適応の重切削工作機械がなければ兵器装甲板に加工できない）。
2. **既存産業との直結**:
   * 抽象的な「科学力」の向上ではなく、サブタイルの町工場、高炉、化学プラントのレシピや歩留まり、戦闘団のモジュール仕様に直接連動する。
3. **不可逆な環境との相互作用**:
   * 母星テラフォーミング（環境の強制改変）とエイリアン生態系（現地の有機循環利用）の間には、土地利用や生息域をめぐる「戦略的トレードオフ」が存在する。

## 2. 3大並列技術ツリーの階層カタログ

各ツリーは**「幹技術（Trunk: 包括的パラダイム転換）」**と、そこから派生する**「葉技術（Leaf: 実装モジュール・施設・生産レシピ）」**で構成される。

---

## 3. 並列発展が生み出す複合シナジー（Hybrid Innovations）

本作の技術システムにおいて最も重要なのは、**「2つ以上のツリーを同時に進めることで、固有のハイブリッド産業・兵器モジュールがアンロックされる」**点である。

```text
                   【A. 惑星産業適応】
                         /\
                        /  \
                       /    \
        [シナジー①]  /      \  [シナジー②]
     キチン重工複合装甲        耐震テラフォーミング堤防
     生体触媒による極限精錬    過酷地熱・水圏再生
                     /        \
                    /__________\
【C. エイリアン生態系】 ─── [シナジー③] ─── 【B. 母星テラフォーミング】
                   超耐性母星ハイブリッド作物
                   共生土壌改良バクテリア
```

### 3.1 シナジー①：【産業適応】×【エイリアン生態系】（Bio-Heavy Industry）

* **キチン重工複合装甲板**:
  * 人類の高張力鋼とエイリアンの積層キチン外骨格を重ね合わせた特殊複合装甲。鋼鉄単体よりも軽量で、強酸・熱線兵器に対する極めて高い防御力を誇る。
* **生体触媒極限精錬（Bio-Hydrometallurgy）**:
  * 異星原生バクテリアを耐腐食性の高圧プラントに導入。本来なら高温・高圧・大量の電力が必要なレアメタル精錬を、常温で高効率に実行。

### 3.2 シナジー②：【産業適応】×【テラフォーミング】（Mega-Engineering Purity）

* **耐震テラフォーミング堤防・メガプラント**:
  * 激しい地殻変動や津波に耐える免震スーパー堤防と、大気浄化スクラバーを一体化。沿岸タイルの安全と母星化を同時に達成。
* **深層地下水メガパイプライン**:
  * 超硬質ボーリング重機を用いて惑星深層の清浄な帯水層を貫通。内陸乾燥地帯に巨大水路を敷設し、即座に大規模工業団地を冷却・稼働させる。

### 3.3 シナジー③：【テラフォーミング】×【エイリアン生態系】（Ecological Hybridization）

* **超耐性母星作物（Hybrid Agro-Crops）**:
  * 母星の小麦・大豆の遺伝子に、異星植物の毒素耐性・急速光合成プロファイルを組み込んだハイブリッド品種。完全なテラフォーミング未完了地（微小瘴気地帯）でも驚異的な収穫量を記録する。
* **選択的共生土壌改良**:
  * 母星型微生物と異星共生菌を混合散布し、不毛の鉱山残土をわずか数ターンで肥沃な土壌へと変換する。

## 5. 思想的摩擦とゲーム進行上のジレンマ（Strategic Trade-offs）

3つのツリーはすべて同時に進めることが理論上可能であるが、**「土地利用（Land Use）」と「国家アフィニティ（Affinity）」において重大なトレードオフ**を生じさせる。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                       ツリー間の構造的コンフリクト                          │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   【テラフォーミング推進 (Purity)】  VS  【エイリアン生体共生 (Harmony)】   │
│                                                                             │
│   ・大気を浄化し母星化する         │   ・異星生態系を保護・共生する        │
│   ・瘴気タイルが消滅する           │   ・瘴気が消えると生体資源が枯渇する  │
│   ・原生エイリアンが激怒・逆襲する │   ・エイリアンと平和共生・交易する    │
│                                                                             │
│   【プレイヤーの決断】:                                                     │
│   「領土全域を母星化して生体資源を諦めるか」                                │
│   「奥地に『原生自然保護区（バイオ特区）』を意図的に残して共生利用するか」   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

1. **資源の枯渇ジレンマ**:
   * 大気スクラバーを回して瘴気を一掃し、土地を肥沃な母星型農場に作り変えると、キチン質や生体触媒を産出する原生植物・生物が死滅し、ツリーCの素材供給がストップする。
2. **外交・エイリアン敵対度への影響**:
   * ツリーB（テラフォーミング）を急速に進める国家は、原生エイリアンから「環境破壊者」として最優先攻撃対象に指定される（[`concept_alien_behavior_territory_and_retaliation.md`](./concept_alien_behavior_territory_and_retaliation.md)参照）。
   * 逆にツリーCに傾倒する国家は、エイリアンとの友好を維持できるが、母星系保守派市民（Purity派）からの支持率低下や国内政治フリクションに直面する。
