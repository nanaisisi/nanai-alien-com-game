# 研究開発・技術ウェブ（Tech Web）およびアフィニティ進化設計仕様書

(Technology Tree, Radial Web Structure, Affinities & Autonomous R&D Steering)

本作（4X大戦略＋サブタイル戦術・戦闘団制）における**「非線形・放射状の技術ウェブ（Tech Web）」**、**「3大アフィニティ（適応思想）とハイブリッド進化」**、**「国内自律研究と国家ステアリング介入」**、および**「戦場残骸・実戦リバースエンジニアリング」**を体系化した設計仕様書である。

---

## 1. 基本設計理念：線形ツリーの否定と「適応」のダイナミクス

従来の多くの4Xゲーム（Civシリーズ等）における「一本道の直線型技術ツリー」は、人類史を特定のゴールへ向かう予定調和として描く。しかし、過酷な未知の異星フロンティアにおける科学技術の発展は、**「足元の生存・環境への適応」と「国家の地政学的・産業的選択」が織りなす放射状の分岐**である。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                           技術発展の基本構造比較                            │
├─────────────────────────────────────────────────────────────────────────────┤
│ 従来の線形ツリー (Linear Tree):                                             │
│   [石器] ───> [鉄器] ───> [火薬] ───> [内燃機関] ───> [宇宙開発] (一本道)   │
│                                                                             │
│ 本作の放射状技術ウェブ (Radial Tech Web):                                   │
│                     【調和・共生 (Harmony)】                                │
│                   （生体装甲 / フェロモン統御）                              │
│                               ▲                                             │
│                               │  [葉: 特化生体工学]                         │
│            [葉: 高度自動化]   │ /                                           │
│                 ┌───── [幹: 生体触媒]                                       │
│                 │             │                                             │
│  【超越・自律】 ◄─── [幹: 計算知性] ─── [基盤: 降着技術] ─── [幹: 重工業冶金] ──► 【純血・母星化】
│  (Supremacy)          │       (Landing Core)       │          (Purity)      │
│  （完全無人機 /        │                            │   （大口径実包 / 重装甲/│
│    量子論理網）        └───── [幹: 高密度エネルギー] ┘      テラフォーミング） │
│                               │                                             │
│                               ▼                                             │
│                     【極限物理・深層開発】                                   │
└─────────────────────────────────────────────────────────────────────────────┘
```

1. **放射状Web構造（Radial Web）**:
   - 中央の「降着基盤技術（Landing Core）」から外縁へ同心円状・扇状に広がる。
   - 1回のゲームですべての技術を網羅することは不可能。どの方向へ進んだかが文明の外見・兵器体系・産業構造を決定づける。
2. **幹技術（Trunk）と葉技術（Leaf）の階層**:
   - **幹技術（Major Breakthrough）**: 産業・学問の根本パラダイムを転換する包括的ブレイクスルー。全分野の基盤となりコストが高い。
   - **葉技術（Applied Specialization）**: 幹から派生する具体的な兵装モジュール、施設、生産歩留まり向上、ドクトリン。迅速に獲得可能。
3. **軍事・民生の一体性**:
   - 「戦車技術」という単体の研究は存在しない。「重構造冶金」が民生建機の耐荷重を上げ、副産物として戦闘団の重装甲スロットを解禁する（[産業進化仕様書](./../industry_logistics/concept_industrial_evolution_and_supply_chains.md)と完全合致）。

## 2. 3大アフィニティ（適応思想）とハイブリッド進化

過酷な異星環境と直面する中で、社会と研究者コミュニティは3つの思想的極（アフィニティ）へ引き寄せられる。アフィニティは単なる選択肢ではなく、**「獲得した技術の累積」によって国家の適応度レベル（Tier 1〜10）が動的に上昇**していく。

```text
               【Harmony: 調和・共生】
               （異星生体融合・現地環境適応）
                     /\
                    /  \
                   /    \
  [Hybrid: Bio-Cyber]  [Hybrid: Bio-Foundry]
      生体サイバネ          強化母星生態系
                 /        \
                /          \
               /____________\
【Supremacy: 超越・自律】    【Purity: 純血・母星化】
（無人機械・AI・量子知性）    （重工業・母星至上・環境改変）
          [Hybrid: Mecha-Purity]
             高密度自動重火工
```

### 2.1 3大単一アフィニティ（Pure Affinities）

| アフィニティ | 思想的背景 | 技術・産業の特質 | 兵器・戦闘団の変容 | 勝利への連動 |
| :--- | :--- | :--- | :--- | :--- |
| **Purity（純血・母星化）** | 「母星の遺産こそ人類の尊厳」。異星の汚染・変異を拒絶し、頑強な機械とテラフォーミングで大地を力づくで人類色に染め上げる。 | 重化学工業、高張力鋼・複合装甲、大口径実体弾・重砲、核分裂/融合推進、大気浄化スクラバー。 | 重装甲・超重戦車・自走榴弾砲。堅牢で火力が高いが、不整地踏破やミズマ腐食への維持費（交換部品）が重い。 | **テラフォーミング完了**：惑星環境の母星化と旧文明の復権 |
| **Harmony（調和・共生）** | 「生き残るには星そのものになるしかない」。原生生物の遺伝子を取り込み、共生細菌や生体触媒によって環境毒を味方につける。 | 異星生体工学、ミズマ循環濃縮、キチン質外骨格、生体リアクター、神経フェロモン誘引。 | キチン複合装甲、酸・毒素噴射、ミズマ内での自動回復・ステルス、多種族混成・融合生物戦闘団（[GAME_DESIGN.md](./../../GAME_DESIGN.md)参照）。 | **生体統合・精神超越**：惑星ハイブマインドとの意識同調 |
| **Supremacy（超越・自律）** | 「脆弱な肉体も未開の自然も不要」。極限の計算力、ナノマシン、完全自動化された無人兵器網によって過酷な惑星を機械的に統御する。 | マイクロエレクトロニクス、超微細ファブ、量子通信網、自律型無人AIドクトリン、光学・指向性エネルギー兵器。 | 完全自律型ドローン群、歩行多脚兵器の高度分散射撃管制、エネルギーシールド、即時データリンク（倫理的摩擦低）。 | **惑星電脳網・完全自律統御**：全インフラの自律AI集権統合 |

### 2.2 ハイブリッド・混成アフィニティ（Dual-Affinity Synergies）

単一のアフィニティに特化するだけでなく、2つの極を並行して高めることで、独自の特化技術・モジュールが解禁される。

1. **Harmony × Supremacy（生体サイバネティクス / Bio-Cybernetics）**:
   - 生体神経組織と超微細シリコンの直結。エイリアン生体ユニットへの遠隔サイバネ統御インプラント、自己増殖型ナノバイオマテリアル。
2. **Purity × Harmony（強化母星生態系 / Bio-Foundry Adaptation）**:
   - 母星の遺伝子プールを異星の頑強な生体触媒で補強。極限環境でも枯れない「超耐性母星作物」、熱帯化対応の重工合金。
3. **Purity × Supremacy（自動重火工・規格絶対主義 / Mecha-Purity）**:
   - 母星の伝統的重砲・装甲プラットフォームを、冷徹な完全自動照準・無人装填システムで極限まで研ぎ澄ました超高密度要塞化ドクトリン。

## 3. 技術ツリーの基本骨格（Radial 4 Tiers）

ウェブは4つの同心円状の階層（Tier）で構成される。外縁に行くほど、幹技術の研究コストが指数関数的に増大する。

```text
[Tier 0: 降着・生存] ──> [Tier 1: 基礎拡張・規格化] ──> [Tier 2: 特化・アフィニティ分岐] ──> [Tier 3: 極限特異点・終局]
```

## 4. 自律研究メカニクスと国家ステアリング介入

本作の研究開発は、プレイヤーが「フラスコポイントを貯めてポチッと押す」だけの万能神型UIを排し、**「現場の科学者・産業界の自律的進捗」に対する「国家指導者としてのステアリング（政策誘導）」**として動作する。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                       自律研究とステアリングの力学                          │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  [現場の産業・環境刺激] ───> 【基礎研究進捗ベクトル (Natural Tendency)】    │
│  （鉱山多 = 冶金進む）           │                                          │
│  （エイリアン交戦多 = 生体進む）  ▼                                          │
│                          【研究スロット】                                   │
│                                 ▲                                           │
│  [プレイヤーの国家政策] ────────┘                                           │
│  （研究予算補助金、重点特許指定、特定大学への奨励金）                       │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 4.1 現場起因の「自律研究ベクトル（Research Momentum）」

国家内の研究施設は、直面している現実の課題に応じて自律的に特定分野へリサーチポイント（RP）を注ぎ込む：

- **交戦環境**: 原生エイリアンとの交戦頻度が高い前線都市では「バイオ・毒素防護」の自律研究が加速する。
- **産業構造**: 重工業・鉱山タイルが多い国家では「高張力冶金」が自然に進捗する。
- **過酷環境**: 極寒・火山・瘴気タイルに入植している場合、環境適応技術のRPが底上げされる。

### 4.2 プレイヤーの介入手段（Steering Controls）

指導者は強制的に現場の興味を180度捻じ曲げることはできないが、以下のステアリング政策でベクトルを誘導する：

1. **重点研究特許の指定（National Priority Focus）**:
   - 特定の幹技術に国家予算（クレジット）を注入し、研究スピードを+50%〜+100%加速させる。
2. **研究奨励金・産学連携ドクトリン（Subsidies & Grants）**:
   - 3大アフィニティのいずれかに税制優遇を与えることで、民間研究機関が自発的にその方向の葉技術を選択する確率を高める。
3. **過渡期フリクション（R&D Friction）**:
   - 重工業ばかり進めていた国が突如「生体共生」にステアリングを切り替えた場合、研究者コミュニティの再編と教育インフラの転換に数ターンの「停滞（移行ラグ）」が発生する。

## 5. 残骸解析・実戦リバースエンジニアリング（Salvage Boost）

[鹵獲・遺棄処理仕様書](./../military_tactics/concept_salvage_scuttling_and_compatibility.md)で定義された通り、敵兵器は自爆・焼却プロトコルによって壊滅的な状態で遺棄されるため、完成品が手に入ることは稀である。しかし、その焼け残った残骸から得られる**「技術的知見（Data Remnants）」**は、技術ツリーを劇的にブーストする。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                     戦場サルベージによる技術ブーストの流れ                  │
├─────────────────────────────────────────────────────────────────────────────┤
│ 激戦地タイルの残骸 (Battlefield Wreckage)                                    │
│   │                                                                         │
│   ├─ 調査・工兵戦闘団による「戦場精査 (Battlefield Forensics)」             │
│   │                                                                         │
│   ▼                                                                         │
│ 【得られる知見の分解】:                                                     │
│   ① 敵国の規格・冶金データ ──> 自国の該当「幹技術」に固定値RPボーナス(5〜15%)│
│   ② 敵の特化モジュールの破片 ──> 該当「葉技術」の研究期間を直接短縮       │
│   ③ 異星生体の死骸サンプリング ──> Harmony系生体ツリーの即時進捗ブースト   │
└─────────────────────────────────────────────────────────────────────────────┘
```

1. **他国アフィニティの盗用（Counter-Affinity Insight）**:
   - 自国がPurity（重工）路線であっても、Supremacy（自律無人）国家の撃破残骸を精査することで、本来自国が苦手とする自律制御系技術のRPを獲得できる。
2. **リバースエンジニアリングの限界**:
   - 残骸から得られるのは「設計思想のヒント（原理）」までであり、自国のサプライチェーン（工作機械や素材）が追いついていなければ、その兵器を自国で量産することはできない（[ブートローダー産業仕様書](./../industry_logistics/concept_bootloader_and_national_supply_chains.md)の制約を受ける）。

## 6. 各種ゲームシステムとの有機的連動

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                           技術ツリーのシステム連動                          │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   ┌───────────────┐     技術解禁      ┌───────────────────────────┐         │
│   │ 研究開発      │ ───────────────>  │ 兵器モジュール・戦闘団     │         │
│   │ (Tech Web)    │                   │ (装甲板・主砲・ドローン)  │         │
│   └───────┬───────┘                   └─────────────┬─────────────┘         │
│           │                                         │                       │
│           │ 産業施設・歩留まり                      │ 部品要求              │
│           ▼                                         ▼                       │
│   ┌───────────────┐                   ┌───────────────────────────┐         │
│   │ サブタイル工業│ <──────────────── │ サプライチェーン・兵站    │         │
│   │ (Fab / プラント)│   モジュール生産  │ (弾薬規格・交換部品)      │         │
│   └───────────────┘                   └───────────────────────────┘         │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

1. **兵器モジュール・戦闘団（Military Tactics）への連動**:
   - 葉技術の獲得によって、兵器カスタマイズの各スロット（装甲、主武装、電子補正、推進機関）に装着可能なモジュールがアンロックされる。
   - アフィニティレベルが上がることで、各戦闘団の基本フレーム（師団スロット構成）が「混成戦闘団」「多脚無人戦闘団」「重装甲機甲戦闘団」へと進化・再編される。
2. **産業・サプライチェーン（Industry & Logistics）への連動**:
   - 新技術の解禁は、同時に「新たな二次資源（論理コア、特殊合金装甲、培養細胞）」の需要を生み出す。
   - 技術先行しても、国内のコンビナートがその素材を量産できなければ、前線部隊に新装備は行き渡らない（産業の足腰が軍事を規定する）。
3. **外交・条約（Diplomacy）への連動**:
   - 他国と「共同研究条約（R&D Pact）」を結ぶことで、相互に隣接する技術ウェブのコストが低減。
   - 特許ライセンス供与により、自国の規格を他国に輸出して「デファクトスタンダード（事実上の標準化）」を握る経済・技術覇権外交が可能となる。
