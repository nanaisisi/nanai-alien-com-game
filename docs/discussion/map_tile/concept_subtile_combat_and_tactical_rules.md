# サブタイル戦術戦闘・ターン構造および境界増援仕様書

(Sub-Tile Tactical Combat, Turn Micro-Structure & Edge Reinforcement Mechanics)

本作（4X大戦略＋サブタイル戦術・戦闘団制）における**「大戦略1ターン内のサブタイル戦術戦闘（343マス）のターン制限・時間分割」**、**「隣接タイルからの増援・長距離支援砲撃の到達ラグ」**、**「戦場外周エッジにおける突破・離脱・追撃処理」**、および**「戦術マップ上の施設破壊による大戦略インフラへの即時フィードバック」**を体系化した設計仕様書である。

---

## 1. 基本設計思想：大戦略と戦術戦闘の融合とテンポ維持

従来の4X＋戦術戦闘ゲーム（例: Total Warシリーズ、Age of Wondersシリーズ）では、戦術戦闘が長引くことで「大戦略マップの進行テンポが崩壊する」「1回の戦闘に30分以上拘束される」という構造的課題を抱えていた。
本作では以下の原則に基づき、**「大戦略のリズムを損なわず、かつ地形・配置・戦術機動の妙味を極限まで引き出す」**システムを構築する。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                    大戦略 ⇔ サブタイル戦術戦闘の結合構造                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【大戦略 1ターン (Macro Turn)】                                            │
│    │                                                                        │
│    ├─ タイル衝突判定（部隊が敵対タイルへ進入、または会敵）                  │
│    │                                                                        │
│    ▼                                                                        │
│  【サブタイル戦術戦闘 (Sub-Tile Tactical Battle: 343マス)】                 │
│    ├─ 時間制約: 最大 12〜15 サブターン（Phase）で強制終了                   │
│    ├─ 1サブターンの意味: 親マップ1ターンの約 1/12 の時間進行                │
│    ├─ 決着がつかない場合: 「未決着交戦（Grinding Combat）」として親マップへ  │
│    │    └─ 双方の残存部隊が同タイル内で対峙・戦線膠着（消耗戦）             │
│    │                                                                        │
│    ├─ 隣接親タイルからの干渉:                                                │
│    │    ├─ 増援部隊: 親タイルの移動力・道路網に応じたサブターン到達ラグ      │
│    │    └─ 支援砲撃・ミサイル: 毎サブターン開始時に指定座標へ弾着            │
│    │                                                                        │
│    └─ 施設破壊の反映:                                                        │
│         └─ 発電所・鉄道・工廠の破壊が、戦闘終了と同時に親タイルTierへ反映   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

1. **有限サブターン制によるテンポ保証**:
   - 戦術戦闘は無限に続かない。大戦略1ターンに対し、戦術戦闘は**最大12〜15サブターン**で区切られる。
   - 制限時間内に敵を全滅・潰走させられなかった場合、戦闘は「膠着状態」として親マップの次ターンへ持ち越される。
2. **完全手動・高速セミオート・即時自動計算（委託）の3段構え**:
   - プレイヤーは戦闘ごとに「指揮介入（手動）」「ドクトリン委託（倍速自動）」「即時結果解決（オート）」を選択可能。
3. **境界（エッジ）の物理的連続性**:
   - 戦術マップの端は「見えない壁」ではなく、隣接親タイルへと続く実際の地理的接続部である。

## 2. 幾何学空間と戦術交戦スケール（343マス）

[`./future_concept_subtile_industry.md`](./future_concept_subtile_industry.md) および [`./sub_tile_seamless_connection.md`](./sub_tile_seamless_connection.md) で定義された $7^3 = 343$ マス（直径約21〜23ヘックス）を作戦空間とする。

```text
               [北エッジ (親タイル #N 接続)]
                     ▲ ▲ ▲ ▲ ▲
                   ／         ＼
 [北西エッジ]    ／             ＼    [北東エッジ]
   ◀ ◀ ◀       ／   【戦術領域】  ＼      ▶ ▶ ▶
              │    (343ヘックス)   │
              │  直径: 約21〜23マス│
 [南西エッジ]  │   主攻正面 / 助攻 │   [南東エッジ]
   ◀ ◀ ◀       ＼  市街・工業拠点 ／      ▶ ▶ ▶
                 ＼             ／
                   ＼         ／
                     ▼ ▼ ▼ ▼ ▼
               [南エッジ (親タイル #S 接続)]
```

### 2.1 距離感・交戦テンポの計算

- **標準小隊の移動力**:
  - 重装甲小隊: 2〜3マス/サブターン
  - 装甲歩兵・軽装輪: 3〜4マス/サブターン
  - 高速偵察・ドローン: 4〜5マス/サブターン
- **射程のカテゴリ分け**:
  - 直接射撃（戦車砲、機関砲、対戦車誘導弾）: 射程 2〜4マス（直視線 LOS が必要）
  - 迫撃砲・近接間接支援: 射程 4〜7マス（LOS不要・山岳越射可能）
  - 野戦重砲・多連装ロケット（SPG/MRLS）: 射程 8〜16マス（戦術マップ全域を射程に収めうるが、最低射程制限 3マス）
- **会敵タイムライン**:
  - サブターン 1〜2: 前哨索敵・砲兵による初期制圧射撃・高台の奪取
  - サブターン 3〜6: 主力部隊の激突・前線突破・市街地交戦
  - サブターン 7〜10: 予備兵力投入・側面迂回・敵陣地中枢の包囲
  - サブターン 11〜15: 掃討、または防衛側の遅滞戦闘・残存部隊のエッジ離脱

## 3. 隣接タイルからの増援（Reinforcements）と到達ラグ

戦闘が発生している親タイルの「隣接6タイル」に友軍戦闘団が存在する場合、その部隊は**「増援（Reinforcement）」**として戦術戦闘に介入できる。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                       増援到達サブターンの算出モデル                        │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  基本到達サブターン (Arrival Sub-Turn) =                                    │
│      基準ラグ (Base: 4ターン)                                               │
│      + 地形走破コスト (Terrain Friction: 平野+0, 森林+2, 湿地+3, 山岳+5)    │
│      - インフラ短縮 (Road/Rail: 舗装路 -2, 高速鉄道 -3 ※最低値 1)          │
│      + 戦域ドクトリン補正 (Doctrine Modifier: 電撃攻勢 -1, 慎重行動 +1)      │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.1 増援の進入プロセス

1. **進入方角の決定**:
   - 隣接親タイルの相対方角（北、北東、南東、南、南西、北西）に応じた**外周エッジ（端の3〜5マス）から進入**する。
   - 例: 北側の親タイルにいた増援戦闘団は、戦術マップの「北エッジ」から隊列を組んで出現。
2. **遅延（Staggered Entry）**:
   - 戦闘団全体が一度に現れるのではなく、先鋒の偵察・軽装甲が先着（例: サブターン3）し、重戦車・後方輜重は遅れて到着（例: サブターン6）する。
3. **退路遮断（Interdiction）**:
   - 隣接タイルが敵の制空権下にある、または敵砲兵の阻止砲撃を受けている場合、進入時に確率で損耗（空爆・地雷原被害）を受け、到達がさらに1〜3サブターン遅延する。

## 4. 親タイル間・長距離支援砲撃（Off-Map Artillery & Missiles）

戦闘中の親タイルに直接進入していない隣接親タイルの長距離砲兵（SPG/MRLS）や海洋メガフロートの艦砲は、**「盤外支援砲撃（Off-Map Fire Support）」**として戦術マップへ射撃を投射できる。

### 4.1 支援砲撃の実行ルール

- **要請権限**:
  - 前線小隊が「観測線（LOS）」または「偵察ドローン」によって敵座標を確定（ペイント）している必要がある。
- **着弾ラグ**:
  - 要請サブターンの**翌サブターン開始時**に弾着（砲弾の飛翔時間）。
- **着弾散布界（CEP）**:
  - 観測誘導ドローンが健在な場合: 誤差 0〜1ヘックス。
  - 視界不良・電子妨害（ジャミング）下: 誤差 2〜3ヘックス（味方への誤爆リスクあり）。
- **弾薬消費**:
  - 盤外砲撃を行うごとに、親タイルの兵站備蓄（弾薬）がリアルタイムで激しく消費される。

## 5. 外周エッジにおける突破・離脱・追撃処理

戦術マップの外周エッジは、退却および突破の境界線として厳密に機能する。

### 5.1 部隊の戦術的離脱（Tactical Retreat）

- **離脱条件**:
  - 友軍の領有する親タイルと接しているエッジマスに到達し、「離脱（Disengage）」を選択。
- **追撃ペナルティ**:
  - 敵の直接射程内（ZOC内）から離脱する場合、背面攻撃（リア・アタック）判定を受け、防御力が半減した状態で1回の機会攻撃（Opportunity Fire）を受ける。
- **離脱後の状態**:
  - 離脱に成功した小隊は、隣接親タイルへと後退し、大戦略マップ上で「再編中（組織力低下）」となる。

### 5.2 敵陣突破（Breakthrough）

- 攻撃側が敵タイルを制圧しきれずとも、**防衛ラインを突破して反対側のエッジへ到達した場合**：
  - 敵親タイルを「通過」して背後の親タイルへと突入する「戦術突破」が成立。
  - これにより、敵の補給路遮断や包囲環の形成が可能となる。

## 6. 戦術マップ上の施設破壊と大戦略インフラへの即時フィードバック

343マスの戦術マップ上には、大戦略タイルのTierを構成する重要インフラ施設（発電所、工場ブロック、精錬所、鉄道ジャンクション、送電タワー）が物理的に配置されている。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                      施設破壊と大戦略への波及メカニクス                     │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  戦術マップ上での破壊事象                                                    │
│    ├─ 発電プラントの爆破 ───► 【大戦略】該当親タイルの稼働率が 0% に急落    │
│    │                          隣接タイルのインフラ結合度 -30% (停電)        │
│    │                                                                        │
│    ├─ 橋梁・鉄道ターミナルの爆破 ► 【大戦略】親タイルの通過移動コストが3倍に│
│    │                              補給物資の輸送ウィンドウ遮断             │
│    │                                                                        │
│    └─ 工業ブロック・民生地区損壊 ► 【大戦略】親タイル進展度 (Progression Tier)│
│                                    Tier 3 ──[荒廃/後退]──► Tier 1           │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 6.1 意図的破壊（焦土作戦）と副次被害（Collateral Damage）

- **市街地・重工業の遮蔽効果**:
  - 工場建屋や高層区画は強固な遮蔽（防護力+40%）を提供するが、砲撃や重火器の集中射撃によって瓦礫化する。
- **焦土作戦（Scorched Earth）**:
  - 防衛側は撤退時、工兵小隊を用いて重要施設に爆薬を設置し自爆破壊（Scuttling）できる。
  - 敵にタイルを奪われても、相手は「Tier 0の荒廃地」しか得られず、インフラ再建に莫大なターン数を強いられる。

## 7. 未決着交戦（Grinding Battle）の処理

最大サブターン（例: 15ターン）が経過しても、双方の部隊が残存し、かつどちらも撤退しなかった場合の処理規定。

1. **戦線膠着（Frontline Stasis）**:
   - 戦術戦闘は一旦中断され、親マップの画面へ復帰する。
   - 親タイル上には**「交戦中（In Battle）アイコン」**が表示され、双方の戦闘団は移動不能（ピン留め）となる。
2. **大戦略次ターンでの再開**:
   - 親マップの次ターンが始まると、**前回の損耗・残存兵力・破壊された地形の状態を100%引き継いだまま**、再びサブターン1から戦闘が再開される。
3. **継続的な兵站流出**:
   - 膠着している戦闘団は、親マップのターン終了ごとに通常の2倍の弾薬・燃料・補給品を消費し続ける。補給が途絶した側から士気崩壊（Surrender）を起こす。

## 8. 実装データ構造案（Rust）

```rust
/// サブタイル戦術戦闘セッション
pub struct TacticalCombatSession {
    pub parent_tile_id: u32,
    pub current_sub_turn: u8,
    pub max_sub_turns: u8, // 通常 12 ~ 15
    pub weather_and_miasma: TacticalEnvironment,
    
    /// 343マスの戦術盤面
    pub sub_grid: SubTileGrid,
    
    /// 展開中の全戦闘部隊
    pub active_combatants: Vec<TacticalUnitInstance>,
    
    /// 進入待ちの増援キュー
    pub pending_reinforcements: Vec<PendingReinforcement>,
    
    /// 盤外支援火力リスト（隣接タイル砲兵）
    pub off_map_support_assets: Vec<OffMapSupportAsset>,
}

/// 増援キュー情報
pub struct PendingReinforcement {
    pub combat_group_id: u32,
    pub entry_edge: HexDirection, // 北、北東、南東など
    pub arrival_sub_turn: u8,     // 到達予定サブターン
    pub interdiction_damage_risk: f32, // 阻止砲撃による損耗リスク
}

/// 盤外火力要請
pub struct FireSupportRequest {
    pub source_tile_id: u32,
    pub target_sub_coord: (i32, i32),
    pub scheduled_sub_turn: u8,
    pub dispersion_radius: u8, // 散布界 (0~3)
    pub munition_type: MunitionStandard,
}
```
