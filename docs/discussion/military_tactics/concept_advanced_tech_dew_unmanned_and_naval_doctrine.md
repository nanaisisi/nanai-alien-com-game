## 2. 無人機・無人自律システム（UxV: Unmanned Systems）の体系的検討

### 2.1 4領域（空・陸・海・潜）の無人機アセットと役割

無人システムは単独で戦線を維持するのではなく、有人部隊（軍団・師団・艦隊）の「消耗可能なセンサー・エフェクター（手足）」として編制内に統合される。

| 領域 | 区分・機体種別 | 主な役割・戦術機能 | ペナルティ・制約 |
| :--- | :--- | :--- | :--- |
| **空中 (UAV)** | **スウォーム滞空型自爆ドローン** | 敵防空レーダーの飽和、前線装甲車両の上面装甲（天板）突入破壊。 | 強風・暴風雨、電波妨害（ジャミング）に極めて脆弱。 |
| | **戦術偵察・ターゲティングUAV** | 師団・大隊レベルでの視界提供、2タイル先への超長距離砲撃諸元伝送。 | 滞空時間に限界、レーザー・CIWSの格好の標的。 |
| **地上 (UGV)** | **前進斥候・ポイント尖兵UGV** | 隘路・森林・市街地廃墟への先行突入、地雷・ブービートラップ啓開。 | 瓦礫・極端な泥濘でのスタック、姿勢復帰不能リスク。 |
| | **無人自走迫・補給支援UGV** | 下車歩兵に随伴する弾薬運搬、遠隔自動射撃支援（120C自走迫）。 | 通信中継車が破壊されると行動不能（停止）に陥る。 |
| **水上 (USV)** | **高速迎撃・哨戒USV** | 港湾・沿岸シーレーンの警備、肉薄する水棲エイリアンへの自爆阻止。 | 外洋波浪（シーステート高）での航行不能、耐波性限界。 |
| | **自律機雷掃海・ソナー敷設USV** | 艦隊前衛での危険海域啓開、音響センサードロップによる探知線構築。 | 艦隊本隊の行動速度（巡航）に同期させるための推進力制約。 |
| **水中 (UUV)** | **大深度探査・待ち伏せUUV** | 潜水艦・水棲巨獣の早期警戒、チョークポイントでの休眠待伏せ雷撃。 | 水中音響通信の帯域極小（指示変更が困難、事前プログラム依存）。 |

### 2.2 有人・無人チーミング（MUM-T）と自律エシュロン

無人機は「兵科」として独立軍団を組むのではなく、既存の諸兵科連合エシュロン内部にスロットとして組み込まれる。

1. **第1層：端末消耗品（アモー・ドローン / Loitering Munitions）**:
   - 弾薬（消費財）として扱われ、歩兵小隊や近接戦闘艦から発射。回収を想定しない。
2. **第2層：戦術随伴型（ロイヤル・ウィングマン / バディUGV）**:
   - 有人車両・有人戦闘機の直協パートナー。有人側のC4I端末から直接リンクし、前衛シールドやセンサー拡張を担当。
3. **第3層：自律哨戒・管制ノード（テザー・アンカー型）**:
   - メガフロート、母艦、師団司令部から運用される大型UAV/USV。長時間の海空域警戒とデータリンク中継を維持。

### 2.3 電子戦（EW）・通信途絶と自律性（エッジAI）のジレンマ

- **有人指揮下の安心感 vs 通信脆弱性**:
  - 人間が遠隔操作（テレオペレーション）する場合、状況判断の柔軟性と倫理責任が保たれるが、敵の強力なECM（電波妨害）や異星の電離層嵐でリンクが切断されると即座に無力化する。
- **エッジAIによる完全自律モード（Fire & Forget）**:
  - 通信遮断下でもあらかじめ学習されたアルゴリズムで自律交戦を行うモード。
  - **リスク（誤認と暴走）**: 友軍識別（IFF）の誤認、民間船や中立入植地への誤爆、エイリアンの生体偽装フェロモンによる標的誤認が発生する。

## 3. 指向性エネルギー兵器（DEW）と次世代電子・物理打撃

### 3.1 高出力レーザー兵器（HEL: High-Energy Laser）

光速で標的に到達し、運動エネルギー弾では迎撃困難な超音速飛翔体や小型群を即時無力化する。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                       高出力レーザー兵器 (HEL) の運用特性                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【メリット】                                                               │
│    ・弾速＝光速（弾道計算・偏差射撃が不要、即時着弾）                       │
│    ・弾薬庫の概念が存在しない（電力と冷却水が続く限り無限に射撃可能）       │
│    ・C-RAM（対迫撃砲・対ロケット・対小型UAV）迎撃率が極めて高い             │
│                                                                             │
│  【物理的・環境的制約（異星の壁）】                                         │
│    ・大気減衰（Thermal Blooming）:                                         │
│      - 異星の濃密な大気や湿気により、ビームが焦点で自己拡散・威力減衰。     │
│    ・瘴気（ミズマ）・粉塵マスキング:                                         │
│      - 胞子雲や微小鉱物粉塵がレーザー光を乱反射・吸収し、有効射程が激減。   │
│    ・ミラー・アブレーション装甲の台頭:                                       │
│      - 生体エイリアンの珪素結晶外殻や特殊誘電体ミラー装甲に対して著しく減衰。│
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

- **ゲーム的役割**:
  - 戦艦・大型空母・基地要塞の「究極の近接防空・ドローンシールド」。
  - 通常の機関砲CIWSのように弾薬切れを起こさず、敵ドローンスウォームや迫撃砲斉射を次々に撃ち落とすが、瘴気濃度が高いタイルでは迎撃成功率が大幅に低下する。

### 3.2 高出力マイクロ波兵器（HPM: High-Power Microwave）

単一の標的を焼き切るレーザーに対し、指向性コーン状に強力な電磁パルスを照射して面制圧を行う。

1. **対ドローンスウォーム・電子兵器無力化**:
   - 照射範囲内のすべての非シールド半導体・アンテナ・センサーを過電流で一網打尽に物理破壊。
   - スウォーム突撃に対する「電磁散弾銃」として機能。
2. **対エイリアン神経パルス兵器（生体電子戦）**:
   - 異星原生生物の感覚器官（生体ソナー・生体電位探知器・中枢神経網）に強力な高周波パルスを照射。
   - 物理的殺傷力は低いものの、群れ全体に激しい空間識失調・錯乱・同士討ち（Stampede）を誘発し、突撃を破綻させる。

### 3.3 電源・熱管理アーキテクチャ（VRM中間バッファと冷却工学）

DEWおよび電磁レールガンの配備は、車体・艦体の「電力・熱マネジメント」に決定的な制約を課す。

- **VRM（中間エネルギーバッファ）の負荷**:
  - 発電機（核融合炉/低速水素直噴機関）から直接大電力を引くことは機関エンストを招くため、超電導フライホイールや大容量コンデンサ（VRMバッファ）に蓄電して瞬間放電する。
  - レーザーの連続照射やレールガンの急速連射を行うとバッファ温度が急上昇し、クールダウン（充填ラグ）が発生する。
- **熱排熱ペナルティ**:
  - 水上艦は海水冷却により高い排熱能力を持つが、地上車両（装甲車・自走砲）に搭載したDEWは熱放出が追いつかず、高温環境タイル（乾燥砂漠・熱帯雨林）では連続射撃制限がかかる。

## 4. 水上システム総合運用・海洋工学ドクトリン（長期深化枠）

### 4.1 陸海シームレス工法（造船・自航回航・海岸揚陸）

陸上戦艦打撃軍団および水上艦隊の結節点となるオペレーション。

1. **臨海造船所（海軍工廠）での大型建造**:
   - 水上艦艇（62隻エシュロン）も陸上戦闘艦（陸上戦艦・小型空母）も、同一の「臨海造船所」の乾ドック・ブロック建造設備を共有。
   - 工業リソース（IND-6造船・海洋重工、IND-2耐食合金）の配分を奪い合う関係となる。
2. **海上自航回航（フェリーモード）の脆弱性**:
   - 陸上戦闘艦は海上航海中、バラスト浮力展開により喫水が深くなり、主砲射撃制限と回避運動制限を受ける。
   - この回航フェーズを敵潜水艦や水棲エイリアンから防護するため、**「護衛艦隊（計28隻）」または「通常艦隊（計62隻）」の同伴護衛スクリーン展開**が必須システムとなる。
3. **敵前海岸揚陸（ビーチヘッド・ロールアウト）**:
   - 港湾のない海岸タイルへの直接上陸。
   - 陸上戦艦は自力クローラーで砂浜からロールアウト。通常地上部隊（機甲・歩兵）は航空艦隊の強襲揚陸艦・LCACを通じて揚陸。

### 4.2 洋上移動支配拠点（メガフロート・自走型MOB）の生態系・軍事動態

固定都市に代わる海洋支配の核。

- **領海動態と主権拡張**:
  - メガフロート（半固定）やMOB（自走型移動海洋基地）は、航行・係留した周囲1〜2タイルに排他的経済水域・防空管制圏を投影する。
  - 資源採掘・洋上養殖・補給デポとして機能し、艦隊の母港不在による戦闘力低下を現場海域で防ぐ。
- **環境破壊とエイリアン刺激**:
  - 海面を巨大浮体で覆うことによる遮光、低周波機関音、熱排水は水棲エイリアンの巣窟を激しく刺激し、周期的な大型海棲獣の襲撃イベント（大深度からの体当たり・触手巻き付き）を誘発する。

### 4.3 三次元立体戦闘（水上・水中・沿岸）とソナー戦

1. **水上打撃 vs 潜水ステルス**:
   - 潜水艦・水中エイリアンはレーダーに映らない「完全潜航モード」で接近。
   - 水上艦隊は汎用フリゲート（16隻）の曳航パッシブソナーと艦載対潜ヘリによる対潜バリアでこれを迎え撃つ。
2. **生体超高圧キャビテーション砲**:
   - 超巨大水棲エイリアン（リヴァイアサン級）が放つ水中衝撃波は、艦艇のキール（竜骨）を直接破壊するバブルパルス効果を持ち、通常装甲を透過して大ダメージを与える。
3. **沿岸火力投射の階層性**:
   - 汎用駆逐艦のレールガン/巡航ミサイルによる沿岸1タイル直接支援（陸上戦力バフ）。
   - 超弩級戦艦の `EM-180C` による沿岸2タイル内陸要塞破砕（長距離間接打撃）。

### 4.4 アイアンボトム・サウンド（沈没艦船の海底有限資源化）

撃沈された艦艇群が残す「戦場の遺産」。

- **特殊残骸タイルの生成**:
  - 62隻規模の大艦隊やメガフロートが沈没したタイルは「アイアンボトム・サウンド（鉄底海峡）」へと変貌。
  - 重油・冷却剤による局所海洋汚染ゾーンを形成。
- **サルベージ・再資源化ダイナミクス**:
  - 工作潜水船団や海洋サルベージ部隊を派遣することで、陸上鉱山を凌駕する高純度特殊合金（IND-2）や希少電子コンポーネントを有限資源として回収・回収工廠へ搬入可能。

## 6. 今後の設計・実装ロードマップ（優先順位）

1. **フェーズ1（直近・確定済）**:
   - 通常海上戦闘団（全6種・計62隻共通固定エシュロン）のTO&E確定。
   - 陸上戦艦打撃軍団のTO&Eおよび造船所建造ルールの確立。
2. **フェーズ2（次期焦点）**:
   - 通常航空戦闘団（全14種）の規模・エシュロン・地上基地依存関係の整理。
   - 野生・固有エイリアン（空棲・水棲）の生態系・ヒエラルキー整理。
3. **フェーズ3（長期実装・本検討書の詳細化）**:
   - 無人システム（UxV）の戦術マップ（サブタイル）展開ロジック策定。
   - 指向性エネルギー兵器（レーザー・HPM）の気象・瘴気減衰演算パラメータ設計。
   - 海上回航・揚陸・MOB拠点のオーバーワールド大戦略移動・補給判定の実装。
