# 軍事編成・部隊単位体系および戦闘団概念仕様書

(Military Echelon, Unit Hierarchy & Combat Group Conceptual Specification)

本作（4X大戦略＋サブタイル戦術・戦闘団制）における**「大戦略マップ（親タイル）と戦術マップ（サブタイル）における軍事組織階層（エシュロン体系）」**、**「なぜ1個の戦闘団が増強師団・諸兵科連合として自己完結しているのか」**、および**「各種戦闘団タイプ（機甲、機械化歩兵、空中機動、海兵水陸、山岳多脚など）の分類体系」**を定義する基本仕様書である。

---

## 1. 軍事組織階層（エシュロン体系）の全体像

本作は大戦略（親タイル）と戦術戦闘（サブタイル）の2重スケールを採用しており、指揮統制とマイクロマネジメント排除の観点から、階層ごとに明確な役割分担を設けている。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                       軍事エシュロン（階層）体系                            │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【方面軍 (Theater Command)】 ── マクロ戦略（方面軍AI・管区統治）          │
│    ・司令官・参謀部が管轄。複数親タイル（戦域）の防衛・進撃方針を統括。    │
│    ・所属戦闘団への補給優先順位、共同管理領域の兵站割当を制御。            │
│                                │                                            │
│                                ▼                                            │
│  【戦闘団 (Combat Group)】 ── 大戦略マップの【最小操作単位（1コマ）】       │
│    ・規模: **増強師団／諸兵科連合連隊・旅団（総員 10,000〜15,000名規模）** │
│    ・実態: 単一兵科ではなく、戦車・歩兵・特科・防空・偵察・兵站が完備。    │
│    ・操作: 地図上での作戦ベクトル（矢印）による移動・スタンス指示。         │
│                                │                                            │
│                                ▼ （親タイル交戦時に展開）                   │
│  【戦術大隊・小隊 (Platoon / Battalion Task Force)】 ── サブタイル展開      │
│    ・規模: 16個の編成枠（TO&E）に格納された各基幹大隊・戦術小隊。          │
│    ・実態: 343マスの戦術盤面上で、下車戦闘、射撃、遮蔽利用、陣地制圧を実施。│
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 2. 部隊単位（Unit Echelon）の定義と規模感

機甲科・諸兵科連合における**「4両＝1小隊、4小隊＝1中隊（16両）、2個戦車中隊＋2個装甲化歩兵中隊＝1個大隊」**という倍々・ペア構造を基底モデルとする。

| 階層 (Echelon) | 兵力規模 | 車両数 | 組織の内訳とペア補完関係 |
| :--- | :--- | :--- | :--- |
| **小隊 (Platoon)** | 30〜40名 | **4両** | 最小射撃単位。2両セクション（バディ）× 2組で相互躍進。 |
| **中隊 (Company)** | 120〜160名 | **16両** | 4個小隊（4両×4＝16両）。同一車種による戦術行動単位。 |
| **大隊 (Battalion)** | 600〜800名 | **約64両** | **諸兵科連合の最小完結単位**。**【2個戦車中隊 (32両) ＋ 2個装甲化歩兵中隊 (32両)】**の 2-2 構成。 |
| **連隊 / 旅団 (Regiment / Brigade)** | 2,500〜3,500名 | 130〜150両 | 2個諸兵科大隊 ＋ 連隊直轄特科・偵察隊。 |
| **増強師団 / 戦闘団 (Combat Group)** | **10,000〜15,000名** | **500〜700両** | **大戦略マップ上の1コマ**。4個連隊相当の戦力 ＋ 師団特科・高射・装輪偵察・兵站。 |

> [!NOTE]
>
> ### スロット数のシステム設計：上限キャップを排した「可変長スロット（Dynamic Slots）」
>
> システム実装上、**「16スロット上限」といった固定キャップ（ハードリミット）は設けない**。
> 戦闘団が保持するスロットは可変長リスト（`Vec<CombatSlot>`）として扱われ、少数の急造部隊（4〜8スロット）から、後期の重厚な超巨大方面直轄軍（20スロット超）まで柔軟に伸縮する。
> 「16スロット」という数字は、あくまで**標準的な増強機甲師団における代表的な編成作例（2進数・倍々構造のモデルケース）**に過ぎない。

## 3. なぜ「諸兵科連合の戦闘団（師団相当）」なのか

従来の4Xゲームで発生していた「戦車単体ユニット」「歩兵単体ユニット」「大砲単体ユニット」を1マスずつ動かすシステムには、以下の重大な欠陥が存在していた。

1. **マイクロマネジメントの破綻**:
   * 大砲を護衛するために戦車と歩兵を毎ターン1ヘックスずつ並走させる必要があり、前線が広がると操作クリック数が激増する。
2. **非現実的な単一兵科運用（スタック問題）**:
   * 「戦車だけを30スタックして突撃」「長距離砲だけ並べて安全圏から撃滅」といった、現実の兵站・防空・諸兵科連合を無視したメタ戦法が横行する。

本作では、大戦略の1コマを**「戦車・歩兵・自走砲・防空・工兵・補給が最初からワンパッケージになった戦闘団」**とすることで、以下のゲーム性を両立している。

* **操作の簡潔性**: プレイヤーは大戦略マップ上で「太い作戦矢印」を指示するだけでよい。
* **組織の深み**: 内部の16スロット構成やドクトリン（機甲重視、歩兵重視、装輪偵察など）により、部隊の性格が自律的に決定される。

## 4. 2進数・倍々構造（2^N Binary Buddy Echelon System）

本作の部隊編制および運用ロジックは、徹底して**「2進数（倍々構造：1 ➔ 2 ➔ 4 ➔ 8 ➔ 16）」**を基本原則として設計されている。
軍事組織における「バディシステム（ペア運用）」と一致し、**同格の2個単位が互いに前進と援護（Fire and Maneuver）を行い、損耗時には2個単位同士で即座に共食い・再編補完できる**極めて明快な数理モデルである。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                 2進数・倍々エシュロン階層構造 (Binary Hierarchy)            │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  2^0 = 1両・班 (Single Vehicle / Team)                                      │
│    │                                                                        │
│    ▼ (×2: ペア・バディ)                                                     │
│  2^1 = 2両 (Section / 分隊バディ) ── 1両が前進、1両が援護監視（相互補完）   │
│    │                                                                        │
│    ▼ (×2: 小隊)                                                             │
│  2^2 = 4両 (Platoon / 基幹戦術小隊) ── 2両セクション × 2ペア                │
│    │                                                                        │
│    ▼ (×2: 中隊ハーフ) ── (4小隊 = 16両で1個基幹中隊)                       │
│  2^3 = 8スロット (半戦闘団タスクフォース) ── 前線主打撃群 vs 後方火力支援群 │
│    │                                                                        │
│    ▼ (×2: 戦闘団完結)                                                       │
│  2^4 = 16スロット (増強機甲師団 / 諸兵科連合戦闘団)                         │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 4.1 2進数ペア補完の数理と現場メリット

1. **1対1（1-1）の直接補完**:
   * 同一スロット内、あるいは隣接する2個スロット（例: Slot 01 と Slot 02）が「ペア大隊」として機能。
   * Slot 01 が激戦で稼働率 40% に落ちた場合、僚友である Slot 02 の健全パーツや弾薬を優先融通し、即座に「1個大隊を100%健全化、1個を後方再編」という2進集約（2-to-1 合併）が自律判定される。
2. **2対2（2-2）の群補完**:
   * 4個スロットからなる基幹戦車連隊群（Slot 01〜04）は、前半2個大隊（01, 02）と後半2個大隊（03, 04）がペアとなって前進・支援を交代。
   * 損耗時も「2個大隊を前線維持、残り2個大隊を後方共食いドナー」として半分ずつ綺麗にリソースをやりくりできる。
3. **8対8（8-8）の師団半身補完**:
   * 16スロット全体は、前半8スロット（直協戦闘群: 戦車＋歩兵）と、後半8スロット（特科・防空・偵察・兵站群）という「刃（Combat）」と「柄（Support）」の 1:1 ペアとして成立。
   * 兵站断絶時も、後方支援群（後半8枠）の補給トラック・ARVから前線装甲群（前半8枠）へ段階的にリソースが注ぎ込まれる。

## 5. 戦闘団タイプ（Archetype）の分類体系

国家の技術水準、地形、ドクトリンに応じて、戦闘団は以下の基本タイプに分化・編成される。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                        戦闘団タイプ（アーキタイプ）                         │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  ①【増強機甲戦闘団 (Heavy Armored Combat Group)】                          │
│      └─ 主力戦車230両超基幹。平原・舗装動脈での絶対的突破力。               │
│         （詳細仕様: concept_combat_group_heavy_armored.md 参照）            │
│                                                                             │
│  ②【機械化歩兵戦闘団 (Mechanized Infantry Combat Group)】                   │
│      └─ 装甲歩兵大隊・重IFV基幹。都市・高Tier施設・森林・隘路の防衛・制圧。 │
│                                                                             │
│  ③【装輪高速機動戦闘団 (Stryker / Wheeled Rapid Reaction Group)】           │
│      └─ 6x6/8x8装輪車台統一。舗装動脈での電撃進撃・緊急展開・シーレーン確保。│
│                                                                             │
│  ④【山岳・極限多脚戦闘団 (All-Terrain Legged Combat Group)】                 │
│      └─ 4脚/多脚歩行車台基幹。急斜面・岩盤・深部泥濘・瘴気バイオーム特化。  │
│                                                                             │
│  ⑤【空中機動・浸透戦闘団 (Airmobile / Infiltration Group)】                 │
│      └─ 垂直離着陸機（VTOL）・ドローン群基幹。地形無視の強襲・後方遮断。     │
│                                                                             │
│  ⑥【海兵・水陸両用戦闘団 (Marine Amphibious Group)】                         │
│      └─ 水陸両用車台・メガフロート展開。海洋タイル・島嶼部・河川交差特化。  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
