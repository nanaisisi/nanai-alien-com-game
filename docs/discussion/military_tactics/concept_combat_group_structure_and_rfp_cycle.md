# 戦闘団スロット構造・RFP自動更新および現場改修仕様書

(Combat Group Slot Architecture, RFP-Driven Block Upgrade & Field Modification Dynamics)

本作（4X大戦略＋サブタイル戦術・戦闘団制）における**「戦闘団（Combat Group）の固定編成スロット構成」**、**「国家RFP（要求仕様方針）を受けた工廠の自動ブロック更新（Block I → Block II）」**、**「前線部隊によるボトムアップな現場改修（Field Mod）の発生・追認」**、および**「新旧混在・過渡期における整備・稼働率ペナルティ算出モデル」**を体系化した設計仕様書である。

---

## 1. 基本思想：固定スロットと自律的進化の共存

本作は、第二次世界大戦〜冷戦期・近未来の「増強師団・連隊戦闘団（Regimental Combat Team / Brigade Combat Team）」を1単位として大戦略マップ上で動かす。
プレイヤーに戦車のボルト締めや、小隊1台ずつの手動発注を行わせるのではなく、**「固定された組織スロット（TO&E）」**に対して、**「国家の要求仕様（RFP）に基づき国内工廠が自動で新型車両を開発・配備し、前線が実戦経験で独自改修を施す」**という自律サイクルを構築する。

### 2.1 間接火力スロットの現代的・近未来分業モデル（Slot 9 vs Slot 10）

現代戦（HIMARS/ATACMS/PrSMの戦訓）および対エイリアン戦における「旧来の無誘導ロケット砲の陳腐化」を踏まえ、間接火力群は明確に役割を分離する。

* **Slot 9: 自走野戦砲兵小隊 (SPG Platoon - 155C級等)**:
  * **役割**: 持続的・即応的な戦術火力支援。
  * **特性**: 1発あたりの弾薬輸送コストが比較的低く、前線歩兵・装甲部隊の要請に応じて常時面制圧・阻止射撃・発煙弾展開を行う「戦場のバックボーン」。
* **Slot 10: 戦術ミサイル・長距離誘導打撃小隊 (LRPF / Missile Launcher)**:
  * **役割**: 後方策源地、大型防空性ノード、敵司令部・巣穴深部を精密破壊する「戦略・作戦級精密打撃」。
  * **発射機の実態**: 固定砲身ではなく、**マルチ弾薬ポッド／TEL（Transporter Erector Launcher）**。搭載コンテナの換装により以下の弾薬を運用：
    * **Tier 1 (レガシー)**: 簡易多連装ロケット（面制圧、安価だが迎撃に弱い旧世紀遺物）。
    * **Tier 2 (現代水準 - GMLRS / ATACMS相当)**:
      * 単弾頭精密型（点目標・司令部破壊）。
      * **クラスター子弾型（DPICM / 面制圧）**: 対エイリアン大群・密集突撃に対する絶対的キルゾーン形成弾頭。平和時の軍縮条約（クラスター弾禁止条約等）は生存競争の前に即時形骸化・解禁される。
    * **Tier 3 (近未来実戦 - PrSM / スマート子弾・徘徊ドローン)**: 長射程高速ミサイル、**センサー信管付自己鍛造弾（BONUS/SMArt型スマート子弾）**、キャニスター射出型自律徘徊ドローン群（Loitering Munition Swarm）。不発弾（UXO）を残さないクリーンな面制圧へと進化。
    * **Tier 4 (SF/極限環境)**: 極超音速滑空弾（HGV）、対生体電磁EMP弾、高エネルギー貫徹キネティック弾頭。
  * **運用リスクと戦後禍**:
    * 弾薬1ポッドあたりの補給ウェイトが極めて重く、兵站ラインや輸送ウインドウを大きく圧迫する。
    * 旧世代クラスター弾を多用した場合、**タイル上に不発弾（UXO: Unexploded Ordnance）が残留**。自軍の追撃移動力低下や、戦後開拓・資源採掘時に工兵による「不発弾掃海（Clearing）」コストを強いる。
    * 対人間勢力戦で旧型クラスターを散布すると、国際世論・外交緊張度が激増する二重規範（対エイリアン解禁 ⇔ 対人間条約違反）が発生。

#### 機甲化戦闘団における運用ダイナミクス

1. **偵察の2重レイヤー構造**:
   * **連隊付装軌偵察（Slot 04）**: 主力戦車と足並みを揃え、泥濘・急斜面でもスタックせず敵前衛やエイリアン大型個体と直接撃ち合って視界をこじ開ける「威力偵察（Recon by Fire）」。
   * **師団装輪偵察2個大隊（Slot 13, 14）**: 師団直轄の独立した機動力として、舗装道路や平原地帯を高速進出。大戦略マップ上で先行して補給回廊・港湾・シーレーンへの連絡線を確保し、鈍重な装軌本隊を誘導する。
2. **装甲化歩兵連隊の絶対的必要性**:
   * 荒野の野戦では戦車の長射程火力が圧倒的だが、高Tier施設・都市部・坑道・森林・巣窟に突入した場合、戦車単体は死角からの奇襲で急速に損耗する。
   * Slot 05〜07 の装甲化歩兵大隊が「下車戦闘（Dismounted Operations）」を展開し、工兵大隊（Slot 08）が障害を啓開することで初めて突破が可能となる。
3. **部品共食い整備（Cannibalization）の互換性グループ**:
   * **装軌重装甲グループ（Slot 01〜10, 15）**: 同一車台（Std-T4等）を共有していれば、戦車・IFV・自走砲・ARV間で履帯ピン、転輪、エンジンブロックの部品流用成功率が 85% と極めて高くなる。
   * **装輪高機動グループ（Slot 13, 14, 16）**: 装軌のパーツは流用できないが、兵站トラック（Slot 16）や民間重機からタイヤ・サスペンション・燃料ポンプを高確率で共食い融通可能。

## 3. RFP駆動型ブロック更新（Block Upgrade Dynamics）

工廠は、プレイヤーが策定した「兵器クラス別RFP（防護/機動/火力スライダー・共通化拘束）」と、獲得済みの「技術（Tech Web）」を照合し、**一定周期または世代交代時に自動的に改良型（Block II / Block III）を設計・提案**する。

### 3.1 ブロック更新の発生フロー

1. **RFP乖離の検知**:
   * 現行配備車両（Block I）の性能値と、プレイヤーが設定した目標RFPとの乖離が閾値を超えた場合、工廠の研究部門が「新型改修案（Revision Plan）」を起工する。
2. **モジュール再編と金型転換試算**:
   * 新規獲得した葉技術（例: セラミック複合装甲、高初速電磁加速砲）を車台の許容ペイロード内で自動統合。
   * 共通化拘束（Family Constraint）に従い、主力戦車と歩兵戦闘車で共通のパワーパック・走行装置を維持するよう自動最適化。
3. **ブロック承認と生産切り替え**:
   * 工廠ラインが「Block II」へ転換開始（金型転換ラグ: 4〜8ターン）。

## 4. ボトムアップな現場改修（Field Modification / Field Mod）

過酷な実戦環境（高濃度ミズマ地帯、エイリアン大群の近接爪攻撃、敵の特定徹甲弾）に晒された戦闘団は、現場の整備兵と工兵小隊の創意工夫により**「非公式な現地改修キット」**を独自開発する。


### 4.1 国家指導者への追認申請UIイベント

現場改修が施された部隊が活躍すると、国家戦略画面（ステアリングUI）に**「現場改修の制式採用諮問（Field Mod Standardization Event）」**が通知される。

* **選択肢 A: 全軍標準仕様として制式化（Adopt as Official Block）**:
  * 改修内容を全工廠へフィードバックし、次期Blockの標準装備とする。
  * コスト: 金型転換費用、全軍への配備ラグ。
* **選択肢 B: 当該戦域・部隊限定の現地運用を追認（Authorize Local Use）**:
  * 他の戦域には展開せず、当該部隊のみで運用継続。兵站への悪影響を局所化。
* **選択肢 C: 軍規違反・整備規律違反として撤去命令（Disallow & Strip）**:
  * 即座に標準仕様へ戻す。共通化率と信頼性は回復するが、現場の士気低下。

## 5. 新旧混在・過渡期整備ペナルティ算出モデル

部隊が旧型（Block I）から新型（Block II）へ装備更新される際、一度に全車両が瞬時に置き換わることはない。補給梯団を通じて1小隊ずつ順次更新されるため、**「新旧混在期間（Transition Phase）」**が発生する。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                    過渡期稼働率ペナルティ (Readiness Loss)                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  実効稼働率 (Effective Readiness) =                                         │
│      基準稼働率 (Base: 95%)                                                 │
│      - [新旧混在度ペナルティ (Heterogeneity Penalty)]                       │
│      - [部品サプライチェーン未成熟ペナルティ (Supply Immaturity)]            │
│      + [共通化ドクトリン補正 (Commonality Bonus)]                           │
│                                                                             │
│  ※ 新旧混在度ペナルティ = 40% × (新型配備率) × (1.0 - 新型配備率)          │
│     （新型配備率が 50% の時に最大 -10% の稼働率低下が発生）                  │
│                                                                             │
│  ※ 部品サプライチェーン未成熟ペナルティ =                                    │
```

### 5.1 ゲームプレイ上の戦略的ジレンマ

* **安易な頻繁更新の罠**:
  * 技術が1つ開発されるたびにRFPを変更して新ブロックを投入すると、前線部隊は常に「新旧混在・部品不足」に喘ぎ、カタログスペックは高いが**実戦での稼働率（出撃可能数）が60%台に低迷**する。
* **計画的ロット更新の重要性**:
  * 数世代の技術をためてから一気に全軍一括転換するか、あるいは特定のエリート方面軍のみを実験部隊として先行更新し、サプライチェーンが成熟してから全軍展開するという、**現実の軍事調達と同様の戦略判断**が勝利の鍵となる。
