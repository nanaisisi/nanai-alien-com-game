# 空中機動・VTOL空地強襲師団 詳細編成・運用仕様書 (Airmobile Strike Division TO&E)

本ドキュメントは、[`concept_military_echelon_and_combat_groups.md`](../force_structure/concept_military_echelon_and_combat_groups.md) および [`concept_toe_feedback_and_cross_echelon_methodology.md`](../force_structure/concept_toe_feedback_and_cross_echelon_methodology.md) に基づき、地形制約を無視して電撃的な垂直突入・要衝急襲・後方遮断を遂行する**「空中機動・VTOL空地強襲師団（Airmobile Strike Division）」**の詳細な戦闘序列（TO&E）、兵科運用メカニクス、航空側翼スクリーン、FARP（前方給油再武装点）兵站ドクトリンを規定する個別仕様書である。

---

## 1. 空中機動師団の概要と戦略的位置づけ

- **部隊規模**: 総員 約14,000名、航空機 80機（重武装戦闘ヘリ/VTOL 32機、強襲戦術輸送ヘリ/VTOL 32機、ISR/EW機 16機）、空挺軽戦闘車両 約192両。
- **編成の核心思想**:
  - **地上重戦車を完全排除した超高機動空地統合軍**:
    - 大河川、断崖、山岳、大深度泥濘といった陸上装軌・装輪部隊が通行不能な地形を完全無視して一撃突入。
    - 師団直属の「強襲航空旅団（計64機: 1飛行隊8機×8個飛行隊）」による自前での近接航空支援（CAS）と全大隊の空挺空中機動を両立。
  - **航空警戒側翼スクリーン（地上装輪連隊の等価代替）**:
    - 地上装輪部隊が随伴できないため、側翼保護は「第1・第2航空警戒飛行隊（戦闘ヘリ8機＋戦術UAV 8機）」による長距離滞空索敵・警戒ラインで代替。
  - **空挺大隊付120C超軽量自走迫（16両）の集中運用**:
    - 空挺降下直後の脆弱性を補うため、各大隊長の手元に16門の120C自走迫（アルミニウム・チタン軽合金車台）を集中し、降下直後から濃密な曲射弾幕と煙幕スクリーンを自力展開。
  - **FARP（前方給油再武装点）先行空輸ドクトリン**:
    - 師団兵站群が突撃第1波と同時にFARP資材・燃料ブラダーを空輸展開し、作戦区域内での戦闘ヘリの滞空即応時間を極限まで延伸。

## 3. 兵站・共食い整備互換性グループ
