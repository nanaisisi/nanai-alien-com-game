# 常設増強師団（TO&E）バリエーション編成定義書

(Reinforced Division Order of Battle & TO&E Variants Definition)

本作における大戦略マップ上の1コマは、臨時混成の戦闘団ではなく、自己完結した国家正規軍の**「常設増強師団（Reinforced Division）」**である。
ゲーム的なスロット枠概念を排し、[`../force_structure/concept_military_echelon_and_combat_groups.md`](../force_structure/concept_military_echelon_and_combat_groups.md) で定義された**小隊（4両/機） ➔ 中隊（16両/機） ➔ 大隊（約48〜80両/機） ➔ 師団**という軍事エシュロン体系に基づき、各種作戦環境・ドクトリンに応じた具体的な戦闘序列（TO&E: Table of Organization and Equipment）を規定する。

※ 米軍式・師団直協航空連隊（ヘリ・VTOL・UAV計32機）の機体スペック・運用規則は [`../specs/AVIATION_ASSETS_AND_DOCTRINE.md`](../specs/AVIATION_ASSETS_AND_DOCTRINE.md) を参照。  
※ 二脚歩行戦闘車両の機体寸法・インフラ拒絶・空輸仕様は [`../specs/HIGH_TIER_BIPEDAL_COMBAT_WALKER.md`](../specs/HIGH_TIER_BIPEDAL_COMBAT_WALKER.md) を参照。  
※ 本部管理中隊（HHC: 通信・救護・整備・補給・工兵・迫撃砲）の基本構造と専門付加部隊は [`../force_structure/concept_headquarters_and_attached_units.md`](../force_structure/concept_headquarters_and_attached_units.md) を参照。

```text
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 4. 任務・ドクトリン別増強師団バリエーション

基本モデルを基点に、作戦目標や投入環境に応じて大隊・中隊構成が最適化される。

### 4.1 空中機動・VTOL空地強襲師団 (Airmobile Strike Division)

- **部隊規模**: 軽快空中強襲師団規模（総員 約12,000名、航空機 96機、軽装甲・空挺戦闘車両 約192両）
- **特徴**: 地上重戦車を排し、航空機動部隊と軽装歩兵のみで構成。山岳・大河・断崖などの通行不能地形を完全無視して突入・要衝確保を行う。
- **編成構成**:
  - `師団直轄 強襲航空旅団` (計64機: 8機×8個飛行隊):
    - `第1〜第4戦闘飛行隊`: 重武装VTOL・戦闘ヘリ（計32機: CAS・対地阻止）
    - `第5〜第8強襲輸送飛行隊`: 戦術強襲輸送ヘリ/VTOL（計32機: 空挺歩兵突入・重物資空輸）
  - `空中機動歩兵連隊` (2個連隊・計4個空挺歩兵大隊):
    - 各大隊が「軽IFV/空挺装甲車 32両 ＋ 空挺自走迫撃砲（120C超軽量自走迫）16両 ＝ 計48両」。
    - 垂直降下直後から大隊自前の即応曲射弾幕・煙幕スクリーンを展開可能。
  - `空挺特科・防空大隊`: 空挺自走ロケット砲 16両 ＋ 軽量自走複合SAM 16両
  - `航空ISR・電子戦隊`: 戦術UAV 8機 ＋ 成層圏中継・EW機 8機
  - `航空兵站群`: 前方給油再武装点（FARP）設営隊 ＋ 空中給油・軽資材補給梯団

### 4.2 無人自律・ドローン飽和特務師団 (Autonomous Drone Swarm Division)

- **部隊規模**: ドローン特務師団規模（総員 約6,000名、母車・UGV・支援車両 約384両、自律ドローン数千機）
- **特徴**: 有人兵員を極限まで減らし、ドローン母車（キャリア）と地上UGVを主軸とした前哨消耗部隊。人的損失による厭戦・政治ペナルティを発生させずに敵防衛線を削る。
- **編成構成**:
  - `自律地上突撃連隊` (2個UGV連隊・計4個大隊):
    - 各大隊が「無人装軌突撃UGV 32両 ＋ 無人重IFV 32両 ＋ 無人自走重迫（120C）16両 ＝ 計80両」。
    - 有人オペレーターを後方に置いたまま、2進数ペアで突撃・曲射支援を完全自動実行。
  - `自律FPV徘徊ドローン連隊` (母車2個大隊・計64両):
    - ドローン射出・誘導母車 64両（自律徘徊型FPV・キャニスター弾幕コンテナ搭載）。
  - `無人自走滑腔砲特科連隊`: 155C無人自動装填自走榴弾砲 32両 ＋ TEL誘導弾発射機 16両
  - `C4I戦術中継・サイバー電子戦大隊`: 長時滞空通信中継UAV 16機 ＋ 地上指向性EW車 16両
  - `自律回収・前線リサイクル整備大隊`: 自律重ARV 16両 ＋ モジュール自動換装ドック

### 4.3 重装甲要塞突破師団 (Heavy Armored Siege Division)

- **部隊規模**: 超重増強攻城師団規模（総員 約28,000名、戦闘・支援車両 約1,500両、直協機 32機）
- **特徴**: 敵主防衛線や高Tier要塞施設・大深度巨大巣穴を粉砕するための重厚長大編成。重戦車と超大口径砲、重戦闘工兵が二重に配置される。
- **編成構成**:
  - `第1〜第2重機甲連隊` (4個重戦車大隊: 計320両):
    - 超重戦車・重突撃砲 128両 ＋ 重IFV 128両 ＋ 120C自走重迫 64両。
  - `重装甲工兵・攻城歩兵連隊` (装甲工兵大隊×2 ＋ 攻城歩兵大隊×2: 計320両):
    - 重啓開工作車・超重架橋車 64両 ＋ 重IFV 64両 ＋ 装甲APC 64両 ＋ 120C自走重迫 64両。
  - `重攻城特科連隊`: 210C超重自走榴弾砲 32両 ＋ 大口径攻城TELミサイル 16両 ＋ 155C自走砲 32両
  - `師団複合高射連隊`: 35C複合機関砲 32両 ＋ 装軌式重SAM 32両（強固な防空アンブレラ）
  - `左右両翼偵察戦闘連隊` (各80両・計160両): 側面からの敵逆襲を機動遅滞・破砕
  - `師団直協航空連隊` (計32機: 戦闘16機＋輸送16機) ＋ `超重ARV整備連隊` (ARV 48両)

### 4.4 山岳猟兵・隘路工兵師団 (Mountain Jaeger & Combat Engineer Division)

- **部隊規模**: 軽快山岳師団規模（総員 約14,000名、軽戦闘車台・多脚機材 約320両/機）
- **特徴**:
  - 重装甲車両や大型機械が登攀不能な急峻山岳、断崖、亀裂地帯、森林隘路に特化した部隊。
  - **「山岳軽装歩兵（猟兵）の下車登攀」＋「強襲戦闘工兵による通路開拓・ワイヤー/足場架橋」＋「直協輸送ヘリ/VTOLによる補給・跳躍侵入」**を中核とする。
  - 多脚機材（Std-L4）は、師団全体ではなく「前衛自律斥候犬（UGV）」「工兵荷役機」「杭打ち固定式アンカー迫撃砲座」の特殊装備として配備される。
- **編成構成**:
  - `第1〜第2山岳猟兵連隊` (山岳猟兵4個大隊):
    - 各大隊が山岳軽装歩兵中隊 ＋ 軽高機動車 ＋ 60C携行迫撃班 ＋ 中隊中迫90C班。
  - `山岳強襲戦闘工兵大隊`: 岩盤爆破・足場架橋車 16両 ＋ 多脚荷役機（Std-L4）32機
  - `前衛斥候・山岳ISR大隊`: 小型4脚自律斥候UGV 64機 ＋ 狭隘地マイクロドローン中隊
  - `山岳砲兵連隊`: 山岳軽分解榴弾砲 24門 ＋ 固定アンカー式120C重迫撃砲座 24基
  - `師団直協山岳航空大隊`: 強襲輸送ヘリ 16機（山頂拠点確保・負傷兵MEDEVAC）
  - `山岳兵站段列`: ラバ型多脚荷役機（Std-L4）64機 ＋ 軽全地形車（ATV）輸送梯団

### 4.5 高級装甲・二脚歩行混成師団 (High-Tier Bipedal Assault Division)

- **部隊規模**: 精鋭増強師団規模（総員 約22,000名、二脚戦闘機 128機、装軌車両 約800両、直協機 32機）
- **特徴**:
  - ガングリフォン風の**装甲車風二脚歩行戦闘車両（全高3.76m以上、全幅5.48m以上、完全歩行駆動）**を、主力戦車や重IFVと小隊単位（4両）で組み合わせた混成中隊（16両）として配備。
  - 一般道路・トンネルを通行できないインフラ制約を抱えるため、大戦略展開には**大型戦略輸送機による空輸（飛行場展開）**、または専用重トランスポーター・海上揚陸が必要。
  - **通常歩行型**による廃墟・高低差での死角クリアリングと、**短時間飛翔型**による障害跳躍・要衝急襲が、戦車の正面突撃力を極限まで高める。
  - 詳細仕様は [`../specs/HIGH_TIER_BIPEDAL_COMBAT_WALKER.md`](../specs/HIGH_TIER_BIPEDAL_COMBAT_WALKER.md) を参照。

## 6. まとめとシステム実装ガイドライン

- **データ構造**: 増強師団エンティティは、所属する各大隊・直轄中隊・航空飛行隊のコレクション（`Vec<Battalion>` / `Vec<Company>`）を保持。
- **UI表示**: 編成画面では「大隊 ➔ 中隊 ➔ 小隊」のツリー型オーダ・オブ・バトルとして一覧表示。
- **航空隊の扱い**: 大戦略マップ上での航空コマ操作を不要とし、師団に所属する米軍式「直協戦闘航空連隊（32機）」「戦術UAV隊」により、戦闘解決システムが自動的にCAS（近接航空支援）や砲兵観測、緊急補給の修正値を適用する。
