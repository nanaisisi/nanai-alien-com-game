# 常設増強師団（TO&E）バリエーション編成定義書

(Reinforced Division Order of Battle & TO&E Variants Definition)

本作における大戦略マップ上の1コマは、臨時混成の戦闘団ではなく、自己完結した国家正規軍の**「常設増強師団（Reinforced Division）」**である。
ゲーム的なスロット枠概念を排し、[`../force_structure/concept_military_echelon_and_combat_groups.md`](../force_structure/concept_military_echelon_and_combat_groups.md) で定義された**小隊（4両/機） ➔ 中隊（16両/機） ➔ 大隊（約48〜80両/機） ➔ 師団**という軍事エシュロン体系に基づき、各種作戦環境・ドクトリンに応じた具体的な戦闘序列（TO&E: Table of Organization and Equipment）を規定する。

※ 米軍式・師団直協航空連隊（ヘリ・VTOL・UAV計32機）の機体スペック・運用規則は [`../specs/AVIATION_ASSETS_AND_DOCTRINE.md`](../specs/AVIATION_ASSETS_AND_DOCTRINE.md) を参照。  
※ 二脚歩行戦闘車両の機体寸法・インフラ拒絶・空輸仕様は [`../specs/HIGH_TIER_BIPEDAL_COMBAT_WALKER.md`](../specs/HIGH_TIER_BIPEDAL_COMBAT_WALKER.md) を参照。  
※ 本部管理中隊（HHC: 通信・救護・整備・補給・工兵・迫撃砲）の基本構造と専門付加部隊は [`../force_structure/concept_headquarters_and_attached_units.md`](../force_structure/concept_headquarters_and_attached_units.md) を参照。

## 1. 軍事部隊階層（Echelon）と編成基準

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                       軍事部隊単位（エシュロン）体系                        │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【小隊 (Platoon)】 ────── 4 両 / 機 (最小射撃・機動単位)                   │
│    ・2両バディ（セクション）× 2組。相互前進・援護監視の基本形。             │
│                                                                             │
│  【中隊 (Company)】 ────── 16 両 / 機 (4個小隊)                            │
│    ・単一兵科中隊、または諸兵科混成中隊（戦車＋歩行機＋随伴歩兵）。         │
│                                                                             │
│  【大隊 (Battalion)】 ──── 約 48 〜 80 両 / 機 (3〜4個中隊 ＋ 大隊迫撃中隊) │
│    ・諸兵科連合の最小完結単位（例: 2個戦車中隊 ＋ 2個歩兵戦闘車中隊 ＋ 迫撃）。│
│                                                                             │
│  【常設増強師団 (Reinforced Division)】 ─ 10,000〜25,000名 / 500〜1,300両＋32機│

│      左右両翼偵察戦闘連隊 ＋ 米軍式直協航空連隊（計32機） ＋ 師団兵站工兵群。│
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 4. 任務・ドクトリン別増強師団バリエーション個別仕様書

基本モデルを基点に、作戦目標や投入環境に応じて最適化された各常設増強師団の個別仕様書一覧。詳細なTO&E・戦闘序列は各個別ドキュメントを参照。

### 4.1 空中機動・VTOL空地強襲師団 (Airmobile Strike Division)

- **個別仕様書**: [`./toe_combat_group_airmobile.md`](./toe_combat_group_airmobile.md)
- **規模・特徴**: 総員 約14,000名、航空機 80機、空挺軽戦闘車両 約192両。地上重戦車を排し、航空機動部隊と軽装甲部隊で山岳・大河・断崖を完全無視して突入。
- **ドクトリン**: 航空側翼警戒飛行隊（戦闘ヘリ＋UAV）、大隊付120C超軽量自走迫（16両）、FARP先行展開。

### 4.2 無人自律・ドローン飽和特務師団 (Autonomous Drone Swarm Division)

- **個別仕様書**: [`./toe_combat_group_drone_swarm.md`](./toe_combat_group_drone_swarm.md)
- **規模・特徴**: 総員 約6,000名（有人オペレーター主体）、UGV・母車 約384両、徘徊ドローン数千機。人的損耗による政治ペナルティを発生させず濃密キルゾーンを突破。
- **ドクトリン**: 無人Std-T4車台共通化（成功率90%）、自律UGV突撃（消耗前提）と有人装甲歩兵（C4I確保・要塞化）の分業、FPV母車連隊（64両）空中スクリーン。

### 4.3 重装甲要塞突破師団 (Heavy Armored Siege Division)

- **個別仕様書**: [`./toe_combat_group_siege_division.md`](./toe_combat_group_siege_division.md)
- **規模・特徴**: 総員 約28,000名、戦闘・支援車両 約1,500両、直協機 32機。主防衛線・要塞都市・大深度巨大巣穴を正面破砕。
- **ドクトリン**: 超重機甲2連隊（突破）＋重装甲工兵・攻城歩兵2連隊（掃討・要塞化）の2-2均等構成、210C超重自走砲（32両）、左右両翼装輪スクリーン（160両）。

### 4.4 山岳猟兵・隘路工兵師団 (Mountain Jaeger & Combat Engineer Division)

- **個別仕様書**: [`./toe_combat_group_mountain_jaeger.md`](./toe_combat_group_mountain_jaeger.md)
- **規模・特徴**: 総員 約14,000名、軽戦闘車台・多脚機材 約320両/機、高高度輸送機 16機。車両通行不能な岩盤・断崖・森林隘路特化。
- **ドクトリン**: 下車登攀＋工兵通路開拓＋高高度空輸。迫撃砲多層分散（小隊60C/中隊90C/大隊120Cアンカー座）を例外承認。小型4脚斥候犬（UGV 64機）による稜線スクリーン。

### 4.5 高級装甲・二脚歩行混成師団 (High-Tier Bipedal Assault Division)

- **個別仕様書**: [`./toe_combat_group_bipedal_assault.md`](./toe_combat_group_bipedal_assault.md)
- **規模・特徴**: 総員 約22,000名、二脚戦闘機 128機、装軌車両 約800両、直協機 32機。ガングリフォン風完全歩行駆動二脚戦闘機を配備。
- **ドクトリン**: 戦車正面突撃と二脚（通常歩行＋短時間飛翔）の小隊混成、インフラ完全拒絶・大型輸送機空輸展開、左右両翼装輪スクリーン（160両）。

### 4.6 装輪高速機動師団 (Stryker / Wheeled Rapid Reaction Division)

- **個別仕様書**: [`./toe_combat_group_wheeled_reaction.md`](./toe_combat_group_wheeled_reaction.md)
- **規模・特徴**: 総員 約16,000名、8x8装輪装甲車台（Std-W8）約720両、直協機 32機。舗装動脈を利用した超高速自走展開（時速80〜100km）。
- **ドクトリン**: 全車同一車台ファミリー（共通化率95%、共食い成功率90%）、装輪機動打撃2連隊（105C/25C）＋装輪装甲歩兵2連隊（IFV/APC）の2-2均等構成。

### 4.7 地域配備・警備師団 (Regional Defense & Security Division)

- **個別仕様書**: [`./toe_combat_group_regional_defense.md`](./toe_combat_group_regional_defense.md)
- **規模・特徴**: 総員 約10,000〜12,000名、軽装甲車・旧式APC 約300両、汎用連絡ヘリ 8機。担当管区（2〜4親タイル）に常駐。
- **ドクトリン**: 現地インフラ自活による超低維持費、主力転地時の留守警備（防衛空白化の防止）、旧式車両・牽引式120C重迫撃砲（大隊16門）とトーチカ複合防御。

## 6. まとめとシステム実装ガイドライン

- **データ構造**: 増強師団エンティティは、所属する各大隊・直轄中隊・航空飛行隊のコレクション（`Vec<Battalion>` / `Vec<Company>`）を保持。
- **UI表示**: 編成画面では「大隊 ➔ 中隊 ➔ 小隊」のツリー型オーダ・オブ・バトルとして一覧表示。
- **航空隊の扱い**: 大戦略マップ上での航空コマ操作を不要とし、師団に所属する米軍式「直協戦闘航空連隊（32機）」「戦術UAV隊」により、戦闘解決システムが自動的にCAS（近接航空支援）や砲兵観測、緊急補給の修正値を適用する。
