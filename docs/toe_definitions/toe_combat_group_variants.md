# 諸兵科連合戦闘団（TO&E）バリエーション編成定義書

(Combat Group Order of Battle & TO&E Variants Definition)

本作における戦闘団（Combat Group）は、大戦略マップ上の1コマとして自己完結した諸兵科連合部隊（増強師団／諸兵科連合旅団規模）である。
ゲーム的なスロット枠概念を排し、[`../force_structure/concept_military_echelon_and_combat_groups.md`](../force_structure/concept_military_echelon_and_combat_groups.md) で定義された**小隊（4両/機） ➔ 中隊（16両/機） ➔ 大隊（約48〜64両/機） ➔ 師団・戦闘団**という軍事エシュロン体系に基づき、各種作戦環境・ドクトリンに応じた具体的な戦闘序列（TO&E: Table of Organization and Equipment）を規定する。

※ 師団直協航空機（ヘリ・VTOL）の機体スペック・運用規則は [`../specs/AVIATION_ASSETS_AND_DOCTRINE.md`](../specs/AVIATION_ASSETS_AND_DOCTRINE.md) を参照。  
※ 二脚歩行戦闘車両の機体寸法・インフラ拒絶・空輸仕様は [`../specs/HIGH_TIER_BIPEDAL_COMBAT_WALKER.md`](../specs/HIGH_TIER_BIPEDAL_COMBAT_WALKER.md) を参照。  
※ 本部管理中隊（HHC: 通信・救護・整備・補給・工兵・迫撃砲）の基本構造と専門付加部隊は [`../force_structure/concept_headquarters_and_attached_units.md`](../force_structure/concept_headquarters_and_attached_units.md) を参照。

## 1. 軍事部隊階層（Echelon）と編成基準

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                       軍事部隊単位（エシュロン）体系                        │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【小隊 (Platoon)】 ────── 4 両 / 機 (最小射撃・機動単位)                   │
│    ・2両バディ（セクション）× 2組。相互前進・援護監視の基本形。             │
│                                                                             │
│  【中隊 (Company)】 ────── 16 両 / 機 (4個小隊)                            │
│    ・単一兵科中隊、または諸兵科混成中隊（戦車＋歩行機＋随伴歩兵）。         │
│                                                                             │
│  【大隊 (Battalion)】 ──── 約 48 〜 64 両 / 機 (3〜4個中隊)                 │
│    ・諸兵科連合の最小完結単位（例: 2個戦車中隊 ＋ 2個歩兵戦闘車［IFV］中隊）。│
│                                                                             │
│  【戦闘団 (Combat Group)】 ─ 10,000〜15,000名 / 500〜700両・機              │
│    ・大戦略マップ上の1コマ。基幹大隊群 ＋ 特科・防空・直協航空・兵站連隊。   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 4. 任務・ドクトリン別戦闘団バリエーション

基本モデルを基点に、作戦目標や投入環境に応じて大隊・中隊構成が最適化される。

### 4.1 空中機動・VTOL空地強襲戦闘団 (Airmobile Strike Group)

- **部隊規模**: 諸兵科連合旅団〜軽師団規模（軽量・高機動力）
- **特徴**: 地上重戦車を排し、航空機動部隊と軽装歩兵のみで構成。山岳・大河・断崖などの通行不能地形を完全無視して突入・要衝確保を行う。
- **編成構成**:
  - `第1〜第2戦闘ヘリ大隊`: 武装VTOL・戦闘ヘリ（計32機）
  - `強襲空中輸送大隊`: 重輸送ヘリ（空挺軽歩兵・軽物資投下）
  - `空中機動歩兵連隊`: 軽装甲歩兵 2個大隊
  - `空挺支援特科隊`: 軽自走迫撃砲・空挺ロケット大隊
  - `航空偵察・防空隊`: 戦術UAV隊 ＋ 自律対空ドローン隊
  - `航空兵站群`: 空中給油・軽資材補給梯団

### 4.2 無人自律・ドローン飽和戦闘団 (Autonomous Drone Swarm Group)

- **部隊規模**: 特務旅団規模
- **特徴**: 有人兵員を極限まで減らし、ドローン母車（キャリア）と地上UGVを主軸とした前哨消耗部隊。人的損失による厭戦・政治ペナルティを発生させずに敵防衛線を削る。
- **編成構成**:
  - `地上突撃UGV連隊`: 無人装軌戦闘大隊 × 2
  - `自律FPV徘徊ドローン連隊`: ドローン母車大隊 × 2
  - `無人自走滑腔砲大隊`: 遠隔射撃支援特科
  - `C4I戦術中継UAV大隊`: 電子戦・通信中継隊
  - `前線リサイクル整備隊`: 自律回収工作小隊 ＋ 電池・推進剤補給梯団

### 4.3 重装甲要塞突破戦闘団 (Heavy Armored Siege Group)

- **部隊規模**: 重増強方面軍・攻城軍団規模
- **特徴**: 敵主防衛線や高Tier要塞施設を粉砕するための重厚長大編成。重戦車と超大口径砲、重戦闘工兵が二重に配置される。
- **編成構成**:
  - `第1〜第2重機甲連隊`: 主力戦車・超重突撃砲 4個大隊
  - `重装甲歩兵・工兵連隊`: 重IFV歩兵 2個大隊 ＋ 重戦闘工兵 2個大隊
  - `重攻城特科連隊`: 210C重榴弾砲大隊 ＋ 攻城ロケット特科大隊
  - `重防空大隊`: 師団直轄複合防空 2個大隊（高高度＋近接迎撃）
  - `重兵站梯団`: 重ARV大隊 ＋ 二重補給連隊

### 4.4 山岳猟兵・隘路工兵戦闘団 (Mountain Jaeger & Combat Engineer Group)

- **部隊規模**: 軽快山岳旅団規模
- **特徴**:
  - 重装甲車両や大型機械が登攀不能な急峻山岳、断崖、亀裂地帯、森林隘路に特化した部隊。
  - **「山岳軽装歩兵（猟兵）の下車登攀」＋「強襲戦闘工兵による通路開拓・ワイヤー/足場架橋」＋「直協輸送ヘリ/VTOLによる補給・跳躍侵入」**を中核とする。
  - 多脚機材（Std-L4）は、師団全体ではなく「前衛自律斥候犬（UGV）」「工兵荷役機」「杭打ち固定式アンカー迫撃砲座」の特殊装備として配備される。
- **編成構成**:
  - `山岳猟兵連隊`: 山岳軽歩兵 2個大隊（急斜面登攀・隘路潜伏・携帯ミサイル）
  - `山岳戦闘工兵大隊`: 障害啓開、岩盤爆破、足場・ワイヤー架橋、多脚荷役機
  - `前衛斥候小隊`: 小型4脚UGV犬群 ＋ 狭隘地マイクロドローン
  - `山岳直協ヘリ隊`: 強襲輸送ヘリ 1個中隊（山頂拠点確保・負傷兵搬送）
  - `山岳分解砲兵隊`: 山岳軽榴弾砲 ＋ 固定アンカー重迫撃砲
  - `山岳兵站段列`: ラバ型多脚荷役機 ＋ 軽全地形車輸送隊

### 4.5 高級装甲・二脚歩行混成戦闘団 (High-Tier Bipedal Assault Group)

- **部隊規模**: 精鋭増強師団規模
- **特徴**:
  - ガングリフォン風の**装甲車風二脚歩行戦闘車両（全高3.76m以上、全幅5.48m以上、完全歩行駆動）**を、主力戦車や重IFVと小隊単位（4両）で組み合わせた混成中隊（16両）として配備。
  - 一般道路・トンネルを通行できないインフラ制約を抱えるため、大戦略展開には**大型戦略輸送機による空輸（飛行場展開）**、または専用重トランスポーター・海上揚陸が必要。
  - **通常歩行型**による廃墟・高低差での死角クリアリングと、**短時間飛翔型**による障害跳躍・要衝急襲が、戦車の正面突撃力を極限まで高める。
  - 詳細仕様は [`../specs/HIGH_TIER_BIPEDAL_COMBAT_WALKER.md`](../specs/HIGH_TIER_BIPEDAL_COMBAT_WALKER.md) を参照。
- **編成構成**:
  - `第1混成機甲大隊`: 主力戦車 2個中隊 ＋ 通常二脚歩行 2個中隊
  - `第2混成機甲大隊`: 短時間飛翔二脚 2個中隊 ＋ 重IFV随伴歩兵 2個中隊
  - `自走特科・アンカー砲兵大隊`: 155C自走砲 ＋ 二脚アンカー重迫撃砲
  - `師団複合防空大隊` ＋ `直協戦闘ヘリ隊` ＋ `戦術UAV観測隊`
  - `重回収整備・航空補給連隊`: 大型クレーンARV ＋ 航空推進剤補給梯団

## 5. 兵站・共食い整備（Cannibalization）の互換性グループ

装備更新・現場整備は、以下の車台・機体規格ごとにグループ化して計算される。

| 互換性グループ | 主な兵器種別 | 共通化率目安 | 共食い成功率 | 特記事項 |
| :--- | :--- | :---: | :---: | :--- |
| **装軌重装甲系** | 戦車、自走砲、重IFV、重ARV | 70〜85% | **85%** | 重油圧・履帯・装甲板の相互融通 |
| **装輪高機動系** | APC、偵察車、トラック、指揮車 | 80〜95% | **80%** | 民間・産業規格部品との互換性が高い |
| **二脚歩行系** | 二脚通常歩行機、短時間飛翔機 | 75〜90% | **80%** | 油圧脚部アクチュエータ、クローフット |
| **回転翼・航空推進系** | 戦闘ヘリ、強襲輸送VTOL、跳躍ブースター | 60〜75% | **70%** | 高度航空タービン・ローター・ノズル |
| **自律電子・無人系** | 戦術UAV、自律UGV、ドローン母車 | 85〜95% | **90%** | モジュール化電子基板、センサ、小型ローター |
| **特殊支援（多脚・工兵）** | 工兵多脚、荷役機、アンカー砲台 | 65〜80% | **75%** | 関節アクチュエータ、油圧杭、ウインチ機構 |

## 6. まとめとシステム実装ガイドライン

- **データ構造**: 戦闘団エンティティは、所属する大隊・直轄中隊のコレクション（`Vec<Battalion>` / `Vec<Company>`）を保持。
- **UI表示**: 編成画面では「大隊 ➔ 中隊 ➔ 小隊」のツリー型オーダ・オブ・バトルとして一覧表示。
- **航空隊の扱い**: 大戦略マップ上での航空コマ操作を不要とし、戦闘団に所属する「直協戦闘航空中隊」「戦術UAV隊」により、戦闘解決システムが自動的にCAS（近接航空支援）や砲兵観測の修正値を適用する。
