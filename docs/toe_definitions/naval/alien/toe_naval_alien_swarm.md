# 野生・固有エイリアン海洋群 編制・生態仕様書 (Native Naval Alien Swarm TO&E)

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../GAME_DESIGN.md) のセクション 3.2.2 に基づき、人類海上戦闘団（艦隊）と完全に一致する兵種体系を持つ**「野生・固有エイリアン海洋群（エイリアン艦隊）」**の編制体系および生体構成を規定する仕様書である。凝った独自設定ではなく、人類艦隊の各兵種に対応した生体海洋群として定義される。

---

## 1. 組織思想（人類艦隊との完全一致）

野生エイリアン海洋群は、人類正規艦隊の各兵種カテゴリーと1対1で完全に一致する機能・規模を持つ。

| 人類艦隊種別 | エイリアン艦隊種別 | 主な役割・戦闘特性 |
| :--- | :--- | :--- |
| **哨戒艦隊** | **エイリアン哨戒艦隊** | 哨戒・近海警戒・索敵に特化した俊敏な海洋生体群 |
| **護衛艦隊** | **エイリアン護衛艦隊** | 防空・対潜水生体への迎撃と遊泳群護衛を担当 |
| **通常艦隊** | **エイリアン通常艦隊** | 外洋での水上打撃・制海権確保を担当する汎用海洋群 |
| **戦艦艦隊** | **エイリアン戦艦艦隊** | 超重装甲と長距離生体砲撃・沿岸破壊を担当する決戦海洋群 |
| **航空艦隊** | **エイリアン航空艦隊** | 飛行型エイリアンを背部で多数輸送・発進させる海洋生体群 |
| **潜水艦隊** | **エイリアン潜水艦隊** | 深海に潜航し、高い隠密性から奇襲雷撃を行う生体潜水群 |

## 2. カテゴリー別詳細編制序列 (TO&E)

### 2.1 エイリアン哨戒艦隊 (Alien Patrol Fleet)

- **役割**: 人類哨戒艦隊と一致。沿岸監視、領海警戒、高速索敵を担当。
- **イメージ・構成**:
  - **小型刺胞遊泳個体**: 群れをなして表層を泳ぎ、敵艦艇や侵入者を早期探知。
  - **高速遊泳魚雷獣**: コルベット艇に匹敵する速度で突進し体当たり自爆・強酸放出。
  - **表層監視種**: 水面から触角を突き出し広域の電波・音波を監視。

### 2.2 エイリアン護衛艦隊 (Alien Escort Fleet)

- **役割**: 人類護衛艦隊と一致。対空・対潜水生体迎撃、大型海洋生物の遊泳路防衛を担当。
- **イメージ・構成**:
  - **棘皮防空個体**: 接近する対艦ミサイルや航空機に対して高圧生体棘を斉射迎撃。
  - **超音波迎撃種**: パルス超音波により海中の魚雷や潜水艦を攪乱・無力化。
  - **中型護衛甲殻獣**: フリゲート艦相当の防護力を持ち、本隊への攻撃を身代わりとなって阻止。

### 2.3 エイリアン通常艦隊 (Alien Regular Fleet)

- **役割**: 人類通常艦隊（駆逐艦・巡洋艦基幹）と一致。外洋における制海権確保と水上打撃。
- **イメージ・構成**:
  - **中型重装甲甲殻獣**: 駆逐艦サイズの強固な甲殻を持ち、正面砲戦・突撃を展開。
  - **強酸投射種**: 長射程の有機強酸弾を連続発射し、敵艦の上部構造物を破壊。
  - **生体魚雷射出種**: 体内で誘導生体魚雷を生成・連続射出。

### 2.4 エイリアン戦艦艦隊 (Alien Battleship Fleet)

- **役割**: 人類戦艦艦隊と一致。超重装甲と長距離大口径生体砲撃による決戦打撃および沿岸砲撃。
- **イメージ・構成**:
  - **超大型甲殻巨獣（リヴァイアサン級）**: 全長200m超。軍艦の大口径砲撃にも耐える超重装甲。
  - **重キャビテーション衝撃砲種**: 口部から超高圧キャビテーション衝撃波を放ち、水上艦を一撃で両断。
  - **共生迎撃群**: 巨獣の体表に生息し、飛来するミサイル・爆弾を迎撃する寄生個体群。

### 2.5 エイリアン航空艦隊 (Alien Carrier Fleet)

- **役割**: 人類航空艦隊（空母・強襲揚陸艦基幹）と一致。洋上から飛行エイリアン群を大量発進させる生体航空拠点。
- **イメージ・構成**:
  - **浮遊母艦生体（バイオキャリア）**: 水面を浮遊する巨大な平坦背部を持ち、数十頭の飛行種を収容・補給。
  - **艦載小型飛行種**: 母艦から一斉に飛び立ち、制空権確保および対艦急降下攻撃を実施。
  - **警戒生体**: 母艦の周囲を旋回し、早期警戒（AEW）を担当。

### 2.6 エイリアン潜水艦隊 (Alien Submarine Fleet)

- **役割**: 人類潜水艦隊と一致。深海での高度な隠密行動、索敵網の突破、奇襲雷撃。
- **イメージ・構成**:
  - **深海潜航巨獣**: 超深海の水圧に耐え、熱・音響シグネチャを極小化して潜航。
  - **超音波共鳴種**: ソナーに映らない生体周波数で群れと通信。
  - **誘導生体魚雷放出種**: 敵スクリュー音を追尾する自律生体魚雷を海中から射出。
