# エイリアン護衛艦隊 詳細編成・生態仕様書 (Alien Escort Fleet TO&E)

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../GAME_DESIGN.md) のセクション 3.2.2 に基づき、海洋生体群の防空・対潜水生体迎撃および遊泳路防衛を担当する野生エイリアンの守備海洋群**「エイリアン護衛艦隊（Alien Escort Fleet）」**の編制体系、個体生態、および迎撃規則を規定する個別仕様書である。人類の「護衛艦隊」と1対1で一致する。

---

## 1. 概要と生態ドクトリン

- **部隊規模**: 中型護衛甲殻獣 数十頭 ＋ 棘皮防空個体・超音波迎撃種 数百頭。
- **作戦上の位置づけ**:
  - 人類護衛艦隊と完全一致。防空・対潜水生体への迎撃と遊泳群護衛を担当。
  - 大型海洋生物（リヴァイアサン級）や繁殖巣穴へのアクセス路を外敵（敵航空機や潜水艦）から防護する。
- **防空・防潜の特化生態**:
  - 上空からの対地攻撃機・対潜哨戒機に対し、海面から高圧生体棘を斉射して迎撃。
  - 海中では高出力パルス超音波を発振し、魚雷の誘導装置や敵潜水艦の音響ソナーを攪乱。

## 3. 構成個体スペックと戦闘メカニクス

### 3.1 中型護衛甲殻獣 (Medium Escort Crustacean)

- **体格**: フリゲート艦相当（全長30〜50m、重量2,000〜4,000トン級）。
- **特徴**: カメや甲殻類に似た重層甲殻を持ち、友軍の背後に回って身代わりとなり砲撃・魚雷を遮断。

### 3.2 棘皮防空個体 (Sea-Urchin AA Beast)

- **体格**: ウニ状・フジツボ状の生体個体（全長3〜5m）。
- **兵装**: **高圧生体棘（対空棘弾）**。
- **役割**: 海面近くを浮遊し、上空を飛行する戦闘機・対潜ヘリ・ミサイルに向けて無数の硬質棘を高圧ガスで斉射、近接信管で空中炸裂させて迎撃する。

### 3.3 超音波迎撃種 (Acoustic Jammer Beast)

- **役割**: クジラやイルカの生体音響器官を巨大化させた個体。水中魚雷の音響シーカーを狂わせ、友軍に命中させず逸らす。

## 4. 作戦特性・運用ルール

1. **防空・防潜スクリーンの展開**:
   - 空母艦載機や潜水艦による奇襲攻撃に対して高い迎撃・攪乱ボーナスを発揮。
2. **水上正面打撃力の限界**:
   - 戦艦や大型駆逐艦のレールガン砲撃に対しては決定的な反撃手段を持たず、防戦一方となる。
