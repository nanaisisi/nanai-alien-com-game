# 航空艦隊 詳細編成・運用仕様書 (Carrier Strike Fleet TO&E)

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../GAME_DESIGN.md) のセクション 3.2.1 に基づき、大型正規空母2隻と艦載機128機を中核とする人類正規海軍の洋上航空決戦部隊**「航空艦隊（Carrier Strike Fleet）」**の編制序列（TO&E）、艦艇スペック、内部2進数制エシュロン、および作戦規則を規定する個別仕様書である。

---

## 1. 概要と戦略的位置づけ

- **艦隊規模**: 計62隻 ＋ 艦載機128機、総員 約16,000名（航空要員含む）。
- **作戦上の位置づけ**:
  - 洋上航空打撃のコア。大戦略マップ上で2タイル先への広域制空・航空阻止・爆撃を実行可能。
  - 敵前上陸作戦時には圧倒的な近接航空支援（CAS）と防空アンブレラを提供。
- **内部2進数（2の累乗）共通階層構造**:
  - 大型正規空母 2隻 ＋ 防空駆逐艦 4隻 ＋ 汎用駆逐艦 8隻 ＋ 汎用フリゲート 16隻 ＋ 護衛コルベット 32隻。

## 3. 作戦・戦術メカニクス

1. **大戦略2タイル先への広域制空・航空阻止**:
   - 128機の艦載機（戦闘機64機、早期警戒機32機、対潜機32機）により、遠隔タイルへの先制航空阻止および陸上軍団の直協援護を展開。
2. **多重レイヤーの空母防衛網**:
   - 防空駆逐艦の長距離SAM、フリゲートの対潜網、前衛32隻の近接戦闘艦が空母2隻を全周包囲し、極めて高い残存性を誇る。
3. **高コストと母港インフラ依存**:
   - 人類海軍において最も膨大な維持費と弾薬・航空燃料を消費するため、補給線の維持が極めて重要。
