# 通常海上戦闘団（人類通常艦隊）詳細編成・運用仕様書 (Regular Naval Fleets TO&E)

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../GAME_DESIGN.md) のセクション 3.2.1 に基づき、海洋・沿海域タイルの制海権確保、通商護衛、沿岸火力支援、および大深度潜水作戦を担う人類正規軍の**「通常海上戦闘団（Regular Naval Fleets）」**全8種の編制序列、艦艇スペック、および作戦規則を規定する仕様書である。

---

## 1. 海上戦闘団の基本エシュロン思想

- **大戦略1コマの規模**: 旗艦を中心に、駆逐艦・フリゲート・潜水艦・補給支援艦など**約16〜32隻の艦艇グループ**により構成される独立戦闘艦隊（Fleet）。
- **沿岸射撃能力**:
  - 戦艦艦隊、通常艦隊等の大口径艦砲・対地ミサイル搭載艦は、**沿海タイルから隣接陸上タイルへの長距離艦砲射撃・対地打撃支援**を行う能力を持つ。

---

## 2. 全8カテゴリーの通常艦隊編成仕様

| 艦隊種別 | 主な役割・特徴 | 構成艦艇イメージ |
| :--- | :--- | :--- |
| **民間船艦隊** | 海上物資輸送・資源搬送・植民入植者輸送 | 大型貨物輸送船、小型連絡船、コンテナタンカー |
| **武装船艦隊** | 軽火器・対空機銃を装備した武装商船団 | 武装貨物船、武装沿岸艇、自衛警備船 |
| **哨戒艦隊** | 領海内監視、海賊・野生海洋エイリアンへの哨戒 | 哨戒コルベット艦（8〜16隻）、対潜哨戒ヘリ、高速ミサイル艇 |
| **護衛艦隊** | 対潜・防空に特化した海上輸送路（シーレーン）護衛 | 護衛フリゲート（8〜12隻）、汎用駆逐艦（4隻）、艦載対潜ヘリ |
| **通常艦隊** | 制海権確保・敵水上部隊撃滅を担う外洋主力戦闘艦隊 | 迎撃防空駆逐艦（4〜8隻）、汎用駆逐艦（8隻）、護衛フリゲート |
| **戦艦艦隊** | 超重装甲と超大口径長距離巨砲による決戦艦隊。強力な沿岸砲撃力 | 超弩級戦艦（2〜4隻）、防空駆逐艦（8隻）、汎用駆逐艦、護衛艦 |
| **航空艦隊** | 洋上航空拠点。艦載機による広域制空・大深度航空爆撃 | 大型正規空母 / 軽空母（2〜4隻）、強襲揚陸艦、艦載戦闘機隊、早期警戒機、直衛駆逐艦 |
| **潜水艦隊** | 極めて高い隠蔽性を持ち、敵水上艦の奇襲撃沈・対地巡航ミサイル発射を担当 | 攻撃型原子力潜水艦（4〜8隻）、巡航ミサイル潜水艦（SSGN） |

## 3. 作戦メカニクス

1. **陸上部隊との相互作用**:
   - 沿岸都市や地上戦闘団に対する艦砲射撃支援（火力ボーナス付与）。
   - 航空艦隊・強襲揚陸艦による海兵部隊・陸上軍団の海上輸送と強襲揚陸作戦。
2. **潜航とソナー探知**:
   - 潜水艦隊は「潜航状態」により敵艦隊のレーダーから不可視となり、対潜哨戒アセット（哨戒機・対潜ヘリ・ソナー艦）を持たない敵に対して一方的奇襲が可能。
