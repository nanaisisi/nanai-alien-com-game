# 融合生物海上戦闘団 詳細編成・運用仕様書 (Fusion Bio-Mechanical Naval Fleets TO&E)

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../GAME_DESIGN.md) のセクション 3.2.4 および 4 に基づき、人類の造船工学・推進プラントと同盟海棲エイリアンの生体組織・耐圧深海甲殻を遺伝子レベルで融合させた次世代海洋決戦部隊**「融合生物艦隊（Fusion Bio-Mechanical Fleet）」**の編制仕様、生体装甲艦艇、および生体魚雷射出システムを規定する仕様書である。

---

## 1. 融合艦艇の技術アーキテクチャ

- **有機装甲船体（Living Hull）**:
  - 特殊高張力鋼と生体甲殻の分子結合フレームにより、魚雷や対艦ミサイルによる被弾亀裂が急速に自己増殖・閉塞。沈没耐性が極めて高い。
- **無音生体推進（Hydro-Dynamic Undulation）**:
  - スクリューキャビテーションを発生させず、巨大な尾鰭・側鰭の有機的波動運動によって水中・水上を航行。パッシブソナー探知をほぼ完全に無力化。

## 2. 融合艦隊の戦闘序列 (TO&E)

| 艦種・構成 | 主な役割・特徴 | 融合兵装・推進 |
| :--- | :--- | :--- |
| **生体装甲フリゲート** | 前方警戒・高速迎撃・哨戒 | 自己修復キチン装甲、生体パルス放電砲、有機無音フィン |
| **有機潜航駆逐艦** | 水上・潜航の双方を自在に移行するハイブリッド駆逐艦 | 耐圧生体肺、生体魚雷射出管（誘導刺胞魚雷×16門）、電磁レールガン |
| **生体魚雷射出巡洋艦** | 洋上・海中からの飽和ミサイル・魚雷投射 | 超大型生体キャニスター、生体巡航ミサイル（自己推進・自律目標識別） |
| **有機母艦（バイオキャリア）** | 生体航空機・小型遊泳種の母艦 | 生体カタパルト、飛行飛翔獣・生体ドローン発着甲板、急速自己増殖ドック |

## 3. 作戦ドクトリン

- **潜航・浮上のシームレス移行**:
  - 水上艦艇でありながら、敵の航空爆撃や対艦ミサイル接近時に急速潜航を行い、攻撃を完全回避。
- **沿岸浸透と陸上攻撃**:
  - 浅瀬や毒性湿地帯を這い上がって沿岸要塞を直接強襲する両生類的な上陸打撃能力を保有。
