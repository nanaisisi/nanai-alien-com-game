# 高級装甲・二脚歩行混成師団 詳細編成・運用仕様書 (High-Tier Bipedal Assault Division TO&E)

本ドキュメントは、[`concept_military_echelon_and_combat_groups.md`](../force_structure/concept_military_echelon_and_combat_groups.md)、[`concept_toe_feedback_and_cross_echelon_methodology.md`](../force_structure/concept_toe_feedback_and_cross_echelon_methodology.md)、および [`HIGH_TIER_BIPEDAL_COMBAT_WALKER.md`](../specs/HIGH_TIER_BIPEDAL_COMBAT_WALKER.md) に基づき、装甲車風二脚歩行戦闘車両を主力戦車や重IFVと有機的に結合させた精鋭打撃部隊**「高級装甲・二脚歩行混成師団（High-Tier Bipedal Assault Division）」**の詳細な戦闘序列（TO&E）、兵科協同メカニクス、インフラ制約、および空輸・兵站二系統ドクトリンを規定する個別仕様書である。

## 1. 二脚歩行混成師団の概要と戦略的位置づけ

- **部隊規模**: 総員 約22,000名、二脚歩行戦闘機 128機、装軌車両 約800両、直協航空機 32機。
- **編成の核心思想**:
  - **装甲車風二脚歩行戦闘機と戦車の小隊混成（協同突破）**:
    - ガングリフォン風の完全歩行駆動二脚戦闘機（通常型＋短時間飛翔型）を配備。
    - 通常歩行型が廃墟・段差・瓦礫の死角を掃討し、短時間飛翔型（30〜60秒ジャンプ）が障害物を飛び越えて敵砲兵・司令部を奇襲。戦車の正面装甲突撃と組み合わさり絶対的突破力を生む。
  - **インフラ完全拒絶と戦略空輸ドクトリン**:
    - 二脚機体は一般道路・橋梁・トンネルを破壊するため、長距離展開には「大型戦略輸送機による飛行場空輸」または「専用重トランスポーター車列・海上揚陸」を必須とする。
  - **兵站・車体二系統化の管理（プラットフォーム共通化）**:
    - 二脚機体同士で脚部アクチュエータ・推進アビオニクスを80%共通化。
    - 随伴車両（IFV/自走迫/支援車）は装軌系Std-T4で統一し、現場整備班の混乱を極限まで抑制。
  - **左右両翼偵察戦闘連隊（計160両）による外側スクリーン**:
    - 二脚機体の短い航続距離と道路不適性を補うため、外側を左右の装輪偵察連隊（各80両）が囲み、側翼と後方動脈を警戒・遅滞防衛。
