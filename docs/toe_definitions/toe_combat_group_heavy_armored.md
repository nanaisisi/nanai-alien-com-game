# 増強機甲戦闘団 詳細編成・運用仕様書 (Heavy Armored Combat Group TO&E)

本ドキュメントは、[`concept_military_echelon_and_combat_groups.md`](../force_structure/concept_military_echelon_and_combat_groups.md) で定義された戦闘団タイプのうち、**「増強機甲戦闘団（Heavy Armored Combat Group / 4連隊・戦車128両＋随伴歩兵128両基幹）」**の詳細な部隊編成（TO&E）、兵科分担、偵察運用、および兵站・共食い整備ダイナミクスを規定する個別仕様書である。

---

## 1. 増強機甲戦闘団の概要と戦略的位置づけ

- **部隊規模**: 総員 約12,000名、戦闘・支援車両 約600両（うち主力戦車 128両、随伴重IFV 128両、直協航空機 32機）。
- **作戦特性**:
  - 開けた平原地帯、乾燥平原、幹線舗装動脈における圧倒的打撃力と突破力。
  - 敵の防衛線・重装甲部隊・エイリアン大型突撃個体を正面から粉砕する「戦略打撃の中核」。
  - 戦車と随伴重IFV歩兵が1:1同数ペアで行動し、戦車の死角奇襲を随伴歩兵が徹底カバー。
- **兵站負荷**:
  - 師団全体の重量が極めて重く、燃料・重砲弾（155C/120C）・航空推進剤の消費が激しい。
  - 高Tier補給デポまたは鉄道網・パイプラインとのインフラ結合度が低下すると急速に継戦能力が落ちる。

## 3. 兵科運用の詳細メカニクス

### 3.1 偵察の2重レイヤー構造（威力偵察 vs 広域高速偵察）

1. **連隊付装軌威力偵察隊（第4機甲大隊）**:
   - **車台**: 装軌クローラー（Std-T4系重偵察戦闘車 / 軽戦車）。
   - **戦術任務**: 戦車本隊の直前を進発し、敵の伏兵陣地やエイリアン大型個体と直接交戦（Recon by Fire）。自らも厚い前面装甲を持つため、被弾に耐えながら敵火点・座標を後続の戦車大隊や特科（自走砲）へ通報する。
2. **師団装甲装輪偵察戦闘大隊（第1・第2大隊）**:
   - **車台**: 装輪 6x6 / 8x8（Std-W6系高速装甲偵察車）。
   - **戦術任務**: 師団司令部直属の長距離索敵部隊。舗装道路や平原地帯を高速（整地速度 75km/h）で駆け抜け、大戦略マップ上で2〜3タイル先行して哨戒。敵の側面機動や、シーレーン・補給回廊の安全を確保する。
   - **地形制約**: 泥濘や山岳に入るとスタックするため、悪路では自動的に戦車本隊の後方警戒へ回る。

### 3.2 装甲化歩兵連隊の下車戦闘・工兵突破

- **下車戦闘（Dismounted Combat）**:
  - タイルが高Tier防衛施設、都市、鉱山坑道、森林、またはエイリアン巣窟の場合、戦車単体での突入は死角奇襲ペナルティ（被弾率 +40%）を受ける。
  - 装甲化歩兵大隊が重IFVから歩兵班を下車展開させることで、ペナルティを相殺し、歩兵火器・携帯誘導弾で拠点を制圧・掃討する。
- **戦闘工兵の障害啓開**:
  - 敵の地雷原、対戦車壕、あるいはエイリアンの生体ミズマ障壁に直面した際、装甲架橋・啓開車両が突入口を開拓し、戦車連隊の突進を可能にする。

### 3.3 特科（砲兵）と高射特科（防空）の独立運用

- **自走特科大隊**: 計48門の155C榴弾砲により、前線戦闘団の全大隊に対して持続的な火力支援（盤外・盤内砲撃）を提供。
- **戦術誘導打撃**: TEL発射機により、後方の高価値目標（敵司令部、補給拠点、大型防空レーダー）を長距離精密攻撃。
- **高射特科**: 師団全体の上空に防空アンブレラを展開。敵の航空攻撃・ドローン群・長距離誘導弾を迎撃・無力化。

## 4. 兵站・共食い整備（Cannibalization）の互換性グループ

機甲戦闘団内部の装備は、車台規格によって2つの互換性グループに分かれる。

| 互換性グループ | 該当部隊 | 車台系統 | 部品共食い成功率 | 主な融通パーツ |
| :--- | :--- | :--- | :---: | :--- |
| **装軌重装甲系** | 戦車大隊、装甲歩兵大隊、自走特科、ARV | 装軌 (Std-T4) | **85%** | 履帯ピン、転輪、油圧サスペンション、エンジンブロック、重装甲板 |
| **装輪高機動系** | 師団装輪偵察大隊、兵站補給連隊 | 装輪 (Std-W6) | **80%** | タイヤ、ドライブシャフト、民間トラック共通パーツ、軽発電機 |

- **装軌 ⇔ 装輪の相互流用**: 規格が異なるため不可（成功率 0%）。
- **整備大隊の役割**: 装甲回収車（ARV）により、破損した戦車・自走砲をサブタイル戦場から安全に回収し、パーツ取りまたは現地修理を実施。
