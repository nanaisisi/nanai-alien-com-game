# 増強機甲戦闘団 詳細編成・運用仕様書 (Heavy Armored Combat Group TO&E)

本ドキュメントは、[`concept_military_echelon_and_combat_groups.md`](../force_structure/concept_military_echelon_and_combat_groups.md) で定義された戦闘団タイプのうち、**「増強機甲戦闘団（Heavy Armored Combat Group / 4個機甲連隊基幹）」**の詳細な部隊編成（TO&E）、兵科分担、偵察運用、および兵站・共食い整備ダイナミクスを規定する個別仕様書である。

## 1. 増強機甲戦闘団の概要と戦略的位置づけ

- **部隊規模**: 総員 約23,000〜25,000名、戦闘・支援車両 約1,230両（うち主力戦車 256両、随伴・歩兵重IFV 320両［256+64］、装甲APC 64両、120C自走重迫撃砲 160両［16×10大隊］、装輪偵察・戦闘車 128両、直協航空機 32機）。
- **編成の核心思想（4個諸兵科混成機甲連隊 ＋ 1個装甲化歩兵連隊 ＋ 左右両翼偵察戦闘連隊 ＋ 特科・高射連隊）**:
  - **装軌系5個の基幹連隊体系（4個機甲連隊 ＋ 1個装甲化歩兵連隊）**:
    - **4個機甲連隊（自律突撃打撃・相互躍進）**: 各機甲連隊が「2個諸兵科連合機甲大隊（各大隊が戦車32両＋重IFV32両＋大隊付自走重迫16両＝計80両）」を基幹とし、大隊単位で完全自律した諸兵科連合突撃・曲射支援が可能。4連隊（計8個大隊）で戦車256両＋重IFV256両＋120C迫撃砲128両の大打撃力を発揮。
    - **第5装甲化歩兵連隊（突破後掃討・要衝確保）**: 重装甲突破の背後で、市街地・要塞・エイリアン巣穴の制圧・掃討・面確保を完結させる装軌系5個目の連隊。「歩兵戦闘車（IFV）大隊（重IFV64両＋自走重迫16両＝計80両）」による強襲突入と、「装甲兵員輸送車（APC）大隊（装甲APC64両＋自走重迫16両＝計80両）」による主力歩兵展開・拠点防衛を統合。
    - **迫撃火力ドクトリン**: 機甲部隊に90Cのような中途半端な軽迫・中迫は持たせず、各大隊付の自走重迫撃砲中隊（16両: 120C装軌）に統一。大隊長の「ポケット砲兵」として直協曲射・煙幕遮蔽を即応投射する。
  - **左右両翼の偵察戦闘連隊（計128両: 第1連隊［左翼］64両 ＋ 第2連隊［右翼］64両）**:
    - 戦車に劣る防御力・突破力の装輪戦力であることを前提に、中央の重装甲突撃主隊を保護する**「左右両翼スクリーン（警戒・遅滞・索敵・遊撃）」**として対称配置。
    - 各連隊が「装輪戦闘大隊（火力16＋歩兵16＝32両）」と「装輪偵察大隊（偵察32両）」を独自に保有。側翼での不意遭遇戦や敵の迂回奇襲部隊に対しても、連隊単独で機動遅滞・撃滅・要衝確保を自力解決できる戦術機動戦力を担保。
  - **特科連隊と高射連隊の完全独立**: 師団砲兵と師団防空をそれぞれ独立した「連隊」として重厚に配備し、前線全域への持続投射火力と濃密な多層防空傘を担保。
- **作戦特性**:
  - 開けた平原地帯、乾燥平原、幹線舗装動脈における圧倒的打撃力と突破力。
  - 敵の防衛線・重装甲部隊・エイリアン大型突撃個体を正面から粉砕する「戦略打撃の中核」。
- **兵站負荷**:
  - 師団全体の重量が極めて重く、燃料・重砲弾（155C/120C）・高品位航空推進剤の消費が最大級。
  - 高Tier補給デポまたは鉄道網・パイプラインとのインフラ結合度が低下すると急速に継戦能力が落ちる。

## 3. 兵科運用の詳細メカニクス

### 3.1 偵察・即応機動（連隊付威力偵察 vs 左右両翼偵察戦闘連隊）

1. **連隊付装軌威力偵察隊（各機甲連隊直轄）**:
   - **車台**: 装軌クローラー（Std-T4系重偵察戦闘車 / 軽戦車）。
   - **戦術任務**: 各機甲連隊の直前を進発し、敵の伏兵陣地やエイリアン大型個体と直接交戦（Recon by Fire）。自らも厚い前面装甲を持つため、被弾に耐えながら敵火点・座標を後続の戦車大隊や特科連隊へ通報する。
2. **師団直轄 2個偵察戦闘連隊（計128両: 第1連隊［左翼］64両 ＋ 第2連隊［右翼］64両）**:
   - **戦術的位置づけ（戦車に劣る防御力を補う側翼スクリーン）**:
     - 装輪車両は装軌主力戦車に比べ装甲防御力・正面突破力で劣るため、敵正面への突撃ではなく、師団の**「左翼スクリーン」および「右翼スクリーン」**として対称に配置。
     - 4個機甲連隊（計512両）が中央突破を行う際、脆弱な側背部や補給動脈が敵の回り込みや軽快遊撃部隊に奇襲されるのを防ぐ。
   - **各連隊の自己完結型編制（戦闘自由度の確保）**:
     - **第1連隊（左翼 64両）** / **第2連隊（右翼 64両）** ともに同一の左右対称編成：
       - **装輪戦闘大隊（計32両）**:
         - **装甲火力戦闘中隊 (16両)**: 105C低反動砲搭載。装輪の高速性（80〜90km/h）を生かした一撃離脱・機動火力打撃。
         - **装輪歩兵戦闘中隊 (16両)**: 25C機関砲と下車歩兵戦闘班。側翼の要衝集落・橋梁の確保、障害物啓開。
       - **装輪偵察大隊（計32両）**:
         - **第1・第2偵察戦闘中隊 (各16両・計32両)**: 25C自動機関砲 ＋ 伸縮式高所センサーマスト ＋ 小型ドローン。
   - **スクリーン運用の戦術機動**:
     - 広大な側翼部で敵の接近を探知した場合、連隊内の105C火力戦闘大隊が急行して**機動遅滞戦闘（Delaying Action）**を展開。敵の迂回部隊を足止め・拘束し、師団中央の機甲主隊が敵主力を粉砕するまでの時間を稼ぐ、あるいは自力で撃滅する。
   - **地形制約**: 泥濘や急峻山岳に入るとスタックするため、悪路では自動的に幹線・舗装動脈の警戒・長距離迂回機動へ回る。

### 3.2 大隊付自走重迫撃砲中隊（16両）の集中運用と第5装甲化歩兵連隊の役割分担

- **大隊直轄自走重迫撃砲中隊（16両）のドクトリン（90Cの排除と大隊集約）**:
  - 機甲部隊および装甲歩兵部隊は全車が装軌装甲化・自走化されており、主力戦車（120C/130C）および重IFV（30C/50C機関砲）という巨大な直射打撃力を誇る。
  - そのため、小隊・中隊単位で機動性を削ぐ90C中迫撃班は配備せず、**各大隊直轄「自走重迫撃砲中隊（120C装軌自走重迫撃砲 16両: 4小隊編成）」**として大隊長の手元に1つに集中運用する。
  - 大隊長の号令一下、突撃軸の前方や直射火器の射界外（稜線裏・窪地・市街地瓦礫）へ、16門の一斉射撃による大口径曲射弾幕および突撃支援用の濃密な煙幕スクリーンを瞬時に投射する。
- **第5装甲化歩兵連隊（IFV ＋ APC）の戦術機能**:
  - **強襲突入（IFV大隊: 重IFV 64両 ＋ 自走重迫 16両）**: 機甲連隊が敵防衛線をこじ開けた直後、重IFVの機関砲制圧射撃とともに歩兵班が即座に下車突入し、トーチカ・ビル内・生体巣穴の深部を掃討。
  - **面制圧・要衝確保（APC大隊: 装甲APC 64両 ＋ 自走重迫 16両）**: IFVに比べキャビン容積が大きく歩兵収容力に優れた装甲APCが、主力歩兵および弾薬・対戦車火器を大量に輸送展開。奪取した重要橋梁・動脈インフラ・防衛線を要塞化し、敵の逆襲を完全拒絶する。
  - これにより、機甲部隊が「後方の掃討・占領警備」で足止めされることなく、常に次の突破作戦へ前進し続けることが可能となる。
- **2-2 相互躍進（Leapfrogging）**:
  - 第1機甲連隊が敵防衛線に突入して交戦・拘束している間に、第2機甲連隊がその間隙を縫って突破・背後遮断を行うバイナリ機動を展開。

### 3.3 特科連隊と高射連隊の独立重厚運用

- **独立特科連隊**:
  - 計48門の155C自走榴弾砲（第1・第2大隊）による間断なき持続支援射撃。
  - 210C重榴弾砲大隊による強固な要塞・巣窟コアの破砕。
  - TEL誘導打撃大隊による長距離精密攻撃（敵司令部・防空レーダーの事前制圧）。
- **独立高射連隊**:
  - 自走機関砲大隊（近距離・対ドローン・対CAS）とSAM大隊（中距離広域防空）が重層的な防空アンブレラを展開。敵の航空侵入・ミサイル攻撃から師団の重車列を保護。

## 4. 兵站・共食い整備（Cannibalization）の互換性グループ

大規模師団のため、車台規格ごとに明確なパーツ融通ラインを確立する。

| 互換性グループ | 該当部隊 | 車台系統 | 部品共食い成功率 | 主な融通パーツ |
| :--- | :--- | :--- | :---: | :--- |
| **装軌重装甲系** | 戦車大隊、重IFV大隊、自走特科、SAM、ARV | 装軌 (Std-T4/T6) | **85%** | 履帯ピン、転輪、油圧サスペンション、大出力ディーゼル/ガスタービン、重装甲板 |
| **装輪高機動系** | 第1・第2偵察戦闘連隊（計128両）、兵站補給連隊 | 装輪 (Std-W8) | **80%** | タイヤ、全輪駆動ドライブシャフト、民間トラック共通部品、発電機 |
| **回転翼・航空推進系** | 師団直協航空連隊（戦闘16＋輸送16） | 航空 (Aero) | **70%** | タービンエンジン、ローターハブ、アビオニクス基板、ノズル部品 |

- **整備回収能力の倍増**: 前方回収・野戦整備大隊に装甲回収車（ARV）32両を集中配備し、激戦下でも損耗車両の回収・共食い整備・現地復旧を高速回転させる。
