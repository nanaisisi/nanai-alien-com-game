# 増強機甲戦闘団 詳細編成・運用仕様書 (Heavy Armored Combat Group TO&E)

本ドキュメントは、[`concept_military_echelon_and_combat_groups.md`](../force_structure/concept_military_echelon_and_combat_groups.md) で定義された戦闘団タイプのうち、**「増強機甲戦闘団（Heavy Armored Combat Group / 4個機甲連隊基幹）」**の詳細な部隊編成（TO&E）、兵科分担、偵察運用、および兵站・共食い整備ダイナミクスを規定する個別仕様書である。

---

## 1. 増強機甲戦闘団の概要と戦略的位置づけ

- **部隊規模**: 総員 約18,000〜20,000名、戦闘・支援車両 約900両（うち主力戦車 256両、随伴重IFV 256両、装輪偵察戦闘車 64両、直協航空機 32機）。
- **編成の核心思想（4個諸兵科混成機甲連隊 ＋ 直轄特科・高射連隊）**:
  - **4個機甲連隊の自律打撃**: 各機甲連隊が「戦車大隊（64両）＋随伴重IFV大隊（64両）」の同数ペアを内包し、連隊単位で完全な諸兵科連合突撃・自己防護が可能。4連隊で戦車計256両＋重IFV計256両の大打撃力を誇る。
  - **師団装甲装輪偵察 2個大隊（計64両）**: 師団直轄として広域高速哨戒・側背警戒・交通路確保を担当する2個大隊（各32両）を配備。
  - **特科連隊と高射連隊の完全独立**: 師団砲兵と師団防空をそれぞれ独立した「連隊」として重厚に配備し、前線全域への持続投射火力と濃密な多層防空傘を担保。
- **作戦特性**:
  - 開けた平原地帯、乾燥平原、幹線舗装動脈における圧倒的打撃力と突破力。
  - 敵の防衛線・重装甲部隊・エイリアン大型突撃個体を正面から粉砕する「戦略打撃の中核」。
- **兵站負荷**:
  - 師団全体の重量が極めて重く、燃料・重砲弾（155C/120C）・高品位航空推進剤の消費が最大級。
  - 高Tier補給デポまたは鉄道網・パイプラインとのインフラ結合度が低下すると急速に継戦能力が落ちる。

## 3. 兵科運用の詳細メカニクス

### 3.1 偵察の多層レイヤー構造（連隊付威力偵察 vs 師団装輪偵察2個大隊）

1. **連隊付装軌威力偵察隊（各機甲連隊直轄）**:
   - **車台**: 装軌クローラー（Std-T4系重偵察戦闘車 / 軽戦車）。
   - **戦術任務**: 各機甲連隊の直前を進発し、敵の伏兵陣地やエイリアン大型個体と直接交戦（Recon by Fire）。自らも厚い前面装甲を持つため、被弾に耐えながら敵火点・座標を後続の戦車大隊や特科連隊へ通報する。
2. **師団装甲装輪偵察戦闘大隊（第1大隊・第2大隊: 計64両）**:
   - **車台**: 装輪 8x8（Std-W8系高速装甲偵察車台共通）。
   - **2機種による「目と牙」の相互補完小隊構成**:
     - **装甲偵察車両 (Armored Reconnaissance Vehicle: 各大隊16両 / 計32両)**:
       - 装備: 25C自動機関砲 ＋ 伸縮式高所センサーマスト（ミリ波レーダー / 熱線暗視） ＋ 小型戦術ドローン発射管。
       - 役割: 敵に察知されず地形の稜線・遮蔽物越しに索敵し、敵陣地の配置・火点を正確に通報・レーザー照射。
     - **装甲火力戦闘車両 (Armored Combat Vehicle / Mobile Gun System: 各大隊16両 / 計32両)**:
       - 装備: 105C低反動ライフル砲 / 高初速滑腔砲 ＋ 旋回砲塔。
       - 役割: 偵察車両が発見した敵先鋒部隊、軽装甲車、中型エイリアン突撃個体を、戦車本隊の到着を待たずに自前で即座に粉砕・排除する「偵察隊の牙」。
   - **戦術任務**: 師団司令部直属の長距離索敵部隊。舗装道路や平原地帯を高速（整地速度 80〜90km/h）で駆け抜け、大戦略マップ上で2〜3タイル先行して哨戒。
   - **2個大隊運用の妙**:
     - **第1大隊**: 主進撃軸の正面・左右フランク（側面）を扇状に索敵し、遭遇した敵前衛を火力戦闘車で即応撃破。
     - **第2大隊**: 後方兵站回廊（動脈インフラ・パイプライン・連絡線）の安全確保、および敵浸透ゲリラ・軽快エイリアン部隊の迎撃・掃討を担当。
   - **地形制約**: 泥濘や急峻山岳に入るとスタックするため、悪路では自動的に戦車本隊の後方・幹線警戒へ回る。

### 3.2 諸兵科混成連隊（戦車64両＋随伴重IFV64両）の連携

- **下車戦闘（Dismounted Combat）の即応性**:
  - タイルが高Tier防衛施設、都市、鉱山坑道、森林、またはエイリアン巣窟の場合、戦車単体での突入は死角奇襲ペナルティ（被弾率 +40%）を受ける。
  - 各連隊内の随伴歩兵大隊が重IFVから歩兵班を即座に下車展開させ、戦車の死角をクリアリングすることでペナルティを完全相殺。
- **2-2 相互躍進（Leapfrogging）**:
  - 第1機甲連隊が敵防衛線に突入して交戦・拘束している間に、第2機甲連隊がその間隙を縫って突破・背後遮断を行うバイナリ機動を展開。

### 3.3 特科連隊と高射連隊の独立重厚運用

- **独立特科連隊**:
  - 計48門の155C自走榴弾砲（第1・第2大隊）による間断なき持続支援射撃。
  - 210C重榴弾砲大隊による強固な要塞・巣窟コアの破砕。
  - TEL誘導打撃大隊による長距離精密攻撃（敵司令部・防空レーダーの事前制圧）。
- **独立高射連隊**:
  - 自走機関砲大隊（近距離・対ドローン・対CAS）とSAM大隊（中距離広域防空）が重層的な防空アンブレラを展開。敵の航空侵入・ミサイル攻撃から師団の重車列を保護。

## 4. 兵站・共食い整備（Cannibalization）の互換性グループ

大規模師団のため、車台規格ごとに明確なパーツ融通ラインを確立する。

| 互換性グループ | 該当部隊 | 車台系統 | 部品共食い成功率 | 主な融通パーツ |
| :--- | :--- | :--- | :---: | :--- |
| **装軌重装甲系** | 戦車大隊、重IFV大隊、自走特科、SAM、ARV | 装軌 (Std-T4/T6) | **85%** | 履帯ピン、転輪、油圧サスペンション、大出力ディーゼル/ガスタービン、重装甲板 |
| **装輪高機動系** | 師団装輪偵察2個大隊、兵站補給連隊 | 装輪 (Std-W8) | **80%** | タイヤ、全輪駆動ドライブシャフト、民間トラック共通部品、発電機 |
| **回転翼・航空推進系** | 師団直協航空連隊（戦闘16＋輸送16） | 航空 (Aero) | **70%** | タービンエンジン、ローターハブ、アビオニクス基板、ノズル部品 |

- **整備回収能力の倍増**: 前方回収・野戦整備大隊に装甲回収車（ARV）32両を集中配備し、激戦下でも損耗車両の回収・共食い整備・現地復旧を高速回転させる。
