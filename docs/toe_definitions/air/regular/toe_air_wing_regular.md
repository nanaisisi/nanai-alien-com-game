# 通常航空戦闘団（人類通常航空隊）詳細編成・運用仕様書 (Regular Air Wings TO&E)

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../GAME_DESIGN.md) のセクション 3.3.1 に基づき、惑星大気圏内の制空権確保、戦略爆撃、長距離兵站空輸、光学・電波ステルス強襲、および空中要塞運用を担う人類正規軍の**「通常航空戦闘団（Regular Air Wings）」**全14種の編制序列、機体スペック、および運用規則を規定する仕様書である。

---

## 1. 航空戦闘団の基本エシュロン思想

- **大戦略1コマの規模**：
  - 一般的な航空団は**約32〜64機の固定翼/垂直離着陸機（4〜8個飛行隊）**により構成。
  - 「空中戦艦航空団」「超大型輸送航空団」等の超重アセットは、巨大空中艦数隻と直衛戦闘機隊からなる戦略独立航空団として運用される。

---

## 2. 全14カテゴリーの通常航空団編成仕様

| 航空団種別 | 主な役割・特徴 | 構成機体イメージ |
| :--- | :--- | :--- |
| **民間航空団** | 惑星内拠点間の長距離高速輸送・定期便 | 大型旅客輸送機、コンテナ貨物機 |
| **武装民間航空団** | 軽火器・自衛チャフを施した民間機 | 機銃ポッド装備武装貨物機 |
| **輸送航空団** | 陸上部隊・装甲車の不整地空輸・戦術投下 | 重戦術軍用輸送機（C-17級・32機） |
| **哨戒航空団** | 広域レーダー警戒・早期警戒・対潜監視 | 早期警戒機（AEW&C 8機）、対潜哨戒機（16機）、護衛戦闘機 |
| **護衛航空団** | 輸送機・民間船航路の局所直衛 | 大型制空戦闘機（32機） |
| **迎撃航空団** | 短距離滑走・道路展開による緊急スクランブル | 軽戦闘機（32〜48機） |
| **垂直離陸航空団** | 飛行場未整備の基地・前線拠点での即応戦闘 | SVTOL戦闘機（32機） |
| **戦闘航空団** | 制空権確保および対地精密打撃の中核主力 | 大型制空戦闘機（32機） ＋ 戦闘爆撃機（16機） |
| **光学・電波ステルス戦闘航空団** | 光学迷彩と電波吸収外皮による完全不可視奇襲 | 光学迷彩ステルス戦闘機（32機） |
| **爆撃航空団** | 敵都市・工業地帯・軍団への戦略絨毯爆撃 | 大型戦略爆撃機（16機）、長距離護衛機（16機） |
| **光学・電波ステルス爆撃航空団** | 防空火網を突破して中枢を精密爆撃 | 光学迷彩ステルス爆撃機（8機）、ステルス護衛機（16機） |
| **空中戦艦航空団** | 超重装甲空中戦艦による低空・中空での接近制圧 | 超大型空中戦艦（1〜2隻）、空中防空巡洋艦、直衛機 |
| **空中空母航空団** | 航続距離の制約を克服する飛行する前線基地 | 超大型空中空母（1隻）、艦載戦闘機隊（48機）、護衛フリゲート |
| **光学・電波ステルス偵察航空団** | 敵防空圏深部への侵入と全域マッピング | 超音速光学ステルス偵察機（16機） |
| **超大型輸送航空団** | 艦隊・軍団単位の超長距離空輸（戦艦を凌駕するコスト） | 超巨大戦略輸送飛行船/輸送機（4隻）、空中護衛フリゲート |

## 3. 作戦メカニクスと気流観測

- **航続距離と基地運用**:
  - 航空団は飛行場（Airbase）または空中空母を拠点として作戦半径（Range）を展開。
- **ステルスと気流観測（戦闘妖精・雪風的ギミック）**:
  - 光学・電波ステルス機は通常のレーダーや目視では捕捉不能だが、高度な気流密度センサーや大気揺らぎ観測施設を展開することで、ステルス機の飛行航跡を逆探知可能。
