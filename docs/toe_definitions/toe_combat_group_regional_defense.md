# 地域配備・警備師団 詳細編成・運用仕様書 (Regional Defense & Security Division TO&E)

本ドキュメントは、[`concept_military_echelon_and_combat_groups.md`](../force_structure/concept_military_echelon_and_combat_groups.md) および [`concept_toe_feedback_and_cross_echelon_methodology.md`](../force_structure/concept_toe_feedback_and_cross_echelon_methodology.md) に基づき、担当管区（2〜4親タイル）に常駐し、低維持コストで重要インフラ警備、治安維持、害獣対処、および主力不在時の時間稼ぎ遅滞戦闘を担う**「地域配備・警備師団（Regional Defense & Security Division）」**の詳細な戦闘序列（TO&E）、留守警備構造、固定陣地・要塞化ドクトリンを規定する個別仕様書である。

---

## 1. 地域配備・警備師団の概要と戦略的位置づけ

- **部隊規模**: 総員 約10,000〜12,000名、軽装甲車・退役改修車両・警備車 約300両、汎用連絡ヘリ 8機。
- **編成の核心思想**:
  - **極めて低い平時維持コストと高い固定抗堪性**:
    - 前線突破用主力師団（重機甲・要塞突破等）が大量の重燃料・高価弾薬を常時消費するのに対し、本師団は現地タイルの民間インフラから直接自活。維持費・燃料消費は正規師団の30%以下に抑制。
    - 移動機動力は低いが、タイルの掩蔽壕、永久トーチカ、地雷原、固定対空砲火と一体化することで、防衛時には数字以上の粘り強い抗堪力を発揮。
  - **主力転地時における「防衛力の欠如」防止（留守警備基盤）**:
    - 主力機甲部隊が他戦線へ機動転地した際も、本師団が留守部隊（Rear Security Element）として現地に残り、治安維持や小規模エイリアンの侵入を完全に迎撃。
    - 大規模な敵性侵攻に対しては、インフラ動脈を用いて主力が救援帰還するまでの「機動遅滞・時間稼ぎ」を完遂。
  - **退役旧式車両（Block I/レガシー）の再活用と牽引式重迫撃砲**:
    - 高価な最新鋭自走迫ではなく、退役した旧式装甲APCやトラック牽引式の120C重迫撃砲（16門×各大隊）を配備。安価ながら防衛戦では十分な曲射火力を投射。
