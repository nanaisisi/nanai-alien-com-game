# 山岳猟兵・隘路工兵軍団 詳細編成・運用仕様書 (Mountain Jaeger & Combat Engineer Corps TO&E)

本ドキュメントは、[`../force_structure/concept_military_echelon_and_combat_groups.md`](../force_structure/concept_military_echelon_and_combat_groups.md)、[`../force_structure/concept_corps_and_division_echelons.md`](../force_structure/concept_corps_and_division_echelons.md)、および [`../force_structure/concept_toe_feedback_and_cross_echelon_methodology.md`](../force_structure/concept_toe_feedback_and_cross_echelon_methodology.md) に基づき、重装軌・装輪車両が進入不可能な急峻山岳、氷河、断崖、および森林隘路に特化した**「山岳猟兵・隘路工兵軍団（Mountain Jaeger & Combat Engineer Corps / 2個師団統合型）」**の詳細な戦闘序列（TO&E）、迫撃砲多層分散ドクトリン、多脚荷役機材、および山岳側翼スクリーン運用を規定する個別仕様書である。

## 1. 山岳猟兵軍団の概要と戦略的位置づけ

- **部隊規模**: 総員 約28,000名、軽戦闘車台・多脚機材 約640両/機、高高度輸送航空機 32機。
- **編成の核心思想**:
  - **1ユニット＝2個山岳師団統合軍団制**:
    - 大戦略マップの1コマは【第1山岳猟兵師団（主登攀・主攻）】と【第2山岳猟兵師団（助攻・隘路遮断）】、軍団司令部、軍団山岳工兵群、および高高度航空群で構成。
    - 各師団の正面戦力は4個山岳猟兵連隊（各連隊が下車登攀猟兵大隊×2 ＋ 山岳工兵中隊）。
  - **「下車登攀」＋「強襲戦闘工兵の通路開拓」＋「高高度直協空輸」の三位一体**:
    - 車両が進入できない岩盤・断崖を山岳猟兵が徒歩・アイゼン・ハーネスで登攀し、工兵がワイヤー架橋・足場爆破で後続ルートを開拓。
    - 高高度対応の直協強襲輸送ヘリが山頂や稜線要衝へ先行突入して拠点を確保。
  - **迫撃砲ドクトリンの例外承認（多層分散配置）**:
    - 車両随伴が不可能な急峻登攀環境のため、大隊集約のみでは歩兵の即応支援が成立しない。
    - したがって本軍団に限り、**「小隊付60C軽迫 / 中隊付90C中迫 / 大隊付120C固定アンカー重迫座」の多層分散配置を正式なドクトリン例外として承認・配備**。
  - **多脚荷役機（Std-L4）の兵站・工兵限定配備**:
    - 全体を多脚化するのではなく、工兵の重機荷役、ラバ型弾薬輸送、および岩盤固定アンカー迫撃砲座の特殊プラットフォームとして多脚機材を集中運用。
  - **小型4脚自律斥候犬（UGV 128機）による山岳側翼スクリーン**:
    - 装輪車両が使えない山岳において、自律4脚斥候犬とマイクロドローンが稜線・断崖の全周にセンサー・トラップ網を展開し、奇襲を警戒・遅滞。
