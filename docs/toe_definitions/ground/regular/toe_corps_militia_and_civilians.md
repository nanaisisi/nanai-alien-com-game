(Tier 0-A 民間人・避難民群 / Tier 0-B 民兵軍団 総合編制仕様)

## 1. 概要と位置づけ (Tier 0 体系)

大戦略マップ上の1コマとして活動する集団のうち、正規軍の組織的訓練・重装備体系を持たない民間ベースの部隊区分。

| エシュロン区分 | 主兵器・プラットフォーム | 機動力・装備実態 | 運用環境・戦略的位置づけ |
| :--- | :--- | :--- | :--- |
| **Tier 0-A: 民間人・避難民群** *(Civilian Refugees)* | 武装なし（工具、鉄パイプ、猟銃程度） | 徒歩 ＋ 民間乗用車・バス・荷車混成 | 攻撃力皆無。戦災都市からの避難、新植民地への入植移動。敵性体・エイリアンと接触すると一方的に虐殺・捕食されるため護衛が必須。都市到着で人口資源化。 |
| **Tier 0-B: 民兵軍団** *(Colonial Militia Corps)* | 小銃、火炎瓶、テクニカル（機銃付4x4）、即席IED | 徴用民間トラック・自家用四駆 ＋ 徒歩 | 開拓拠点の自活防衛・治安維持。正規軍と比べて極めて低維持費。小型エイリアンや軽装ゲリラなら撃退可能だが、重装甲・大型種には無力。 |

## 2. Tier 0-A: 民間人・避難民群 (Civilian Refugees & Settlers)

軍事的な戦闘組織ではなく、入植民、開拓作業員、被災避難民が自発的または行政主導で大移動を行う大集団コマ。

### 2.1 編成構成（人口 約30,000〜50,000人規模）

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 民間人・避難民群（大戦略1コマ: 約40,000名集団）構成概要                      │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  【避難民・移民代表部 / 自治連絡班】                                         │
│    ├─ 自治会長・行政官・医師・技術者グループ                                 │
│    └─ 非常用簡易通信機・メガホン・救急救護テント                             │
│                                                                              │
│  【前衛群 (Forward Column)】                                                 │
│    ├─ 先頭車両群（自家用乗用車、バン、軽トラ、農業トラクター 約400両）       │
│    └─ 徒歩避難民・荷車牽引グループ（約15,000名）                             │
│                                                                              │
│  【中央輜重・家族群 (Center Column)】                                        │
│    ├─ 大型民間バス・長距離輸送トラック（約200両: 食料・私財・燃料積載）      │
│    └─ 高齢者・子ども・負傷者収容グループ（約15,000名）                       │

│    └─ 落伍者収容トラック・徒歩追従グループ（約10,000名）                     │

```

### 2.2 運用特性とルール

- **戦闘能力**:
  - 対地攻撃力：0（反撃能力は極小・無視できるレベル）。
  - 対空能力：0。
  - 防御力：最低（防弾装甲なし。接触即壊滅リスク）。
- **移動力**:
  - 舗装道路では民間車両により標準速度を発揮できるが、不整地・山岳・泥濘地では極端に移動速度が低下（徒歩・軽車両の立ち往生）。
- **兵站・維持コスト**:
  - 軍事用弾薬消費はゼロ。ただしターンごとに一定量の食料（またはエネルギー）を消費。
- **ゲーム内機能**:
  - **都市吸収（入植・避難完了）**: 友軍都市タイルに到達・進入するとコマが解消され、都市人口（Population）が直接増加する。
  - **救出護衛任務**: 前線から後方へ退却させる際、敵エイリアン（特に俊敏な小型種スウォーム）の格好の標的となるため、装輪機動部隊や軽歩兵による先導・護衛が不可欠。

## 3. Tier 0-B: 民兵軍団 (Colonial Militia Corps)

正規軍を常駐させる予算や生産力がない開拓初期の植民拠点や、占領地の治安維持のために組織される準軍事・市民自衛組織。

### 3.1 戦闘序列 (TO&E)

エシュロン体系（2個師団相当の統合管区制）を踏襲しつつ、装備はすべて民間徴用車と軽火器で構成される。

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 民兵軍団（2個民兵師団基幹・植民地自衛警備仕様）戦闘序列 (TO&E)               │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  【軍団本部および直属警備群】 (Militia Corps HQ & Support)                   │
│    ├─ 自衛団本部管理中隊（民間オフロード車、商用無線通信バン 16両）          │
│    ├─ 徴用物資補給隊（民間ダンプ・パネルバン・タンクローリー 128両）         │
│    └─ 救護・応急医療隊（改造救急車、民間ドクターカー 32両）                  │
│                                                                              │
│  【第1民兵師団】 (1st Colonial Militia Division / 約12,000名)                │
│    ├─ 師団本部・治安維持警護中隊                                             │
│    ├─ 第1・第2・第3・第4 民兵連隊 (各連隊: 3個大隊基幹)                     │
│    │    ├─ 下車民兵（旧式自動小銃、散弾銃、火炎瓶、携帯無線） 約2,000名     │
│    │    ├─ テクニカル小隊（ピックアップトラック＋重機関銃/対戦車誘導弾）32両 │
│    │    └─ 輸送用徴用トラック・マイクロバス 64両                             │
│    └─ 師団簡易支援砲火隊（トラック荷台据付の簡易無誘導ロケット・81C迫撃砲） │
│                                                                              │
│  【第2民兵師団】 (2nd Colonial Militia Division / 約12,000名)                │
│    └─ （第1師団と同等構成: 民兵連隊×4 ＋ テクニカル群 ＋ 徴用輸送隊）        │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
```

- **定員規模**: 総員 約26,000名、テクニカル（武装トラック） 約250両、徴用輸送車 約600両、火器（迫撃砲・簡易ロケット） 64基、航空機 0機。
- **作戦特性**:
  - **対小型エイリアン・治安維持**:
    - 小型エイリアンの浸透やゲリラ的な暴動に対しては、圧倒的な人員数と軽火器の弾幕で有効な迎撃・面制圧が可能。
  - **重装甲・大型エイリアンへの完全な脆弱性**:
    - 防弾鋼板を持たない民間車基幹のため、大型エイリアンの突撃や敵正規軍の榴弾砲撃・戦車砲には耐えられず、瞬時に士気崩壊（Rout）を起こす。
  - **低維持費と即応動員**:
    - 正規軍のような先端資材（高度電子部品、重装甲板、航空燃料）の維持費をほとんど消費せず、都市・集落の余剰人員から超低コスト・短ターンで緊急編成可能。
  - **正規軍へのアップグレード**:
    - 工業力と兵器生産が整った段階で、追加コストを支払うことで「Tier 1 軽歩兵軍団」や「Tier 2 自動車化軽歩兵軍団」へと再編成・装備改修が可能。

## 4. 戦術・ゲーム内メカニクスまとめ

1. **エシュロン体系との整合**:
   - 大戦略コマ（軍団）としての取り回し（1タイル専有、隣接支援）は正規軍と同様に機能するが、小隊・中隊レベルの戦術マップに展開した際、正規戦車・歩行機のようなハイエンド兵器は一切出現せず、テクニカルと無数の下車歩兵・即席障害物で防衛線を敷く。
2. **植民地防衛のリアリズム**:
   - 前線の重機甲軍団が敵主力や巨大怪獣を粉砕している間、後方要衝・鉱山・補給路の警備を民兵軍団が安価に請け負うことで、正規軍の配置を前線へ集中させることができる。
