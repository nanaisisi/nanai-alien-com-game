# 自動車化・軽歩兵軍団 詳細編成・運用仕様書 (Motorized & Light Infantry Corps TO&E)

(Tier 1 軽歩兵 / Tier 2 自動車化軽歩兵 / Tier 3 自動車化歩兵 総合編制仕様)

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../GAME_DESIGN.md)、[`../../../force_structure/concept_military_echelon_and_combat_groups.md`](../../../force_structure/concept_military_echelon_and_combat_groups.md)、[`../../../force_structure/concept_corps_and_division_echelons.md`](../../../force_structure/concept_corps_and_division_echelons.md)、および [`toe_corps_variants.md`](./toe_corps_variants.md) に基づき、歩兵多層エシュロン（Tier 1〜3）に属する**「軽歩兵軍団」「自動車化軽歩兵軍団」「自動車化歩兵軍団」**の戦闘序列（TO&E）、4x4軽装甲車（LAV）プラットフォーム運用、牽引砲 ⇄ トラック荷台架装自走砲の火力格差、および2個師団統合型軍団編制を規定する個別仕様書である。

---

## 1. 概要と多層エシュロンの位置づけ

| エシュロン区分 | 基幹プラットフォーム | 砲兵・重火力アセット | 運用環境・戦略的位置づけ |
| :--- | :--- | :--- | :--- |
| **Tier 1: 軽歩兵軍団** | 車両なし（完全徒歩行軍） | 携帯ATM班、60C軽迫、81C中迫 | 急峻山岳、密林、洞窟、湿地。燃料消費ゼロ。防御力・平地機動は最低だが悪路突破力最大。 |
| **Tier 2: 自動車化軽歩兵軍団** | 4x4軽装甲車（LAV） ＋ トラック | 牽引式120C重迫撃砲、牽引式155C榴弾砲 | 幹線道路での高速転進。牽引砲のため陣地展開・射撃準備に時間を要し対砲兵戦に脆弱。 |
| **Tier 3: 自動車化歩兵軍団** | 4x4軽装甲車（LAV） ＋ トラック自走砲 | 8x8トラック架装120C自走迫、155Cトラック自走砲 | 同一の4x4 LAVを基幹としつつ火砲を自走化。即応火力投射とシュート＆スクートを実現。 |

- **作戦特性**: 険峻な山岳断崖や深い森林タイルにおいて移動力ペナルティを受けず、敵のレーダー・熱源探知を極限まで低減して行動。

## 3. Tier 2 & Tier 3: 自動車化（軽）歩兵軍団 戦闘序列

Tier 2とTier 3は、歩兵乗車車両を同一の**「4x4軽装甲車（LAV）」**で共通化し、部品補給・兵站負荷を統一している。火力支援梯団のみが「牽引砲」か「トラック荷台架装自走砲」かで分岐する。

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 自動車化歩兵軍団（2個師団統合型・4x4 LAV基幹）戦闘序列 (TO&E)                 │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  【軍団司令部および自動車化直轄群】                                          │
│    ├─ 軍団司令部管理中隊（4x4 LAV指揮通信車 8両、大型トラック移動司令部）     │
│    ├─ 軍団重兵站補給連隊（6x6 / 8x8大型輸送トラック 256両）                    │
│    └─ 軍団直轄航空隊（計32機: 戦闘ヘリ16機 ＋ 戦術輸送ヘリ16機）               │
│                                                                              │
│  【第1自動車化歩兵師団】 ◀── [主攻軸]                                         │
│    ├─ 師団司令部管理中隊 ＋ 師団輸送飛行隊（輸送ヘリ 8機）                     │
│    ├─ 第1・第2・第3・第4 自動車化歩兵連隊                                    │
│    │    ├─ 4x4 LAV（乗員2＋下車歩兵8名固定）各連隊 80両                       │
│    │    └─ 連隊迫撃砲中隊:                                                   │
│    │         ・Tier 2の場合: トラック牽引式120C重迫撃砲 16門                  │
│    │         ・Tier 3の場合: 8x8トラック架装120C自走迫撃砲 16両               │
│    └─ 師団野戦特科連隊:                                                      │
│         ・Tier 2の場合: トラック牽引式155C榴弾砲 48門                         │
│         ・Tier 3の場合: 155C装輪トラック自走榴弾砲 48両                       │
│                                                                              │
│  【第2自動車化歩兵師団】 ◀── [助攻 / 側翼軸]                                 │
│    └─ （第1師団と同等構成: 4x4 LAV各連隊80両 ＋ 砲兵 ＋ 輸送ヘリ8機）         │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
```

- **定員規模**: 総員 約26,000名、4x4 LAV 約640両、輸送トラック 約400両、火砲 128門/両、航空機 計48機。
- **作戦特性**:
  - **舗装路自走**: 舗装された幹線道路タイルで時速90km以上の高速機動を発揮。
  - **Tier 2（牽引型）**: 射撃準備（放列布置）に1ターン、陣地撤収に1ターンを要するため、敵の対砲兵射撃や長距離爆撃の標的になりやすい。
  - **Tier 3（自走型）**: 停車後即座に発射し数分で離脱する「シュート＆スクート」が可能であり、生存性と支援火力の即応性が大幅に向上。
