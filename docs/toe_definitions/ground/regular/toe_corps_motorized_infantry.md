# 自動車化歩兵軍団 詳細編成・運用仕様書 (Motorized Infantry Corps TO&E)

(Tier 3 自動車化歩兵軍団 専門編制仕様)

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../GAME_DESIGN.md)、[`../../../force_structure/concept_military_echelon_and_combat_groups.md`](../../../force_structure/concept_military_echelon_and_combat_groups.md)、[`../../../force_structure/concept_corps_and_division_echelons.md`](../../../force_structure/concept_corps_and_division_echelons.md)、および [`../../../force_structure/concept_corps_variants.md`](../../../force_structure/concept_corps_variants.md) に基づき、同一の4x4軽装甲車（LAV）プラットフォームを基幹としつつ、すべての火砲をトラック荷台架装自走砲に換装した非装甲・軽装甲部隊最上位の**「自動車化歩兵軍団（Motorized Infantry Corps / Tier 3 / 2個師団統合型）」**の戦闘序列（TO&E）、即応火力投射、シュート＆スクート戦術、および2層航空運用を規定する個別仕様書である。

---

## 1. 概要と戦略的位置づけ

- **定員規模**: 総員 約26,000名、4x4 LAV 約640両、輸送・弾薬トラック 約400両、トラック自走火砲 128両（8x8トラック架装120C自走迫撃砲 32両 ＋ 155C装輪トラック自走榴弾砲 96両）、航空機 計48機。
- **編成の核心思想**:
  - **火砲の完全自走化とシュート＆スクート**:
    - Tier 2の牽引砲を排し、荷台架装型自走砲（120C自走迫・155Cトラック自走榴弾砲）に統一。
    - 停車から1分以内に射撃を開始し、射撃終了後数分以内に陣地を離脱する「シュート＆スクート（Shoot-and-Scoot）」を確立。
  - **4x4 LAVプラットフォームの共通化**:
    - 乗車車両はTier 2と同一規格の4x4 LAV（乗員2＋下車歩兵8名固定）を採用し、部品補給・整備負荷を低減。

## 3. 作戦特性と運用ルール

1. **即応射撃と高い生存性**:
   - 陣地展開アクションを要さず、移動直後に砲撃支援が可能。敵の反撃弾道が到達する前に陣地を離脱するため、対砲兵戦での生存率が格段に高い。
2. **装輪機動軍団（Tier 4）へのステップアップ**:
   - 車両防御力は4x4 LAVの防弾鋼板レベル（小火器・破片防御）にとどまるため、敵の重機関砲や大型エイリアンとの直接交戦には耐えられない。本格的な前線突破には8x8重装甲（Std-W8）統一の「装輪機動軍団」が必要となる。
