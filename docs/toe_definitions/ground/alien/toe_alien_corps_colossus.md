# 超大型エイリアン軍団 詳細編成・生態仕様書 (Colossus Behemoth Corps TO&E)

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../GAME_DESIGN.md) のセクション 3.1.2 に基づき、全高20m級の超大型接近戦型巨獣（タイタン級）を中核とし、敵要塞線や機甲防衛線を正面から圧壊・蹂躙する決戦部隊**「超大型エイリアン軍団（Colossus Behemoth Corps）」**の編制体系、巨獣生態、および破壊メカニクスを規定する個別仕様書である。

---

## 1. 概要と生態ドクトリン

- **部隊規模**: 超大型接近戦型巨獣 数頭〜十数頭 ＋ 直協護衛群（中型格闘種 数千頭、小型種 数万頭）。
- **作戦上の位置づけ**:
  - 人類の永久要塞、都市防衛ライン、陸上戦艦打撃軍団など、通常戦力では突破不可能な戦略拠点を正面から粉砕する決戦兵力。
  - 圧倒的な質量と超巨大鎌腕により、敵戦車やトーチカを一撃で踏み潰し・蹂躙する。
- **超大型接近戦型と長距離砲撃型の明確な分離**:
  - 本部隊は**「超大型接近戦型」**に特化した部隊であり、遠距離砲撃は行わない。
  - 砲撃任務は別個の「長距離砲撃軍団（超大型ニードル砲撃型）」が担当する。

## 3. 構成個体スペックと戦闘メカニクス

### 3.1 超大型接近戦型巨獣 (Titan Melee Colossus)
- **体格**: タイタン級（全高18〜25m、全長30〜45m、重量300〜500トン）。
- **特徴**:
  - 地震のような地響きを伴って進撃する超巨大生体兵器。
  - **超重複合キチン装甲**: 重戦車のAPFSDS徹甲弾や大口径榴弾の直撃を多数受けても進撃を停止しない規格外の耐久力。
  - **超巨大鎌腕と踏み潰し**:
    - 主力戦車を一瞬でペシャンコに圧壊する巨大な足踏みと、バンカーや防壁を薙ぎ払うビル大の鎌腕。
    - 敵防衛線に肉薄した場合、1個大隊規模の戦力を数分で物理的に粉砕・蹂躙する。
  - **遠距離攻撃能力の欠如**: 射撃兵器は一切持たず、敵陣地に突入して初めてその破壊力を発揮する。

### 3.2 巨獣専従対空種 (Colossus AA Protector)
- **体格**: 大型〜超大型（重量40トン級）。
- **兵装**:
  - **近接信管生体弾幕砲**: 高度数千メートルまで届く生体破片弾を高密度で連射。
  - **長距離自律追尾生体ミサイル**: 巨獣を狙う敵大型爆撃機やステルス攻撃機を長距離から迎撃。
- **役割**: 巨大ゆえに敵航空攻撃の格好の標的となる巨獣を、上空からの誘導爆弾・対地ミサイルから防護。

### 3.3 巨大再生分泌種 (Mega-Regeneration Beast)
- **役割**: 巨獣の巨体に対応するため、タンク車数台分に相当する生体修復ゼリーを連続噴出し、深層の筋肉組織や甲殻を急速再生。

## 4. 作戦特性・運用ルール

1. **要塞・都市粉砕能力**:
   - 地形障害物やトーチカ、都市建造物を「障害物」として扱わず、踏み潰しながら直進可能。
2. **長距離砲撃・ミサイルへの脆弱性**:
   - 接近戦に持ち込めば無敵の強さを誇るが、接近するまでに人類の「長距離ミサイル打撃軍団」や「陸上戦艦打撃軍団」の超長距離レールガン砲撃に晒された場合、突入前に甚大な損傷を被るリスクがある。
3. **足元防護の重要性**:
   - 巨獣の足元に敵の対戦車歩兵や小型車両が潜り込むと死角となるため、随伴の中型・小型格闘種が密着して護衛を展開する。
