# 野生・固有エイリアン陸上軍団 編制・生態仕様書 (Native Ground Alien Corps TO&E)

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../GAME_DESIGN.md) に基づき、野生エイリアンの陸上軍団および生体兵器カテゴリーを規定する仕様書である。

> [!NOTE]
> **野生エイリアンの戦闘ドクトリンと生態**:
>
> - **格闘種の威力階層と破壊時間**:
>   - **戦車型（大型格闘種）**: 主力戦車を一撃で破壊する超兵器ではなく、「**厚い装甲に張り付き、長い時間を掛けて装甲板を切り刻み・こじ開けて破壊する**」。
>   - **中型格闘種**: 「**大型格闘種にできないことは中型格闘種にもできない**」原則に従う。主力戦車は破壊できず、**装甲車（IFV/APC）に対しても破壊するのに長い時間がかかる**。一方で**軽装甲車（4x4 LAVや非装甲トラック）なら短時間で切り裂き・破壊**できる。
>   - **小型格闘種**: 装甲目標には歯が立たず、下車歩兵や非装甲目標の殺傷・足止めに特化。
> - **指揮種の排除**: 人間のような指揮通信車に相当する「指揮種」は存在しない。群生本能やフェロモン連鎖によって自律的に前進・群がる。
> - **対空能力の例外保持**: 空中からの航空攻撃に一方的に蹂躙されるのを防ぐため、対空種のみ**生体機関砲による近接信管砲弾（対空破片炸裂弾）**と**生体ミサイル（自律追尾生体弾）**による本格的な対空迎撃火力を例外的に保持する。
> - **超大型種（タイタン級）と部隊の分離**:
>   1. **超大型エイリアン軍団**: 超大型接近戦型巨獣を基幹とし、圧倒的な質量と超巨大鎌腕で敵陣地や戦車を踏み潰し・蹂躙する部隊。
>   2. **長距離砲撃軍団**: 超大型ニードル砲撃型巨獣を基幹とし、巨体の割にはミサイル程度の威力しかない長距離ニードル（巨大棘弾）を遠距離から放物線投射する部隊。
> - **陸棲航空型**: 制空権確保は空棲種（エイリアン航空団）の役割とし、陸棲航空型は低空急降下して敵地上部隊へ「**近接空中格闘襲撃**」を仕掛ける飛行怪獣。

## 1. エイリアン生体兵器・種別体系（個体カテゴリー）

| 生体種別 | 体格・規模 | 主な特徴・戦闘能力 |
| :--- | :--- | :--- |
| **小型格闘種** | 小型（人馬〜軽車両大） | 敏捷な四肢と鋭い爪・小鎌を持つ格闘個体。装甲目標には通用しないが、敵歩兵や非装甲目標に群がって殺傷する。 |
| **中型格闘種** | 中型（装甲車大） | 戦車型より一回り小さいカマキリ状格闘種。**大型格闘種にできないことは中型にもできず戦車は破壊不能**。**装甲車（IFV/APC）の破壊には時間がかかるが、軽装甲車（4x4 LAV）なら短時間で解体・破壊**する。機関砲等の射撃兵器は持たない。 |
| **戦車型（大型格闘種）** | 大型（主力戦車大） | 重厚なキチン殻を持つ大型カマキリ状怪獣。一撃必殺ではなく、**敵戦車に組み付き、長い時間をかけて装甲を切り裂き・剥ぎ取って破壊**する。装甲車相手ならより短時間で破壊可能。 |
| **超大型接近戦型** | 超大型（タイタン級: 全高20m級） | 圧倒的な質量と超巨大鎌腕を持つ決戦格闘巨獣。敵防衛線に肉薄し、戦車や陣地を踏み潰して圧壊する。 |
| **超大型ニードル砲撃型** | 超大型（タイタン級: 全高20m級） | 巨体の割には**ミサイル程度の威力**の巨大生体ニードル（高圧骨棘弾）を遠距離から放物線砲撃する巨獣。長射程だが大味。 |
| **陸棲航空型（飛行格闘種）** | 有翼飛行型（ワイバーン型） | 制空戦闘ではなく、低空急降下して敵地上部隊（装甲車両の上面や下車歩兵）に爪・鎌腕で「**空中格闘襲撃**」を仕掛ける飛行生物。 |
| **対空種** | 中型〜大型 | **生体機関砲の近接信管砲弾**（目標付近で破片が炸裂する濃密対空弾幕）と**生体ミサイル**（高機動で敵機を追尾する自律生体弾）を完備し、敵戦闘機・攻撃ヘリを迎撃する防空個体。 |
| **治療種** | 中型（再生分泌種） | 負傷した個体の甲殻や鎌腕に修復分泌液を塗布し、急速に組織を再生させる個体。 |

## 2. エイリアン陸上軍団（部隊カテゴリー）

人類の兵器編成をそのまま真似るのではなく、生物のサイズ・階層（小型・中型・大型・超大型）および専用役割をベースとした生体軍団体系を展開する。

| 軍団種別 | 構成エシュロン | 主な特徴・戦闘ドクトリン |
| :--- | :--- | :--- |
| **小型エイリアン軍団** | 小型格闘種 主体 | 数千〜数万頭の小型格闘種が津波のように押し寄せる軽量スウォーム軍団。隘路・密林・山岳での浸透突撃に優れる。 |
| **中型エイリアン軍団** | 中型格闘種 基幹 ＋ 小型種 | カマキリ状中型格闘種を主力とし、足元を小型種が埋めるバランス型突撃軍団。軽装甲部隊や拠点を力押しで圧迫。 |
| **大型エイリアン軍団** | 戦車型（大型格闘種） 基幹 ＋ 中型・小型種 | 戦車型大型格闘種が前面に立ち、敵戦車隊と泥沼の格闘戦を展開しつつ、中型・小型種が浸透して包囲殲滅を図る主力軍団。 |
| **超大型エイリアン軍団** | 超大型接近戦型 ＋ 直協群 | 全高20m級の格闘巨獣を核とする決戦軍団。圧倒的な巨体質量と大鎌で敵防衛線・戦車を踏み潰して前進。 |
| **長距離砲撃軍団** | 超大型ニードル砲撃型 ＋ 護衛群 | 超大型ニードル砲撃巨獣を中核とする長距離投射部隊。遠距離からミサイル程度のニードル弾を放物線投射して散発的支援・牽制。 |
| **陸棲航空格闘軍団** | 陸棲航空型（飛行格闘種） 主体 | 有翼格闘種が低空急降下し、地上部隊の頭上や車両上面を鋭い鎌腕と爪で切り裂く地上急襲航空群（制空権確保は空棲種の担当）。 |

## 3. 各軍団の詳細編成仕様 (TO&E)

### 3.1 小型エイリアン軍団 (Small Swarm Corps)

- **役割**: 山岳、密林、洞窟などの不整地を自在に移動し、数と機動力で敵前線を圧迫・包囲。
- **構成**:
  - **小型格闘種**: 鋭い爪と素早い機動で歩兵や非装甲車両に肉薄する格闘個体。
  - **対空種（小型迎撃型）**: 近接信管生体弾幕で上空のヘリ・低空航空機を迎撃。
  - **治療種**

### 3.2 中型エイリアン軍団 (Medium Swarm Corps)

- **役割**: 人類の軽装甲・装甲化部隊に対抗する主力格闘軍団。4x4軽装甲車なら短時間で切り刻み、装甲車（IFV/APC）に対しては時間を掛けて解体・制圧を図る。
- **構成**:
  - **中型格闘種**: 戦車型より一回り小さいカマキリ状格闘個体。戦車は破壊できないが、軽装甲車（LAV）を素早く解体し、装甲車（IFV/APC）には時間を掛けて装甲板をこじ開ける。
  - **小型格闘種**: 中型種の隙間を埋めて敵歩兵を掃討し、足を止める随伴群。
  - **対空種**: 生体機関砲の近接信管砲弾と生体ミサイルで敵攻撃機・ヘリを迎撃。
  - **治療種**

### 3.3 大型エイリアン軍団 (Heavy Tank-Beast Corps)

- **役割**: 人類の機甲軍団・装甲化軍団に正面から激突する決戦部隊。
- **構成**:
  - **戦車型（大型格闘種）**: 主力戦車と同等以上の体躯と重キチン殻を持つ格闘怪獣。敵戦車に組み付き、長い時間を掛けて鎌腕で装甲を破壊。
  - **中型格闘種**: 戦車型の側背を護衛し、敵の随伴歩兵・IFVを掃討。
  - **小型格闘種**: 敵の視界や射線を奪う前衛スクリーン。
  - **対空種（大型防空型）**: 機甲戦の頭上を守る濃密な近接信管弾幕と自律追尾生体ミサイル網。
  - **治療種**

### 3.4 超大型エイリアン軍団 (Colossus Behemoth Corps)

- **役割**: 要塞や都市、主防衛線を正面粉砕する規格外の超巨大接近戦軍団。
- **構成**:
  - **超大型接近戦型**: 全高20m級。敵の砲火を浴びながら前進し、巨大な鎌腕と踏み潰しで陣地・戦車を一掃。
  - **護衛用中型・小型格闘種**: 巨獣の足元に敵歩兵や対戦車兵が取り付くのを防ぐ護衛群。
  - **対空種（統合防空個体）**: 巨獣の巨躯を狙う敵爆撃機や対地攻撃機を近接信管砲弾と大型生体ミサイルで迎撃。
  - **大型治療種**

### 3.5 長距離砲撃軍団 (Long-Range Needle Artillery Corps)

- **役割**: 超大型ニードル砲撃種を中核とし、遠距離から敵拠点や防衛線へ向けて放物線ニードル投射を行う支援砲撃部隊。
- **構成**:
  - **超大型ニードル砲撃型**: 巨体の割にはミサイル程度の威力しかない巨大ニードル弾を遠距離から放物線投射し、敵陣地を散発的に嫌がらせ・牽制。
  - **護衛用中型・小型格闘種**: 発射位置を固める接近戦護衛群。
  - **対空種（陣地防衛型）**: 砲撃巨獣を上空からの航空攻撃から防護。
  - **治療種**

### 3.6 陸棲航空格闘軍団 (Aviation Melee Swarm)

- **役割**: 制空権確保は空棲種（エイリアン航空団）の任務であるため、陸棲航空型は制空権争いではなく、低空から直接敵地上部隊へ急降下して「**地上部隊への近接空中格闘・奇襲**」を行う航空格闘部隊。
- **構成**:
  - **陸棲航空型（飛行格闘種）**: 翼幅10〜15mの有翼生物。低空急降下して装甲車両の上面や砲塔、指揮所、下車歩兵を爪と鎌腕で切り裂く。
