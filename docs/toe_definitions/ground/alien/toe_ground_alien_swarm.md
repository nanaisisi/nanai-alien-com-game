# 野生・固有エイリアン陸上軍団 編制・生態仕様書 (Native Ground Alien Corps TO&E)

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../GAME_DESIGN.md) および [`../../../force_structure/concept_corps_and_division_echelons.md`](../../../force_structure/concept_corps_and_division_echelons.md) に基づき、人類陸上軍団（2個師団統合制・諸兵科連合）と完全に一致する兵種体系を持つ**「野生・固有エイリアン陸上軍団（Native Ground Alien Corps）」**の編制体系および生体構成を規定する仕様書である。

> [!NOTE]
> **エイリアンの移動形態について**:
> エイリアンは装軌・装輪などの機械的駆動ではなく「すべて自肢で歩行・疾走・跳躍・飛翔」する。複雑な車体区分にこだわる必要はなく、人類の兵器機能（戦車砲、機関砲、ミサイル、迫撃砲、榴弾砲、対空火器、指揮、治療、輸送）と1対1で対応する**「生体種別（生体ロール）」**によって軍団が構成される。

---

## 1. 組織思想（人類兵種との完全一致）

野生エイリアン陸上軍団は、人類正規軍団の各兵種カテゴリーと1対1で完全に一致する機能・規模を持つ。

| 人類軍団種別 | エイリアン軍団種別 | 主な役割・戦闘特性 |
| :--- | :--- | :--- |
| **軽歩兵軍団** | **エイリアン軽歩兵軍団** | 不整地・山岳・森林での展開力に優れた中型格闘・生体火器群 |
| **自動車化歩兵軍団** | **エイリアン自動車化歩兵軍団** | 乗り物種（輸送種）と弾丸発射型・迫撃砲種による高速展開部隊 |
| **装輪機動軍団** | **エイリアン装輪機動軍団** | 平原・道路での高速疾走と生体機関砲・生体ミサイルによる強襲 |
| **空中機動軍団** | **エイリアン空中機動軍団** | 有翼飛行個体による地形無視の垂直急襲・後方遮断 |
| **装甲化軍団** | **エイリアン装甲化軍団** | 戦車種・弾丸発射型・榴弾種・対空種による諸兵科連合バランス型部隊 |
| **機甲軍団** | **エイリアン機甲軍団** | 超大型戦車種（タイタン級）を基幹とする圧倒的不整地突破・決戦打撃 |
| **歩行戦闘軍団** | **エイリアン歩行戦闘軍団** | 高脚逆関節種・跳躍種による都市廃墟や段差障害の立体跳躍戦闘 |
| **長距離ミサイル打撃軍団** | **エイリアン長距離ミサイル打撃軍団** | 2タイル先の敵拠点・部隊への長距離ミサイル種による弾道投射 |

## 2. エイリアン生体兵器・種別体系（人類兵器ロールとの対応）

エイリアン軍団を構成する各個体は、人類の装甲戦闘車両・火砲・支援システムと機能的に1対1で対応している。

| 人類兵器・機能 | エイリアン生体種別 | 主な戦闘能力・特徴 |
| :--- | :--- | :--- |
| **主力戦車 (MBT)** | **戦車種** | 極厚のキチン質重甲殻を持ち、直射で重装甲を撃ち抜く高初速徹甲弾（骨弾/超高圧ジェット）を射出。 |
| **機関砲搭載装甲車 (IFV/RCV)** | **弾丸発射型（生体機関砲種）** | 硬質有機弾を高回転・連続発射する生体機関砲器官を備え、対軽装甲・対歩兵・弾幕掃討を担当。 |
| **対戦車誘導弾 (ATGM)** | **生体ミサイル発射種** | 熱や電波、金属反応を自律追尾する誘導生体ミサイルを背部から連続射出。 |
| **自走迫撃砲 (120C)** | **迫撃砲種** | 背部の大口径射出孔から高粘度強酸弾や有機クラスター弾を高角曲射し、障害物越しの敵を面制圧。 |
| **自走榴弾砲 (155C/160C)** | **榴弾種** | 長大な生体砲身器官から大威力榴弾を中・長距離曲射し、敵陣地や敵部隊を破砕。 |
| **TEL長距離ミサイル** | **長距離ミサイル種** | 2タイル先の敵拠点・部隊へ成層圏経由で届く超長距離生体弾道弾を射出する超大型種。 |
| **自走対空機関砲 ＋ 対空SAM** | **対空種** | **生体対空機関砲**（高角濃密破片弾幕）と**生体対空ミサイル**（超音速追尾飛行弾）を完備した対空防衛種。 |
| **指揮通信車 (CP/C4I)** | **指揮種** | 強力なシナプス波・フェロモンを放ち、群れの目標集中、射撃統制、統率・士気を維持する中枢脳波種。 |
| **救護・外科車 (AME/MED)** | **治療種** | 前線で損傷した生体の甲殻や筋肉に高濃度修復液・成長因子を注入し、急速細胞再生を行う。 |
| **IFV / APC（装甲兵員輸送・戦闘車）** | **装甲腹腔種（装甲乗り物種）** | 強固な外骨格・甲殻に覆われた内部腹腔（キャビティ）に戦闘個体を収容・防護して運搬。上部に生体機関砲や生体ミサイル器官を備えた戦闘型（IFV相当）と、大容量兵站・人員輸送型（APC相当）が存在。 |
| **トラック / 非装甲・軽輸送車両** | **背乗り種（非装甲乗り物種）** | 露出した背部や平坦な外殻の上に戦闘個体や資材を多数乗せて高速運搬する四肢・多脚種。装甲による完全防護はないが、軽快かつ迅速な乗下車・物資展開が可能。 |

## 3. カテゴリー別詳細編制序列 (TO&E)

### 3.1 エイリアン軽歩兵軍団 (Alien Light Infantry Corps)

- **役割**: 人類軽歩兵軍団と一致。険峻な山岳、断崖、密林、洞窟を自在に踏破行軍し、近接格闘および酸弾射撃を行う。
- **構成**:
  - **弾丸発射型（軽甲殻）**: 不整地を俊敏に移動し、有機弾頭を連射する中型戦闘個体。
  - **迫撃砲種（軽快型）**: 険峻な地形から高角で酸弾を曲射支援する砲撃個体。
  - **突撃格闘種**: 肉薄して敵の防衛線を突破する中型格闘個体。
  - **指揮種**、**治療種**

### 3.2 エイリアン自動車化歩兵軍団 (Alien Motorized Infantry Corps)

- **役割**: 人類自動車化歩兵軍団（4x4 LAV基幹）と一致。背乗り種（軽快輸送）や装甲腹腔種に搭乗・随伴して迅速に展開・陣地制圧を行う。
- **構成**:
  - **背乗り種（非装甲高速輸送）**: 背部に戦闘個体を乗せて高速行軍・即応展開する四肢種。
  - **装甲腹腔種（生体機関砲装備型）**: 腹腔に戦闘個体を保護・収容し、生体機関砲で支援する前線強襲型。
  - **弾丸発射型**: 機関砲・生体火器による制圧射撃個体。
  - **迫撃砲種**: 120C自走迫相当の曲射支援個体。
  - **生体ミサイル発射種**: 車両・重目標を狙撃する誘導弾投射個体。
  - **対空種**、**指揮種**、**治療種**

### 3.3 エイリアン装輪機動軍団 (Alien Wheeled Mobile Corps)

- **役割**: 人類装輪機動軍団（8x8 Std-W8）と一致。平原・舗装路での猛烈な長距離疾走と、前線での強力な装甲突撃・火力を両立。
- **構成**:
  - **疾走戦車種**: 時速80〜90kmで長距離を走り抜ける高速巡航・重装甲突撃種。
  - **弾丸発射型（重装甲疾走種）**: 8輪IFV相当の分厚い甲殻と連射生体機関砲を持つ主力種。
  - **装甲腹腔種（高速重装甲型）**: 8輪APC相当。分厚い装甲腹腔内に個体を収容して前線に突入。
  - **生体ミサイル発射種**: 疾走しながら誘導弾を斉射する高機動打撃個体。
  - **迫撃砲種**、**対空種（機関砲・ミサイル完備）**
  - **指揮種**、**治療種**

### 3.4 エイリアン空中機動軍団 (Alien Airmobile Strike Corps)

- **役割**: 人類空中機動・空地強襲軍団と一致。地形障害を完全無視して低空・中空から敵後方や重要拠点を垂直急襲。
- **構成**:
  - **有翼格闘飛翔種（ワイバーン型）**: 低空急降下して敵部隊を強襲する主力飛行戦闘種。
  - **空中生体機関砲・酸爆撃種**: 上空から濃密な弾幕と強酸爆弾を投射する対地制圧飛行種。
  - **飛翔腹腔種（巨大嚢胞空輸種）**: 地上戦闘種や物資を体内に抱え込み、前線不整地に直接空輸展開。
  - **空中指揮種**、**空中治療種**

### 3.5 エイリアン装甲化軍団 (Alien Armored Combat Corps)

- **役割**: 人類装甲化軍団（諸兵科連合）と一致。戦車種・弾丸発射型・榴弾種・対空種が有機的に連携するバランス型主力打撃群。
- **構成**:
  - **戦車種**: 前線で敵戦車・強固な陣地と直射交戦を行う重装甲主力種。
  - **弾丸発射型（重装甲種）**: 戦車に直随伴して弾幕を張り、敵歩兵や軽車両を掃討。
  - **装甲腹腔種（IFV/APC型）**: 戦車直協で戦闘個体を保護・展開し、生体機関砲で援護。
  - **生体ミサイル発射種**: 敵装甲目標を遠距離から精密撃破。
  - **榴弾種**: 160C砲塔自走榴弾砲相当の連続曲射支援を行う中型重砲撃種。
  - **対空種**: 生体対空機関砲と対空ミサイルで部隊上空の防空傘を形成。
  - **指揮種**、**治療種**、**背乗り種（弾薬・物資運搬）**

### 3.6 エイリアン機甲軍団 (Alien Heavy Armored Corps)

- **役割**: 人類常設増強機甲軍団（重戦車4連隊基幹）と一致。圧倒的不整地突破力と戦略打撃力を持つ決戦軍団。
- **構成**:
  - **超大型戦車種（タイタン級）**: 全高15〜20m。重戦車の主砲直撃にも耐える超重甲殻と破壊的直射砲器官を持つ決戦巨獣。
  - **超重榴弾種**: 210C車体据付超重自走砲に匹敵する破壊力で、敵要塞や防衛線を粉砕する大型砲撃種。
  - **弾丸発射型（重装甲随伴種）**、**生体ミサイル発射種**
  - **超重装甲腹腔種**: 最重装甲で個体を保護して敵主防衛線内部へ強行突入・展開。
  - **対空種（統合防空個体群）**: 巨獣の頭上を覆う重対空弾幕・ミサイル迎撃網。
  - **中枢指揮種**、**大型治療種（急速再生結節）**、**重補給背乗り種**

### 3.7 エイリアン歩行戦闘軍団 (Alien Bipedal Assault Corps)

- **役割**: 人類歩行戦闘車両軍団（二脚混成）と一致。都市廃墟、瓦礫帯、巨大段差での立体跳躍・死角奇襲を担当。
- **構成**:
  - **跳躍高脚戦車種**: 長い逆関節脚で高所や障害物の陰へ跳躍し、立体射界から直射徹甲弾を撃ち込む中型歩行種。
  - **弾丸発射型（跳躍種）**: ビル屋上から屋上へ跳躍しながら生体機関砲を乱射。
  - **生体ミサイル発射種（跳躍型）**: 死角から急浮上・跳躍して誘導弾を撃ち下ろす。
  - **高脚対空種**、**跳躍指揮種**、**治療種**

### 3.8 エイリアン長距離ミサイル打撃軍団 (Alien Long-Range Missile Strike Corps)

- **役割**: 人類長距離ミサイル打撃軍団（重装輪TEL基幹）と一致。2タイル先の後方から敵拠点・部隊へスタンドオフ弾道投射を行う。
- **構成**:
  - **長距離ミサイル種**: 成層圏まで届く大型生体弾道弾を背部射出孔から垂直発射する超大型種。
  - **目標指示観測種**: 前線で高周波・生体フェロモンを発し、長距離ミサイルへ着弾目標座標を誘導伝達。
  - **対空種（陣地防衛）**: 後方発射陣地を敵航空攻撃から防護。
  - **護衛用弾丸発射型**、**指揮種**、**治療種**
