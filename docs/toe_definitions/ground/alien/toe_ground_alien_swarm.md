# 野生・固有エイリアン陸上軍団 編制・生態仕様書 (Native Ground Alien Corps TO&E)

本ドキュメントは、[`../../../GAME_DESIGN.md`](../../../GAME_DESIGN.md) のセクション 3.1.2 に基づき、人類陸上軍団（2個師団統合制・諸兵科連合）と完全に一致する兵種体系を持つ**「野生・固有エイリアン陸上軍団（Native Ground Alien Corps）」**の編制体系および生体構成を規定する仕様書である。凝った独自設定ではなく、人類軍団の兵種に対応した生体軍団として定義される。

---

## 1. 組織思想（人類兵種との完全一致）

野生エイリアン陸上軍団は、人類正規軍団の各兵種カテゴリーと1対1で完全に一致する機能・規模を持つ。

| 人類軍団種別 | エイリアン軍団種別 | 主な役割・戦闘特性 |
| :--- | :--- | :--- |
| **軽歩兵軍団** | **エイリアン軽歩兵軍団** | 徒歩主体の生体突撃群。山岳・隘路・森林・不整地への高い適性 |
| **自動車化歩兵軍団** | **エイリアン自動車化歩兵軍団** | 軽装甲中型四肢獣と生体酸迫撃・生体砲による高速機動展開 |
| **装輪機動軍団** | **エイリアン装輪機動軍団** | 平原・道路での猛スピード疾走と装甲突撃・火力投射の両立 |
| **空中機動軍団** | **エイリアン空中機動軍団** | 有翼飛行個体による地形無視の垂直急襲・後方遮断 |
| **装甲化軍団** | **エイリアン装甲化軍団** | 重キチン殻中型獣・索敵肢獣・生体自走砲によるバランス型突破 |
| **機甲軍団** | **エイリアン機甲軍団** | 超大型巨獣（タイタン級）を基幹とする圧倒的不整地突破・決戦打撃 |
| **歩行戦闘軍団** | **エイリアン歩行戦闘軍団** | 逆関節高脚獣・跳躍獣による都市廃墟や段差障害の立体跳躍戦闘 |
| **長距離ミサイル打撃軍団** | **エイリアン長距離ミサイル打撃軍団** | 2タイル先の敵拠点・部隊への長距離生体胞子弾道投射 |
| **調査軍団** | **エイリアン調査軍団** | 未知環境探査・地下巣穴拡張・生体防護に特化した調査群 |

## 2. カテゴリー別詳細編制序列 (TO&E)

### 2.1 エイリアン軽歩兵軍団 (Alien Light Infantry Corps)
- **役割**: 人類軽歩兵軍団と一致。険峻な山岳、断崖、密林、洞窟を自在に行軍し、近接肉薄攻撃を行う。
- **イメージ・構成**:
  - **軽装甲爪獣群**: 歩兵サイズの四肢格闘種。密集隊形による強襲。
  - **酸噴射小型種**: 携帯火器・迫撃砲相当の射程で高圧強酸を噴射。
  - **壁面登攀突撃体**: 垂直の岩壁や建築物を登攀して奇襲。

### 2.2 エイリアン自動車化歩兵軍団 (Alien Motorized Infantry Corps)
- **役割**: 人類自動車化歩兵軍団（4x4 LAV基幹）と一致。軽装甲と機動力を兼ね備え、迅速な展開・陣地占領を行う。
- **イメージ・構成**:
  - **軽甲殻四肢獣**: 軽装甲車に匹敵する速度と装甲を持つ中型四肢種。
  - **生体酸液迫撃種**: 120C自走迫撃砲相当の面制圧酸弾を投射。
  - **小型生体砲射出種**: 155C榴弾砲相当の遠距離酸弾を投射。

### 2.3 エイリアン装輪機動軍団 (Alien Wheeled Mobile Corps)
- **役割**: 人類装輪機動軍団（8x8 Std-W8）と一致。平原・舗装路での高速巡航と強力な正面突撃・火力を両立。
- **イメージ・構成**:
  - **高速四肢疾走甲殻獣**: 時速90kmで長距離を疾走する大型中型獣。
  - **衝角中型獣**: MCV/IFVに匹敵する質量と装甲で敵車両を体当たり粉砕。
  - **生体徹甲角個体**: 主力戦車の側面をも貫く硬質角を持つ強襲種。

### 2.4 エイリアン空中機動軍団 (Alien Airmobile Strike Corps)
- **役割**: 人類空中機動・空地強襲軍団と一致。地形障害を完全無視して低空・中空から敵後方や重要拠点を垂直強襲。
- **イメージ・構成**:
  - **中型有翼ワイバーン**: 翼幅10m。低空急降下による対地襲撃。
  - **低空滑空捕食種**: 音もなく滑空して指揮所や下車歩兵を強襲。
  - **滞空酸爆撃個体**: 有機爆弾を抱えて中空に滞空し、頭上から精密投下。

### 2.5 エイリアン装甲化軍団 (Alien Armored Combat Corps)
- **役割**: 人類装甲化軍団（諸兵科連合）と一致。戦車連隊・装輪偵察連隊の組み合わせに相当するバランス型主力打撃群。
- **イメージ・構成**:
  - **重キチン殻中型獣**: 機関砲に耐える重装甲を持ち前線を突破。
  - **前腕衝角種**: 障害物や陣地を粉砕する重突撃体。
  - **高速索敵肢獣**: 左右両翼を哨戒・スクリーン展開する俊敏種。
  - **生体自走砲種**: 前線に直協して曲射支援を行う中型砲撃種。

### 2.6 エイリアン機甲軍団 (Alien Heavy Armored Corps)
- **役割**: 人類常設増強機甲軍団（重戦車4連隊基幹）と一致。圧倒的不整地突破力と戦略打撃力を持つ決戦軍団。
- **イメージ・構成**:
  - **破城超大型巨獣（タイタン級）**: 全高20m超、重戦車の主砲直撃にも耐える超巨大怪獣。
  - **生体プラズマ投射巨獣**: 重戦車砲・重特科を凌駕するプラズマ弾を直射・曲射。
  - **共生護衛群**: 巨獣の体表や足元を護衛し、対戦車攻撃を迎撃する小型種群。

### 2.7 エイリアン歩行戦闘軍団 (Alien Bipedal Assault Corps)
- **役割**: 人類歩行戦闘車両軍団（二脚混成）と一致。都市廃墟、瓦礫帯、巨大段差での立体跳躍・死角奇襲を担当。
- **イメージ・構成**:
  - **高脚逆関節怪獣**: 長い逆関節脚で高所や障害物の陰へ水平射撃・踏み込み。
  - **跳躍大顎種**: ビル屋上から屋上へ跳躍し、立体的な死角から急襲。
  - **立体機動生体個体**: 瓦礫や狭隘な路地で素早く身を隠しながら格闘戦を展開。

### 2.8 エイリアン長距離ミサイル打撃軍団 (Alien Long-Range Missile Strike Corps)
- **役割**: 人類長距離ミサイル打撃軍団と一致。2タイル先の後方から敵拠点・部隊へスタンドオフ弾道投射を行う。
- **イメージ・構成**:
  - **大深度生体胞子射出巨獣**: 成層圏まで届く大型生体弾道弾を背部射出孔から垂直発射。
  - **弾道酸投射種**: 長距離曲射によって着弾エリアを強酸と爆圧で面制圧。
  - **共鳴目標指示種**: 前線で超低周波を発し、長距離砲獣へ目標座標を伝達。

### 2.9 エイリアン調査軍団 (Alien Survey & Exploration Corps)
- **役割**: 人類調査・科学探査軍団と一致。未知バイオームの探査、巣穴開拓、環境適応解析を担当。
- **イメージ・構成**:
  - **探査触手種**: 地質・大気成分・鉱脈を敏感に感知する感知個体。
  - **環境適応変異種**: 放射線・有毒ガス・極限温度下でも活動可能な変異種。
  - **巣穴掘削防護体**: 調査隊の安全を確保しつつ地下坑道を掘削する大型工兵種。
