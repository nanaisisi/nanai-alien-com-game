# 指針ベース手動操作・意図伝達UI/UX仕様書

(Directive-Based Manual Control & Intent-Driven Interaction Architecture)

本作（4X大戦略＋サブタイル戦術・戦闘団制＋自律サプライチェーン）における**「プレイヤーが直接手動で部隊や方面軍へ介入する際に、マイクロマネジメント（ちまちました駒動かしや個別生産キュー）に堕ちず、大局的な『指針・意図（WHAT / GOAL）』を直感的に伝達する操作体系」**を体系化したUI/UX仕様書である。

---

## 1. 基本課題：手動操作における「手続き」と「指針」の断絶

従来のターン制大戦略・4Xゲームにおいて、手動操作が中盤以降に「クリック苦痛作業」へと破綻する根本原因は、プレイヤーが**「手続き（HOW）」を1手ずつ人力で入力させられる構造**にある。

```text
【従来の苦痛な手動操作（手続きの強制入力）】
  1. 都市Aをクリック
  2. 生産リストから「戦車」を1両ずつ選択
  3. 毎ターン完成した戦車を前線まで1ヘックスずつポチポチ移動
  4. 海岸で「輸送船」を作って乗せ、海上で海賊を避けて1マスずつ航行
  ➡ 領土と部隊が増えるにつれてクリック数が爆発し、ゲームが破綻。

【本作の指針ベース手動操作（目的・意図の提示）】
  1. 地図上に目標地点へ「太い作戦矢印（ベクトル）」を引く
  2. 「迅速行軍」「警戒索敵」「死守」などの姿勢（スタンス）を指定
  ➡ 移動経路、道路トラック牽引、港湾での船腹プール（SLC）消費、
     接敵時の下車戦闘隊形への移行は、すべて現場バランサーが自律解決。
```

---

## 2. 3大指針インターフェース（Directive Interaction Pillars）

プレイヤーが手動で介入する際のインターフェースを、以下の3つの直感的な「指針入力」に集約する。

```text
┌────────────────────────────────────────────────────────────────────────┐
│               【指針ベース手動操作の3大インターフェース】              │
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│ 1. 作戦ベクトル描画 (Mission Vector)                                   │
│    [部隊/戦闘団] ══════════(太い作戦矢印)══════════> [目標拠点/防衛線] │
│      └─ 道路トラック牽引・海上SLC消費・迂回索敵を自動選択              │
│                                                                        │
│ 2. 要求仕様・編制枠指定 (RFP & Group Blueprint)                        │
│    [戦闘団インスペクター] ──> [ドクトリンタグ: 機動装甲重視]           │
│      └─ 工廠ラインのロット生産・動脈自動回送・損耗自動補充             │
│                                                                        │
│ 3. 交戦姿勢・交戦規程 (Stance & Rules of Engagement)                   │
│    [トグル切替]: 【急行・強行突破】 / 【警戒索敵】 / 【遅滞防衛】      │
│      └─ サブタイル交戦時の後退・盤外砲撃要請・下車タイミングを決定     │
│                                                                        │
└────────────────────────────────────────────────────────────────────────┘
```

### 2.1 作戦ベクトル描画（Mission Vector: 「どこへ向かうか」）

- **操作**: 部隊を選択し、ドラッグ＆ドロップまたは右クリック長押しで地図上に**「太い作戦矢印」**を引く。
- **自律解決（裏方の過程）**:
  - **舗装道路・鉄道網がある場合**: 近傍デポから非戦闘車両・トラックを自動牽引し、高速機動モードで巡航。
  - **海洋を跨ぐ場合**: 自動的に最寄り港湾へ急行し、国家の海上輸送船腹プール（SLC）を消費して海上回廊へ転進。
  - **敵性地域接近時**: 自動的に速度を落として下車し、戦闘隊形（警戒スタンス）へ展開。

### 2.2 要求仕様・編制枠指定（RFP Blueprint: 「どうありたいか」）

- **操作**: 戦闘団のドクトリン傾向をタグ（例: `[装甲打撃]`, `[軽歩兵山岳適応]`, `[長距離防護砲撃]`）で切り替える。
- **自律解決（裏方の過程）**:
  - 個別の車両や砲をプレイヤーが生産発注する必要はない。
  - 国内の工廠バランサーが自動で適合する共通モジュール・シャーシをロット生産し、物理インフラ動脈を通じて前線デポへ自動補充・換装する。

### 2.3 交戦姿勢・交戦規程（Stance & ROE: 「どう振る舞うか」）

部隊や方面軍に対し、状況に応じた「姿勢」を3大スタンスから選択する。

| スタンス名 | 挙動の指針 | メリット（現場の自律判断） | リスク・トレードオフ |
| :--- | :--- | :--- | :--- |
| **① 急行・強行突破(Fast Transit)** | 最速での目標到達を最優先 | 道路網やトラック牽引を限界まで維持して急行 | 奇襲を受けた際の展開遅延、待ち伏せ被弾時の脆弱性 |
| **② 警戒索敵・接敵前進(Cautious Recon)** | 安全第一での段階的前進 | 悪路や視界不良タイル手前で自動下車、偵察兵を先行展開 | 移動力半減、燃料消費増 |
| **③ 遅滞防衛・損害回避(Delaying Action)** | 時間稼ぎと戦力温存 | サブタイル戦闘で撃ち合わず、境界へ後退しながら盤外砲撃を要請 | 前線タイルの一時的後退、インフラ被弾リスク |

## 3. UI/UX表現とフィードバック（意図の可視化）

プレイヤーが指針を入力した際、UIは「今、現場がどう解釈して動いているか」を視覚的にフィードバックする。

```text
┌────────────────────────────────────────────────────────────────────────┐
│ 【メイン画面上の指針可視化】                                           │
│                                                                        │
│   [第1機甲戦闘団] ───(実線: 道路トラック移動)───> [A港]                │
│                                                    │                   │
│                                      (破線インジケータ: 海上航行 2T)   │
│                                                    │                   │
│                                                    ▼                   │
│                     [目標都市B] <───(警戒歩行)─── [B港]                │
│                                                                        │
│   ※ 矢印の上に「予想所要ターン: 4T (消費SLC: 5)」がツールチップ表示    │
└────────────────────────────────────────────────────────────────────────┘
```

1. **移動経路のハイブリッド描画**:
   - 陸上トラック区間（実線）、海上転進区間（波線インジケータ）、下車警戒区間（点線）が自動で色分け表示される。
2. **途中変更・キャンセル（柔軟な上書き）**:
   - 途中で戦況が変わった場合、矢印の先端を別の場所へドラッグし直すだけで、現場は即座に最寄りの安全ルートへ針路変更する。
3. **インスペクターでの「現場の解釈」表示**:
   - 部隊カードに「現在：港湾Aに向けて道路急行中（牽引トラック12両）」と、現場の執行状況が分かりやすいフレーバーテキストとして表示される。

## 4. 本設計がもたらすゲーム的価値

1. **ターン数や部隊数が増えても疲弊しない（スケーラビリティ）**:
   - 100の部隊があっても、プレイヤーが毎ターン触るのは「戦況が変わって指針を変えたい3〜5部隊の矢印・スタンス」だけ。
2. **「優秀な軍隊を指揮している」快感**:
   - 目的地を指示するだけで、軍隊が道路を走り、船に乗り、海岸で警戒隊形を組むスマートなシークエンスを眺める楽しさ。
3. **自律制御システムとの完全な整合**:
   - プレイヤーが「指針（WHAT）」を出し、独立自動バランサーが「経路・配分・平滑化（HOW）」を裏方で解き、結果が既存システムに表出するというアーキテクチャが美しく完結する。
