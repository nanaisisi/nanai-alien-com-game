# 国家ドクトリン・自動化ステアリングUI/UX仕様書

(National Doctrine & Automation Steering UI/UX Specification)

本ドキュメントは、本作（4X大戦略＋サブタイル戦術・戦闘団制）における**「指示せず誘導する（Steering）」プレイスタイルを支えるGUIダッシュボード、ドクトリン操作系、移行ラグの可視化、およびフィードバック提示**の設計仕様書である。

---

## 1. UI/UX設計のコアコンセプト

本作は「都市や兵器を1つずつ手動生産キューに入れる」伝統的な4X型マイクロマネジメントではなく、**「国家指導者としての大方針（ドクトリン・RFP）を発令し、現場の自律工廠と方面軍司令部を意図した方向へ誘導する」マクロステアリング**（[`../industry_logistics/concept_doctrine_and_equipment_steering.md`](../industry_logistics/concept_doctrine_and_equipment_steering.md)）を最大の特徴とする。

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        ステアリングUIの根幹思想                        │
└────────────────────────────────────────────────────────────────────────┘
  【直接命令の排除】
    ・「この工場でこの戦車を3台作れ」というボタンは存在しない。
    ・「主力戦車クラスは共通化率70%以上、防御重視で更新せよ」という要求仕様(RFP)を出す。
        │
  【移行ラグ（慣性）の直感的可視化】
    ・方針を変更しても、前線や工場は即座に切り替わらない。
    ・「工廠ライン転換ゲージ」「改修遅延ペナルティ」がグラフィカルに明示される。
        │
  【現場からの提案と追認（ボトムアップ・フィードバック）】
    ・現場工廠が開発した「現場改修キット（Field Mod）」を国家が制式採用するか否かの承認UI。
```

## 3. 主要操作コンポーネントとインタラクション仕様

### 3.1 共通化スライダーと移行ラグ・ゴーストゲージ

* **操作**:
  * プレイヤーがスライダーをドラッグすると、目標値（Target Point）が即座に移動。
* **表示（ゴーストゲージ方式）**:
  * 現在の実効値を示す**実線バー**と、目標値を示す**点線（ゴースト）バー**が表示される。
  * スライダーを大きく動かすほど、両者の乖離（ギャップ）が広がり、画面上に**「予想転換所要時間: ○○ターン」「想定整備ペナルティ: -△△%」**が赤字・警告アイコン付きでダイナミックにプレビューされる。
* **確定アクション**:
  * 「ドクトリン布告（Issue Decree）」ボタンを押すことで正式発令。即座に全国の工廠へ改修・再編命令が伝達される。

### 3.2 兵器クラス別 RFP（要求仕様）カード

各クラス（歩兵装具、装甲車台、多脚兵器、ドローン、海洋艦艇等）ごとに、独立した要求仕様カードを配置。

1. **基本スタンスのトグル**:
   * `[生存・防護重視]` / `[火力・射程重視]` / `[機動・展開力重視]` / `[生産性・消耗戦重視]`
2. **モジュール固定（Lockdown）指定**:
   * 「主砲口径は 120mm 共通規格のまま維持せよ」「動力は核融合セルを強制指定」など、特定の既存インフラ・弾薬サプライチェーン（[`../industry_logistics/concept_resource_economy_and_logistics.md`](../industry_logistics/concept_resource_economy_and_logistics.md)）を破壊しないための制約条件ピン留め機能。

### 3.3 現場発議（ボトムアップ・イノベーション）の承認ポップアップ

現場の戦闘団や地方工廠が過酷な実戦を経て独自に生み出した「現地改修（Field Mod）」が、定期的にステアリングトレイへ通知される。

* **UI演出**:
  * 画面右下の通知トレイに「整備兵のスパナ」アイコンが点滅。
  * クリックすると、改修されたモジュール比較図面（現行標準 vs 現場改修品）がポップアップ表示。
* **プレイヤーの意思決定**:
  * **[国家制式化]**: 予算と工業リソースを投じ、全軍の標準規格としてカタログ登録（Tech Webの派生ノードが即時アンロック）。
  * **[黙認・現地留保]**: その方面軍・戦闘団のみでの改造を許可（追加コストゼロだが、他部隊とのパーツ融通にわずかな非互換ペナルティ）。
  * **[軍紀違反・撤去命令]**: 改造を禁止し、正規規格へ強制復帰（統制は維持されるが、現場部隊の士気低下）。

## 4. 方面軍（Theater）および戦闘団との連携UI

全体マップ上で特定の戦闘団（Brigade）または方面軍司令部（HQ）を選択した際の、ステアリング連動インスペクター。

```text
┌────────────────────────────────────────────────────────┐
│ 【第2方面軍 (極地・ミズマ戦線)】           [HQ詳細]    │
├────────────────────────────────────────────────────────┤
│ ドクトリン受領状況: 85% 浸透 (新式弾薬への更新中)      │
│ 補給チェーン健全性: ● 良好 (最寄りデポから 2 タイル)   │
│                                                        │
│ [作戦方針スライダー]                                  │
│ 慎重・防壁構築 ──────●──────── 積極進出・哨戒          │
│                                                        │
│ [交戦規定 (ROE) スイッチ]                              │
│ [ 専守防衛 ]  [ 威嚇・グレーゾーン阻止 ]  [ 臨戦交戦 ] │
│                                                        │
│ 所属部隊の装備共通化率: 68% (自軍平均より高規格)       │
│ 不稼働兵器: 4両 (新型アクチュエータ部品待ち)           │
└────────────────────────────────────────────────────────┘
```

1. **補給・弾薬互換警告**:
   * 戦闘団が使用している弾薬規格（旧規格A型 vs 新規格B型）が、後方の補給パイプラインと不一致を起こしている場合、部隊アイコン上に「弾薬不整合マーク（黄色の弾丸！）」が点灯。
2. **ワンクリック重点補給指定**:
   * 「この方面軍を最優先転換地区に指定する（Priority Re-arming）」トグルを入れることで、全国の優先生産資材が集中配分され、移行ラグ期間を半減させる。

## 5. アクセシビリティおよび情報階層（Info-Hierarchy）設計

* **カラーユニバーサルデザイン**:
  * 安定状態: スレートブルー・シアン（落ち着いたSF計器調）
  * 移行中・転換中: アンバー（琥珀色・注意）
  * 重度の兵站混乱・弾薬枯渇: クリムゾンレッド（緊急警告）
* **ツールチップによる因果関係の説明**:
  * すべてのスライダーやステータスバーにマウスホバー（ホバーカード）を設行。
  * 例: 「なぜ整備ペナルティが -15% なのか？」→ *「3ターン前に主力戦車のエンジンモジュール規格を急変させたため、第2工廠での工具再調整と整備兵の再教育が完了していません（あと3ターンで解消）」* と具体的な文脈を表示。
