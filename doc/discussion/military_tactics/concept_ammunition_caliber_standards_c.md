# 入植惑星における独自弾薬・火砲規格体系（C規格 / 単位：C）

本ドキュメントは、入植惑星における兵器・兵站体系の中核をなす独自火砲・弾薬単位**「C規格（単位：C / シー）」**の世界観的成立背景、物理単位の定義、口径階層、およびゲームシステム（兵器モジュール・サプライチェーン・共通化ドクトリン）との連動仕様を定義する。

---

## 1. 世界観的成立背景（なぜ統一されたC規格が存在するのか）

### 1.1 母星冷戦の終結・雪解け期と規格統一の歴史

かつて母星文明にも長期にわたる冷戦時代が存在し、各陣営・軍閥が独自の火器体系や雑多な口径・弾薬規格を乱立させていた。

しかし、**冷戦終結に伴う雪解け期（Detente）とそれに続く爆発的なグローバル化（経済・産業の一体化）**が訪れた際、地球の現実史をはるかに上回る徹底的な軍縮と国際工業標準化運動が断行された。

1. **グローバル経済圏の統合と徹底した軍事標準化**:
   - 多国籍重工企業と国際統括機関の主導により、兵站互換性と生産効率を阻害していた旧時代の乱立規格を全面的に整理・統合。
   - 工作機械の共通化と将来の装薬モジュール化を見据え、火器の内径（ボア径）を整然とした整数ステップで統一する**「C規格（単位：C）」**が策定された。
2. **外星入植船団への継承とフロンティアでの重要性**:
   - 母星での資源逼迫に伴い計画された外星入植において、この高度に合理化されたC規格が共通軍事標準（Baseline）として各勢力の船団にそのまま持ち込まれた。
   - 母星からの補給線が途絶し、限られた工作機械と現地資源で弾薬・砲身を自給自足しなければならない入植地において、この規格統一は兵站破綻を防ぐ絶対的な基盤となった。
3. **対エイリアン生態系（硬質外骨格・高密度群生体）への適応**:
   - 異星特有の頑強な原生生物に対抗するため、口径ピッチ（C単位）の体系自体は維持したまま、薬室構造や推進方式（ケースレスCT弾、高密度徹甲弾、電熱化学ETC等）をモジュール単位で進化させることで適応を果たしている。

## 2. 単位「C（シー）」の定義とゲームデザイン上の位置づけ

### 2.1 ゲームデザイン・プレイヤー体験上の意図

- **ミリメートルを連想させる直感的な数値スケール**:
  - 本作の舞台は地球ではないため地球固有の度量衡（メートル法やインチ法）そのものは登場しないが、プレイヤーが兵器の威力や役割を直感的に把握できるよう、**「ミリメートルっぽい親しみやすい数値感覚（6C＝小銃、30C＝機関砲、105C＝戦車主砲など）」**として設計されている。
  - 端数の多い現実のミリ口径（5.56mmや7.62mmなど）をそのまま持ち込むのではなく、整理された整数値として表現することで、UIの視認性と架空SFとしてのフレーバーを両立させている。

### 2.2 世界観内での物理的定義

- **「C（シー）」は銃腔・砲腔の内径（ボア径）を表す工業・軍事単位**である。
- 単位記号・呼称ともに**「C（シー）」**を用いる。
- 呼称例：
  - `6C弾`（ロク・シーだん）
  - `15C重機`（ジュウゴ・シーじゅうき）
  - `30C砲`（サンジュウ・シーほう）
  - `105C主砲`（ヒャクゴ・シーしゅほう）

### 2.3 「0捨1入」による工業標準化と「口径×長さC」表記

旧時代の「〇〇×△△mm」のような雑多な端数は廃止され、ボア径（内径）および薬莢長・弾薬全長はすべて**「0捨1入（端数は上位の整正ステップへ繰り上げ）」**によって統一規格化されている。

- **0捨1入（工業切り上げ規約）の意義**:
  - わずかでも基準寸法を超過した端数を切り捨てると、薬室閉鎖不良や異常腔圧を招く危険がある。
  - 冷戦終結期の標準化運動では、口径（ボア径）のみならず薬莢・弾薬長に対しても**「0捨1入」による整然としたステップ規格化**を断行し、工作機械の共通化とフロンティアでの安全・確実な再生産マージンを確立した。
- **基本表記フォーマット**:
  - **`口径 × 長さC`**（例：`30×180C`、`120×600C`）
  - 口径のみを総称・略称する場合は `30C`、`120C` のように表記する。
  - 電磁砲や大口径砲など弾薬長を固定しないものは単一口径 `15C`、`180C` として表す。

## 4. 弾薬バリエーションと推進技術（フロンティア工学）

「C」は口径および長さを表すため、技術レベル（フロンティア工業の世代）に応じて同一寸法内で弾薬の推進方式・構造が進化する。

```text
[第1世代: 従来型火薬推進] ──> [第2世代: 高密度ケースレス(CT)] ──> [第3世代: 電熱化学・電磁加速]
 (金属薬莢/現地リサイクル)       (無薬莢/軽量化/弾倉容量増)           (超高初速/貫徹力激増)
```

1. **ケースレス（無薬莢）/ テレスコープ弾（CT弾）**:
   - `6×50C-CT` や `30×180C-CT`。推進薬のブロック内に弾頭を埋め込んだ円筒弾薬。
   - 排莢口が不要になり、砂塵や異星環境の極限気候（硫黄ガス、極低温）に強く、装弾数が1.4倍に向上。
2. **電熱化学（ETC）装薬弾**:
   - `130×700C-ETC`。電気エネルギーで液体・プラズマ点火を行い、通常の化学火薬の限界初速を突破。
3. **電磁投射サブキャリバー弾（Rail/Coil Sabot）**:
   - 電磁加速砲から射出されるダーツ型徹甲弾。装甲貫徹に特化。
   - **単発発射向け運用特性**: 大容量コンデンサの充電サイクルとレール部の排熱冷却を要するため、機関砲のような高速連射ではなく**「単発発射（撃破確実な単発高打撃・長距離狙撃）」**として運用される。
   - **設置容積比率（火砲口径の約3倍相当の砲塔・車体容積）**:
     - 電磁砲は加速レール長・大容量コンデンサバンク・冷却機構を一体収容する必要があるため、**同口径の火砲に対して約3倍相当の砲塔・架台容積**を占有する。
     - **15C 電磁砲** ≒ **45C火砲相当**の砲塔規模（中口径機関砲マウント級）
     - **40C 電磁砲** ≒ **旧130Cライフル速射艦砲相当**の砲塔・甲板容積（フリゲート・駆逐艦主砲マウント級）
     - **180C 電磁砲** ≒ **540C火砲相当**の砲塔規模（超弩級要塞砲・巨大艦載砲塔級）

## 5. ゲームシステム・兵站との連動

### 5.1 サプライチェーン（生産消費）の簡素化

ゲーム内の弾薬リソースを無数に細分化してプレイヤーを煩雑にさせることを防ぎ、工業モジュール単位で**「小口径弾（6×50C / 8×60C）」「機関砲弾（13C〜50C）」「重砲・戦車砲弾（60C〜140C）」「超重砲・電磁砲弾（160C+ / 電磁特殊弾）」の弾薬サプライカテゴリ**に集約して管理する。

### 5.2 兵器モジュール共通化（Commonality）への寄与

- `concept_weapon_module_commonality.md` で規定された「共通性（Commonality）」と直結。
- 例えば、歩兵戦闘車（IFV）と対空自走砲が同じ `30×180C` 砲身モジュールを共有していれば、**「30C共通ライン」による弾薬・交換砲身の兵站ボーナス**が発生する。
- 口径（ボア径）が共通であれば、薬室・弾薬長が異なる場合でも**工作機械・砲身素材レベルの共通性ボーナス**を享受できる。
