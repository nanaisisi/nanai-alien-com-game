# 非ユニット輸送体系仕様書：非ユニット船舶海上輸送と徒歩部隊・車両輸送

(Non-Unit Transport Architecture: Sea Lift Logistics & Vehicle-Integrated Infantry Mobility)

本作（4X大戦略＋サブタイル戦術・戦闘団制）における**「個別の戦闘ユニット（コマ）としてマップを埋め尽くさない海上輸送（非ユニット船舶・シーリフト輸送船団・回廊）」**および**「徒歩・軽装歩兵戦闘団による非戦闘車両・牽引トレーラー輸送メカニクス」**を体系化した設計仕様書である。

---

## 1. 基本思想と問題意識

### 1.1 大戦略ゲームにおける「輸送ユニット」の2大破綻

従来のヘックス制4Xや大戦略ゲームでは、部隊輸送に関して以下の深刻なゲームデザイン上の破綻を抱えていた。

1. **輸送船コマの海面氾濫（シーレーンの過密とマイクロマネジメント地獄）**:
   - 歩兵を海を渡らせるたびに「輸送船ユニット」を個別に建造・操縦させるか、水域に入ると全ユニットが勝手に小舟化する。
   - 海上が輸送船のコマで埋まり、護衛艦隊の操作と輸送船の移動クリック作業だけでプレイヤーのターン時間が浪費される。
2. **「徒歩部隊」と「車両・トラック」の不自然な二元論**:
   - 歩兵部隊は永久に足で歩くか、高価な装甲戦闘車両（IFV/APC）を配備して機械化歩兵化するかの両極端になりがちである。
   - 現実の軍事における「非装甲の民間徴用トラック、牽引トレーラー、軽汎用車（UTV/ピックアップ）に分乗して道路を高速巡航し、戦闘直前に下車展開する」という**非ユニット的機動（Motorized / Truck-Borne Lift）**が再現されていない。

### 1.2 本作の解決方針：輸送インフラの「非ユニット化」と「格納・積載力学」

- **海上輸送の非ユニット化（Strategic Sea Lift）**:
  - 商船・輸送船団はマップ上の操作コマにせず、**港湾間をつなぐ「海上回廊（シーレーン）」および「国家/方面軍海上輸送船腹プール（Sea Lift Capacity）」**として抽象化。
  - 陸上ユニットは港湾から目的地港湾（または確保された揚陸海岸）を指定するだけで、船腹キャパシティを消費して自動的に海上回廊を航行・移送される。
- **徒歩部隊の車両輸送・牽引力学（Field Motorization & Trailer Logistics）**:
  - 徒歩部隊（軽歩兵・開拓団・工兵）が、工廠や兵站デポにある「非戦闘車両・トラック・重牽引台車（トレーラー）」を一時的に牽引・積載装備することで、道路・平地での行軍速度を飛躍的に向上させる。
  - 戦闘突入時や悪路・湿地進入時には車両が足かせになるリスク（下車戦闘ラグ、燃料消費、奇襲被弾時の脆弱性）を伴わせる。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                       【非ユニット輸送の全体アーキテクチャ】                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【海上輸送：非ユニット船舶シーリフト】                                      │
│    [出航港湾 A] ──(輸送船腹プール消費)──> [海上回廊・シーレーン] ──> [到着港 B]  │
│         │                                        │                          │
│         │ ユニットコマは海上に存在しない          │ 潜水艦・敵水上部隊による │

│                                                                             │

```

## 2. 非ユニット船舶による海上輸送（Strategic Sea Lift System）

### 2.1 輸送船腹プール（Sea Lift Capacity: SLC）

海洋を跨ぐ部隊輸送は、個別の輸送船を建造して動かすのではなく、国家または都市の**「海上輸送船腹プール（SLC）」**をリソースとして消費する。

1. **船腹ポイント（SLC Points）の算出**:
   - `SLC = 港湾レベル(Lv)の合計 × 係数 ＋ 商船団工廠割り当て ＋ 海運協定ボーナス`
   - 重工業・海洋重工（IND-6）により民間標準型貨物船（Standard Freighter）や揚陸ポンツーンを量産備蓄することで最大SLCが拡張される。
2. **部隊サイズごとの船腹消費コスト**:
   - 偵察戦闘団（軽車両）: **1 SLC**
   - 軽歩兵戦闘団（徒歩・小火器中心）: **2 SLC**
   - 開拓・工兵戦闘団（大型建機・物資）: **3 SLC**
   - 機械化・戦車戦闘団（重装甲・自走砲）: **5〜8 SLC**

### 2.2 海上輸送の実行シーケンス

1. **乗船（Embarkation）**:
   - 友軍または中立利用協定のある「港湾タイル」「沿岸要塞」「メガフロート都市」にユニットを進入させる。
   - UIの部隊アクションから**【海上転進（Sea Transit）】**を選択し、到達先の沿岸・港湾を指定。
   - ユニットはマップ上から消去され（`DeploymentStatus::Embarked`）、ステータスが「海上航行中」となる。
2. **航行（Transit Phase）**:
   - 毎ターン、海上回廊の距離（ヘックス数）と海流・天候に応じた巡航速度で自動進行。
   - マップ上には輸送船ユニットのコマは描画されず、**シーレーン航路上に「転進中インジケータ（部隊バッジ）」**のみが控えめに表示される。
3. **揚陸・上陸（Disembarkation）**:
   - **港湾への着岸**: ターン開始時に即座に揚陸完了。そのターンの残り移動力は半分になるが即時戦闘行動可能。
   - **未開拓海岸への強襲揚陸（Amphibious Assault）**: 港湾設備のない砂浜・浅海への揚陸は、追加の1ターン「展開遅延（Landing Delay）」を受け、敵の沿岸砲火・迎撃に対して脆弱な状態となる。

### 2.3 海上回廊の安全性と通商破壊（Interdiction & Escort）

輸送船ユニットをコマとして動かさない代わりに、**「哨戒艦隊」と「通商破壊」の抽象交戦モデル**を採用する。

```text
┌────────────────────────────────────────────────────────┐
│             【海上輸送回廊の危険度判定】               │
├────────────────────────────────────────────────────────┤
│  基本安全度: 100%                                      │
│   - 敵性潜水艦・襲撃艦の哨戒網進入: -30%〜-60%         │
│   - 深海巨大エイリアン生息域の通過: -20%               │
│   + 友軍駆逐艦・フリゲートによる護衛任務(Escort): +40% │
│   + 沿岸航空基地からの哨戒機カバー: +30%               │
└────────────────────────────────────────────────────────┘
```

- **被襲撃イベント**:
  - 安全度が低下した回廊を部隊が航行すると、ターン終了時に「船団被襲撃」イベントが発生。
  - 損害判定により、輸送中の部隊が**「HP損耗（20%〜50%）」「装備シャシーの喪失」「最悪の場合は全部隊水没壊滅」**の被害を受ける。
  - これにより、「空母や巡洋艦で航路の安全を確保してから陸上部隊を渡海させる」という海軍の存在意義が極めて自然に成立する。

## 3. 非自動車化部隊（徒歩部隊）による車両輸送・モーターライズ力学

### 3.1 概念：非自動車化部隊（Non-Motorized Units）の定義とジレンマ

本作における**「非自動車化部隊（Non-Motorized Units）」**とは、固有の動力車両（装甲兵員輸送車や歩兵戦闘車）を常備保有せず、基本編成が徒歩行軍・小火器・人力搬送に準拠した戦闘団（軽歩兵、開拓団、山岳猟兵、戦闘工兵、治安警備隊など）を指す。

- **非自動車化時の強み（足回りに縛られない柔軟性）**:
  - 密林、険峻な山岳、瓦礫都市、瘴気湿地など、車両が進入不可能な極限地形でも移動ペナルティを最小限に抑えて踏破可能。
  - 熱源・エンジン音・電波放射が存在しないため、敵性エイリアンや広域レーダー網に対する被発見率（シグネチャ）が極めて低い。
  - 燃料（エネルギー備蓄）や交換タイヤ・履帯などの補給消費がほぼゼロであり、兵站維持が容易。
- **非自動車化時の弱み（戦略機動力の欠如）**:
  - 平原や長大な舗装道路・幹線インフラ上であっても行軍速度が徒歩ペース（毎ターン1〜2マス）に縛られ、広大な異星大陸での機動戦・増援展開に追従できない。

### 3.2 補給トラック・非戦闘車両ストックの一時配備（モーターライズ化）

非自動車化部隊は、工廠・兵站デポ・都市に保管されている「汎用トラック（GUV: General Utility Truck）」や「全地形牽引トレーラー（All-Terrain Trailer）」を一時的に牽引・積載装備することで、恒久的な機械化部隊（IFV/APC保有部隊）に改編することなく、機動時のみ**【自動車化行軍モード（Motorized Transit）】**へ移行できる。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                 【徒歩部隊の車両化（モーターライズ）状態】                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  [通常状態: 徒歩行軍 (Foot March)]                                          │
│   - 移動力: 2                                                               │
│   - 道路ボーナス: なし（または軽微）                                        │
│   - 悪路（山岳・湿地）走破性: 高                                            │
│   - 防御準備完了状態（即時反撃可能）                                        │
│                                                                             │
│       ▲ 解除（下車） [D]                      ▼ 車両牽引・乗車 [M]          │
│       │ (1ターン展開ラグ / 移動力消費)        │ (トラック備蓄を1消費)       │
│                                                                             │
│  [車両行軍状態: トラック分乗 (Motorized Transit)]                           │
│   - 移動力: 4〜5（舗装路・幹線道路上では移動力消費 1/3）                    │
│   - 悪路走破性: 極めて低（山岳・密林進入不可またはスタック）                │
│   - 脆弱性: 奇襲・空爆を受けた場合、防御力 -50%（トラックごと炎上リスク）  │
│   - 燃料消費: 毎ターンエネルギー・燃料を微量消費                            │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.3 車両の「非ユニット化」と自動回収

- トラックやトレーラーは、マップ上の独立した戦闘コマではなく、**部隊の付属装備（モビリティ・モジュール）**として扱われる。
- 激戦地で部隊が下車展開して戦闘状態に入った場合、車両ストックは以下のいずれかの処理が行われる：
  1. **後方待機（Staged in Rear）**: 部隊がタイルを離れるまで後方に退避。戦闘終了後に再搭乗可能。
  2. **現地遺棄・損耗（Scuttled / Abandoned）**: 奇襲を受け退却した場合、トラックストックは破壊または中立残骸となる。
  3. **兵站線への自動返納**: 都市領内であれば、自動的に都市の兵站プールへ返却される。

### 4.1 海上輸送・転進コンポーネント

```rust
use bevy::prelude::*;
use crate::map::hex::HexCoord;
use crate::faction::types::FactionId;

/// 海上輸送航行中コンポーネント
#[derive(Component, Debug, Clone, Reflect)]
pub struct SeaTransitRoute {
    /// 出航地港湾座標

    pub capacity: u32,
    /// 現在使用中のSLC
    pub in_use: u32,
}
```

### 4.2 車両化・牽引モビリティコンポーネント

```rust
/// 徒歩部隊の機動移動形態
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Reflect, Default)]
pub enum MobilityDoctrine {
    /// 徒歩行軍（不整地適応・即時射撃体制）

pub struct UnitMobility {

    pub deployment_delay: u8,
    /// 牽引・搭乗中の車両種別ID
    pub attached_vehicle: Option<String>,
}
```

## 5. UI/UX設計方針

### 5.1 マップ上での表現

1. **シーレーン（航路）の可視化**:
   - 航行中の部隊は3Dモデルを表示せず、海上に淡いシアン色の破線（航路プロット）と、現在地を示す小さな「⚓マーク＋部隊アイコン」のビルボードのみを描画。
   - プレイヤーは海上が過密にならず、どこに向かっているかが直感的に把握可能。
2. **トラック搭乗状態のアイコン**:
   - ユニットの体力バー・種別バッジの横に「🚚（トラック牽引中）」ピクトグラムを表示。
   - 移動可能範囲マーカー（ゴールド/シアンサークル）が、道路に沿って大きく伸びる描画に変化。

### 5.2 操作インターフェース

- **港湾タイル選択時**:
  - パネルに「海上輸送待機部隊一覧」「港湾SLC使用率: 12 / 20」を表示。
- **部隊選択時**:
  - ショートカットキー `[Alt + M]`: 車両搭乗 / 下車展開の切り替え。
  - ショートカットキー `[Shift + S]`: 港湾滞在時に海上転進ターゲット指定モードへ突入。
