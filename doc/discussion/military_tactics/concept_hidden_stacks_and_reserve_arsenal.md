# ユニット非表示スタック・非配備兵器および艦艇格納仕様書

(Hidden Stacks, Undeployed Arsenals & Reserve Fleet Architecture)

本作（4X大戦略＋サブタイル戦術・戦闘団制）における**「大戦略マップ上でのユニット非表示スタック（格納・待機・予備役・輸送搭載）メカニクス」**、**「工廠・ドック・基地内に眠る非配備兵器・艦艇（予備役・戦略備蓄・モスボール・艤装待ちプール）」**、および**「戦場展開ラグ・維持コスト・再活性化動員力学」**を体系化した設計仕様書である。

---

## 1. 基本設計思想：マップの可読性とリアリズムの高度な両立

### 1.1 従来の4X・大戦略ゲームが抱える2大欠陥

1. **スタックの山と視覚的ノイズ（SoD: Stack of Doom / ユニット過密）**:
   - 1マスに十数個のユニットが重なり、旗やアイコンが重なって何が存在するのか一目で判別できない。
   - 毎ターン数十・数百の極小ユニットを個別クリックして動かす「作業地獄」が発生する。
2. **「生産完了＝即座に前線ユニット化」という非現実性**:
   - 工場で戦車や戦闘機が完成した瞬間、マップ上に巨大なコマとして現れ、維持費を食いながら前線へ自走・行軍を強いられる。
   - 保管所（デポ）に眠る予備兵器や、港湾でモスボール保管（休役）された艦艇、輸送艦・列車内に積載された部隊の概念が存在しない。

### 1.2 本作の解決アプローチ：「1タイル1アクティブ」＋「多層非表示スタック・予備プール」

本作では、大戦略マップ上の視覚的明瞭度（クリーンさ）を徹底するため、**「大戦略マップ上にアイコンとして自立表示されるのは、1タイルにつき【アクティブ哨戒部隊（Active Garrison）】の最大1ユニットのみ」**とする。
それ以外の部隊や兵器群は、すべて**親タイルのインフラや母艦・輸送機関、国家兵器庫（Arsenal）の「内部スタック（非表示）」**として格納・統合管理される。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                 大戦略マップ表示 ⇔ 内部非表示スタック構造                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【大戦略マップ視覚表示】                                                   │
│    └─ [親タイル]: 第3機械化戦闘団（アクティブ駐留：1個のみ表示）            │
│          │                                                                  │
│          ▼ (タイル詳細パネル / ドック / 工廠をクリック展開)                 │
│                                                                             │
│  【内部・非表示スタック (Hidden Stacks & Reserves)】                        │
│    ├─ ① 輸送・格納スタック (Embarked / Hangar Stacks)                      │
│    │    ├─ 地下シェルター・要塞格納庫内の待機小隊群                         │
│    │    ├─ 大型揚陸艦・空母の格納庫（ハンガー）内の艦載機・強襲部隊         │
│    │    └─ 幹線鉄道・重輸送トレーラーに積載された長距離移動部隊             │
│    │                                                                        │
│    ├─ ② 施設直結・戦略予備 (Base Reserve / Mothballed Fleet)               │
│    │    ├─ 都市・軍港に係留された【モスボール保管艦艇（休役艦）】           │
│    │    ├─ 航空基地の掩体壕に眠る【予備機プール】                           │
│    │    └─ 兵站デポに積載された【Gen 0 虎の子母星兵器ストック】             │
│    │                                                                        │
│    └─ ③ 国家工廠・兵装プール (National Arsenal & Materiel Stock)            │
│         ├─ 戦闘団に未配属の完成品シャシー・モジュール（装甲板、主砲）       │
│         ├─ 損耗補充用の交換エンジン・予備履帯・補修部品                     │
│         └─ 戦時即時動員待機（即応予備枠）                                   │
│                                                                             │

```

## 2. ユニット非表示スタック（Hidden Stack）の4大カテゴリ

大戦略マップ上で部隊が単独コマとして地表に露出せず、内部に格納されるケースは以下の4つに体系化される。

| カテゴリ | 格納先（ホスト） | マップ上の外観 | 主な状態・機能 |
| :--- | :--- | :--- | :--- |
| **① 搭載・輸送スタック (Embarked Stack)** | 大型揚陸艦、空母、重輸送列車、大型輸送機 | ホスト（母艦・輸送機関）のみがマップ上に表示 | 搭載中の部隊は移動力消費・索敵を行わず、母艦の移動に追従。母艦撃沈時は積載部隊も壊滅・大損耗の危機。 |
| **② 陣地・要塞掩蔽スタック (Bunker / Garrison Stack)** | 地下要塞、シェルター、防空ドーム (Tier 2〜4) | 親タイルの施設バッジ（数字アイコン）のみ表示 | 砲爆撃・軌道爆撃から完全防護。アクティブ部隊が損耗・撤退した際、次順の防衛線として自動出撃。 |
| **③ 港湾・ドック保管艦艇 (Mothballed Fleet)** | 軍港、海洋メガフロート、浮ドック | 軍港アイコンの右下に係留数「⚓ ×4」等を表示 | 動力炉停止・最低限の警備員のみで維持費を80%カット。実戦配備には「再活性化（整備・出渠ラグ）」を要する。 |
| **④ 工廠・デポ非配備兵器 (Depot Pool)** | 国家・方面軍工廠、兵站デポ | マップ上には一切現れず、兵站管理台帳にのみ集計 | 戦闘団のスロットが被弾・喪失した際の「自動補充源」、または新規戦闘団編成用の資材プール。 |

## 3. 非配備兵器・艦艇（Arsenal & Reserve Fleet）の運用力学

### 3.1 艦艇・大型兵器の「モスボール（保管役）」メカニクス

海洋艦艇（駆逐艦、巡洋艦、揚陸母艦、潜水艦）や超大型地上兵器は、平時に常時フル稼働・全開哨戒させると燃料・部品・人件費（食料）が国家財政を圧迫する。
そのため、プレイヤーはこれらを**「非配備（モスボール保管）」**として軍港・ドックに係留できる。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                 艦艇・大型兵器の配備ステータス遷移サイクル                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│      [国家工廠・造船ドック]                                                 │
│                │                                                            │
│                ├─ (即時配備: 高コスト) ───────────┐                         │
│                ▼                                  ▼                         │
│      【非配備・保管艦 (Mothballed)】     【現役配備艦 (Active Duty)】       │
│      ・維持コスト: 20% (防食・警備のみ)  ・維持コスト: 100% (燃料/弾薬/人件)│
│      ・索敵/迎撃: 不可 (港湾内に係留)    ・索敵/迎撃: 常時稼働              │
│      ・出撃準備: 2〜4ターンの出渠ラグ    ・移動: 即時機動可能               │
│                │                                  │                         │
│                │ ◄── [有事の再活性化 (Recommission)]                       │
│                └──── [平時の休役保管 (Decommission)] ───┘                   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

#### モスボール運用のルール

1. **維持費の激減**:
   - 燃料・弾薬消費は**ゼロ**。維持費（耐食コーティング・最低限の監視電力）は現役時の**15〜20%**に圧縮。
2. **再活性化ラグ（Recommissioning Lag）**:
   - 保管艦を現役戦闘艦隊へ復帰させるには、規模に応じて**1〜4大戦略ターン**の「ドック点検・注水・乗員慣熟」期間を要する。
   - 敵の急襲を受けた場合、保管中の艦艇は港湾内で「静止目標」となり、自衛砲火も撃てず撃沈されるリスクを負う。
3. **技術的陳腐化（Retrofit Pressure）**:
   - 保管期間中も技術開発は進むため、旧式化した保管艦を再配備する際は「近代化改修（Refit）」を行うか、そのままロートル艦として消耗前提で投入するかの選択を迫られる。

## 4. 輸送艦・母艦における「非表示スタック（搭載）」と戦術展開

### 4.1 搭載時の大戦略ルール

- **スタックの不可視化**:
  - 空母に3個飛行小隊、強襲揚陸艦に1個機甲戦闘団が搭載されている場合、大戦略マップ上には**「母艦のアイコン1個」**のみが表示され、艦艇バッジに「[✈3] [⛨1]」のような簡潔なピクトグラムが付与される。
- **兵站の一体化**:
  - 搭載中の部隊は独自の燃料を消費せず、母艦側の補給タンクから一括補給を受ける。

### 4.2 サブタイル戦術戦闘（343マス）への展開フロー

海沿いや洋上タイルで戦闘が発生した際、搭載スタックは以下のように戦術マップへ展開（実体化）する。

```text
【戦術マップ開始時 (サブターン 0)】
  - 洋上マスに母艦（強襲揚陸艦・空母）が配置される。
  - 格納庫内のユニットはマップ上には存在しない（非表示・展開待機）。

【サブターン 1〜3 (航空発進・舟艇発射)】
  - プレイヤーは母艦のコマンド「艦載機発進」「エアクッション艇（LCAC）発進」を実行。
  - 母艦の隣接サブタイルへ、格納されていた戦闘車両・ドローン・攻撃機が物理的に出現。
  - 海岸線へ向けて強襲上陸機動を開始する。
```

> **リスクとリターン**:
> 母艦が上陸前に敵の対艦ミサイルや沿岸砲撃で撃沈された場合、**内部に格納されていた非表示スタック部隊は全員が海中に没し、壊滅（全滅または重度損耗）**する。
> 「スタックして運ぶ便利さ」の裏には、常に「一網打尽の破滅的リスク」が伴う。

## 5. データ構造設計（Rust / Bevy ECS モデル）

Bevy ECS におけるユニットスタックと非配備兵装の実装アーキテクチャ。

```rust
use bevy::prelude::*;

/// ユニットの現在の配備・格納ステータス
#[derive(Component, Debug, Clone, PartialEq, Eq)]
pub enum DeploymentStatus {
    /// 地表アクティブ駐留 (大戦略マップに表示される主部隊: 1タイル最大1つ)
    ActiveGarrison,
    /// 地下要塞・シェルター待機 (非表示スタック: アクティブ部隊の予備)
    BunkerReserve { priority_order: u8 },
    /// 輸送艦・母艦・列車への積載中 (非表示スタック: ホスト追従)
    Embarked { carrier_entity: Entity },
    /// 港湾・基地でのモスボール休役保管 (非配備兵器: 出渠ラグあり)
    Mothballed { reactivation_turns_remaining: u8 },
    /// 工廠・デポ内の資材・予備役プール (実体ユニットではなく兵装ストック)
    DepotInventory,
}

/// 輸送母艦・格納施設コンポーネント (他のユニットを内部スタック可能)
#[derive(Component, Debug, Clone, Default)]
pub struct HangarBay {
    /// 最大積載スロット容量 (トン数または小隊数)
    pub capacity: u32,
    /// 現在内部に非表示格納されているユニットエンティティのリスト
    pub stored_units: Vec<Entity>,
}

/// 国家・方面軍工廠の非配備兵器・艦艇プール
#[derive(Resource, Debug, Clone, Default)]
pub struct NationalArsenalPool {
    /// 勢力識別子
    pub faction_id: String,
    /// 未配備・予備役の完成品車台ストック (シャシーID -> 保管数)
    pub chassis_stock: std::collections::HashMap<String, u32>,
    /// 未配備の兵装モジュールストック (モジュールID -> 保管数)
    pub weapon_module_stock: std::collections::HashMap<String, u32>,
    /// 母星遺産（Gen 0）の封印保管ストック
    pub legacy_gen0_sealed_units: Vec<String>,
}

/// 大戦略マップ上の表示切り替えシステム
pub fn update_unit_visibility_system(
    mut query: Query<(&DeploymentStatus, &mut Visibility)>,
) {
    for (status, mut visibility) in query.iter_mut() {
        match status {
            DeploymentStatus::ActiveGarrison => {
                // アクティブ部隊のみ地表に描画
                *visibility = Visibility::Inherited;
            }
            DeploymentStatus::BunkerReserve { .. }
            | DeploymentStatus::Embarked { .. }
            | DeploymentStatus::Mothballed { .. }
            | DeploymentStatus::DepotInventory => {
                // 内部スタック・非配備兵器はマップ描画を完全非表示
                *visibility = Visibility::Hidden;
            }
        }
    }
}
```

## 6. UI/UX表現：非表示スタックの明瞭な可視化

マップ上で非表示であっても、プレイヤーが「何がどこにどれだけあるか」を直感的に把握できるUIダッシュボードを提供する。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│  [南洋前進基地 - 親タイル #142] 基地管理パネル                                │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【地上・アクティブ防衛部隊】                                               │
│    [⛨] 第7沿岸警備戦闘団 (充足率: 98% / 弾薬: 良好 / 迎撃スタンバイ)        │
│                                                                             │
│  【地下要塞・格納スタック (Hidden Stacks: 2部隊待機中)】                    │
│    ├─ [1] 第12機械化歩兵大隊 (掩体退避中: 砲爆撃被弾率 0%)                  │
│    └─ [2] 方面軍即応予備戦車小隊 (防衛線突破時に自動カウンター)            │
│                                                                             │
│  【軍港・停泊ドック】                                                       │
│    ├─ [現役] 沿岸哨戒艇「シースパロー」 ── [海上哨戒中]                      │
│    └─ [休役] 重巡洋艦「オーシャン・ガード」 ── 【モスボール保管中】          │
│         ├─ 維持費: 8 / ターン (通常時: 45 / ターン)                         │
│         └─ [再配備 (Recommission) を発令] ── (所要: 2ターン)                 │
│                                                                             │
│  【基地弾薬庫・兵器デポ】                                                   │
│    ├─ 120C徹甲弾: 450発 / 25C機関砲弾: 1200発                              │
│    └─ 予備Std-W6装輪車台: 4台 / 予備FCSモジュール: 2基                      │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

1. **タイルバッジ・スタックカウンター**:
   - マップ上のタイル右下に、アクティブ部隊アイコンに添えて「`+2`（格納予備あり）」「`⚓1`（係留艦艇あり）」等の極小ピクトを表示。
   - プレイヤーはマップを引いた視点でも「この拠点の奥底に予備戦力が眠っているか」を一目で識別可能。
2. **ワンクリック展開・出渠**:
   - 基地パネルから「前線へ配置」「ドックから出撃」を押すだけで、アクティブ部隊枠への配置や再活性化プロセスが開始される。

## 7. まとめと他システムとの連携

- **[`../map_tile/concept_tile_progression_system.md`](../map_tile/concept_tile_progression_system.md) との連携**:
  - タイルの「1タイル1部隊」の原則を崩すことなく、要塞Tierの上昇（Tier 2前哨→Tier 4要塞中枢）に伴って地下格納スタックの許容量（Bunker Capacity）が拡張される。
- **[`../map_tile/concept_maritime_governance_and_ocean_engineering.md`](../map_tile/concept_maritime_governance_and_ocean_engineering.md) との連携**:
  - メガフロート都市や浮ドックにおける「モスボール艦隊」の維持・展開。荒天や深海エイリアン襲撃時に係留艦が受ける被災リスク。
- **[`./concept_frontier_industry_and_weapon_generations.md`](./concept_frontier_industry_and_weapon_generations.md) との連携**:
  - 母星から持ち込んだ虎の子の**「Gen 0 遺産兵器」**を、安易に前線で使い潰さず、デポ内に「非配備戦略備蓄」として封印温存するプレイスタイルを正当化・支援する。
