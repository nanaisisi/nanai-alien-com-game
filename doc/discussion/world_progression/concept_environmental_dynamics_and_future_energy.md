# 環境保護・生態系フィードバックと未来エネルギー・熱量管理仕様検討書 (Environmental Dynamics & Future Energy Engineering)

本ドキュメントは、異星フロンティア開拓における**「環境保護・熱量汚染と生態系フィードバック（ガイア・リアクション）」**、ならびに文明の発展を支える**「未来エネルギー（グリーン水素・核融合・海洋温度差発電・超伝導送電）のサプライチェーンと熱収支力学」**を定義する総合設計書である。

---

## 1. 基本理念と二項対立

人類による異星開拓は、「エネルギーの爆発的獲得と消費」なくして成立しない。しかし、異星の自然環境（大気・海洋・土壌・原生生物網）は無抵抗な資源の供給源ではなく、**排熱・化学汚染・生息域破壊に対して能動的かつ敵対的に反応する動的システム**である。

```text
 ┌─────────────────────────────────────────────────────────────┐
 │               エネルギー獲得と環境負荷の二項対立              │
 ├──────────────────────────────┬──────────────────────────────┤
 │  【エネルギー・工業推進】    │    【環境保護・持続性】      │
 │ ・重水素/ヘリウム3核融合      │ ・原生バイオーム・生態系の保全 │
 │ ・海水電解グリーン水素生産   │ ・熱汚染・温排水の厳格管理   │
 │ ・超巨大データセンター/兵器   │ ・大気・気候の自発的荒天抑止 │
 │ ➔ 高出力・高速発展・高排熱   │ ➔ 低反発・安定秩序・高コスト │
 └──────────────────────────────┴──────────────────────────────┘
                               │
                               ▼
 ┌─────────────────────────────────────────────────────────────┐
 │        【ガイア・リアクション（惑星生態系の反発）】          │
 │  ・排熱閾値超過 ➔ 局所スーパーセル（人工暴風雨）の自己生成   │
 │  ・温排水・化学汚染 ➔ 好熱性エイリアン・刺胞プランクトン暴走 │
 │  ・環境保護主義派閥（グリーン・ディシデント）の内乱・抗議    │
 └─────────────────────────────────────────────────────────────┘
```

## 2. 熱量管理力学（Thermal Budget & Dynamics）

すべてのタイル（陸上・海洋・地下）は、稼働する産業施設・兵器・エネルギー炉によって熱量を蓄積・放出する。

### 2.1 熱収支モデル (Thermal Balance)

各タイルの熱状態は、以下の熱収支方程式によってターン毎に更新される。

$$Q_{\text{accumulated}} = \sum Q_{\text{generation}} - \left( Q_{\text{natural\_dissipation}} + Q_{\text{active\_cooling}} \right)$$

* **$Q_{\text{generation}}$（総発熱量）**:
  * 核分裂炉 / 核融合炉の余剰熱
  * 重工業（IND-2製鉄・IND-6造船・重化学）の稼働排熱
  * 超伝導AI中枢・大出力レールガン充電・シールドジェネレーター
* **$Q_{\text{dissipation}}$（自然放熱能）**:
  * **海洋タイル**: 極めて巨大（海水の比熱・海流循環による吸熱）
  * **温帯・平野タイル**: 中程度（大気放散）
  * **ツンドラ・氷雪タイル**: 放熱効率大（ただし周囲の融解・泥濘化を誘発）
  * **砂漠・密閉地下タイル**: 放熱能が極めて低い（放熱限界による熱飽和ペナルティ大）
* **$Q_{\text{active}}$（能動冷却インフラ）**:
  * 冷却塔、海洋取水循環パイプ、ヒートシンクラジエーターアレイ（IND-2/IND-5部材を消費）

### 2.2 熱過負荷（Heat Overload）ペナルティ

放熱が追いつかず熱量がタイルの許容量を超過した場合、以下の段階的ペナルティが発生する。

| 蓄熱フェーズ | 状態名 | 発生ペナルティ・事象 |
| :--- | :--- | :--- |
| **Phase 1** | **熱飽和警告 (Thermal Saturation)** | 施設の稼働効率が低下（機器保護による自動出力セーブ：生産量 -20%）。 |
| **Phase 2** | **局所熱汚染 (Local Thermal Shock)** | 周辺原生生物の敵対度が上昇。好熱性害虫・菌糸の繁殖によるインフラ侵食。作業員の熱疲労。 |
| **Phase 3** | **人工気候撹乱 (Micro-Climate Anomaly)** | 強烈な上昇気流による**「局所スーパーセル（暴風雨・落雷・降雹）」**が常時発生。タイルの耐久値が毎ターン減耗。 |
| **Phase 4** | **熱暴走・メルトダウン危機 (Thermal Meltdown)** | 核融合炉・発電所モジュールの緊急自動停止（停電パニック）、または火災・爆発誘発。 |

## 3. 未来エネルギー体系（Future Energy Logistics）

文明が脱炭素・脱化石燃料を達成した未来における、クリーンエネルギーの生産・輸送・運用チェーン。

```text
【未来エネルギーの4大柱】

 ① 海水電解グリーン水素       ② 重水素/He-3核融合        ③ 海洋温度差発電 (OTEC)     ④ 超伝導地熱・深層地殻熱
 ┌──────────────────────┐  ┌──────────────────────┐  ┌──────────────────────┐  ┌──────────────────────┐
 │ 海水 ➔ 淡水化 ➔ 電解 │  │ 重水素抽出 ➔ 磁気閉込め│  │ 表層温水と深層冷水の │  │ 超深度掘削 ➔ 高温岩体│
 │ 液化水素 (LH2) 貯蔵  │  │ トカマク/レーザー点火 │  │ 温度差で熱電併給発電 │  │ スターリング/熱電変換│
 └──────────────────────┘  └──────────────────────┘  └──────────────────────┘  └──────────────────────┘
            │                         │                         │                         │
            └─────────────────────────┼─────────────────────────┴─────────────────────────┘
                                      ▼
                        【超伝導グリッド & パワーセル】
                         都市・重工業・軍事拠点への給電
```

### 3.1 海水電解グリーン水素システム (Green Hydrogen)

* **生産基盤**:
  * 主に**海洋メガフロート**や沿岸工業地帯に配置。洋上風力・太陽光・核融合の余剰電力を利用し、海水を淡水化・電気分解。
* **貯蔵と輸送**:
  * **極低温液化水素（LH2）**: 大容量タンクで保管され、長距離輸送船（LH2キャリア）やパイプラインで内陸へ輸送。
  * **水素吸蔵合金 / 有機ハイドライド**: 地上輸送用。IND-2特殊合金を消費して安全な常温輸送を実現。
* **リスクと管理**:
  * **ガス漏洩と爆発**: 被弾や整備不良時に壊滅的な爆発事故（広範囲サブタイル消滅）を引き起こす危険性。
  * **超高圧・極低温維持**: 冷却電力の途絶が即座に気化ベント・圧力上昇事故を招く。

### 3.2 海洋核融合発電 (Marine Nuclear Fusion)

* **燃料調達（重水素・Deuterium）**:
  * 海水中に無尽蔵に存在する重水素（D）を同位体分離プラントで濃縮。燃料枯渇の心配が事実上ゼロ。
* **立地優位性**:
  * 核融合炉は天文学的な中性子線発熱と熱負荷を伴うため、**「無尽蔵の冷却水（海水）に直接アクセスできる海洋・沿岸」**が最適立地となる。
* **ヘリウム3（He-3）の代替**:
  * 放射化が極めて少ない先進核融合（D-He3反応）。燃料は月面・小惑星採掘または大気採取船に依存するが、炉の寿命が伸び熱汚染が激減する。

### 3.3 海洋温度差発電（OTEC: Ocean Thermal Energy Conversion）

* **温排水のコジェネレーション（熱電併給）**:
  * 核融合炉や重工業から出る高温温排水と、深海から汲み上げた深層冷水（約4℃）の温度差を利用してアンモニア等の低沸点媒体を蒸発・発電。
* **環境負荷の相殺**:
  * 工業排熱を「電力」として回収しつつ、温排水の温度を下げて放流するため、**「熱汚染の防止」と「追加電力の獲得」を同時に達成する必須環境インフラ**。

### 3.4 全面電力化エコシステムとエネルギー兵站 (Electrification & Energy Logistics)

核融合と水素によって達成される「脱化石燃料・全面電力化」の運用と、入植地におけるエネルギー兵站の構造：

* **送電インフラ階層**:
  * **超伝導幹線グリッド**: 都市コア・工業団地・沿岸核融合炉を結ぶ送電網。送電損失はほぼゼロだが、送電線敷設にIND-1特殊合金（超伝導マテリアル）と地中埋設工事が必要。
  * **無線マイクロ波/レーザー給電**: 険しい山岳、孤立した前線監視ポストア、および滞空ドローンへ軌道・母基地から直接電力を照射。異星の電磁嵐や濃密雲霧による散乱・減衰ペナルティを受ける。
* **蓄電・可搬エネルギーキャリア（兵站の物理形態）**:
  * **超高密度全固体パワーセル / ナノチューブキャパシタ**: 機甲ビークル・歩哨ノードの標準動力。高密度だが、充電サイクルや異星極限温度でのセル寿命減耗（SOH低下）があり、現地ナノファブがなければ不可逆消耗品となる。
  * **交換式バッテリーコンテナ**: 前線基地や工事現場へ「充電済みコンテナ」を物理輸送する兵站トレイン。急速充電設備のない前線でも数分で車両の動力回復が可能。
  * **水素直接還元（DRI）製鉄・プラズマ熱プロセス**: 冶金・製造工程におけるコークス（石炭）廃止。核融合・OTEC電力と電解水素を直結した「全電化・ゼロカーボン重工コンビナート」を構成。

## 4. 環境保護・生態系フィードバック（Eco-Governance）

異星の生態系は、人類の介入度合いに応じて「環境負荷度（Eco-Stress）」を蓄積し、臨界点に達すると強烈な反発を引き起こす。

### 4.1 3大環境負荷インジケーター

各タイルおよび国家全体で以下の3指標が追跡される。

1. **熱汚染指数 (Thermal Pollution Index)**:
   * 海洋・河川への温排水放流、大気への高熱放射。
2. **化学・重金属汚染度 (Chemical/Toxic Load)**:
   * IND-1鉱山スラグ、IND-5セメント粉塵、ロケット推進薬燃焼残渣、プラスチック・重金属破片。
3. **生息域侵食度 (Habitat Disruption)**:
   * 埋め立て造成による沿岸生態系消失、原生林伐採、ソナー・低周波音による海洋生物回遊路の遮断。

### 4.2 ガイア・リアクション（惑星生態系の報復イベント）

環境負荷指数が一定値を超過したタイルまたは海域で発生する動的クライシス。

* **好熱性エイリアン・ブルーム（熱狂繁殖）**:
  * 高温海水に誘引された原生プランクトンや刺胞生物が爆発的に増殖。取水フィルターを瞬時に目詰まりさせ、都市のバラスト排水・冷却系を麻痺させる。
* **リヴァイアサン級の巣窟化・激突**:
  * 深海の巨大共鳴種が温排水口や強力な超伝導電磁ノイズを「敵対的侵入者」または「熱源餌場」と認識し、浮体や海底送電ケーブルに物理突進。
* **局所気候の崩壊（アシッド・テンペスト / 酸性過熱嵐）**:
  * 熱と大気汚染物質が結合し、強酸性の暴風雨が発生。屋外装甲やソーラーパネルを急速に腐食させ、露天配備の歩行兵器や航空機が行動不能に陥る。

### 4.3 環境統治アプローチのイデオロギー分岐

プレイヤー勢力は環境とエネルギーに対して以下のドクトリンを選択・調整する。

## 5. 産業・インフラとの相互作用

### 5.1 サプライチェーン連動

* **熱対策モジュールの需要**:
  * `IND-2: 特殊合金工廠` ➔ 超高熱伝導グラフェンヒートシンク、耐熱チタン複合管。
  * `IND-6: 造船・海洋重工` ➔ 深海冷水揚水管（ライザーパイプ）、OTEC発電モジュール。
  * `IND-5: 建材工廠` ➔ 断熱多孔質ジオポリマー、耐熱遮蔽壁。
* **グリーン水素・重水素の補給路**:
  * 海上プラットフォームで生産された液化水素・重水素は、**「特殊極低温タンカー」**または**「海底パイプライン」**を経由して内陸のロケット射場や重工業ハブへ供給される。この補給線の途絶は、直ちに国家全体の電力・宇宙輸送停止を引き起こす。
