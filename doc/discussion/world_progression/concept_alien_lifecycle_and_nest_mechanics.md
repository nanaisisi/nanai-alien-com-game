# エイリアン生態ライフサイクル・巣窟運用および環境インタラクション仕様書

(Alien Ecological Lifecycle, Nest Mechanics, and Biome Interactions)

本ドキュメントは、本作（4X大戦略＋サブタイル戦術・戦闘団制）における**「原住エイリアンの自律的生態系」「巣窟（Nest）のライフサイクルと繁殖・暴走」「瘴気（ミズマ）の動的変容」「人類勢力との軍事・生態兵站インタラクション」**を定義する詳細設計仕様書である。

---

## 1. 原生生物の基本設計思想

本作におけるエイリアン（原生生物）は、単なる「プレイヤーを邪魔する野良モンスター（Barbarian/Neutral）」ではない。
入植惑星の自然環境そのものであり、**「駆除・開発の障害」「生体資源の供給源」「他国に対する兵器・盾としての利用対象」**という重層的な存在として機能する。

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   エイリアン生態系の3大アプローチ                      │
└────────────────────────────────────────────────────────────────────────┘
  【Purity (純血・母星化)】
    ・完全駆除とミズマ浄化。母星環境への強制的テラフォーミング。
    ・巣窟の焼却・殲滅により人類本来の居住・工業サイトを確保。
        │
  【Harmony (調和・共生)】
    ・フェロモン共鳴による不可侵・共生。ミズマをバフ（遮蔽・再生）に転換。
    ・巣窟を破壊せず「共生採取ノード」とし、軍用生体兵器を直接使役。
        │
  【Supremacy (超越・自律)】
    ・生態データの徹底解剖と機械・サイバネティクスへの資材的利用。
    ・電磁インプラントや生体捕獲による機械的強制使役・キメラ改造。
```

## 2. 巣窟（Nest）のライフサイクルと状態推移

エイリアンの巣窟は、サブタイル上に物理的な核（ハブ構造）を持つ有機体アーキテクチャであり、以下の5つのフェーズを動的に遷移する。

```text
 [休眠期 (Dormant)] 
       │ (環境変化・近接刺激)
       ▼
 [活性期 (Active)] ◄───────┐
       │ (有機質・バイオ蓄積) │ (撃退・過剰採取)
       ▼                    │
 [繁殖・拡張期 (Spawning)] ─┘
       │ (臨界ストレス・フェロモン暴走)
       ▼
 [暴走・群れ大侵入 (Swarm Outbreak)]
       │ (寿命・大攻勢消耗)
       ▼
 [壊滅・枯渇 (Exhausted / Carcass)] ── (胞子残留・再生) ──► [休眠期]
```

### 2.1 各フェーズの詳細挙動

1. **休眠期 (Dormant)**:
   - 濃密なミズマの霧に包まれており、外見上は巨大な岩石・植物の塊に見える。
   - 人類部隊が近接サブタイルへ進入しない限り、外に出撃することはなく、周囲の探査難易度を跳ね上げるステルス特性を持つ。
2. **活性期 (Active)**:
   - 近隣での人類による採掘掘削、重工業プラントの熱・振動、または送電線（[`../map_tile/concept_tile_centric_expansion.md`](../map_tile/concept_tile_centric_expansion.md)）の電磁波を検知して覚醒。
   - 周囲数サブタイルに小型の偵察・採餌個体（ドローン型エイリアン）を放出し、哨戒を開始。
3. **繁殖・拡張期 (Spawning)**:
   - 巣窟内部のバイオ原質（[`../industry_logistics/concept_resource_economy_and_logistics.md`](../industry_logistics/concept_resource_economy_and_logistics.md)）が一定値に達すると、中型・大型の戦闘種を生成。
   - 一定期間放置されると、胞子ポッドを隣接タイルへ射出して「副巣（Satellite Nest）」を増殖させる。
4. **暴走・群れ大侵入 (Swarm Outbreak)**:
   - 大気汚染指数の急上昇、あるいは人類側の攻撃によって巣窟の「女王核（Brood Queen）」に一定以上のダメージが与えられた際、非常警報フェロモンが分泌される。
   - 周辺の全エイリアン部隊が統率された「大暴走集団（Swarm）」と化し、最も強い振動・汚染を発している人類の前哨基地・コンビナートへ向けて津波のように突撃する。
5. **壊滅・枯渇 (Exhausted / Carcass)**:
   - 巣窟の核が破壊されると、巨大な生体残骸（Carcass）と化す。
   - ここは**高品位バイオ原質・特異遺伝子サンプルの極めて優良な採掘スポット**となり、研究開発（Tech Web）の特許進展を劇的にブーストする。

## 3. 瘴気（ミズマ / Miasma）の動的変容と拡散システム

ミズマは単なる固定のマップエフェクトではなく、巣窟を発生源として大気循環・地形・人類活動によって動的に満ち引きする**流体的な環境要素**である。

```text
 発生源: 巣窟 (Nest) ── (風向・気流) ──► 低地・森林・水辺に滞留
    │                                         │
    ├─ 人類 (未適応): 腐食毒・装甲劣化・視界遮蔽 ◄┤
    ├─ 人類 (調和適応): ステルス被覆・自己修復ブースト
    └─ 人類 (環境改善): 浄化プラント・焼却砲による駆逐
```

### 3.1 ミズマの物理・戦術特性

- **視界・索敵阻害**:
  - ミズマ濃度が高いサブタイルでは、通常の光学レーダー・電子センサーの索敵範囲が50%以上減衰。
- **装甲・機構への腐食ダメージ**:
  - 非対応の通常戦闘団（Purity未完全、または密閉装甲モジュール未装備）がミズマ内に滞在・交戦した場合、毎ターン部隊の耐久度（HP）および兵器モジュールの稼働率に継続ダメージ（Attrition）。
- **地形への浸透**:
  - 河川や海洋沿岸部、湿地帯などの低地タイルへ重力に従って流れ込み、濃縮される。

### 3.2 人類側の対処と環境改変

1. **浄化スクラバー施設（Atmospheric Scrubber）**:
   - 工業タイルまたは前哨基地に建設。周囲タイルのミズマ濃度を毎ターン低減し、クリーンな居住可能地帯を維持。
2. **生体凝固・焼却弾（Thermal Pyrolysis Bombs）**:
   - 航空機モジュールや重砲戦闘団から投射。着弾サブタイルのミズマを一瞬で燃焼・消滅させ、数ターンの間ミズマの再流入を防ぐ。
3. **生体フィルター適応（Harmony Affinity）**:
   - 調和思想を進めた国家では、歩兵の人工エラ・生体サイバネ化、車両のキチン質外装により、**ミズマを逆に「自軍の姿を隠す煙幕」および「生体エネルギー補給源」として利用**可能となる。

## 4. 生態兵站と外交・軍事利用（武器としてのエイリアン）

プレイヤーはエイリアンを直接倒すだけでなく、その習性を利用して他国との戦争を優位に進めることができる。

```text
[自国・砲兵戦闘団] ── (長距離フェロモン弾投射) ──► [敵国 重工業タイル]
                                                        ▲
                                                        │ (フェロモン追尾)
                                            [大暴走エイリアン群 (Swarm)]
```

### 4.1 フェロモン誘導兵器（Pheromone Steering Shells）

- **メカニクス**:
  - 巣窟から採取した誘引フェロモンを弾頭に装填し、敵対国の重要インフラ（採掘コンビナート、発電所、あるいは敵戦闘団）へ長距離砲撃・投下。
- **効果**:
  - 周辺数タイルの休眠・活性エイリアンを興奮状態にし、被弾ターゲットへ殺到させる。
  - **自国の公式な部隊を直接侵入させずに敵のインフラを壊滅させる**、極めて強力なグレーゾーン工作・間接攻撃として機能する。

### 4.2 共生採取協定（Symbiotic Harvesting）

- **メカニクス**:
  - Harmony路線において、巣窟を完全破壊せず、周囲に「低周波共鳴タワー」を設営して巣窟と一定の共生距離を保つ。
- **恩恵とリスク**:
  - 巣窟から定期的に**高品位バイオ医薬品、自己増殖型装甲素材、特殊生体ポリマー**が自動搬出される。
  - しかし、他国からの刺激や環境激変で共鳴タワーが停電・機能停止した場合、直近の自国開拓都市が最初の捕食対象となる破滅的リスク（諸刃の剣）を背負う。

## 5. エイリアンのクラス分類と戦闘団における戦術対処

サブタイル戦闘において遭遇する主要なエイリアン種別と、推奨される戦闘団モジュール構成。

| クラス名 | 生態・行動パターン | 特徴・脅威度 | 推奨モジュール対策 |
| :--- | :--- | :--- | :--- |
| **スウォーム・ローチ (Scout/Lesser)** | 群生・超高速機動。数十〜数百の個体で歩兵や非装甲車両を取り囲む。 | 軽微（単体）〜中（群）。近接噛みつきによる機動輪・脚部損傷。 | 広角散弾砲、近接迎撃機関銃、火炎放射モジュール |
| **シザー・マンティス (Medium Striker)** | 硬質キチン装甲と巨大な鎌。ミズマ内から奇襲突撃。 | 高。中戦車の側面装甲を一撃で切り裂く。 | 高速徹甲弾（APFSDS）、履帯・多脚の全周防御スカート |
| **スピッター・ワーム (Artillery Biomorph)** | 地中に潜伏し、長距離から高酸性腐食液を曲射弾道で発射。 | 極高。インフラ施設や後方野戦病院・弾薬集積所を溶かす。 | 対砲兵レーダー、長距離精密誘導迫撃砲、航空阻止 |
| **コロッサス・リヴァイアサン (Titan)** | 山岳級の巨躯を持つ超大型個体。数ターンかけて大陸を回遊。 | 災害級。踏み潰されたサブタイルの施設・部隊は即座に壊滅。 | レールガン集中射撃、重多脚歩行要塞、またはフェロモン誘導による回避 |
